# multFastFunc.c 程式說明：函式化的移位乘法

`multFastFunc.c` 把快速乘法包成一個函式 `mul(a, b)`，主程式只負責呼叫它並印出結果。
演算法是標準的「俄羅斯農夫法 / 移位加法」：把 b 從最低位元開始看，b 的該位元是 1
就把目前倍數的 a 加進結果 r，然後 `b` 右移一位、`a` 左移一位，重複到 b 變成 0。
這是「乘法定義為一系列先加後移」的經典寫法，也是 `mult2/Mult.asm`（組合語言快速乘法）
的 C 語言藍本。

## 概述

- 角色：第 4 章快速乘法的函式版；示範「把演算法模組化成可重複呼叫的函式」。
- 介面：`int mul(int a, int b)` 回傳 `a × b`。
- `main` 呼叫 `mul(3,5)` 與 `mul(6,7)` 驗證。
- 與其他檔案的關係：
  - `mult.c`：重複加法（O(R0)）版本；
  - `multFast.c`：同為移位乘法但「預建遮罩陣列」；
  - `mult2/Mult.asm`：本程式演算法的 Hack 組合語言實作。

```c
int mul(int a, int b) {
  int r = 0;
  while (b > 0) {
    if (b % 2 == 1) {   // b 為奇數 = 最低位元為 1
      r += a;           // 該位元貢獻目前的 a
    }
    b = b >> 1;         // 檢查 b 的下一位
    a = a << 1;         // a 倍數乘 2，對齊下一位
  }
  return r;
}
```

## 原理：從 LSB 起的移位乘法

任意整數 `b = b0 + b1·2 + b2·4 + …`（bi ∈ {0,1}），所以

```
a × b = a·b0 + a·b1·2 + a·b2·4 + …
      = (該加就加，每圈把 a 的權重 ×2)
```

做法不從遮罩陣列下手，而讓 `a` 自己在每一圈 `a = a << 1`（權重 2^i）翻倍，`b`
每一圈 `b = b >> 1`（把下個位元移到最低位）。這樣檢查的一律是「b 現在的 LSB」，
也就是 `b % 2 == 1`。

追蹤 `mul(6,7)`（b=7=111b，a=6）：

| 圈 | b | 最低位元 | 動作 | r | 之後 |
|----|----|----|----|----|----|
| 1 | 7 | 1 | r+=6 | 6 | b=3, a=12 |
| 2 | 3 | 1 | r+=12 | 18 | b=1, a=24 |
| 3 | 1 | 1 | r+=24 | 42 | b=0, a=48 |

`r=42 = 6×7` 正確。`mul(3,5)`：b=5=101b，第 1 圈加 3、第 2 圈不動、第 3 圈加 12 → 15。

### 為什麼要從 LSB 開始？

右移 b 不會剪掉還未檢查的資料，且「b 右移 / a 左移」讓兩個值同步位移；若從 MSB
開始，則必須先算好 b 的位元長度（`multFast.c` 就是先建 15 個遮罩再倒著掃）。
LSB 法不需要知道長度，b 變 0 自然結束，程式最簡潔。

## 實作細節

- **`b % 2 == 1` ↔ `b & 1`**：兩者都測「第 0 位元」，組合語言只要 `D&A` 一行
  （`mult2/Mult.asm` 的 `@R0 D=M @R4 A=M D=D&A` 就是在測某一位元）。
- **`b >> 1` 與 `a << 1` 的組合語言對應**：Hack 沒有 shift 指令。實作時
  「除以 2」用「反覆減法」或用其他技巧較繁，但「乘以 2」只要 `M = D+M`
  （組合語言習慣用「自己加自己」當左移）。因全部乘數都是正的（`while(b>0)`），
  本函式不處理負數；若 b 為負，迴圈根本不進入、直接回傳 0。
- **函式呼叫**：Hack 組合語言沒有 `call` / `return`。真正的 Hack 版（見
  `組合語言的函數呼叫.md`）會用「把回報位址放進某暫存器（如 SP 或自訂），再
  `0;JMP` 到函式、函式算完再跳回」的方式模擬。Chapter 7/8 的 VM 才會出現完整
  的 call/return 堆疊框架。

## 與組合語言版（mult2/Mult.asm）的對照

`mult2/Mult.asm` 做的事與本函式相同，只是把 `b` 當成 `R0`、`a` 的倍數存在 RAM[3]
（MAND）、遮罩存在 RAM[4]（MASK）：每圈「若 `R0 & MASK ≠ 0` 就 R2 += MAND」，
然後 `MAND = MAND+MAND`、`MASK = MASK+MASK`。把兩份程式並排讀，就能看到 C 的
`if (b%2==1)`、`a<<=1`、`b>>=1` 三個動作各自的機械碼長相。

## 測試與驗證

```
$ cc multFastFunc.c -o multFastFunc && ./multFastFunc
mul(3,5)=15
mul(6,7)=42
```

## 延伸討論

- 複雜度 O(位元數)，16 位元數固定最多 16 圈，且**不需要儲存整個遮罩陣列**，
  記憶體成本最低，是三支乘法 C 程式中最好翻譯成組合語言的。
- `if (b % 2 == 1)` 這個條件也能寫 `r += b & 1 ? a : 0`；關鍵在於「加法要有條件」。
- 真實 CPU（ARM、x86）的 `MUL` 指令就是硬體化這種「移位-相加」電路，Chapter 2 的
  Hack ALU 沒有乘法器，所以組合語言層必須自己組出來。
