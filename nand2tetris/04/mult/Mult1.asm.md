# Mult1.asm 程式說明：用暫存變數 a 計數的乘法

`Mult1.asm` 是第 4 章乘法習題的另一個教學版本。與 `Mult.asm` 算的是同一件事
（`R2 = R0 × R1`），但改用「多宣告一個變數 `a`」來當迴圈計數器，避免把乘數 R0 用壞；
同時示範「先減 1、再加」的另一種迴圈寫法，以及**第一個自訂變數會被配置到 RAM[16]**
的規則。直接翻譯的組合語言為（把加法放在減法之後）：

```c
R2 = 0;
a = R0;            // 把 R0 複製到暫存變數 a
while (1) {
  if (a <= 0) break;   // 對應 @a D=M @EXIT D;JLE
  a = a - 1;           // 對應 @a M=M-1
  R2 = R2 + R1;        // 對應 @R1 D=M @R2 M=D+M
}
```

## 概述

- 角色：`Mult.asm` 的變體，強調「變數宣告/配置」與「迴圈計數器獨立於輸入」。
- 輸入：R0、R1；輸出：R2。
- 與 `Mult.asm` 的三個差別：
  1. 用符號 `@R0` `@R1` `@R2`，而不用數字 `@0` `@1` `@2`（兩者等價）。
  2. 多了一個變數 `a` 保存 R0 的副本，迴圈改數 `a`，原 R0 到最後仍然是 3。
  3. 迴圈內先 `a=a-1` 再做 `R2=R2+R1`（次序不同、結果相同）。

## 架構總覽：變數位址配置

| 符號 | 位址 | 說明 |
|------|------|------|
| `R0` | RAM[0] | 乘數（原封不動） |
| `R1` | RAM[1] | 被乘數 |
| `R2` | RAM[2] | 結果 |
| `a` | **RAM[16]** | 迴圈計數器，R0 的副本 |
| `(LOOP)` | 程式第 13 行 | 迴圈入口 |
| `(EXIT)` | 程式第 26 行 | 迴圈出口 |

`a` 被配到 **RAM[16]** 的原因：RAM[0..15] 全部被預定義符號（R0~R15、SP、LCL、ARG、
THIS、THAT）佔用，組合器遇到第一個還沒看過的符號時，就從 16 開始往上配置。所以
「第一個變數 = RAM[16]、第二個 = RAM[17]」是第 6 章組合器會嚴格執行的規則。

## 實作細節：逐段解說

```
// R2 = 0
@R2      // A = 2
M = 0    // RAM[2] = 0

// a = R0
@R0      // A = 0
D = M    // D = R0
@a       // A = 16
M = D    // RAM[16] = R0   ← 把乘數複製一份到 a

(LOOP)
// if (a <= 0) goto EXIT
@a       // A = 16
D = M    // D = a
@EXIT    // A = EXIT 的位址
D; JLE   // 若 a <= 0 就離開迴圈

// a = a - 1
@a
M = M-1  // RAM[16]-- ，目前 A 仍指向 RAM[16]

// R2 = R2 + R1
@R1      // A = 1
D = M    // D = R1
@R2      // A = 2
M = D+M  // RAM[2] = D + RAM[2]

// goto LOOP
@LOOP
0; JMP

(EXIT)
@EXIT
0; JMP   // 無窮迴圈結束程式
```

### 技巧重點

1. **複製暫存器內容**：`@R0 D=M @a M=D` 這三行是 Hack 的「暫存器搬移」
   `a = R0`（D 暫存器是唯一的搬運工：先 `D=M` 取出，再 `M=D` 存入）。
2. **減法的反向條件**：迴圈寫成 `while(1){ if(a<=0) break; ... }`，也就是
   「無限迴圈中，用反條件跳出去」，比 `while(a>0)` 更接近組合語言呈線性的寫法。
   `D;JLE`（D≤0 跳）正好等於 `if (a <= 0) goto EXIT`。
3. **`M=D+M` 的副作用**：第 23 行 `@R2 M = D+M` 使用上一行 `@R2` 留下的 A，
   因此 `M` 是 RAM[2]。這種「A 指向誰，M 就是誰」的間接定址是看 Hack 組合語言的
   第一道門檻。

## 執行追蹤（R0=3, R1=5）

| 迴圈次 | 進入時 a | 做完 `a-1` | 做 `R2=D+M` | 離開時 a | R2 |
|------|------|------|------|------|------|
| 1 | 3 | 2 | 0+5=5 | 2 | 5 |
| 2 | 2 | 1 | 5+5=10 | 1 | 10 |
| 3 | 1 | 0 | 10+5=15 | 0 | 15 |
| 4 | 0 | ── a≤0 → EXIT ── | ── | 0 | 15 |

`R2 = 15`，且注意原 R0 仍然是 3——計數器 `a` 保護了輸入。

## 測試與驗證

可沿用 `Mult.tst`（載入 `Mult1.hack` 後把檔名改成對應的 `.hack`）。重點檢查：

- RAM[2] 初始為 -1 時，程式確實先執行 `@R2 M=0` 把它歸零。
- 多組輸入（0×0、3×1、2×4、6×7）都比對 `Mult.cmp`。

## 延伸討論

- 本例在正式習題中並非必要（習題只要求 R2=R0×R1），它示範的是程式設計上的好習慣：
  **不要破壞輸入**。Chapter 6 的 Hack 組合器符號表正是用「變數從 RAM[16] 開始配置」的
  規則，讓你提前熟悉。
- 若把 `a=a-1` 移到 `R2=R2+R1` 後面，就成了 `Mult.asm` 的結構；兩者迴圈次數相同，
  但「先檢查再做事」vs「先做事再檢查」在 `while` 語意上是不同的，寫組合語言時必須
  自己判斷條件擺在哪。
