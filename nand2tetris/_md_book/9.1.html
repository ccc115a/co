9.1 Jack 語言語法簡介：物件導向與語法結構

學習目標

讀完本節後，你應該能：

  • 說明 Jack 語言在整個 Nand2Tetris 工具鏈中的定位
  • 列出 Jack 語言的完整語法結構（類別、方法、函式、建構子）
  • 使用 Jack 語言的五種基本型別（int、boolean、char、void、物件型別）
  • 撰寫包含陣列、陳述式、運算式的 Jack 程式
  • 區分 constructor、method、function 三種子程式的差異與用途
  • 撰寫一個完整的、可編譯執行的 Jack 最小類別

前言

從第 4 章的 Hack 機器語言，到第 7-8 章的虛擬機中間碼，我們一路「向下」理解了計算機系統的每一層翻譯。現在，是時候回頭「向上」了——用一種人類看得懂、但仍然足夠貼近底層的語言來寫程式。這就是 Jack 語言。

Jack 語言是 Nand2Tetris 課程專門設計的高階程式語言。它在語法上接近 C 與 Java 的交集，刻意砍掉了指標、繼承、泛型等複雜特性，只保留最核心的物件導向結構。這種「有控制的簡化」有兩個目的：

  1. 降低編譯器實作的門檻：第 10-11 章你要自己寫編譯器，Jack 的語法設計恰好讓「寫一個能用的編譯器」成為可能；
  2. 揭露高階語言的底層本質：當你用 Jack 寫出 var Array a;，背後的 VM 編譯器會把它翻成對 heap 的配置指令——你親眼看見「物件」被拆成「記憶體位址 + 偏移量」的過程。

本節帶你完整走一遍 Jack 語言的語法結構。不需要死背，因為接下來兩節你會用它來寫遊戲——學語法最快的方式是用它寫東西。

1. Jack 語言的定位：C/Java 的精簡子集

Jack 語言在整個 Nand2Tetris 工具鏈中的位置如下：

Jack 源碼 (.jack)
    │
    ▼ Jack Compiler（第 10-11 章實作）
VM 中間碼 (.vm)
    │
    ▼ VM Translator（第 7-8 章實作）
Hack 組合語言 (.asm)
    │
    ▼ Assembler（第 6 章實作）
Hack 機器碼 (.hack)
    │
    ▼ 載入到 Hack 電腦（第 5 章實作）
硬體執行

Jack 語言做了以下取捨：

特性 Jack 語言 C / Java 取捨原因
基本型別 int（16-bit）、char、boolean 8/16/32/64-bit 多種 Hack 只有 16-bit word
陣列 ✅ 一維 ✅ 多維 二維用物件模擬
物件導向 ✅ 類別、方法、欄位 ✅ 加上繼承、介面 砍掉繼承以簡化編譯器
字串 String 類別 內建型別 用陣列實作
指標 ❌ 不直接支援 ✅ 陣列 + 物件已可達成
遞迴 ✅ ✅ VM 呼叫堆疊天然支援
全域變數 ✅ static 變數 ✅
區域變數 ✅ var ✅ 對應 VM local 段

2. 程式結構：檔案即類別

Jack 程式的結構遵循「一個檔案 = 一個類別」的原則。每個 .jack 檔案包含一個類別的完整定義。

2.1 類別的骨架

class ClassName {

    // 欄位（field）宣告
    field int x;
    field int y;

    // 靜態變數（static）宣告
    static boolean initialized;

    // 建構子（constructor）
    constructor ClassName new(int ax, int ay) {
        let x = ax;
        let y = ay;
        return this;
    }

    // 方法（method）
    method void move(int dx, int dy) {
        let x = x + dx;
        let y = y + dy;
    }

    // 函式（function）—— 不與物件綁定
    function void printStatus() {
        Output.printString("position: ");
        Output.printInt(x);
    }
}

2.2 語法要素總覽

一個完整的 Jack 類別由以下元素組成：

class 宣告       →  class 類別名 {
變數宣告（零或多）  →  field / static + 型別 + 名稱;
子程式（零或多）   →  constructor / method / function + 回傳型別 + 名稱(參數列表) { 語句 }
                      }

語法规則：

  • 類別名稱、變數名稱、子程式名稱：必須以英文字母開頭，後接英文字母或數字，大小寫敏感
  • 註解：// 行註解（與 Hack 相同）
  • 語句以分號 ; 結尾
  • 大括號 {} 用於區隔程式區塊

3. 型別系統

3.1 基本型別

Jack 只有四種基本型別：

int x;          // 16-bit 有號整數，範圍 -32768 到 32767
char c;         // 字元（本質上是 16-bit 整數的 ASCII 碼）
boolean flag;   // 布林值，true 或 false（底層為 0 或 -1）
void v;         // 無回傳值（只用於函式/方法的回傳型別）

重點理解：在 Hack 硬體層，所有東西都是 16-bit 位元組。int、char、boolean 的差別只在語意層，底層完全相同。boolean 的 true 在 Hack 裡是 -1（全部位元設為 1），false 是 0。

3.2 物件型別（class as type）

除了基本型別之外，任何已定義的類別都可以當作型別使用：

// 假設已有一個 MyClass 類別
var MyClass obj;    // 宣告一個 MyClass 型別的變數
var Array arr;      // 宣告一個 Array 型別的變數

在底層，物件型別的變數實際上儲存的是一個記憶體位址（指向 heap 中的物件實體），這在 9.2 節會深入討論。

3.3 關鍵字與識別字

Jack 的保留字：

class  constructor  method  function
var    field   static   let
if     else    while    do
return true    false    null
this    void

4. 變數種類

Jack 有四種變數，分別對應到 VM 的四個記憶體段：

4.1 欄位（field）

物件導向的「成員變數」，每個物件實例各有一份。

class Point {
    field int x;   // 每個 Point 物件都有自己的 x
    field int y;   // 每個 Point 物件都有自己的 y
}
  • 底層對應：VM 的 this 段（物件的 heap 位址 + 偏移量）
  • 只能在 constructor 或 method 中存取（不能在 function 中）

4.2 靜態變數（static）

類別共用的變數，整個程式只有一份。

class Game {
    static int score;    // 所有 Game 操作共享同一個 score
    static int level;
}
  • 底層對應：VM 的 static 段（編譯器自動分配的全域位址）
  • 可在任何子程式中存取

4.3 局部變數（local）

在子程式內部宣告的變數。

function int add(int a, int b) {
    var int result;          // 局部變數
    let result = a + b;
    return result;
}
  • 底層對應：VM 的 local 段
  • 宣告語法：var 型別 名稱;（可一次宣告多個：var int x, y, z;）

4.4 參數（argument）

傳入子程式的參數。

method void moveTo(int newX, int newY) {   // newX, newY 是 argument
    let x = newX;
    let y = newY;
}
  • 底層對應：VM 的 argument 段
  • 宣告語法：在子程式參數列表中指定

5. 陳述式（Statements）

Jack 有五種陳述式：

5.1 let 敘述（賦值）

let x = 5;              // 基本賦值
let y = x + 3;          // 運算式賦值
let name = "hello";     // 字串賦值（字串是物件）

注意：Jack 強制使用 let 關鍵字來賦值（不同於 C/Java），這是為了語法解析的明確性。

5.2 if 敘述（條件分支）

if (x > 10) {
    // 當 x > 10 時執行
    let y = 1;
} else {
    // 否則執行
    let y = 0;
}

規則：條件必須包在小括號 () 中，執行區塊必須包在大括號 {} 中。else 是可選的。

5.3 while 敘述（迴圈）

var int i;
let i = 0;
while (i < 10) {
    // 迴圈體
    let i = i + 1;
}

5.4 do 敘述（方法呼叫）

do Screen.drawRectangle(10, 10, 50, 50);
do Output.printString("hello");

規則：呼叫「回傳 void 的方法或函式」時，必須用 do 開頭。呼叫有回傳值的函式時，不能用 do（用在運算式中）。

5.5 return 敘述

return;          // 回傳 void
return x + 1;    // 回傳值

5.6 let 敘述的特殊用法：陣列元素賦值

var Array arr;
let arr = Array.new(10);        // 建立長度 10 的陣列
let arr[0] = 42;                // 設定第一個元素
let arr[3] = arr[0] + arr[1];   // 用運算式索引

6. 運算式（Expressions）

Jack 的運算式遵循直覺的優先順序：

6.1 算術運算

let sum = a + b;
let diff = a - b;
let prod = a * b;
let quot = a / b;       // 整數除法
let rem  = a % b;       // 餘數（注意：Jack 規格中 % 不是標準運算符，請用 Math 模組）

6.2 邏輯運算

let result = (a > b) & (c < d);    // AND（位元運算）
let result = (a > b) | (c < d);    // OR（位元運算）
let result = ~flag;                 // NOT（位元取補）

重要：Jack 的邏輯運算使用位元運算符 &、|、~（而非 &&、||、!），這是刻意的設計——在 16-bit word 上，位元 AND/OR/NOT 和布林 AND/OR/NOT 是等價的。

6.3 比較運算

(a == b)     // 等於
(a != b)     // 不等於
(a < b)      // 小於
(a > b)      // 大於
(a <= b)     // 小於等於
(a >= b)     // 大於等於

6.4 運算優先順序

優先順序（高→低） 運算符 說明
1 () 括號
2 -（一元）、~ 一元負號、位元取補
2 *、/ 乘法、除法
3 +、- 加法、減法
4 &、\| 位元 AND、OR
5 ==、!=、<、>、<=、>= 比較

7. 函式、方法與建構子

這是 Jack 語言最關鍵的設計，三種子程式的差異決定了它們在底層如何被翻譯成 VM 碼。

7.1 constructor（建構子）

建立新物件、配置記憶體。

class Point {
    field int x;
    field int y;

    constructor Point new(int ax, int ay) {
        var Point p;
        let p = Point.new(ax, ay);
        let p.x = ax;
        let p.y = ay;
        return p;
    }
}

底層翻譯：

  1. 呼叫 Memory.alloc 配置物件大小的 heap 空間
  2. 把配到的位址當作 this
  3. 執行建構子本體
  4. 回傳 this（即新物件的位址）

7.2 method（方法）

物件導向的「成員函式」，自動擁有 this 參數。

class Point {
    field int x;
    field int y;

    method void move(int dx, int dy) {
        let x = x + dx;    // 直接存取 field（底層透過 this 偏移量）
        let y = y + dy;
    }
}

底層翻譯：

  1. 隱含一個第一參數 this（物件位址），由編譯器自動傳入
  2. 在方法內部，x 被翻譯為 this 段的第 0 個偏移，y 為第 1 個偏移

呼叫方式：

var Point p;
let p = Point.new(3, 4);    // 呼叫 constructor
do p.move(1, 2);            // 呼叫 method（p 自動成為 this）

7.3 function（靜態函式）

不與任何物件實例綁定的函式，類似 Java 的 static 方法或 C 的自由函式。

class Math {
    static int abs(int x) {
        if (x < 0) {
            return -x;
        }
        return x;
    }
}

底層翻譯：

  1. 沒有隱含的 this 參數
  2. 只能存取 static 變數和參數、局部變數
  3. 不能存取 field 變數（因為沒有物件實例）

7.4 三種子程式對比

特性 constructor method function
隱含 this 參數 ✅（新物件位址） ✅（呼叫者位址） ❌
可存取 field ✅ ✅ ❌
可存取 static ✅ ✅ ✅
可存取 argument/local ✅ ✅ ✅
需要 return this ✅（constructor） ❌ ❌
記憶體配置 Memory.alloc 不配置 不配置

8. 完整的 Jack 類別範例

下面給出一個完整的、可編譯的 Jack 程式。這個範例展示了所有語法元素：類別定義、三種子程式、field/static 變數、陣列操作、條件與迴圈。

8.1 Rectangle.jack —— 繪製矩形的類別

// Rectangle.jack
// 一個在螢幕上繪製矩形的類別

class ScreenTest {

    field int x;
    field int y;
    field int width;
    field int height;

    static int count;

    constructor ScreenTest new(int ax, int ay, int aw, int ah) {
        let x = ax;
        let y = ay;
        let width = aw;
        let height = ah;
        let count = count + 1;
        return this;
    }

    method void draw() {
        var int i;
        let i = 0;
        while (i < height) {
            do Screen.drawRectangle(x, y + i, x + width, y + i);
            let i = i + 1;
        }
    }

    method void moveDown(int step) {
        let y = y + step;
    }

    method int getX() {
        return x;
    }

    method int getY() {
        return y;
    }

    function int getCount() {
        return count;
    }
}

8.2 Main.jack —— 主程式入口

// Main.jack
// 程式進入點：建立矩形並繪製

class Main {

    function void main() {
        var ScreenTest rect;

        let rect = ScreenTest.new(20, 20, 80, 40);
        do rect.draw();

        let rect = ScreenTest.new(150, 100, 60, 60);
        do rect.draw();

        Output.printString("Created ");
        Output.printInt(ScreenTest.getCount());
        Output.printString(" rectangles.");

        return;
    }
}

8.3 編譯與執行流程

1. 編寫原始碼
   ScreenTest.jack + Main.jack

2. 編譯（使用第 10-11 章的 Jack Compiler）
   JackCompiler Main.jack
   → 產生 Main.vm, ScreenTest.vm

3. 載入 VM 模擬器執行
   VMEmulator → 載入 *.vm → 執行 → 螢幕上出現兩個矩形

9. 完整語法規則（EBNF 簡化版）

為了嚴謹起見，這裡列出 Jack 語言的完整語法規則。這也是你在第 10 章寫 parser 時的規格說明：

program         = class* ;
class           = 'class' className '{' classVarDec* subroutineDec* '}' ;
classVarDec     = ('field' | 'static') type varName (',' varName)* ';' ;
type            = 'int' | 'char' | 'boolean' | className ;
subroutineDec   = ('constructor' | 'function' | 'method')
                   subroutineName '(' parameterList ')'
                   subroutineBody ;
parameterList   = (type varName (',' type varName)*)? ;
subroutineBody  = '{' varDec* statements '}' ;
varDec          = 'var' type varName (',' varName)* ';' ;

className       = identifier ;
subroutineName  = identifier ;
varName         = identifier ;
identifier      = letter (letter | digit)* ;

statements      = statement* ;
statement       = letStatement | ifStatement | whileStatement |
                  doStatement | returnStatement ;
letStatement    = 'let' varName ('[' expression ']')? '=' expression ';' ;
ifStatement     = 'if' '(' expression ')' '{' statements '}'
                  ('else' '{' statements '}')? ;
whileStatement  = 'while' '(' expression ')' '{' statements '}' ;
doStatement     = 'do' subroutineCall ';' ;
returnStatement = 'return' expression? ';' ;

expression      = term (op term)* ;
term            = unaryOp term | '(' expression ')' |
                  integerConstant | stringConstant |
                  keywordConstant | varName |
                  varName '[' expression ']' | subroutineCall ;
subroutineCall  = subroutineName '(' expressionList ')' |
                  (className | varName) '.' subroutineName '(' expressionList ')' ;
expressionList  = (expression (',' expression)*)? ;
op              = '+' | '-' | '*' | '/' | '&' | '|' | '<' | '>' | '=' ;
unaryOp         = '-' | '~' ;
keywordConstant = 'true' | 'false' | 'null' | 'this' ;

本章小結

  • Jack 語言是 Nand2Tetris 專門設計的高階語言，語法接近 C/Java 的精簡子集。
  • 一個檔案 = 一個類別。類別內可包含 field（物件欄位）、static（共用變數）和三種子程式。
  • 三種子程式的差異是核心：constructor（建立物件）、method（物件操作，隱含 this）、function（靜態函式，無 this）。
  • Jack 只有四種基本型別（int、char、boolean、void），物件型別由類別定義。
  • 陣列是內建支援的，但只有一維——二維用物件模擬。
  • 陳述式有五種：let（賦值）、if（分支）、while（迴圈）、do（void 方法呼叫）、return（回傳）。
  • 運算式使用 &、|、~ 作為邏輯運算（位元等價），比較運算回傳 boolean。
  • 這些語法設計的每一個選擇，都在為第 10-11 章的編譯器實作降低難度——同時讓你親眼看到「高階語法結構如何被拆解為記憶體操作」。

在下一節 9.2 中，我們會把鏡頭拉近，看看物件、陣列在記憶體裡到底是什麼——你會發現，「物件」只是一段連續記憶體的位址，「陣列」也不過是指標語法糖。
