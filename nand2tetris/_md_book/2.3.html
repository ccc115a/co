2.3 邏輯與運算結合：設計 Hack ALU

到目前為止，我們有了加法器、增量器與各種邏輯閘。本節要把它們通通「收編」進一個萬能晶片——算術邏輯單元（Arithmetic Logic Unit, ALU）。ALU 是 CPU 的運算心臟：只要切換幾個控制位元，它就能執行加、減、與、或、非、取負等 18 種核心運算。

前言

前面我們分別建好了「算術」工作（加法）與「邏輯」工作（And、Or、Not）所需的電路。但真實的 CPU 不可能為每一種運算都準備一個獨立電路——那會太龐大、太浪費。設計者的目標是：用一顆晶片、透過幾個「控制位元」，就能在眾多運算之間自由切換。

這就是算術邏輯單元（ALU） 的誕生。它是組合邏輯（combinational）電路：給定輸入 x、y 與控制訊號，輸出端立刻呈現對應的運算結果，不需任何時鐘或暫存。

Nand2Tetris 中定義的 Hack ALU 是一顆極簡而優雅的機器：只用 6 個控制位元 zx, nx, zy, ny, f, no，就能編排出 18 種不同的運算。理解這 6 個控制位元的運作，等同於真正理解了一台電腦的「心臟」是如何運算的。

Hack ALU 的完整規格

介面定義

Hack ALU 的輸入與輸出如下：

六個控制位元功能速查

控制位元 名稱 功能
zx zero x zx = 1 時，把 x 強制歸零（x = 0）
nx negate x nx = 1 時，把（已處理的）x 取反
zy zero y zy = 1 時，把 y 強制歸零（y = 0）
ny negate y ny = 1 時，把（已處理的）y 取反
f function f = 0 時，輸出 x AND y；f = 1 時，輸出 x + y
no negate out no = 1 時，把最終結果取反

0 0 0 0 0 0 x&y
0 1 0 1 0 1 x|y

關鍵彙整

  • 常數：0、1、-1 都可經由「歸零 + 取反」組合出來。
  • x / y 本身：把它們都歸零後再還原，或直接傳遞。
  • 負數與自增/自減：-x、x-1、x+1 等，仰賴二補數與 no 方向取反。
  • 算術：x+y、x-y、y-x。
  • 邏輯：x&y、x|y。

小技巧：x-y 與 y-x 其實是「把減數先取反再加一」的體現，但 ALU 透過控制位元巧妙地組合出「取反」與「加一」，因此不需要另外多一個減法器。這與 2.2 節二補數的結論一脈相承。

ALU 的邏輯設計

我們可以將 ALU 的設計拆成清晰的幾個「子動作」，每一個動作都用一個 Nand2Tetris 的既有晶片完成：

子動作 1：歸零（zeroing）

用一個 16 位元 Mux16：當 zx = 1 時選擇 0；否則選擇 x 本身。

子動作 2：取反（negating）

用一個 16 位元 Not16 與另一個 Mux16：當 nx = 1 時輸出去反後的結果。

同理處理 y。

子動作 3：選擇 AND 或加法（f）

  • 用 And16 算出 xAfterNot AND yAfterNot。
  • 用 Add16 算出 xAfterNot + yAfterNot。
  • 用 Mux16 依 f 選擇其一：f = 0 選 AND，f = 1 選加法。

子動作 4：最終取反（no）

  • 用 Not16 與 Mux16 依 no 決定是否取反最終結果。

整個 ALU 使用的「積木」非常有限：Mux16、Not16、And16、Add16。這正是 Nand2Tetris 「只用手邊的材料」精神的極致體現。

逐步拆解一個運算實例

以 out = x - y（控制位元 zx=0, nx=1, zy=0, ny=0, f=1, no=1）為例，逐步追蹤：

  1. zx=0 → x 不被歸零；nx=1 → x 被取反為 ~x。
  2. zy=0 → y 不被歸零；ny=0 → y 保持原樣。
  3. f=1 → 計算 ~x + y。
  4. no=1 → 把結果取反成 ~(~x + y)。

設計思路與實作步驟

設計 Hack ALU 的整體步驟可歸納如下：

  1. 歸零輸入：用 zx, zy 配合 Mux16 將 x / y 可選擇地歸零，作為「產生 0、1、-1 等常數」的基礎。
  2. 取反輸入:用 nx, ny 配合 Not16 + Mux16 將 x / y 可選擇地取反，以支援 NOT、負數與減法。
  3. 核心運算：同時用 And16 與 Add16 預先算出兩種「主候選」結果。
  4. 選擇主函式：用 f 在 AND 與加法之間切換。
  5. 輸出取反：用 no 決定是否對整體結果取反，以展開「最後一哩」的組合空間。
  6. 產生標誌：輸出 zr（結果為零）與 ng（結果為負），供條件跳躍使用（2.4 節）。

這種「先盡量保留可能性，再用控制位元篩選」的設計哲學，讓一個小小的晶片能涵蓋高達 18 種運算，也讓控制位元的編排一目了然。

本章小結

  • ALU 是組合邏輯晶片，無須時鐘；結果由輸入與控制位元即刻決定。
  • 六個控制位元 zx, nx, zy, ny, f, no 依序完成「歸零、取反、選運算、取反輸出」四階段。
  • 18 種運算涵蓋常數、傳遞、邏輯（&、|、!）與算術（+、-、++、--）等核心能力。
  • ALU 僅使用 Mux16、Not16、And16、Add16 四種現成積木，體現模組化組合精神。
  • 大量運算（尤其減法與負數）的背後，全是二補數的巧妙應用。

目前我們的 ALU 還缺最後兩個輸出：zr（結果是否為零）與 ng（結果是否為負）。少了它們，CPU 無法判斷條件與執行跳躍。下一節我們將補齊這兩個標誌位，並討論如何在硬體模擬器上徹底驗證 ALU 的正確性。
