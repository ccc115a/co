# 第十章第二節：詞法分析（Lexical Analysis / Tokenizer）

## 前言

詞法分析是編譯器管線的第一步，也是最基礎的一步。它的任務看似簡單：**將一串原始碼字元轉換為一串有意義的記號（token）**。然而，這個「簡單」的步驟卻是整個編譯過程的基石——如果詞法分析器出錯，後面的所有分析都將建立在錯誤之上。

想像你在讀一句中文：「我今天去了動物園」。你的大腦會自動把字元組合成有意義的單元：「我」、「今天」、「去了」、「動物園」。詞法分析器做的事情與此類似——它掃描字元流，把連續的字元組合成一個個有意義的 token。

在本節中，我們將定義 Jack 語言的 token 類型，學習正規表示式的應用，並動手實作一個完整的 JackTokenizer。

---

## 10.2.1 Token 的分類

在 Jack 語言中，每一個 token 都屬於以下五種類型之一：

### 1. Keyword（關鍵字）

關鍵字是 Jack 語言預先保留的詞彙，具有特殊的語法意義。它們**不能**作為變數名或函式名。

Jack 的完整關鍵字清單（共 27 個）：

| 分類 | 關鍵字 |
|------|--------|
| **類別與結構** | `class`, `constructor`, `function`, `method`, `field`, `static` |
| **變數宣告** | `var` |
| **資料型態** | `int`, `char`, `boolean`, `void` |
| **語句** | `let`, `do`, `if`, `else`, `while`, `return` |
| **常值** | `true`, `false`, `null`, `this` |
| **運算** | `and`, `or`, `not` |

### 2. Symbol（符號）

符號是語法結構中的標點符號或運算符號。Jack 使用以下 20 個符號：

```
( ) [ ] . , ; + - * / & | < > = ~ { }
```

其中有些符號具有多重含義。例如 `<` 在 XML 輸出中需要被轉義為 `&lt;`，`>` 轉義為 `&gt;`，`"` 轉義為 `&quot;`，`&` 轉義為 `&amp;`。

### 3. IntegerConstant（整數常量）

Jack 的整數常量是 16 位元的帶號整數，範圍為 0 到 32767（非負整數）。它由一串連續的十進位數字組成。

合法的整數常量：
```
0, 42, 32767, 100, 255
```

### 4. StringConstant（字串常量）

字串常量是由雙引號 `"` 包圍的一串字元。字串中不包含雙引號本身，且雙引號不屬於字串內容的一部分。

合法的字串常量：
```
"Hello, World!", "Nand2Tetris", "a"
```

### 5. Identifier（識別碼）

識別碼是程式設計師自行命名的標識符，用於變數名、函式名、類別名等。Jack 的識別碼必須以英文字母或底線 `_` 開頭，後續可跟字母、數字或底線。

合法的識別碼：
```
x, myVar, _count, outputString, ScreenWidth
```

不合法的識別碼：
```
2ndValue    // 不能以數字開頭
class       // 這是關鍵字，不能當識別碼
my-var      // 不合法的字元 '-'
```

## 10.2.2 正規表示式與 Token

在形式語言理論中，每一種 token 類型可以用**正規表示式（Regular Expression）**來描述：

```
keyword      = "class" | "constructor" | "function" | "method" | "field" |
               "static" | "var" | "int" | "char" | "boolean" | "void" |
               "let" | "do" | "if" | "else" | "while" | "return" |
               "true" | "false" | "null" | "this" | "and" | "or" | "not"

symbol       = "{" | "}" | "(" | ")" | "[" | "]" | "." | "," | ";" |
               "+" | "-" | "*" | "/" | "&" | "|" | "<" | ">" | "=" | "~"

integerConstant = [0-9]+

stringConstant  = '"' [^"]* '"'

identifier    = [a-zA-Z_][a-zA-Z0-9_]*
```

詞法分析器的工作，就是按照這些規則，從左到右掃描字元流，每次匹配最長的合法 token。

---

## 10.2.3 無視空白與註解

詞法分析器必須在掃描時自動跳過以下內容：

### 空白字元
- 空格（space, ` `）
- 製表符（tab, `\t`）
- 換行符（newline, `\n`）
- 回車符（carriage return, `\r`）

### Jack 的註解格式

Jack 支援兩種註解：

1. **單行註解**：以 `//` 開頭，直到行尾
   ```
   // 這是一行註解
   var int x; // 這也是註解
   ```

2. **多行註解**：以 `/*` 開頭，以 `*/` 結尾（可跨越多行）
   ```
   /* 這是
      多行
      註解 */
   ```

**注意**：Jack 語言**不支援**巢狀的多行註解。也就是說，`/* ... /* ... */ ... */` 中第二個 `*/` 會被視為註解的結束，而非巢狀結構。

## 10.2.4 JackTokenizer 的介面設計

我們的 JackTokenizer 類別需要提供以下介面：

```python
class JackTokenizer:
    """將 Jack 原始碼的字元流轉換為 token 流。"""

    def __init__(self, input_file: str) -> None:
        """開啟輸入檔案並預讀第一個 token。"""

    def has_more_tokens(self) -> bool:
        """是否還有尚未處理的 token？"""

    def advance(self) -> None:
        """讀取下一個 token，並更新 token 型別與值。"""

    def token_type(self) -> str:
        """回傳目前 token 的型別（KEYWORD, SYMBOL, IDENTIFIER,
           INT_CONST, STRING_CONST, EOF 之一）。"""

    def keyword(self) -> str:
        """回傳目前 token 的關鍵字（僅在 token_type() == KEYWORD 時有效）。"""

    def symbol(self) -> str:
        """回傳目前 token 的符號（僅在 token_type() == SYMBOL 時有效）。"""

    def identifier(self) -> str:
        """回傳目前 token 的識別碼（僅在 token_type() == IDENTIFIER 時有效）。"""

    def int_val(self) -> int:
        """回傳目前 token 的整數值（僅在 token_type() == INT_CONST 時有效）。"""

    def string_val(self) -> str:
        """回傳目前 token 的字串值（僅在 token_type() == STRING_CONST 時有效）。"""
```

## 10.2.5 完整的 JackTokenizer 實作（Python）

以下是完整的 Python 實作：

```python
import re
import sys
import os

# Token 型別常數
KEYWORD = "KEYWORD"
SYMBOL = "SYMBOL"
IDENTIFIER = "IDENTIFIER"
INT_CONST = "INT_CONST"
STRING_CONST = "STRING_CONST"
EOF = "EOF"

# Jack 關鍵字集合
KEYWORDS = {
    "class", "constructor", "function", "method",
    "field", "static", "var", "int", "char", "boolean",
    "void", "true", "false", "null", "this",
    "let", "do", "if", "else", "while", "return",
    "and", "or", "not"
}

# Jack 符號集合
SYMBOLS = set('{}()[.,;+-*/&|<>=~')

# XML 轉義對照表
XML_ESCAPE = {
    "<": "&lt;",
    ">": "&gt;",
    "&": "&amp;",
    '"': "&quot;"
}


class JackTokenizer:
    """將 Jack 原始碼的字元流轉換為 token 流。"""

    def __init__(self, input_file: str) -> None:
        with open(input_file, "r", encoding="utf-8") as f:
            self.source = f.read()
        self.pos = 0          # 目前掃描位置
        self.current_token = ""
        self.current_type = EOF
        self._skip_whitespace_and_comments()

    def _current_char(self) -> str:
        """回傳目前位置的字元，超出範圍則回傳空字串。"""
        if self.pos < len(self.source):
            return self.source[self.pos]
        return ""

    def _peek_char(self, offset: int = 1) -> str:
        """向前看 offset 個字元。"""
        idx = self.pos + offset
        if idx < len(self.source):
            return self.source[idx]
        return ""

    def _skip_whitespace_and_comments(self) -> None:
        """跳過所有空白字元與註解。"""
        while self.pos < len(self.source):
            ch = self.source[self.pos]

            # 跳過空白字元
            if ch in " \t\n\r":
                self.pos += 1
                continue

            # 處理單行註解
            if ch == "/" and self._peek_char() == "/":
                self.pos += 2
                # 跳過直到行尾
                while self.pos < len(self.source) and self.source[self.pos] != "\n":
                    self.pos += 1
                continue

            # 處理多行註解
            if ch == "/" and self._peek_char() == "*":
                self.pos += 2
                # 跳過直到找到 */
                while self.pos < len(self.source):
                    if self.source[self.pos] == "*" and self._peek_char() == "/":
                        self.pos += 2
                        break
                    self.pos += 1
                continue

            # 不是空白也不是註解，停止跳過
            break

    def has_more_tokens(self) -> bool:
        """判斷是否還有未處理的 token。"""
        self._skip_whitespace_and_comments()
        return self.pos < len(self.source)

    def advance(self) -> None:
        """讀取下一個 token。"""
        self._skip_whitespace_and_comments()

        if self.pos >= len(self.source):
            self.current_type = EOF
            self.current_token = ""
            return

        ch = self.source[self.pos]

        # --- 字串常量 ---
        if ch == '"':
            self.current_type = STRING_CONST
            self.pos += 1  # 跳過開頭的 "
            start = self.pos
            while self.pos < len(self.source) and self.source[self.pos] != '"':
                self.pos += 1
            self.current_token = self.source[start:self.pos]
            self.pos += 1  # 跳過結尾的 "
            return

        # --- 整數常量 ---
        if ch.isdigit():
            self.current_type = INT_CONST
            start = self.pos
            while self.pos < len(self.source) and self.source[self.pos].isdigit():
                self.pos += 1
            self.current_token = self.source[start:self.pos]
            return

        # --- 符號 ---
        if ch in SYMBOLS:
            self.current_type = SYMBOL
            self.current_token = ch
            self.pos += 1
            return

        # --- 識別碼或關鍵字 ---
        if ch.isalpha() or ch == "_":
            start = self.pos
            while self.pos < len(self.source) and (
                self.source[self.pos].isalnum() or self.source[self.pos] == "_"
            ):
                self.pos += 1
            word = self.source[start:self.pos]
            if word in KEYWORDS:
                self.current_type = KEYWORD
            else:
                self.current_type = IDENTIFIER
            self.current_token = word
            return

        # 未預期的字元
        raise SyntaxError(f"Unexpected character: '{ch}' at position {self.pos}")

    def token_type(self) -> str:
        """回傳目前 token 的型別。"""
        return self.current_type

    def keyword(self) -> str:
        """回傳關鍵字值。"""
        return self.current_token

    def symbol(self) -> str:
        """回傳符號值。"""
        return self.current_token

    def identifier(self) -> str:
        """回傳識別碼值。"""
        return self.current_token

    def int_val(self) -> int:
        """回傳整數值。"""
        return int(self.current_token)

    def string_val(self) -> str:
        """回傳字串值。"""
        return self.current_token

    def token_to_xml(self) -> str:
        """將目前 token 轉為 XML 格式的字串。"""
        type_map = {
            KEYWORD: "keyword",
            SYMBOL: "symbol",
            IDENTIFIER: "identifier",
            INT_CONST: "integerConstant",
            STRING_CONST: "stringConstant"
        }
        xml_type = type_map.get(self.current_type, "unknown")
        value = self.current_token
        # 對 XML 特殊字元進行轉義
        escaped = XML_ESCAPE.get(value, value)
        return f"<{xml_type}> {escaped} </{xml_type}>"


def tokenize_file(input_path: str) -> None:
    """對一個 .jack 檔案執行詞法分析，輸出 XxxT.xml。"""
    tokenizer = JackTokenizer(input_path)
    base = os.path.splitext(input_path)[0]
    output_path = base + "T.xml"

    with open(output_path, "w", encoding="utf-8") as out:
        out.write("<tokens>\n")
        while tokenizer.has_more_tokens():
            tokenizer.advance()
            if tokenizer.token_type() == EOF:
                break
            out.write("  " + tokenizer.token_to_xml() + "\n")
        out.write("</tokens>\n")

    print(f"Tokenized: {input_path} -> {output_path}")


if __name__ == "__main__":
    if len(sys.argv) < 2:
        print("Usage: python JackTokenizer.py <file.jack>")
        sys.exit(1)
    tokenize_file(sys.argv[1])
```

## 10.2.6 設計思路與實作步驟

### 步驟一：讀取並清除

首先將整個 `.jack` 檔案讀取為一個字串。使用位置指標 `pos` 從左到右掃描，並在掃描過程中自動跳過空白與註解。

### 步驟二：識別 Token 類型

按照以下優先順序判斷 token 類型：

1. **空白/註解** → 跳過
2. **`"`** → 字串常量
3. **數字** → 整數常量
4. **符號字元** → 符號
5. **字母或底線** → 先讀取完整單字，再判斷是否為關鍵字

### 步驟三：預先讀取（Lookahead）

詞法分析器通常需要「向前看」一個字元來判斷 token 的邊界。例如，遇到 `/` 時，需要查看下一個字元：
- 如果下一個是 `/` → 這是單行註解的開頭
- 如果下一個是 `*` → 這是多行註解的開頭
- 否則 → 這是除法運算符號

### 步驟四：XML 轉義

由於我們要將 token 輸出為 XML 格式，必須處理 XML 的保留字元。在 XML 中，以下字元具有特殊意義：

| 字元 | XML 轉義 | 常見場景 |
|------|----------|---------|
| `<` | `&lt;` | 小於運算符 |
| `>` | `&gt;` | 大於運算符 |
| `&` | `&amp;` | 邏輯且運算符 |
| `"` | `&quot;` | 字串常量 |

## 10.2.7 執行範例

假設我們有以下 Jack 原始碼 `Main.jack`：

```jack
// This file is part of the materials supplied with Nand2Tetris.
class Main {
    function void main() {
        var int x;
        let x = 3;
        do Output.printString("Hello");
        return;
    }
}
```

執行 tokenizer 後，產生的 `MainT.xml` 輸出如下：

```xml
<tokens>
  <keyword> class </keyword>
  <identifier> Main </identifier>
  <symbol> { </symbol>
  <keyword> function </keyword>
  <keyword> void </keyword>
  <identifier> main </identifier>
  <symbol> ( </symbol>
  <symbol> ) </symbol>
  <symbol> { </symbol>
  <keyword> var </keyword>
  <keyword> int </keyword>
  <identifier> x </identifier>
  <symbol> ; </symbol>
  <keyword> let </keyword>
  <identifier> x </identifier>
  <symbol> = </symbol>
  <integerConstant> 3 </integerConstant>
  <symbol> ; </symbol>
  <keyword> do </keyword>
  <identifier> Output </identifier>
  <symbol> . </symbol>
  <identifier> printString </identifier>
  <symbol> ( </symbol>
  <stringConstant> Hello </stringConstant>
  <symbol> ) </symbol>
  <symbol> ; </symbol>
  <keyword> return </keyword>
  <symbol> ; </symbol>
  <symbol> } </symbol>
  <symbol> } </symbol>
</tokens>
```

你會注意到：
- 註解 `// This file is part of...` 已被完全移除
- 空白被忽略，只保留有意義的 token
- `"Hello"` 被識別為字串常量（不含引號）
- `{` 和 `}` 分別作為獨立的符號 token

## 10.2.8 常見陷阱與除錯技巧

### 陷阱一：多行註解中的 `/`

```jack
/* 注解中有除法運算： 10 / 2 */
```

正確的實作會正確處理這種情況，因為 `/*` 開頭後，一切都視為註解直到 `*/`。

### 陷阱二： `<` 和 `>` 的 XML 轉義

如果你忘記轉義 `<` 為 `&lt;`，輸出的 XML 將無法被正確解析，因為 `<` 會被視為 XML 標籤的開頭。

### 陷阱三：字串中的空格

```
"Hello World"
```

`"Hello World"` 應該被識別為一個完整的字串常量 token，而不是兩個單獨的 token。 tokenizer 需要正確處理引號內的內容。

### 陷阱四：數字後接識別碼

```
2ndValue
```

在 Jack 中這是不合法的（不以數字開頭的識別碼），但 tokenizer 可能會將 `2` 識別為整數常量，將 `ndValue` 識別為識別碼。這是符合 tokenizer 行為的——語法檢查應該由後續的 parser 負責。

## 本章小結

本節深入探討了詞法分析器的原理與實作：

- **Token 分類**：Jack 語言有 5 種 token 類型——keyword、symbol、integerConstant、stringConstant、identifier。
- **正規表示式**：每種 token 都可以用正規表示式來描述其格式。
- **空白與註解**：tokenizer 必須自動跳過空白和兩種格式的註解（`//` 與 `/* ... */`）。
- **XML 轉義**：輸出 XML 時必須處理 `<`、`>`、`&`、`"` 四個特殊字元。
- **實作策略**：使用位置指標逐字掃描，根據字元類型分支判斷 token 型別，一次性讀取整個檔案到記憶體以簡化實作。
