# 第十章第三節：語法分析（Parsing / Context-Free Grammar）

## 前言

詞法分析器（Tokenizer）已經將原始碼字元流轉換為 token 流，但這些 token 目前還只是一條扁平的序列。語法分析器（Parser）的任務是**理解這些 token 之間的結構關係**——哪些 token 屬於同一個語句？哪些語句屬於同一個函式？函式又如何嵌套在類別之中？

語法分析是編譯器中最「智慧」的階段。它需要根據語言的文法規則（Grammar），判斷 token 序列是否構成合法的程式結構，並將其組織成一棵語法樹（Parse Tree）。

在本節中，我們將學習上下文無關文法（Context-Free Grammar, CFG）的基礎概念，完整定義 Jack 語言的文法，並使用遞迴下降法（Recursive Descent）實作一個解析器。

---

## 10.3.1 上下文無關文法（Context-Free Grammar）

### 文法是什麼？

一個**上下文無關文法**由四個部分組成：

```
G = (V, Σ, R, S)
```

- **V**：非終端符號集合（Variables / Non-terminals），代表語法結構
- **Σ**：終端符號集合（Terminals），代表語言的基本詞彙（即 token）
- **R**：產生式規則集合（Production Rules），定義非終端符號如何展開
- **S**：起始符號（Start Symbol），代表整個程式的結構

### 產生式規則的寫法

產生式規則的格式為：

```
非終端符號 → 候選式1 | 候選式2 | 候選式3
```

例如，一個簡單的算術表達式文法：

```
expr   → term (('+' | '-') term)*
term   → factor (('*' | '/') factor)*
factor → integerConstant | '(' expr ')'
```

這個文法表示：一個表達式（expr）由一個或多個項（term）組成，項之間用 `+` 或 `-` 連接；每個項由一個或多個因子（factor）組成，因子之間用 `*` 或 `/` 連接；每個因子可以是整數常量或括號包圍的子表達式。

### 遞迴性

上下文無關文法的核心特徵是**遞迴性**——非終端符號可以出現在自己的產生式規則的右側。例如上面的 `factor → '(' expr ')'` 中，`expr` 透過 `term` 和 `factor` 間接引用了自己。這種遞迴性使文法能夠描述任意深度的嵌套結構。

## 10.3.2 Jack 語言的完整文法

以下是 nand2tetris 中 Jack 語言的完整文法規則。這些規則精確地定義了什麼是合法的 Jack 程式。

### 程式結構

```ebnf
class            → 'class' className '{' classVarDec* subroutineDec* '}'
classVarDec      → ('static' | 'field') type varName (',' varName)* ';'
type             → 'int' | 'char' | 'boolean' | className
subroutineDec    → ('constructor' | 'function' | 'method') ('void' | type)
                   subroutineName '(' parameterList ')' subroutineBody
parameterList    → (type varName (',' type varName)*)?
subroutineBody   → '{' varDec* statements '}'
varDec           → 'var' type varName (',' varName)* ';'
className        → identifier
subroutineName   → identifier
varName          → identifier
```

### 語句

```ebnf
statements       → statement*
statement        → letStatement | ifStatement | whileStatement |
                   doStatement | returnStatement
letStatement     → 'let' varName ('[' expression ']')? '=' expression ';'
ifStatement      → 'if' '(' expression ')' '{' statements '}'
                   ('else' '{' statements '}')?
whileStatement   → 'while' '(' expression ')' '{' statements '}'
doStatement      → 'do' subroutineCall ';'
returnStatement  → 'return' expression? ';'
```

### 表達式

```ebnf
expression       → term (op term)*
term             → unaryOp term | primaryTerm
primaryTerm      → integerConstant | stringConstant | 'true' | 'false' |
                   'null' | 'this' | varName | varName '[' expression ']' |
                   subroutineCall | '(' expression ')'
subroutineCall   → subroutineName '(' expressionList ')' |
                   (className | varName) '.' subroutineName '(' expressionList ')'
expressionList   → (expression (',' expression)*)?
op               → '+' | '-' | '*' | '/' | '&' | '|' | '<' | '>' | '='
unaryOp          → '-' | '~' | 'not'
```

### 文法的閱讀方式

讓我們逐條解釋關鍵規則：

**`class` 規則**：一個類別以 `class` 關鍵字開頭，接著是類別名稱，大括號內包含零或多個類別變數宣告（`classVarDec*`）和零或多個函式宣告（`subroutineDec*`）。星號 `*` 表示零次或多次重複。

**`expression` 規則**：表達式是一個或多個 `term`，term 之間用二元運算符 `op` 連接。這確保了運算的左結合性。

**`term` 規則**：一個 term 可以是帶一元運算符的 term（如 `-x` 或 `~flag`），也可以是 primaryTerm（基本元素）。

**`subroutineCall` 規則**：函式呼叫有兩種形式——直接呼叫 `foo(args)` 或透過物件呼叫 `obj.foo(args)`。

## 10.3.3 遞迴下降解析法

### 什麼是遞迴下降？

**遞迴下降解析（Recursive Descent Parsing）** 是一種直覺的語法分析方法，其核心思想是：

> **文法中的每一個非終端符號，對應解析器中的一個函式。**

例如，對於 Jack 文法：

```
class → 'class' className '{' classVarDec* subroutineDec* '}'
```

我們會有一個 `compile_class()` 函式，它依次：
1. 檢查並消費 `class` 關鍵字
2. 檢查並消費 className（識別碼）
3. 檢查並消費 `{`
4. 循環處理 classVarDec
5. 循環處理 subroutineDec
6. 檢查並消費 `}`

### 與文法的對應關係

每個文法規則轉換為一個函式，函式內部按照候選式的結構，呼叫其他函式或檢查 token：

```
文法規則:          函式結構:
─────────          ─────────
A → B C D          compile_A():
                     compile_B()
                     compile_C()
                     compile_D()

A → B | C          compile_A():
                     if token is first(B):
                       compile_B()
                     elif token is first(C):
                       compile_C()

A → B*             compile_A():
                     while token in first(B):
                       compile_B()

A → B?             compile_A():
                     if token in first(B):
                       compile_B()
```

### LL(1) 文法

遞迴下降解析器要求文法是 **LL(1)** 的——即在任何時刻，只需要向前看**一個** token 就能決定使用哪一條產生式規則。Jack 的文法被設計為大致上滿足 LL(1) 的要求。

## 10.3.4 CompilationEngine 的結構

我們的 CompilationEngine 使用 JackTokenizer 提供的 token 流，並輸出 XML 格式的語法樹（或直接產生 VM 碼）。

### 類別介面

```python
class CompilationEngine:
    """組譯引擎：從 token 流構建語法分析結果。"""

    def __init__(self, tokenizer: JackTokenizer, output_file: str) -> None:
        """
        使用給定的 JackTokenizer 建立編譯引擎，
        並將輸出寫入 output_file。
        """

    # --- 程式結構 ---
    def compile_class(self) -> None:
        """編譯整個 class 結構。"""

    def compile_class_var_dec(self) -> None:
        """編譯一個 classVarDec（field 或 static 變數宣告）。"""

    def compile_subroutine(self) -> None:
        """編譯一個函式/建構子/方法的宣告與主體。"""

    def compile_parameter_list(self) -> None:
        """編譯參數列表。"""

    def compile_subroutine_body(self) -> None:
        """編譯函式主體。"""

    def compile_var_dec(self) -> None:
        """編譯一個 var 變數宣告。"""

    # --- 語句 ---
    def compile_statements(self) -> None:
        """編譯語句序列。"""

    def compile_let(self) -> None:
        """編譯 let 語句。"""

    def compile_if(self) -> None:
        """編譯 if 語句。"""

    def compile_while(self) -> None:
        """編譯 while 語句。"""

    def compile_do(self) -> None:
        """編譯 do 語句。"""

    def compile_return(self) -> None:
        """編譯 return 語句。"""

    # --- 表達式 ---
    def compile_expression(self) -> None:
        """編譯表達式。"""

    def compile_term(self) -> None:
        """編譯 term。"""

    def compile_expression_list(self) -> None:
        """編譯表達式列表。"""
```

### 輔助方法

## 10.3.5 完整的 CompilationEngine 實作（Python）

以下是完整的遞迴下降解析器實作。為了專注於語法分析，我們在此只輸出 XML，不產生 VM 碼（VM 碼生成將在後續章節介紹）。

```python
from JackTokenizer import (
    JackTokenizer, KEYWORD, SYMBOL, IDENTIFIER,
    INT_CONST, STRING_CONST, EOF
)


class CompilationEngine:
    """組譯引擎：從 token 流構建 XML 語法樹。"""

    def __init__(self, tokenizer: JackTokenizer, output_file: str) -> None:
        self.tokenizer = tokenizer
        self.out = open(output_file, "w", encoding="utf-8")
        self.indent_level = 0

    def _write_xml(self, text: str) -> None:
        indent = "  " * self.indent_level
        self.out.write(f"{indent}{text}\n")

    def _write_open(self, tag: str) -> None:
        self._write_xml(f"<{tag}>")
        self.indent_level += 1

    def _write_close(self, tag: str) -> None:
        self.indent_level -= 1
        self._write_xml(f"</{tag}>")

    def _write_token(self) -> None:
        """輸出目前 token 的 XML 表示。"""
        self._write_xml(self.tokenizer.token_to_xml())

    def _eat(self, expected: str = None) -> None:
        """消費目前的 token（並寫入 XML），可選地驗證其值。"""
        if expected:
            actual = ""
            tt = self.tokenizer.token_type()
            if tt == KEYWORD:
                actual = self.tokenizer.keyword()
            elif tt == SYMBOL:
                actual = self.tokenizer.symbol()
            elif tt == IDENTIFIER:
                actual = self.tokenizer.identifier()
            elif tt == INT_CONST:
                actual = str(self.tokenizer.int_val())
            elif tt == STRING_CONST:
                actual = self.tokenizer.string_val()
            if actual != expected:
                raise SyntaxError(
                    f"Expected '{expected}', got '{actual}' "
                    f"(type={tt})"
                )
        self._write_token()
        self.tokenizer.advance()

    def compile(self) -> None:
        """開始編譯整個程式。"""
        self.tokenizer.advance()  # 預讀第一個 token
        self.compile_class()
        self.out.close()

    # ======================================================
    # 程式結構
    # ======================================================

    def compile_class(self) -> None:
        """class className '{' classVarDec* subroutineDec* '}'"""
        self._write_open("class")

        self._eat("class")           # 'class'
        self._eat()                  # className
        self._eat("{")               # '{'

        # 處理 classVarDec*
        while self._current_is_class_var():
            self.compile_class_var_dec()

        # 處理 subroutineDec*
        while self._current_is_subroutine():
            self.compile_subroutine()

        self._eat("}")               # '}'
        self._write_close("class")

    def _current_is_class_var(self) -> bool:
        tt = self.tokenizer.token_type()
        if tt == KEYWORD:
            kw = self.tokenizer.keyword()
            return kw in ("field", "static")
        return False

    def _current_is_subroutine(self) -> bool:
        tt = self.tokenizer.token_type()
        if tt == KEYWORD:
            kw = self.tokenizer.keyword()
            return kw in ("constructor", "function", "method")
        return False

    def compile_class_var_dec(self) -> None:
        """('static' | 'field') type varName (',' varName)* ';'"""
        self._write_open("classVarDec")

        self._eat()                  # 'static' 或 'field'
        self._eat()                  # type
        self._eat()                  # varName
        while self.tokenizer.symbol() == ",":
            self._eat(",")           # ','
            self._eat()              # varName
        self._eat(";")               # ';'

        self._write_close("classVarDec")

    def compile_subroutine(self) -> None:
        """('constructor' | 'function' | 'method') ('void' | type)
           subroutineName '(' parameterList ')' subroutineBody"""
        self._write_open("subroutineDec")

        self._eat()                  # 'constructor'/'function'/'method'
        self._eat()                  # 'void' 或 type
        self._eat()                  # subroutineName
        self._eat("(")               # '('
        self.compile_parameter_list()
        self._eat(")")               # ')'
        self.compile_subroutine_body()

        self._write_close("subroutineDec")

    def compile_parameter_list(self) -> None:
        """(type varName (',' type varName)*)?"""
        self._write_open("parameterList")

        tt = self.tokenizer.token_type()
        if tt == KEYWORD and self.tokenizer.keyword() in (
            "int", "char", "boolean"
        ) or tt == IDENTIFIER:
            self._eat()              # type
            self._eat()              # varName
            while self.tokenizer.symbol() == ",":
                self._eat(",")       # ','
                self._eat()          # type
                self._eat()          # varName

        self._write_close("parameterList")

    def compile_subroutine_body(self) -> None:
        """'{' varDec* statements '}'"""
        self._write_open("subroutineBody")

        self._eat("{")               # '{'

        while self.tokenizer.token_type() == KEYWORD and \
              self.tokenizer.keyword() == "var":
            self.compile_var_dec()

        self.compile_statements()

        self._eat("}")               # '}'
        self._write_close("subroutineBody")

    def compile_var_dec(self) -> None:
        """'var' type varName (',' varName)* ';'"""
        self._write_open("varDec")

        self._eat("var")             # 'var'
        self._eat()                  # type
        self._eat()                  # varName
        while self.tokenizer.symbol() == ",":
            self._eat(",")           # ','
            self._eat()              # varName
        self._eat(";")               # ';'

        self._write_close("varDec")

    # ======================================================
    # 語句
    # ======================================================

    def compile_statements(self) -> None:
        """statement*"""
        self._write_open("statements")

        while True:
            tt = self.tokenizer.token_type()
            if tt != KEYWORD:
                break
            kw = self.tokenizer.keyword()
            if kw == "let":
                self.compile_let()
            elif kw == "if":
                self.compile_if()
            elif kw == "while":
                self.compile_while()
            elif kw == "do":
                self.compile_do()
            elif kw == "return":
                self.compile_return()
            else:
                break

        self._write_close("statements")

    def compile_let(self) -> None:
        """'let' varName ('[' expression ']')? '=' expression ';'"""
        self._write_open("letStatement")

        self._eat("let")             # 'let'
        self._eat()                  # varName
        if self.tokenizer.symbol() == "[":
            self._eat("[")           # '['
            self.compile_expression()
            self._eat("]")           # ']'
        self._eat("=")               # '='
        self.compile_expression()
        self._eat(";")               # ';'

        self._write_close("letStatement")

    def compile_if(self) -> None:
        """'if' '(' expression ')' '{' statements '}'
           ('else' '{' statements '}')?"""
        self._write_open("ifStatement")

        self._eat("if")              # 'if'
        self._eat("(")               # '('
        self.compile_expression()
        self._eat(")")               # ')'
        self._eat("{")               # '{'
        self.compile_statements()
        self._eat("}")               # '}'
        if self.tokenizer.token_type() == KEYWORD and \
           self.tokenizer.keyword() == "else":
            self._eat("else")        # 'else'
            self._eat("{")           # '{'
            self.compile_statements()
            self._eat("}")           # '}'

        self._write_close("ifStatement")

    def compile_while(self) -> None:
        """'while' '(' expression ')' '{' statements '}'"""
        self._write_open("whileStatement")

        self._eat("while")           # 'while'
        self._eat("(")               # '('
        self.compile_expression()
        self._eat(")")               # ')'
        self._eat("{")               # '{'
        self.compile_statements()
        self._eat("}")               # '}'

        self._write_close("whileStatement")

    def compile_do(self) -> None:
        """'do' subroutineCall ';'"""
        self._write_open("doStatement")

        self._eat("do")              # 'do'
        self._compile_subroutine_call()
        self._eat(";")               # ';'

        self._write_close("doStatement")

    def compile_return(self) -> None:
        """'return' expression? ';'"""
        self._write_open("returnStatement")

        self._eat("return")          # 'return'
        tt = self.tokenizer.token_type()
        # 如果下一個 token 不是 ; ，則編譯表達式
        if tt != SYMBOL or self.tokenizer.symbol() != ";":
            self.compile_expression()
        self._eat(";")               # ';'

        self._write_close("returnStatement")

    # ======================================================
    # 表達式
    # ======================================================

    def compile_expression(self) -> None:
        """term (op term)*"""
        self._write_open("expression")

        self.compile_term()

        while self.tokenizer.token_type() == SYMBOL and \
              self.tokenizer.symbol() in "+-*/&|<>=":
            self._eat()              # op
            self.compile_term()

        self._write_close("expression")

    def compile_term(self) -> None:
        """primaryTerm | unaryOp term"""
        self._write_open("term")

        tt = self.tokenizer.token_type()

        if tt == INT_CONST:
            self._eat()              # integerConstant
        elif tt == STRING_CONST:
            self._eat()              # stringConstant
        elif tt == KEYWORD and self.tokenizer.keyword() in (
            "true", "false", "null", "this"
        ):
            self._eat()              # keywordConstant
        elif tt == SYMBOL and self.tokenizer.symbol() in "-~":
            self._eat()              # unaryOp
            self.compile_term()
        elif tt == SYMBOL and self.tokenizer.symbol() == "(":
            self._eat("(")           # '('
            self.compile_expression()
            self._eat(")")           # ')'
        elif tt == IDENTIFIER:
            # 可能是 varName, varName[expr], 或 subroutineCall
            self._eat()              # 先消費識別碼
            self._after_identifier_term()
        else:
            raise SyntaxError(
                f"Unexpected token in term: "
                f"type={tt}, value={self.tokenizer.current_token}"
            )

        self._write_close("term")

    def _after_identifier_term(self) -> None:
        """在消費了一個 identifier 之後，判斷 term 的其餘部分。"""
        tt = self.tokenizer.token_type()
        if tt == SYMBOL and self.tokenizer.symbol() == "[":
            # varName '[' expression ']'
            self._eat("[")           # '['
            self.compile_expression()
            self._eat("]")           # ']'
        elif tt == SYMBOL and self.tokenizer.symbol() == "(":
            # subroutineName '(' expressionList ')'
            self._eat("(")           # '('
            self.compile_expression_list()
            self._eat(")")           # ')'
        elif tt == SYMBOL and self.tokenizer.symbol() == ".":
            # (className | varName) '.' subroutineName '(' expressionList ')'
            self._eat(".")           # '.'
            self._eat()              # subroutineName
            self._eat("(")           # '('
            self.compile_expression_list()
            self._eat(")")           # ')'

    def _compile_subroutine_call(self) -> None:
        """subroutineName '(' expressionList ')' |
           (className | varName) '.' subroutineName '(' expressionList ')'"""
        self._eat()                  # subroutineName 或 className/varName
        if self.tokenizer.symbol() == ".":
            self._eat(".")           # '.'
            self._eat()              # subroutineName
        self._eat("(")               # '('
        self.compile_expression_list()
        self._eat(")")               # ')'

    def compile_expression_list(self) -> None:
        """(expression (',' expression)*)?"""
        self._write_open("expressionList")

        # 如果不是 )，表示有表達式
        tt = self.tokenizer.token_type()
        if not (tt == SYMBOL and self.tokenizer.symbol() == ")"):
            self.compile_expression()
            while self.tokenizer.symbol() == ",":
                self._eat(",")       # ','
                self.compile_expression()

        self._write_close("expressionList")
```

## 10.3.6 設計思路與實作步驟

### 步驟一：文法到函式的映射

遞迴下降解析器的核心設計原則是**一個文法規則 = 一個函式**。每個 `compile_*` 函式對應文法中的一個非終端符號。

函式的執行流程完全遵循文法的結構：
- **序列**（`A B C`）→ 函式內依次呼叫 `compile_A(); compile_B(); compile_C();`
- **選擇**（`A | B`）→ 用 `if/elif` 根據目前 token 決定走哪個分支
- **重複**（`A*`）→ 用 `while` 迴圈，條件為「目前 token 屬於 A 的 FIRST 集合」
- **可選**（`A?`）→ 用 `if` 判斷是否匹配

### 步驟二：前瞻（Lookahead）

遞迴下降解析器通常只需要向前看一個 token 就能做出決定。例如：

- 在 `compile_if` 中，遇到 `else` 後面的 `{` 時，需要判斷 `else` 子句是否存在
- 在 `compile_term` 中，遇到 `IDENTIFIER` 時，需要判斷它是變數、陣列存取還是函式呼叫——這需要看下一個 token 是 `[`、`.`、`(` 還是其他

### 步驟三：輔助 `_eat()` 方法

`_eat()` 方法封裝了「讀取並驗證 token」的邏輯。它會：
1. （可選地）驗證目前 token 是否符合預期值
2. 將目前 token 輸出為 XML
3. 呼叫 `tokenizer.advance()` 移到下一個 token

這個設計使得每個 `compile_*` 函式的主體非常清晰，幾乎像是文法規則的直接翻譯。

## 10.3.7 運算元 precedence 與表達式解析

在設計表達式解析時，運算元的優先順序是核心考量。Jack 運算元的優先順序（由高到低）：

| 優先順序 | 運算元 | 說明 |
|----------|--------|------|
| 1（最高） | `()` `[]` `.` | 括號、陣列、成員存取 |
| 2 | `-` `~` `not` | 一元運算符 |
| 3 | `*` `/` | 乘法、除法 |
| 4 | `+` `-` | 加法、減法 |
| 5 | `<` `>` `=` | 比較運算 |
| 6 | `&` `\|` | 邏輯運算 |
| 7（最低） | `and` `or` | 邏輯且/或 |

在我們的文法中，`expression → term (op term)*` 確保同一層級的左結合運算；而 `term` 內部遞迴處理一元運算符，實現了高優先級運算的正確處理。

### 識別碼後的分支判斷

`compile_term` 中遇到 `IDENTIFIER` 時的判斷是整個解析器最精巧的部分：

```
遇到 identifier 時：
    下一個 token 是 '[' ?  → 陣列存取: varName[expr]
    下一個 token 是 '(' ?  → 函式呼叫: myFunc(args)
    下一個 token是 '.' ?  → 方法呼叫: obj.method(args)
    以上皆非?              → 普通變數: varName
```

這個判斷只需要看一個 token（`[`、`(`、`.` 或其他），完美符合 LL(1) 的要求。

## 10.3.8 錯誤處理

### 常見的語法錯誤

1. **缺少分號**
   ```
   let x = 5    // 錯誤：缺少 ;
   ```

2. **缺少括號**
   ```
   if x > 0 {   // 錯誤：缺少 (
   ```

3. **不匹配的符號**
   ```
   while (x > 0) [    // 錯誤：應該是 {，不是 [
   ```

4. **未預期的 token**
   ```
   let = 5;      // 錯誤：let 後面應該是變數名
   ```

### 簡易的錯誤報告

在遞迴下降解析器中，我們可以透過在 `_eat()` 中的驗證來產生錯誤訊息：

```python
def _eat(self, expected: str = None) -> None:
    tt = self.tokenizer.token_type()
    actual = self._get_token_value()
    if expected and actual != expected:
        raise SyntaxError(
            f"Line error: expected '{expected}', "
            f"got '{actual}' (type={tt})"
        )
    # ... 繼續處理
```

## 本章小結

本節深入探討了語法分析器的原理與實作：

- **上下文無關文法**（CFG）以非終端符號、終端符號、產生式規則和起始符號來精確定義語言的語法結構。
- **Jack 文法**包含程式結構、語句和表達式三大類規則，涵蓋了所有合法的 Jack 程式結構。
- **遞迴下降解析法**將每個文法規則映射為一個函式，是最直覺的語法分析方法。
- **CompilationEngine** 透過 `_eat()` 輔助方法和各 `compile_*` 函式，將 token 流組織成層次分明的語法樹。
- **運算元優先順序**透過文法的層次結構（expression → term → primaryTerm）自然實現。
- **前瞻一個 token** 足以做出所有語法決策，符合 LL(1) 的要求。
