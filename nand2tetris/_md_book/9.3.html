9.3 使用 Jack 編寫第一個圖形化小遊戲

學習目標

讀完本節後，你應該能：

  • 使用 Jack OS 提供的 Screen（繪圖）、Keyboard（鍵盤輸入）、Output（文字輸出）等 API
  • 理解「先擦後畫」的動畫模型，避免畫面殘影
  • 設計並撰寫一個完整的小遊戲（拍子接球遊戲）
  • 走完整個開發流程：編寫 → 編譯 → 載入 VM 模擬器 → 執行與測試
  • 使用 Sys.wait 控制遊戲幀率、用方向鍵控制物件移動
  • 除錯 Jack 遊戲的常見問題（閃爍、卡鍵、越界、碰撞不準）

前言

9.1 教了你 Jack 的語法，9.2 揭開了物件與陣列的記憶體底層。現在該把這些知識派上用場了——我們要寫一個真正能玩的圖形化小遊戲。

本節做的遊戲是經典的拍子接球（Pong）：螢幕下方有一支拍子，用左右方向鍵控制；一顆球在螢幕四周彈來彈去，接到球就得分，漏掉球就少一條命。規則簡單、畫面單純，卻完整覆蓋了遊戲開發的核心主題：

  • 畫面輸出：如何畫方塊、擦方塊
  • 使用者輸入：如何讀鍵盤、處理方向鍵
  • 碰撞偵測：球與牆、球與拍子的碰撞判斷
  • 遊戲迴圈：狀態更新與幀率控制
  • 計分與生命：掛上基本的 game state

更重要的是，這支程式會忠實走過你親手打造（或即將打造）的整條工具鏈：.jack → 編譯器 → .vm → VM 翻譯器 → Hack 電腦。當遊戲在模擬器裡跑起來那一刻，就是整條「從 0 到 1」之路的階段性回報。

1. 前置知識：Jack OS 提供的 API

在寫遊戲之前，先認識 Jack 作業系統提供的幾個「現成工具」類別。它們在 Nand2Tetris 工具包的 OS/ 目錄裡，以 .vm 檔的形式存在（第 12 章你會自己實作它們）。

1.1 Screen 類別 —— 畫到螢幕上

Screen 管理從 16384 開始的螢幕記憶體映射（第 4 章有詳細介紹）。

方法 功能 底層知識
Screen.clearScreen() 把整個螢幕清成背景色 把 8192 個 word 全部設 0
Screen.setColor(boolean b) 設定「目前的畫筆顏色」 true=黑，false=白
Screen.drawPixel(x, y) 在座標 (x, y) 畫一個點 計算 word 位址 + 位移 此後所有繪圖方法的量產基礎
Screen.drawLine(x1, y1, x2, y2) 畫一條線 內建 Bresenham 演算法
Screen.drawRectangle(x1, y1, x2, y2) 畫一個實心矩形 重複呼叫 drawLine
Screen.drawCircle(x, y, r) 畫一個實心圓 用中點畫圓法

螢幕座標系統：解析度 512 × 256，左上角為原點 (0,0)，x 向右、y 向下遞增。

// 基本用法
do Screen.setColor(true);                    // 換黑色：開始作畫
do Screen.drawRectangle(100, 100, 300, 160); // 畫一個實心長方形
do Screen.setColor(false);                   // 換白色：變成橡皮擦
do Screen.drawRectangle(100, 100, 300, 160); // 把同一個長方形「擦掉」

設計思路：setColor(false) 就是橡皮擦。黑白系統的巧妙之處在於——「擦除」不是特殊功能，只是用同一個繪圖 API 通通畫成背景色（0）。這讓動畫就變成「先畫白、再畫黑」的循環，正是本節遊戲動畫的最核心機制。

1.2 Keyboard 類別 —— 讀取鍵盤

Keyboard 讀取位址 24576 的鍵盤記憶體映射。

方法 功能
Keyboard.keyPressed() 回傳目前被按下的鍵的碼（沒有按鍵時回傳 0）
Keyboard.readChar() 等待並回傳使用者按下的一個字元
Keyboard.readLine() 讀一整行文字（直到 Enter）
Keyboard.readInt() 讀一整行並轉成整數

方向鍵與特殊鍵的碼（這些是 Jack OS 的既定規格）：

鍵 碼 鍵 碼
左方向鍵 130 空白鍵 32
上方向鍵 131 Enter 128
右方向鍵 132 Backspace 129
下方向鍵 133 ESC 27 
// 讀取目前按下的鍵
var int key;
let key = Keyboard.keyPressed();
if (key = 132) {          // 右方向鍵（注意：比較用單等號 =）
    do Screen.drawPixel(10, 10);
}

1.3 Output 類別 —— 顯示文字

Output 把文字畫住螢幕上方，以「字元格」為單位（每格 8×8 像素，共 32 欄 × 16 列）。

方法 功能
Output.moveCursor(row, col) 移動游標（row: 0-15, col: 0-31）
Output.printChar(char c) 印一個字元
Output.printString(String s) 印一串文字
Output.printInt(int n) 印一個整數
Output.println() 換行 
do Output.moveCursor(0, 0);
do Output.printString("Score: ");
do Output.printInt(42);

1.4 Sys 與 Math 類別

類別 常用方法 用途
Sys Sys.wait(ms) 暫停指定的毫秒數，控制遊戲幀率
Sys.halt() 系統停止 結束程式
Math Math.abs(x) 絕對值（碰撞運算常用）
Math Math.multiply(a,b)、Math.divide(a,b) 乘除法（16-bit Hack 沒有硬體乘法）

var int d;

2. 遊戲設計：拍子接球（Pong）

2.1 遊戲規則

  • 一支拍子（寬 80、高 6 像素）固定在螢幕底部 (y=240)，用 左/右方向鍵 移動
  • 一顆球（半徑 3 像素）在螢幕內飛行，撞到左右牆與天花板會反彈
  • 球碰到 拍子 → 得分 +1，球向上反彈
  • 球漏到螢幕底部以下 → 生命 -1，球重置回上方
  • 生命歸零 → 顯示 Game Over；按 ESC 隨時離開

2.2 「先擦後畫」的動畫模型

Game Loop（遊戲迴圈）是每一支即時遊戲的心跳：

┌────────────────────────────────────┐
│  1. 讀取鍵盤輸入                     │
│  2. 根據輸入更新物件狀態（座標）      │
│  3. 把舊畫面「擦掉」（畫成白色）      │
│  4. 把新畫面「畫上」（畫成黑色）      │
│  5. Sys.wait 控制幀率                │
└────────────────────────────────────┘
         ▲                          │
         └──────── 無限重複 ──────────┘

物件移動的標準做法是「先擦舊、再畫新」：

do drawBall(false);              // 先在舊位置畫白（擦掉）
let ballX = ballX + ballVX;      // 更新座標
let ballY = ballY + ballVY;
do drawBall(true);               // 再在新位置畫黑（畫出）

2.3 檔案結構

本專案由兩個類別組成，放在同一個專案目錄（編譯器一次處理一個目錄）：

PongGame/
├── Main.jack    ← 程式入口：顯示說明、等待開始、啟動遊戲
└── Pong.jack    ← 遊戲本體：拍子、球、碰撞、計分、主迴圈

3. 逐步實作

3.1 第一步：Pong 類別的欄位設計

先把遊戲的「狀態」想清楚——遊戲裡需要記住的一切就住在欄位裡。回想 9.2 節：每到達一個欄位，new 時就要多 alloc 一個 word，記憶體圖就會多一格。

class Pong {

    // ------ 拍子 ------
    field int paddleW;    // 拍子寬度（固定 80）
    field int paddleX;    // 拍子左端 x 座標（要移動的就是它）
    field int paddleY;    // 拍子頂端 y 座標（固定 240）

    // ------ 球 ------
    field int ballR;      // 球半徑（用正方形近似）
    field int ballX;      // 球心 x
    field int ballY;      // 球心 y
    field int ballVX;     // 水平速度（每幀移動像素）
    field int ballVY;     // 垂直速度

    // ------ 遊戲狀態 ------
    field int score;      // 得分
    field int lives;      // 剩餘生命

這個類別共有 9 個 field，因此建構子會向 Memory.alloc(9) 請求 9 個 word 的 heap 空間。

3.2 第二步：建構子與繪圖方法

建構子把物件初始化之後畫出初始畫面。注意「匯集所有常數」的習慣——遊戲的魔法數字全部集中在這裡，改速度、改拍子寬度只要動建構子一行。

    constructor Pong new() {
        let paddleW = 80;
        let paddleX = 216;          // (512 - 80) / 2：置中
        let paddleY = 240;
        let ballR = 3;
        let score = 0;
        let lives = 3;
        do resetBall();             // 把球放回上方並畫出
        do drawPaddle(true);
        do drawScore();
        do drawInstructions();
        return this;                // 回傳物件的 heap 位址
    }

繪圖方法做成「帶布林參數的版本」——true 畫黑（出現）、false 畫白（消失）。這樣同一支方法同時是「畫筆」也是「橡皮擦」：

    // 依參數 colored 決定是畫出還是擦掉拍子
    method void drawPaddle(boolean colored) {
        do Screen.setColor(colored);
        do Screen.drawRectangle(paddleX, paddleY,
                                paddleX + paddleW, paddleY + 6);
        return;
    }

    // 依參數 colored 決定是畫出還是擦掉球（用小正方形近似圓形）
    method void drawBall(boolean colored) {
        do Screen.setColor(colored);
        do Screen.drawRectangle(ballX - ballR, ballY - ballR,
                                ballX + ballR, ballY + ballR);
        return;
    }

    // 重置球的位置：放到頂端中間，向下飛
    method void resetBall() {
        let ballX = 256;
        let ballY = 20;
        let ballVX = 2;
        let ballVY = 2;
        do drawBall(true);
        return;
    }

3.3 第三步：文字輸出方法

用 Output 顯示分數與操作說明：

    method void drawScore() {
        do Output.moveCursor(0, 0);
        do Output.printString("  Score: ");
        do Output.printInt(score);
        do Output.printString("    Lives: ");
        do Output.printInt(lives);
        do Output.printString("       ");
        return;
    }

    method void drawInstructions() {
        do Output.moveCursor(2, 3);
        do Output.printString("Pong! Bounce the ball!");
        do Output.moveCursor(3, 3);
        do Output.printString("Arrows=move  ESC=quit");
        return;
    }

    method void drawGameOver() {
        do Output.moveCursor(12, 6);
        do Output.printString("Game Over! Final Score: ");
        do Output.printInt(score);
        do Output.moveCursor(14, 6);
        do Output.printString("Press ESC to quit");
        return;
    }

細節：printString 結尾多印幾個空白，用來「蓋掉」比上一幀短的殘留文字（例如 Lives: 3 變成 Lives: 2 時，多出來的尾巴要用空格蓋住）。

3.4 第四步：拍子移動

讀方向鍵，移動拍子。移動前先擦舊位置、移動後畫新位置。用邊界檢查避免拍子衝出螢幕：

    method void movePaddle() {
        var int key;
        let key = Keyboard.keyPressed();
        if (key = 132) {                      // 132 = 右方向鍵
            if (paddleX + paddleW < 511) {    // 別衝出右緣
                do drawPaddle(false);          // 擦掉舊位置
                let paddleX = paddleX + 8;
                do drawPaddle(true);           // 畫到新位置
            }
        }
        if (key = 130) {                      // 130 = 左方向鍵
            if (paddleX > 0) {                // 別衝出左緣
                do drawPaddle(false);
                let paddleX = paddleX - 8;
                do drawPaddle(true);
            }
        }
        return;
    }

3.5 第五步：球的移動與碰撞

這是遊戲最「物理」的部分。球的座標每個 frame 加上速度向量；撞牆就翻轉對應方向的速度分量：

    // 碰撞判斷：球要往下、且落在拍子所在的 y 帶，且水平位置在拍子範圍內
    method boolean ballHitPaddle() {
        if (ballVY < 0) { return false; }                  // 往上飛不會碰到
        if (ballY + ballR < paddleY) { return false; }     // 還沒到拍子高度
        if (ballY + ballR > paddleY + 8) { return false; } // 已穿過拍子帶
        if (ballX < paddleX) { return false; }             // 在拍子左邊外
        if (ballX > paddleX + paddleW) { return false; }   // 在拍子右邊外
        return true;
    }

    method void moveBall() {
        do drawBall(false);                 // 擦掉舊球
        let ballX = ballX + ballVX;         // 更新座標
        let ballY = ballY + ballVY;

        if (ballX < ballR) {                // 撞左牆
            let ballX = ballR;
            let ballVX = -ballVX;
        }
        if (ballX > 511 - ballR) {          // 撞右牆
            let ballX = 511 - ballR;
            let ballVX = -ballVX;
        }
        if (ballY < ballR) {                // 撞天花板
            let ballY = ballR;
            let ballVY = -ballVY;
        }
        if (ballHitPaddle()) {              // 接到球！
            let ballVY = -ballVY;           // 向上反彈
            let ballY = paddleY - ballR;    // 貼齊拍子上緣，避免卡住
            let score = score + 1;
        }
        do drawBall(true);                  // 畫上新球
        return;
    }

    // 掉球：生命減一，若還有命就把球重置回上方
    method void loseLife() {
        let lives = lives - 1;
        if (lives > 0) {
            do resetBall();
        }
        return;
    }

設計思路：ballHitPaddle 的檢查順序暗藏了除錯智慧——把最不可能的條件放前面、最貴的運算放後面（其實這五個條件都很便宜，但「先排除多數情況」的思考習慣本身很有價值）。更重要的是條件完整：只往下飛、只在那條 y 帶、只當水平位置重疊才算「命中」。這三件事缺一不可，否則球會「穿過」拍子或「隔空」接住。

3.6 第六步：遊戲主迴圈

主迴圈把每一幀的片段組合起來：讀鍵盤 → 動拍子 → 動球 → 檢查生命 → 更新分數 → 暫停讓畫面停留。ESC 隨時直接離場：

    method void run() {
        var int key;
        while (true) {
            let key = Keyboard.keyPressed();
            if (key = 27) {              // ESC → 離開遊戲
                return;
            }
            if (lives > 0) {
                do movePaddle();
                do moveBall();
                if (ballY > 300) {         // 球掉出螢幕底部
                    do loseLife();
                }
                if (lives > 0) {
                    do drawScore();
                    do Sys.wait(30);       // 每幀 30ms ≈ 33 fps
                }
            } else {
                do drawGameOver();         // 生命歸零
                do Sys.wait(200);
            }
        }
        return;
    }

3.7 Main 類別：程式入口

Main.main() 是 Jack 程式的起點（就像 C 的 main）。它先顯示說明、等待玩家按空白鍵開始，再交給 Pong.run() 接手：

// Main.jack

class Main {

    function void main() {
        var Pong game;
        do Output.moveCursor(8, 6);
        do Output.printString("Welcome to Pong!");
        do Output.moveCursor(10, 6);
        do Output.printString("Press SPACE to start...");
        while (Keyboard.keyPressed() = 0) {     // 等待任何按鍵
            do Sys.wait(20);
        }
        let game = Pong.new();                  // 建立遊戲物件
        do game.run();                          // 進入主迴圈
        return;
    }
}

3.8 完整程式碼：Pong.jack

將上面的片段組合成一個完整檔案，即可直接交給 Jack 編譯器：

// Pong.jack
// 拍子接球小遊戲：方向鍵移動拍子，接住反彈的球
// 左右牆與天花板會反彈；漏球扣命；ESC 離開

class Pong {

    field int paddleW;
    field int paddleX;
    field int paddleY;

    field int ballR;
    field int ballX;
    field int ballY;
    field int ballVX;
    field int ballVY;

    field int score;
    field int lives;

    constructor Pong new() {
        let paddleW = 80;
        let paddleX = 216;
        let paddleY = 240;
        let ballR = 3;
        let score = 0;
        let lives = 3;
        do resetBall();
        do drawPaddle(true);
        do drawScore();
        do drawInstructions();
        return this;
    }

    method void run() {
        var int key;
        while (true) {
            let key = Keyboard.keyPressed();
            if (key = 27) {
                return;
            }
            if (lives > 0) {
                do movePaddle();
                do moveBall();
                if (ballY > 300) {
                    do loseLife();
                }
                if (lives > 0) {
                    do drawScore();
                    do Sys.wait(30);
                }
            } else {
                do drawGameOver();
                do Sys.wait(200);
            }
        }
        return;
    }

    method void movePaddle() {
        var int key;
        let key = Keyboard.keyPressed();
        if (key = 132) {
            if (paddleX + paddleW < 511) {
                do drawPaddle(false);
                let paddleX = paddleX + 8;
                do drawPaddle(true);
            }
        }
        if (key = 130) {
            if (paddleX > 0) {
                do drawPaddle(false);
                let paddleX = paddleX - 8;
                do drawPaddle(true);
            }
        }
        return;
    }

    method boolean ballHitPaddle() {
        if (ballVY < 0) { return false; }
        if (ballY + ballR < paddleY) { return false; }
        if (ballY + ballR > paddleY + 8) { return false; }
        if (ballX < paddleX) { return false; }
        if (ballX > paddleX + paddleW) { return false; }
        return true;
    }

    method void moveBall() {
        do drawBall(false);
        let ballX = ballX + ballVX;
        let ballY = ballY + ballVY;

        if (ballX < ballR) {
            let ballX = ballR;
            let ballVX = -ballVX;
        }
        if (ballX > 511 - ballR) {
            let ballX = 511 - ballR;
            let ballVX = -ballVX;
        }
        if (ballY < ballR) {
            let ballY = ballR;
            let ballVY = -ballVY;
        }
        if (ballHitPaddle()) {
            let ballVY = -ballVY;
            let ballY = paddleY - ballR;
            let score = score + 1;
        }
        do drawBall(true);
        return;
    }

    method void loseLife() {
        let lives = lives - 1;
        if (lives > 0) {
            do resetBall();
        }
        return;
    }

    method void resetBall() {
        let ballX = 256;
        let ballY = 20;
        let ballVX = 2;
        let ballVY = 2;
        do drawBall(true);
        return;
    }

    method void drawPaddle(boolean colored) {
        do Screen.setColor(colored);
        do Screen.drawRectangle(paddleX, paddleY,
                                paddleX + paddleW, paddleY + 6);
        return;
    }

    method void drawBall(boolean colored) {
        do Screen.setColor(colored);
        do Screen.drawRectangle(ballX - ballR, ballY - ballR,
                                ballX + ballR, ballY + ballR);
        return;
    }

    method void drawScore() {
        do Output.moveCursor(0, 0);
        do Output.printString("  Score: ");
        do Output.printInt(score);
        do Output.printString("    Lives: ");
        do Output.printInt(lives);
        do Output.printString("       ");
        return;
    }

    method void drawInstructions() {
        do Output.moveCursor(2, 3);
        do Output.printString("Pong! Bounce the ball!");
        do Output.moveCursor(3, 3);
        do Output.printString("Arrows=move  ESC=quit");
        return;
    }

    method void drawGameOver() {
        do Output.moveCursor(12, 6);
        do Output.printString("Game Over! Final Score: ");
        do Output.printInt(score);
        do Output.moveCursor(14, 6);
        do Output.printString("Press ESC to quit");
        return;
    }
}

4. 編譯與執行

4.1 需要的工具鏈元件

元件 狀態 說明
Jack Compiler 第 10-11 章實作 / 使用官方成品 把 .jack 翻譯成 .vm
OS 的 .vm 檔 官方提供（或第 12 章自製） Math.vm、Screen.vm、Keyboard.vm、Output.vm、Sys.vm、String.vm、Array.vm、Memory.vm
VM Emulator 官方工具 載入 .vm 檔執行，附螢幕與鍵盤模擬

4.2 步驟一：編寫並組織專案目錄

把兩份原始碼放進一個目錄（編譯器以「資料夾」為單位）：

PongGame/
├── Main.jack
└── Pong.jack

4.3 步驟二：編譯 .jack → .vm

使用 Nand2Tetris 工具的 Jack Compiler：

# 方法一：使用官方 GUI 工具
$ nand2tetris/tools/JackCompiler.sh            # 然後選 PongGame 資料夾

# 方法二：使用官方命令列工具
$ nand2tetris/tools/JackCompiler.sh PongGame/

# 方法三：使用你自己在第 10-11 章實作的 Jack 編譯器
$ python3 JackCompiler.py PongGame/

編譯成功後，PongGame/ 目錄內出現 Main.vm 與 Pong.vm。編譯器的統計資訊會告訴你每個類別的 VM 指令數。

看一下成品長什麼樣（README 的 Pong.vm 片段）：

// Pong.vm（節錄）
function Pong.new 0
push constant 9
call Memory.alloc 1
pop pointer 0
...
function Pong.moveBall 0
push pointer 0
pop local 0
...

請對照 9.2 節的內容自行追蹤：push constant 9 call Memory.alloc 就是建構子向 heap 請求 9 個 word——這正是「物件 = 一段連續記憶體」的證據。

4.4 步驟三：載入 VM Emulator

  1. 開啟 nand2tetris/tools/VMEmulator.sh（Windows 為 .bat）；
  2. File → Load Program → 選擇 PongGame 資料夾（模擬器會自動載入資料夾內所有 .vm）；
  3. 如果 OS 服務沒有自動載入，把 nand2tetris/tools/OS/ 下的 .vm 檔一起載入（模擬程式的 Settings 會列出 OS 的 .vm）。

4.5 步驟四：執行與測試

  1. 按下 Run（或 Step 逐步執行）；看到起始畫面「Welcome to Pong!」與「Press SPACE to start...」；
  2. 按空白鍵 → 遊戲開始，螢幕上方出現分數列，底部出現拍子，頂端出現球；
  3. 球開始飛行，撞牆反彈；
  4. 按 右方向鍵 → 拍子右移；按 左方向鍵 → 拍子左移；
  5. 讓球落在拍子上 → 分數 +1、球往上彈；
  6. 故意漏球 3 次 → Game Over 畫面與最終分數；
  7. 按 ESC → 程式結束（在 VM Emulator 中 Sys.halt 或 return 結束）。

4.6 驗證與除錯技巧

當遊戲行為不如預期，用這張查表快速定位：

症狀 幾乎可以肯定是 修法
畫面殘影、球拖尾 「先擦後畫」順序錯，或忘了擦舊物件 檢查 moveBall / movePaddle 是否先 draw...(false)
球「穿過」拍子 碰撞的 y 帶太窄，或速度太快時跳過了那條帶 放寬 y 帶 (paddleY+8)；把速度調小
拍子移動很卡 Sys.wait 太大；或不必要的每幀重畫 只重畫「有變化」的物件；縮小 wait
文字重疊或殘留 printInt 數字變短，舊尾巴沒蓋掉 在 printString 結尾補空白
按鍵沒反應 用錯 key 碼（方向鍵是 130~133，不是 ASCII） 對照 1.2 節的按鍵碼表
一進遊戲就 Game Over 初始位置或速度設錯，球直接掉出底部 檢查 resetBall 的 ballY=20 與 ballVY>0

設計思路：除錯的最高原則就是「二分法」。如果畫面完全不對，先不管邏輯，把 do moveBall() 暫時註解掉——如果拍子還能動、球靜止，就證明輸入與繪圖是好的，問題只在球。如果拍子也不動，再切一半：先查鍵盤，再查繪圖。永遠先縮小懷疑範圍，而不是盯著整支程式猜。

5. 可玩的範例講解

把執行過程「拆解」到 VM 層，會看到遊戲背後的每一步：

你看到的畫面 對應的 Jack 程式 在底層做的事
拍子出現 let game = Pong.new() 內的 drawPaddle(true) Screen.drawRectangle 把一段連續的螢幕記憶體 word 設為 -1
拍子右移 movePaddle 偵測 key=132 舊位置矩形「填 0」→ paddleX+8 → 新位置矩形「填 -1」
球反彈 moveBall 的 ballVX = -ballVX 速度向量取反，座標下次往另一方向累加
分數 +1 ballHitPaddle() 回傳 true 8 個 word 的記憶體（樣板）與拍子的記憶體範圍重疊判斷
Game Over lives=0 → drawGameOver() 純文字輸出到螢幕記憶體的第 13-14 列

同時，這支遊戲展示了本節三個「再想一層」的關鍵設計：

  1. 物件狀態全部住在 field 裡——拍子座標、球座標、速度、分數、生命，都是物件的記憶體內容。遊戲世界就是物件的集合，物件的互動就是記憶體狀態的讀寫（對照 9.2 節）。
  2. 碰撞是「邏輯判斷」而不是「物理引擎」——只做了簡單的區間重疊（overlap）判斷，就足以駕馭這個 512×256 的虛擬世界。
  3. 遊戲迴圈就是「讀輸入 → 更新狀態 → 繪圖 → 讓步」——這個骨架可以無限擴充：加二號玩家、加速球、加音效……骨幹完全不動。

6. 延伸挑戰

學完本節後，動手改改看（每一項都只需要動一支方法）：

  • 加速：每接一次球，讓 ballVX/ballVY 稍微變大（小心：太快會「跳穿」拍子，這正是碰撞 y 帶要設計成容錯的原因）。
  • 隨機發球：重設球時用 Math.multiply 或簡短判斷讓 ballVX 有時為負。
  • 計分增強：把 Output.printString 換成遊戲內繪圖計分（用小方塊畫生命值）。
  • 雙人對戰：把拍子換成左右兩支，各自用 WASD 與方向鍵控制。
  • 改寫成貪吃蛇雛形：用 9.2 節的陣列知識存蛇身座標，frame 間「擦尾畫頭」就能動起來。

本章小結

  • 遊戲需要三大 OS API：Screen（畫）、Keyboard（讀輸入）、Output（印文字），配 Sys.wait 控制節奏。
  • 「先擦後畫」是黑白螢幕上動畫的基本單位：setColor(false) 就是橡皮擦，同一個 drawRectangle 先畫白、再畫黑。
  • Game Loop 骨架＝讀輸入 → 更新狀態 → 繪圖 → 讓步（wait），無限重複。
  • 拍子移動用方向鍵碼（左 130、右 132），移動前檢查邊界避免越界。
  • 球的運動是「座標 += 速度」，撞牆就翻轉對應速度分量；碰撞要用「y 帶 + 水平重疊 + 方向」三個條件精準判斷。
  • 完整開發流程：編寫 .jack → JackCompile 翻譯成 .vm → VM Emulator 載入（連同 OS 的 .vm）→ 執行測試 → 對照症狀表除錯。
  • 建構子裡的 push constant 9 call Memory.alloc 見證了 9.2 節的核心主張：物件的 9 個欄位就是 heap 上連續的 9 個 word。
