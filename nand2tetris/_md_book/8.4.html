8.4 打造完整的 VM Translator

學習目標

讀完本節後，你應該能：

  • 說明 VM Translator 的整體架構與「Parser + CodeWriter」的管線分工
  • 說明如何把多個 .vm 檔案整合成單一 .asm 輸出
  • 說出 bootstrap code 在何處產生、為何要產生
  • 看懂並自行修改一支完整可執行的 Python VM Translator
  • 用 VM 模擬器 / CPU 模擬器驗證翻譯結果
  • 診斷常見錯誤（指標未初始化、label 撞名、local 未歸零等）

前言

第 7、8.1、8.2、8.3 節，我們把 VM 指令的每一種翻譯規則都講清楚了：算術、記憶體段、控制流、函式呼叫、bootstrap。但它們一直像一張張散落的樂譜——現在，是時候把它們指揮成一支交響樂。

本節把散落的規則組裝成一支完整、可執行的 VM Translator：輸入 .vm 檔（甚至一整個目錄的多個 .vm 檔），輸出可以被 6.3 節組譯器吃掉的 .asm 檔案。我們會沿用本書的老方法：先用清楚的架構圖與職責分工規劃，再寫一支簡潔、可讀的 Python 程式。

1. VM Translator 的整體架構與管線

1.1 抽象階層：VM 是「第二種機器語言」

回顧整條編譯鏈：

Jack（高階語言）
   │  第 10–11 章：編譯器
   ▼
VM（虛擬機中間碼）──────┐
   │                      │
   │  第 8 章：VM Translator│
   ▼                      │
Hack 組合語言 (.asm)       │
   │  第 6 章：組譯器        │
   ▼                      │
Hack 機器碼 (.hack)        │
   │                      │
   ▼                      ▼
Hack 硬體（第 5 章）   不同平台的 VM Translator（其他硬體）

VM 之所以叫「虛擬機」，正因為它抽象化了「堆疊機＋八個記憶體段的機器」。同一個 VM 程式，只要換一個平台的 VM Translator，就能跑在完全不同的硬體上——這就是「可移植性」的由來。

1.2 管線總覽

整套流程可以畫成五段：

① 收集 .vm 檔      （單一檔案，或整個目錄的 .vm）
      │
      ▼
② 產生 bootstrap   （初始化 SP，呼叫 Sys.init）
      │
      ▼
③ 逐檔解析         （Parser 讀取每條 VM 指令）
      │
      ▼
④ 逐指令翻譯       （CodeWriter 依指令類型寫出 Hack 組合語言）
      │
      ▼
⑤ 寫出 .asm       （組譯器吃掉 → .hack → 硬體執行）
核心對象只有兩個：**Parser** 與 **CodeWriter**。

2. 劃分粗細：Parser + CodeWriter

Nand2Tetris 的官方 Java 版，以及本節的 Python 版，都把 Translator 切成兩個清晰的責任區：

對象 職責 不知道的事
Parser 讀檔、去除註解與空白、把一行 VM 指令拆成「指令類型與參數」 不知道怎麼翻譯成 Hack
CodeWriter 依指令類型，寫出對應的 Hack 組合語言行 不在乎指令來自哪個檔案

這種「讀取/解析」與「產生/輸出」的分離，是編譯器設計的核心原則——它讓你可以各自獨立測試、獨立替換。

2.1 Parser 的職責

Parser 需要提供：

  • 一次只「注視」一條指令（hasMoreCommands() / advance()）；
  • 判斷當前指令的類型（commandType()）：
    • C_ARITHMETIC：add、sub、neg、eq、gt、lt、and、or、not；
    • C_PUSH：push <segment> <i>；
    • C_POP：pop <segment> <i>；
    • C_LABEL、C_GOTO、C_IF：label / goto / if-goto <symbol>；
    • C_FUNCTION、C_CALL、C_RETURN：function / call / return。
  • 對 push/pop 給出 arg1（segment）與 arg2（index）；
  • 對 label/goto/if-goto/function/call 給出 arg1（symbol/name）；
  • 對算術指令，arg1 就是指令本身。

2.2 CodeWriter 的職責

CodeWriter 需要維護：

  • 目前的輸出檔案（一個 .asm，可能串接多個 .vm）；
  • 目前的函式名 self.function（供 label/goto 加前綴）；
  • 今天的函式連結：label 計數器「目前目錄的 label 計數」。

它的方法一一對應指令類型：

writeArithmetic(cmd)     # add, sub, eq, ...
writePushPop(cmd, seg, i)
writeLabel(label)
writeGoto(label)
writeIf(label)
writeFunction(name, nLocals)
writeCall(name, nArgs)
writeReturn()
writeInit()              # bootstrap
setFileName(name)

設計思路：劃分粗細的另一個好處——CodeWriter 可以跨檔案跨指令重用。第 7 章的算術/記憶體段翻譯、8.1 的控制流、8.2 的函式呼叫，全都匯聚在 CodeWriter 的各個 write* 方法裡，Parser 不須知道細節，只需「分派」。

3. 處理多個 .vm 檔案的整合

真實專案的 VM 常散在數個 .vm 檔（例如 Main.vm、Sys.vm、Math.vm）。Translator 的整合策略：

3.1 輸出一個 .asm

VM Translator 對一個輸入程式（一個目錄或一個檔案）只會產生一個 .asm。它會：

  1. 把所有 .vm 檔依序處理；
  2. 每個 .vm 檔的內容依序翻譯；
  3. 全部寫進同一個 .asm。

3.2 各檔案標籤命名

因為 Hack 標籤必須全域唯一，而聚合後來自不同檔案的 label 可能同名，所以在「目前檔名」與「目前函式名」之外，我們還需要目前目錄的標籤計數器。

慣例的完整命名規則：

元素 規則
函式內部 label / goto / if-goto 目前函式名$VM標籤
call 產生的返回位址 目前函式名$ret.<全域計數器>

3.3 檔案命名約定

輸出 .asm 的名稱，依輸入而定：

  • 輸入是一個目錄時：輸出名 = 目錄名 + .asm（例如 Program 目錄 → Program.asm）；
  • 輸入是單一 .vm 檔時：輸出名 = 該檔名（去掉 .vm）+ .asm（例如 Foo.vm → Foo.asm）。

4. bootstrap code 的產生

在任何 .vm 檔的內容之前，Translator 要先寫入 bootstrap code（見 8.2 節第 5 節）：

@256
D=A
@SP
M=D              // SP = 256
// call Sys.init 0
...（call 的完整序列）...
(Sys.init$ret.0)

為何要放在開頭？

  • 若它是第一個寫出的內容，則 Sys.init 將是整個程式的第一條指令；
  • 這保證 VM 程式「從 Sys.init 執行」，完全不需要作業系統或 loader 來「先執行哪支函式」；
  • SP 設 256 則避開了暫存器區（0–15）與可供裝載器使用的記憶體區（16–255）。

產生順序：writeInit() 先被呼叫一次，接著才逐檔處理各 .vm。

# 主流程中的 bootstrap
writer.writeInit()            # ① bootstrap
for path in vm_files:         # ② 逐檔
    writer.setFileName(path)
    parser = Parser(path)
    while parser.hasMoreCommands():
        ... translate ...
writer.close()                # ③ 關檔

5. 完整可執行的 VMTranslator

以下是把 7、8 章所有規則落成的一支完整 Python Translator。它沿用 6.3 節組譯器「單一檔案、直接可跑」的風格。為求清楚，程式依「CodeWriter → Parser → 主流程」順序撰寫。

#!/usr/bin/env python3
"""
VMTranslator.py —— 將 VM 語言 (.vm) 翻譯為 Hack 組合語言 (.asm)

用法：
    python3 VMTranslator.py Foo.vm        → Foo.asm
    python3 VMTranslator.py ProgDir       → ProgDir.asm（處理目錄內所有 .vm）

架構：Parser（解析單一 .vm）＋ CodeWriter（產生 Hack 組合語言）
"""
import sys, os


# ================= CodeWriter =================

class CodeWriter:
    def __init__(self, output_path):
        self.f = open(output_path, 'w', encoding='utf-8')
        self.filename = None       # 目前 .vm 檔名（不加副檔名）
        self.function = 'Sys.init' # 目前函式名（bootstrap 前暫用）
        self.label_count = 0       # 全域 call 返回位址計數器（每檔平移）
        self.seg_base = {
            'local': 'LCL', 'argument': 'ARG', 'this': 'THIS',
            'that': 'THAT', 'pointer': 'THIS', 'temp': '5',
        }

    def setFileName(self, path):
        self.filename = os.path.basename(path).replace('.vm', '')

    def _out(self, line):
        self.f.write(line + '\n')

    # ---------- 堆疊基本動作 ----------
    def _stack_push_D(self):
        """把 D 暫存子的值推上堆疊"""
        self._out('@SP'); self._out('A=M'); self._out('M=D')
        self._out('@SP'); self._out('M=M+1')

    def _fetch_segment_addr(self, seg, i):
        """把「seg 第 i 個元素的位址」算進 D 暫存子"""
        if seg in ('local', 'argument', 'this', 'that'):
            base = self.seg_base[seg]
            self._out(f'@{base}'); self._out('D=M')
            self._out(f'@{i}');     self._out('D=D+A')
        elif seg == 'pointer':
            self._out(f'@{i}'); self._out('D=A')
            self._out(f'@{self.seg_base[seg]}'); self._out('D=A+D')
        elif seg == 'temp':
            self._out(f'@{i}'); self._out('D=A')
            self._out(f'@{self.seg_base[seg]}'); self._out('D=A+D')
        elif seg == 'static':
            self._out(f'@{self.filename}.{i}'); self._out('D=A')
        elif seg == 'constant':
            self._out(f'@{i}'); self._out('D=A')

    # ---------- 算術 / 邏輯 ----------
    def writeArithmetic(self, cmd):
        # 先完成二元的「把 RAM[SP-2] 的舊值放進 D」的取用
        if cmd in ('add', 'sub', 'and', 'or'):
            self._out('@SP'); self._out('AM=M-1')
            self._out('D=M')               # D = y
            self._out('A=A-1')             # A 指到 x
            m = {'add': 'M=D+M', 'sub': 'M=M-D',
                 'and': 'M=D&M', 'or': 'M=D|M'}[cmd]
            self._out(m)                    # x op y 存回
        elif cmd in ('eq', 'gt', 'lt'):
            self._out('@SP'); self._out('AM=M-1')
            self._out('D=M'); self._out('A=A-1')
            self._out('D=M-D')             # D = x - y
            label_true = f'{self.function}.${self.label_count}'
            self.label_count += 1
            label_end = f'{self.function}.${self.label_count}'
            self.label_count += 1
            jump = {'eq': 'JEQ', 'gt': 'JGT', 'lt': 'JLT'}[cmd]
            self._out(f'@{label_true}'); self._out(f'D;{jump}')
            self._out('@SP'); self._out('A=M-1'); self._out('M=0')
            self._out(f'@{label_end}'); self._out('0;JMP')
            self._out(f'({label_true})')
            self._out('@SP'); self._out('A=M-1'); self._out('M=-1')
            self._out(f'({label_end})')
        elif cmd == 'neg':
            self._out('@SP'); self._out('A=M-1')
            self._out('M=-M')
        elif cmd == 'not':
            self._out('@SP'); self._out('A=M-1')
            self._out('M=!M')

    # ---------- 記憶體段 ----------
    def writePushPop(self, command, seg, index):
        if command == 'push':
            if seg == 'constant':
                self._out(f'@{index}'); self._out('D=A')
            elif seg in ('local', 'argument', 'this', 'that', 'pointer', 'temp'):
                self._fetch_segment_addr(seg, index)
                self._out('A=D'); self._out('D=M')
            elif seg == 'static':
                self._out(f'@{self.filename}.{index}')
                self._out('D=M')
            self._stack_push_D()
        else:  # pop
            # 先算目標位址存 R13
            if seg in ('local', 'argument', 'this', 'that', 'pointer', 'temp', 'static'):
                self._fetch_segment_addr(seg, index)
                self._out('@R13'); self._out('M=D')
                self._out('@SP'); self._out('AM=M-1'); self._out('D=M')
                self._out('@R13'); self._out('A=M'); self._out('M=D')

    # ---------- 控制流（8.1） ----------
    def writeLabel(self, label):
        self._out(f'({self.function}${label})')

    def writeGoto(self, label):
        self._out(f'@{self.function}${label}')
        self._out('0;JMP')

    def writeIf(self, label):
        self._out('@SP'); self._out('AM=M-1'); self._out('D=M')
        self._out(f'@{self.function}${label}')
        self._out('D;JNE')

    # ---------- 函式呼叫（8.2） ----------
    def writeFunction(self, name, nLocals):
        self.function = name
        self._out(f'({name})')
        for _ in range(nLocals):
            self._out('@0'); self._out('D=A')
            self._stack_push_D()

    def writeCall(self, name, nArgs):
        ret = f'{self.function}$ret.{self.label_count}'
        self.label_count += 1
        self._out(f'@{ret}'); self._out('D=A'); self._stack_push_D()   # retAddr
        for base in ('LCL', 'ARG', 'THIS', 'THAT'):                     # frame
            self._out(f'@{base}'); self._out('D=M'); self._stack_push_D()
        self._out('@SP'); self._out('D=M')                              # ARG
        self._out(f'@{5 + nArgs}'); self._out('D=D-A')
        self._out('@ARG'); self._out('M=D')
        self._out('@SP'); self._out('D=M'); self._out('@LCL'); self._out('M=D')
        self._out(f'@{name}'); self._out('0;JMP')                       # 跳進
        self._out(f'({ret})')                                           # 返回位址

    def writeReturn(self):
        self._out('@LCL'); self._out('D=M'); self._out('@R13'); self._out('M=D')  # frame
        self._out('@R13'); self._out('D=M'); self._out('@5'); self._out('A=D-A')
        self._out('D=M'); self._out('@R14'); self._out('M=D')          # retAddr
        self._out('@SP'); self._out('AM=M-1'); self._out('D=M')        # 回傳值
        self._out('@ARG'); self._out('A=M'); self._out('M=D')          # *ARG = 回傳值
        self._out('@ARG'); self._out('D=M+1'); self._out('@SP'); self._out('M=D')
        for off, reg in ((1, 'THAT'), (2, 'THIS'), (3, 'ARG'), (4, 'LCL')):
            self._out('@R13'); self._out('D=M')
            self._out(f'@{off}'); self._out('A=D-A'); self._out('D=M')
            self._out(f'@{reg}'); self._out('M=D')
        self._out('@R14'); self._out('A=M'); self._out('0;JMP')

    def writeInit(self):
        self._out('@256'); self._out('D=A'); self._out('@SP'); self._out('M=D')
        self.writeCall('Sys.init', 0)

    def close(self):
        self.f.close()


# ================= Parser =================

ARITHMETIC = {'add', 'sub', 'neg', 'eq', 'gt', 'lt', 'and', 'or', 'not'}

class Parser:
    def __init__(self, path):
        self.lines = []
        with open(path, 'r', encoding='utf-8') as f:
            for raw in f:
                line = raw.split('//')[0].strip()
                if line:
                    self.lines.append(line)
        self.idx = 0
        self.current = None

    def hasMoreCommands(self):
        return self.idx < len(self.lines)

    def advance(self):
        self.current = self.lines[self.idx]
        self.idx += 1

    def commandType(self):
        first = self.current.split()[0]
        if first in ARITHMETIC:
            return 'C_ARITHMETIC'
        if first == 'push':
            return 'C_PUSH'
        if first == 'pop':
            return 'C_POP'
        if first == 'label':
            return 'C_LABEL'
        if first == 'goto':
            return 'C_GOTO'
        if first == 'if-goto':
            return 'C_IF'
        if first == 'function':
            return 'C_FUNCTION'
        if first == 'call':
            return 'C_CALL'
        if first == 'return':
            return 'C_RETURN'
        raise ValueError(f'未知指令：{self.current}')

    def arg1(self):
        if self.commandType() == 'C_RETURN':
            return None
        parts = self.current.split()
        return parts[1] if len(parts) > 1 else parts[0]

    def arg2(self):
        return int(self.current.split()[2])


# ================= 主流程 =================

def translate(input_path, writer):
    if os.path.isdir(input_path):
        vm_list = sorted(
            os.path.join(input_path, f) for f in os.listdir(input_path)
            if f.endswith('.vm'))
        base = os.path.basename(os.path.abspath(input_path))
        out = os.path.join(input_path, base + '.asm')
    else:
        vm_list = [input_path]
        out = input_path.replace('.vm', '.asm')
    writer = CodeWriter(out)
    writer.writeInit()                     # bootstrap 在最前面
    for vm in vm_list:
        writer.setFileName(vm)
        parser = Parser(vm)
        while parser.hasMoreCommands():
            parser.advance()
            t = parser.commandType()
            if t == 'C_ARITHMETIC':
                writer.writeArithmetic(parser.current)
            elif t in ('C_PUSH', 'C_POP'):
                command = parser.commandType()
                writer.writePushPop(
                    'push' if t == 'C_PUSH' else 'pop',
                    parser.arg1(), parser.arg2())
            elif t == 'C_LABEL':
                writer.writeLabel(parser.arg1())
            elif t == 'C_GOTO':
                writer.writeGoto(parser.arg1())
            elif t == 'C_IF':
                writer.writeIf(parser.arg1())
            elif t == 'C_FUNCTION':
                writer.writeFunction(parser.arg1(), parser.arg2())
            elif t == 'C_CALL':
                writer.writeCall(parser.arg1(), parser.arg2())
            elif t == 'C_RETURN':
                writer.writeReturn()
    writer.close()
    print(f'{len(vm_list)} 個 .vm → {out}')
    return out


if __name__ == '__main__':
    if len(sys.argv) != 2:
        print('用法：python3 VMTranslator.py <Foo.vm 或 目錄>')
        sys.exit(1)
    translate(sys.argv[1], None)

設計思路：請特別注意 label_count 如何被「算術比較」與「call 返回位址」共用——它是一個全域遞增計數器，保證任何生成的唯一標籤都不會撞名。比較（eq/gt/lt）用它產生 foo$.0、foo$.1 這類暫時標籤，call 用它產生 foo$ret.2 等，通通落在同一個「不會與任何標籤/變數衝突」的命名空間。

6. 如何用 VM 模擬器測試

有了 Translator，接下來要證明它「真的會跑」。

6.1 測試用的 VM 程式

我們用一支結果可心算的程式當測試樣本，沿用第 6.4 節的「已知答案」哲學。寫一個會用函式呼叫與迴圈的 Main.vm：計算一個函式 square(x) = x * x，並呼叫多次：

// Main.vm

push constant 0
return
function Main.square 0      // 參數 0 = x
push argument 0
push argument 0
call Math.multiply 2        // x * x

7. 常見錯誤與除錯

無論架構多漂亮，第一次跑幾乎都會撞牆。以下是最高頻的錯誤與解法。

7.1 錯誤一：frame / 指標沒初始化（最常見）

症狀：空指標、奇異的 loop、Sys.init 沒被呼叫就亂跑。 根源：忘了 writeInit()，或 SP 沒有設 256。 除錯法：檢查 .asm 前幾行是否為 @256 / D=A / @SP / M=D。任何 push 之前都必須已定義 SP、LCL、ARG、THIS、THAT。

7.2 錯誤二：local 段沒歸零

症狀：函式的 local 值「莫名其妙有舊資料」。 根源：writeFunction 忘了把 nLocal 個 0 推上堆疊。 除錯法：找 (foo) 標籤之後，應緊跟 nLocal 組「@0 / D=A / @SP / A=M / M=D / @SP / M=M+1」。

7.3 錯誤三：return 順序錯（回傳值搬移與 SP 設定）

症狀：回傳值不見、或返回後 SP 錯位。 根源：在「還原 SP」之後才搬回傳值（次序顛倒），或忘了 M=D。 除錯法：對照 8.3 節第 3.3 節——「先 *ARG=pop()，後 SP=ARG+1」，順序不可顛倒。

7.4 錯誤四：frame 元素還原錯偏移

症狀：這個函式返回後，caller 的 THIS/THAT/ARG 亂掉。 根源：還原時偏移算錯（例如把 THAT 讀成 THIS）。frame 由下而上：frame-1=THAT、frame-2=THIS、frame-3=ARG、frame-4=LCL。 除錯法：把 8.3 節的 frame 佈局表貼在眼前，逐一對照 A=D-A 與目標暫存器。

7.5 錯誤五：label 撞名

症狀：不同函式的同名 label 跳到同一處。 根源：翻譯 label/goto/if-goto 時沒加函式名前綴。 除錯法：確認 writeLabel/writeGoto/writeIf 都使用 self.function$...。

7.6 錯誤六：算術比較（eq/gt/lt）用錯跳躍

症狀：eq/gt/lt 結果永遠為 0 或 -1。 根源：D;JEQ 等條件寫反，或 -1（真）與 0（假）的「true/false」約定沒遵守。Nand2Tetris 的約定是 真 = -1（所有位元為 1）、假 = 0。 除錯法：驗證 push constant 3; push constant 3; eq 應得 -1（且堆疊剩一個元素）。

7.7 除錯心法總表

症狀 優先懷疑 快查方法
開頭就亂跑 無 bootstrap / SP 未設 看 .asm 前幾行
local 有舊值 function 沒歸零 看 (foo) 後幾行
回傳值消失 return 搬移順序 檢查 *ARG=pop 與 SP=ARG+1 次序
THIS/THAT 亂 frame 偏移錯 對照 frame 佈局表
跳錯地方 label 沒加前綴 搜 $ 是否出現在每個 label
相等比較錯 true/false 約定 測 eq→ -1、ne→ 0

8. 本章小結

  • VM Translator 的架構是 Parser + CodeWriter：Parser 解析 .vm，CodeWriter 依指令種類生成 Hack 組合語言。
  • 多個 .vm 檔會被整合成單一 .asm，輸出名取決於輸入是目錄還是檔案。
  • bootstrap code 永遠放在最前：初始化 SP=256 並 call Sys.init 0，這是整個程式的起點。
  • 完整可執行的 Python VMTranslator 約 250 行即可完成整條管線：算術、記憶體段、控制流、函式呼叫、bootstrap。
  • 唯一標籤由「函式名 + $ + 全域計數器」產生，一次性解決 label 與 call 返回位址的撞名問題。
  • 測試要走完整鏈路：.vm → .asm → .hack → CPU 模擬器，用「結果可心算」的程式當樣本，VM Emulator 只當對照組。
  • 常見六大類錯誤：指標未初始化、local 未歸零、return 順序、frame 偏移、label 撞名、真值約定——各有對應快查法。
