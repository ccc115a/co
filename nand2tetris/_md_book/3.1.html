第 3.1 章：觸發器（D Flip-Flop）—— 引入時間與狀態

前言

在前兩章中，我們從最基本的 NAND 閘出發，一路建構出 ALU 等組合邏輯電路。組合邏輯電路有一個關鍵特性：輸出僅取決於當前的輸入，不具備任何「記憶」能力。然而，一個真正的電腦必須能夠「記住」東西——暫存中間運算結果、追蹤程式執行到哪一行、保存變數的值。這一切都需要一種全新的電路元件：能够保留狀態的記憶單元。

本章將介紹計算機系統中最底層、最關鍵的元件——D 觸發器（D Flip-Flop，簡稱 DFF）。它是整個電腦記憶體層級的基石，從 1-bit 暫存器到數 GB 的主記憶體，最終都建構在 DFF 之上。理解 DFF，就是理解電腦如何從「無狀態的邏輯閘」蜕變為「有狀態的計算機」。

3.1.1 為何需要記憶：組合邏輯 vs 時序邏輯

組合邏輯的侷限

回顧我們已經設計過的元件：NAND 閘、NOT、AND、OR、Mux、Adder、ALU……它們都有一個共同特點：

輸入 → [組合邏輯電路] → 輸出

無論輸入如何變化，輸出都會即時跟隨改變（忽略極微小的傳播延遲）。這意味著：

  • 電路沒有「記住」先前輸入的能力
  • 一旦輸入消失，輸出立即回到由當前輸入決定的值
  • 無法保存任何「狀態」資訊

舉個例子，假設我們用 NAND 閘搭建了一個 XOR 閘：

A = 1, B = 0 → Output = 1
A = 0, B = 0 → Output = 0  ← 輸出立即改變，不記得「曾經是 1」

時序邏輯的突破

電腦需要「記住」資料。例如：

  • 暫存器需要保留被寫入的值，直到下次被覆寫
  • RAM 需要保存資料，即使電路的其他部分在運作
  • 程式計數器需要追蹤目前執行到哪一行指令

這些需求催生了**時序邏輯（Sequential Logic）**電路。時序邏輯的輸出同時取決於：

  1. 當前的輸入
  2. 先前的狀態（歷史資訊）
                    ┌──────────────┐
輸入 ──────────────→│              │
                    │  時序邏輯電路  │──→ 輸出
先前狀態 ──┐       │              │
           │       └──────────────┘
           └─────────────────────────┘
              （透過記憶單元回饋）

狀態的本質

「狀態（State）」是系統在某一時刻的完整描述。對於一個電路而言，狀態就是所有記憶單元中儲存的值。兩個電路即使接收相同的輸入，如果內部狀態不同，也可能產生不同的輸出——這正是電腦能執行不同程式、處理不同資料的原因。

3.1.2 時脈（Clock）概念

為什麼需要時脈？

在時序電路中，如果讓記憶單元「隨時」更新狀態，會產生嚴重的問題：

  1. 不穩定（Instability）：輸出改變可能反饋到輸入，導致連鎖反應
  2. 競態條件（Race Condition）：多個記憶單元同時更新時，更新順序不確定
  3. 時序不可預測：難以保證所有資料在同一時間準備就緒

解法是引入一個全局的節拍器——時脈（Clock）。時脈是一個在 0 和 1 之間規律振盪的信號：

時脈信號（Clock）：

    ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐
    │  │  │  │  │  │  │  │  │  │
────┘  └──┘  └──┘  └──┘  └──┘  └──

    ↑      ↑      ↑      ↑      ↑
  第1週期  第2週期  第3週期  第4週期  第5週期

邊緣觸發（Edge Triggering）

nand2tetris 採用正緣觸發（Rising Edge Triggering）：記憶單元只在時脈信號從 0 變為 1 的上升沿那一瞬間更新狀態。

時脈：     ──┐  ┌──┐  ┌──┐  ┌──
             │  │  │  │  │  │
         ────┘  └──┘  └──┘  └──

觸發點：      ↑           ↑
            邊緣1        邊緣2
          （在此瞬間
          更新狀態）

在觸發點之外的所有時間，記憶單元鎖住當前的值，不受輸入變化的影響。這就是「同步」的意義——所有狀態更新都在統一的時脈節拍下發生。

一個直覺類比

想像一個房間裡有一面鏡子（狀態）和一台攝影機（時脈）：

  • 攝影機不按快門時：鏡子前的人可以隨意走動、改變姿勢（輸入變化）
  • 攝影機按下快門的瞬間：鏡子前的影像被「定格」並記錄下來（狀態更新）
  • 之後：記錄下的影像不隨人的移動而改變（狀態保持）

3.1.3 D Flip-Flop 的運作原理

DFF 的介面

D 觸發器（D Flip-Flop）是 nand2tetris 架構中最底層的記憶元件，它只有兩個接腳：

        ┌─────────┐
  D ────│         │──── Q
        │  DFF    │
 clk ───│         │
        └─────────┘

D：資料輸入（Data Input）
Q：資料輸出（Output）
clk：時脈信號（Clock）——由系統全局提供，內部隱含連接

DFF 的行為

DFF 的功能極其簡單，卻至關重要：

在時脈上升沿，將輸入 D 的值複製到輸出 Q；其餘時間 Q 保持不變。

用公式表示：

Q(t+1) = D(t)    （在時脈上升沿時）
Q(t+1) = Q(t)    （其餘時間）

時序圖

以下時序圖展示了 DFF 在不同輸入下的行為：

時脈 clk  : ──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──
             │  │  │  │  │  │  │  │  │  │  │  │
         ────┘  └──┘  └──┘  └──┘  └──┘  └──┘  └──

資料輸入 D : ────────┐                    ┌──────────
                     │                    │
                     └────────────────────┘
                     （D=0 持續一段時間後變為 1）

輸出 Q    : ──┐        ┌─────────────────────
             │        │
         ────┘  ┌─────┘
         初始=0 │ ← 上升沿2：D=0，Q 保持 0
               ← 上升沿1：D=1，Q 變為 1
                                          ← 上升沿3：D=1，Q 保持 1

關鍵觀察

  1. Q 只在上升沿改變：即使 D 在非觸發時刻劇烈變化，Q 也無動於衷
  2. Q 總是「慢一拍」追蹤 D：D 的值在上升沿被「鎖存」，下一個上升沿才反映到 Q
  3. DFF 是原子操作：不論其內部多麼複雜（在 nand2tetris 中假設為原子元件），它的行為完全由 D 和時脈決定

3.1.4 暫存器需要暫存資料的能力

為什麼暫存器必須具備「保持」能力？

暫存器（Register）是 CPU 中用來暫存運算資料的高速記憶單元。考慮以下場景：

場景：加法運算

LOAD  R1, 5      ; 將 5 載入暫存器 R1
LOAD  R2, 3      ; 將 3 載入暫存器 R2
ADD   R3, R1, R2 ; R3 = R1 + R2

在執行第三條指令時，R1 和 R2 必須仍然保持著 5 和 3。如果暫存器沒有「保持」能力，那麼在執行第二條指令時，R1 的值就會消失。

Mux 的局限

你可能會想：「我們之前不是用 Mux 做過選擇嗎？」沒錯，但 Mux 只能選擇某個輸入，它不具備保存輸出的能力。暫存器需要的是一種特殊的機制：

                 ┌─────────────┐
新資料 ─────────→│             │──→ 輸出（必須保持）
                 │  暫存器     │
指令控制 ───────→│  load=0 時   │
                 │  保持舊值    │
                 └─────────────┘
  • 當 load = 1 時，接受新資料
  • 當 load = 0 時，保持舊資料不變

這種「有條件地更新」的能力，正是 DFF 與 Mux 搭配後所能提供的——這正是下一章（3.2）要實現的 Bit 元件。

3.1.5 DFF 在 nand2tetris 中作為最底層元件

原語（Primitive）的哲學

nand2tetris 的設計哲學是一層一層地抽象：

NAND 閘
  └→ 各種邏輯閘（NOT, AND, OR, XOR...）
       └→ 組合邏輯元件（Mux, Adder, ALU...）
            └→ 【DFF】← 時序邏輯的起點
                 └→ Bit（1-bit 暫存器）
                      └→ Register（16-bit 暫存器）
                           └→ RAM8 / RAM64 / ... / RAM16K
                                └→ 程式計數器（PC）

DFF 是組合邏輯世界與時序邏輯世界的分水嶺：

特性 組合邏輯元件 DFF
有記憶 否 是
依賴時脈 否 是
輸出取決於 當前輸入 當前輸入 + 過去狀態
nand2tetris 中 用 NAND 閘建構 假設為原子元件

DFF 被假設為已存在

在 nand2tetris 的硬體模擬器（Hardware Simulator）中，DFF 是一個內建的原子元件（Primitive），你不需要用 NAND 閘去實現它。它的存在是整個時序邏輯體系的公理——就像歐幾里得幾何中的公設一樣。

你不需要理解 DFF 的內部實現，只需要理解它的行為規範。

這就像你不需要理解電晶體的量子力學，就能使用 NAND 閘一樣。每一層抽象都建立在對下一層的「信任」之上。

3.1.6 時序圖說明與完整範例

完整的 DFF 操作範例

以下展示 DFF 在連續多個時脈週期中的行為：

        T0    T1    T2    T3    T4    T5    T6
        │     │     │     │     │     │     │

clk  : ─┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──
        │  │  │  │  │  │  │  │  │  │  │  │  │  │
    ────┘  └──┘  └──┘  └──┘  └──┘  └──┘  └──┘  └──

D    : ──────────┐              ┌──────────────────
        1       0              1
                  └──────────────┘

Q    : ──┐        ┌──────────────┐
        0 1      1              0
         ↑        ↑              ↑
       T0沿     T1沿          T3沿
       D=1→Q=1  D=0→Q=0      D=0→Q 保持 0
                                   （注意：T3沿時 D 仍為 0）

逐週期分析：

時脈邊緣 當時 D 的值 Q 的新值 說明
T0 上升沿 1 1 D=1，Q 從 0 變為 1
T1 上升沿 0 0 D=0，Q 從 1 變為 0
T2 上升沿 0 0 D=0，Q 保持 0
T3 上升沿 1 1 D=1，Q 從 0 變為 1

與組合邏輯的對比

如果同樣的 D 信號接在一個直接連通的導線上（無 DFF）：

D    : ──────────┐              ┌──────────────────
                  └──────────────┘

Output（無 DFF）: ──────────┐              ┌──────
                  直接跟隨 D 的變化

輸出會在 D 變化的瞬間就改變——沒有任何「鎖存」的效果。這就是 DFF 的價值所在。

本章小結

本章介紹了從組合邏輯邁向時序邏輯的關鍵一步——D 觸發器（DFF）。以下是核心要點：

  1. 組合邏輯無法記憶：輸出完全由當前輸入決定，不保留歷史資訊
  2. 時序邏輯引入狀態：透過記憶單元，電路可以「記住」過去的資訊
  3. 時脈是同步的基石：統一的時脈信號確保所有狀態更新在同一節奏下進行
  4. DFF 是最底層的記憶元件：
    • 在時脈上升沿鎖存輸入 D 的值到輸出 Q
    • 其餘時間 Q 保持不變
    • 在 nand2tetris 中被視為原子元件（Primitive）
  5. DFF 是暫存器的基礎：結合 Mux 與 DFF，即可建構具有「載入/保持」功能的暫存器

在下一章（3.2）中，我們將利用 DFF 搭配 Mux，建構出完整的 1-bit 暫存器（Bit）和 16-bit 暫存器（Register），正式進入暫存器的設計世界。
