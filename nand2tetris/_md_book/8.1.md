# 8.1 控制流翻譯：條件與無條件跳躍（goto / if-goto）

## 學習目標

讀完本節後，你應該能：

- 說出 VM 語言中 `label`、`goto`、`if-goto` 三指令各自的功能
- 說明 `if-goto` 的常見陷阱：要「先 pop、後判斷」的堆疊順序
- 把三個控制流指令翻譯成 Hack 的 A-指令與跳躍指令
- 用「函式名前綴」的技巧解決全域 label 命名衝突
- 完成一支「VM → Hack」的完整控制流翻譯範例

---

## 前言

第 7 章的 VM 程式是**由上往下流水式**執行的：指令一條接一條，沒有繞路的本事。但真實的程式絕不這樣單調——迴圈、條件分支、巢狀判斷，全都建立在「把執行點跳來跳去」的能力上。

本節把這種能力加進 VM 語言：`label`（貼標籤）、`goto`（無條件跳到標籤）、`if-goto`（符合條件才跳）。別小看這三條，它們是所有高階語言的 `if` / `while` / `for` 底下的骨架。更關鍵的是，它們在 Hack 上幾乎是「一比一」的翻譯——除了命名衝突這一顆地雷。

---

## 1. VM 的三個控制流指令

VM 語言在第 7 章已有了堆疊與算術的指令。本節新增三個「程序控制」指令，它們的規格非常簡單：

| VM 指令 | 語法 | 功能 |
|---------|------|------|
| `label` | `label <符號>` | 在目前位置宣告一個標籤，供跳轉目標使用 |
| `goto` | `goto <符號>` | 無條件跳轉到該標籤 |
| `if-goto` | `if-goto <符號>` | 從堆疊彈出一個值，若非零就跳轉到該標籤 |

### 1.1 label：只貼標籤，不執行任何動作

`label abc` 只是「在這裡留一個記號」，本身不產生任何運算。它的作用永遠只有一個：**成為 `goto` 與 `if-goto` 的跳躍目標**。

```vm
label LOOP_START      // 宣告一個標籤，指出接下來的位址
push constant 1
...
```

### 1.2 goto：無條件跳躍

`goto LOOP_START` 的意思是：「不管發生什麼事，執行位置直接移到 `LOOP_START` 那條指令之後」。對應到 Hack，就是一條無條件跳躍的 C-指令。

### 1.3 if-goto：條件跳躍（重點！）

`if-goto LOOP_END` 的完整語意是：

1. **先從堆疊彈出一個值**（pop）；
2. 把這個值寫進一個暫存（D）；
3. 若該值**非零**，跳轉到 `LOOP_END`；
4. 若該值為零，什麼都不做，繼續下一條指令。

> **設計思維（關鍵陷阱）**：`if-goto` 的判斷值是「從堆疊上彈下來的」，不是直接以 `RAM[SP-1]` 為準。所以翻譯時**一定要執行一次 pop**——即使你只是「讀一眼」那個值。翻譯錯了就會出現「堆疊永遠多一層」的隱形 bug。

## 2. 翻譯成 Hack 的 A-指令與跳躍指令

Hack 在 4.2 節已經有完整的跳躍機制：

- **A-指令** `@Symbol`：把 Symbol（或常數位址）載入 A 暫存器，同時設定跳躍目標；
- **C-指令** `D;JGT`：以 D 暫存器的值為條件，決定是否跳到 A 暫存器所指的位址。

### 2.1 翻譯 goto

`goto XXX` 的翻譯，就是「把 A 設為標籤位址，再無條件跳過去」：

```asm
// goto XXX
@XXX            // A = 標籤位址
0;JMP           // 無條件跳到 A 所指處
```

`0;JMP` 的 comp 是常數 `0`（永遠不為「跳躍條件」所困），jump 是 `JMP`（無條件），所以無論如何都會跳。

### 2.2 翻譯 if-goto

`if-goto XXX` 的翻譯，就是要「先 pop 一個值到 D，再條件跳躍」：

```asm
// if-goto XXX（先 pop，後判斷；非零才跳）
@SP
M=M-1           // SP--（準備 pop）
A=M             // A = 現在 SP 指到的位置
D=M             // D = 剛彈出的值（RAM[SP]）
@XXX            // A = 標籤位址
D;JNE           // 若 D ≠ 0（非零）→ 跳到 XXX
```

翻譯的步驟拆開看：

1. `@SP / M=M-1`：把堆疊指標往下移一格（這一格就是剛被彈出的元素）；
2. `A=M`：讓 A 指向「剛被 pop 出來的值」所在的位置；
3. `D=M`：把那個值讀進 D —— **等於完成了 pop**；
4. `@XXX`：設定跳躍目標；
5. `D;JNE`：D 非零才跳（JNE 就是「不等於零」就跳，正好對應 VM 的「非零即跳」）。

> **設計思路**：VM 的 `if-goto` 用的是「非零跳」，Hack 的 `JNE` 也是「不等於零跳」，兩者語意完全一致，所以不須做任何數值轉換，直接「先 pop 到 D、再用 JNE」就完成。

### 2.3 翻譯 label

`label XXX` 在 Hack 上，其實就是一個「符號宣告」：

```asm
// label XXX
(XXX)          // Hack 的標籤宣告
```

它不佔任何指令列，只是告訴組譯器「標籤 XXX = 接下來那一列指令的位址」，這正是 6.2 節處理 `(LOOP)` 時的規則。

## 3. 符號唯一的藝術：函式名前綴

現在遇到最大的坑：**VM 的全域標籤與 Hack 的全域標籤不同**。

在 VM 世界裡，一個程式可能由很多函式組成，每個函式內部都可能有自己的迴圈。如果編譯器把每個函式的 `while` 都翻譯成同名的 `label LOOP`，那 Hack 檔案裡就會出現好幾個 `(LOOP)`——組譯器會把同名標籤全部對應到**同一個位址**，程式亂成一團。

Hack 的標籤**全域且必須唯一**。解法很優雅：**在每個 VM label 前面加上「函式名稱」前綴**。

### 3.1 命名規則

- 假設目前正處理的函式叫 `foo`；
- VM 語言見到 `label bar`，翻譯成 Hack 標籤 `foo$bar`；
- 這樣每個函式內部的標籤都不同名，就不會碰撞。

例如：

| 所在函式 | VM 指令 | 翻譯成 Hack 標籤 |
|----------|---------|------------------|
| `foo` | `label LOOP` | `(foo$LOOP)` |
| `main` | `label LOOP` | `(main$LOOP)` |
| `compute` | `label END` | `(compute$END)` |

`foo$LOOP` 與 `main$LOOP` 雖然 VM 都叫 `LOOP`，但翻譯後完全不同名，天下太平。

> **設計思維**：其實不只「函式內部同名迴圈」會衝突，只要程式規模稍大，像 `label END` 這種通用名字幾乎必然重複。把函式名前綴當成「強制規則」而不是「有時需要」，是最省心的做法——**一律加前綴，永遠不會錯**。

### 3.2 在翻譯時如何得知「目前函式」

翻譯器在處理 VM 指令時，需要追蹤「目前函式名」。這在 8.2 節碰到 `function` 指令時會真正建立起來；本節先透露機制：**CodeWriter 維護一個 `current_function` 字串變數**，每次遇到 `function foo` 就更新為 `foo`，之後所有 label/goto 都套用這個前綴。

```python
self.function = "foo"          # 目前所在函式
def writeLabel(self, label):
    line = "(" + self.function + "$" + label + ")"
    self.output(line)
def writeGoto(self, label):
    self.output("@" + self.function + "$" + label)
    self.output("0;JMP")
def writeIf(self, label):
    self.output("@SP")
    self.output("M=M-1")
    self.output("A=M")
    self.output("D=M")
    self.output("@" + self.function + "$" + label)
    self.output("D;JNE")
```

## 4. 完整翻譯範例：VM → Hack

把上述知識合起來，看一支真實範例。假設函式叫 `main`，內容是一個「從 5 倒數到 1、每次印出數字」的迴圈：

```vm
// main 函式（以某種方式被呼叫後進入）
push constant 5
pop local 0
label LOOP
push local 0
if-goto END
push local 0
// （呼叫 output 印出，此處省略具體 call）
push local 0
push constant 1
sub
pop local 0
goto LOOP
label END
```

思考流程：

- `label LOOP` → Hack 標籤 `(main$LOOP)`；
- `if-goto END` → 先 pop 一個值（這裡是 `local 0` 的內容），非零跳 `main$END`；
- `goto LOOP` → 無條件跳 `main$LOOP`。

### 4.1 逐段翻譯對照

前面幾行先建立迴圈的控制變數：

| VM | Hack |
|----|------|
| `push constant 5` | `@5`<br>`D=A`<br>`@SP`<br>`A=M`<br>`M=D`<br>`@SP`<br>`M=M+1` |
| `pop local 0` | `@LCL`<br>`D=M`<br>`@0`<br>`D=D+A`<br>`@R13`<br>`M=D`<br>`@SP`<br>`AM=M-1`<br>`D=M`<br>`@R13`<br>`A=M`<br>`M=D` |
| `label LOOP` | `(main$LOOP)` |

關於 `pop local 0` 的翻譯（第 7 章的記憶體段規則）：local 段以 `LCL` 為基底，偏移 `0`，所以目標位址 = `LCL + 0`。要「先算好目標位址、再 pop」，於是先把它暫存到臨時暫存器 `R13`，接著才把 SP 減一並把值寫進 `R13` 所指處。

### 4.2 完整的 Hack 輸出

整段 `main` 的翻譯結果如下（從「建立迴圈」到迴圈結束，去掉印出細節）：

```asm
@5
D=A
@SP
A=M
M=D
@SP
M=M+1
@LCL
D=M
@0
D=D+A
@R13
M=D
@SP
AM=M-1
D=M
@R13
A=M
M=D
(main$LOOP)
@LCL
D=M
@0
A=D+A
D=M
@SP
A=M
M=D
@SP
M=M+1
@SP
AM=M-1
D=M
@main$END
D;JNE
@LCL
D=M
@0
A=D+A
D=M
@SP
A=M
M=D
@SP
M=M+1
...
@LCL
D=M
@0
D=D+A
@R13
M=D
@SP
AM=M-1
D=M
@R13
A=M
M=D
@main$LOOP
0;JMP
(main$END)
```

注意三條控制流指令各自在 Hack 上的落腳點：

| VM 指令 | Hack 對應 |
|---------|-----------|
| `label LOOP` | `(main$LOOP)` |
| `if-goto END` | `... D=M`（pop 到 D）→ `@main$END` → `D;JNE` |
| `goto LOOP` | `@main$LOOP` → `0;JMP` |

跳轉目標完全用 `main$` 前綴區隔，即使別支函式也有 `END`、`LOOP` 標籤，也能互不干擾。

> **設計思路**：留意 `if-goto` 那幾行——`@SP / AM=M-1 / D=M`。`AM=M-1` 一次做了兩件事：把 SP 減一「且」讓 A 同時指到新位置。這就是「把 pop 過的值放進 D」的標準寫法。把它背熟，它會在第 8 章接下來的每一個條件判斷裡不斷出現。

## 5. 設計思路與實作步驟總整理

把「控制流翻譯」整個流程濃縮成拍板定案的三步：

### 5.1 步驟一：先決定標籤命名空間

正式寫 CodeWriter 前，先立下鐵律：

```
Hack 標籤 = 目前函式名 + "$" + VM 標籤名
```

### 5.2 步驟二：寫三支翻譯函式

每個函式只做「把 VM 控制流指令變成 Hack 幾行」，不含任何高階邏輯：

```python
def writeLabel(self, label):  # label → (fn$label)
def writeGoto(self, label):   # goto → @fn$label / 0;JMP
def writeIf(self, label):     # if-goto → pop to D / @fn$label / D;JNE
```

### 5.3 步驟三：追蹤目前函式名

在 CodeWriter 中維護 `self.function`，於每個 `function` 指令處更新，三支翻譯函式都讀它來加前綴。

> **設計思路**：把「命名唯一性」的責任完全交給 CodeWriter，VM 程式設計師完全不必擔心名字衝突。這是編譯器設計的重要理念——**複雜度交由工具承擔，使用者的介面保持乾淨**。

## 6. 本章小結

- VM 增加三支程序控制指令：`label`（宣告）、`goto`（無條件跳）、`if-goto`（條件跳）。
- `if-goto` 的規格是「**先 pop 一個值到 D，非零才跳**」——翻譯時務必執行一次真正的 pop，不可只讀。
- `goto` 翻譯成 `@XXX` ＋ `0;JMP`；`if-goto` 翻譯成「pop 到 D」＋ `@XXX` ＋ `D;JNE`；`label` 翻譯成 `(XXX)`。
- **函式名前綴**（`函式名$標籤名`）是解決 Hack 全域標籤衝突的標準手法，CodeWriter 追蹤目前函式名來自動套用。
- 三支翻譯函式各自獨立、極簡，為 8.2 節的 `function` / `call` / `return` 打好了基礎。

真正的「跳來跳去」只是讓程式**有了迴圈與分支**，但頂多算是「忍者摺紙」。下一節，我們把最重要的東西端上桌——**函式呼叫**。沒有它，程式永遠只是一條平鋪的直線。
