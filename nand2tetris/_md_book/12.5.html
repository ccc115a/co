12.5 系統基礎：String, Array, Sys

學習目標

讀完本節後，你應該能：

  • 說明 String 類別：字串在記憶體中如何表示、有哪些操作（length、charAt、setCharAt、appendChar、eraseLastChar、intValue、setInt）
  • 說明整數與字串的互轉（intValue、setInt）如何用除法實作
  • 說明字串連接（append）的原理，以及與 Output 的關係

前言

到目前為止，我們寫了 Math（數學）、Memory（記憶體）、Screen（繪圖）、Output（文字）、Keyboard（輸入）。但還有三樣「系統地基」沒搞定：

  1. String：Jack 程式中無處不在的字串，究竟在記憶體裡怎麼存放？怎麼連結、怎麼跟數字互換？
  2. Array：Jack 的陣列——Array.new(n) 到底是怎麼「生出」一段連續記憶體的？用完要怎麼還？
  3. Sys：整個系統的主控者——電腦開機從哪裡執行？如何停止？如何「等一秒」？

本節我們把它們一次補齊。寫完這三個類別，加上前四節的 Math、Memory、Screen、Output、Keyboard，整個 Nand2Tetris 的作業系統就完工了。屆時「從邏輯閘到能玩 Tetris 的完整電腦系統」的最後一塊拼圖——作業系統——就位。

1. String 類別：字串的表示與操作

1.1 字串在記憶體中怎麼表示

在 Jack 中，一個 String 物件的本質是：

  • 一段連續記憶體緩衝區（用來存字元）；
  • 加上幾個「控制欄位」：字串目前長度（length）、緩衝區容量（maxLength）。

以作業系統實作的角度看，String 物件內部用一個 Array 存放字元（每個字元是一個 0..127 的整數，即 ASCII），再加上長度與容量兩個欄位。示意：

String 物件（配置在 heap 記憶體）：
┌─────────────┬─────────────┬──────────────────────────┐
│ 長度 length  │ 容量 maxLen  │ 字元緩衝區 data[]          │
│ (欄位)       │ (欄位)       │ data[0..length-1]         │
└─────────────┴─────────────┴──────────────────────────┘

每當「append 一個字元」且尚未超過 maxLen，就寫入 data[length] 並把 length 加 1。超過容量則忽略或截斷。

1.2 String API

方法 簽名 功能說明
new String.new(int maxLen) → String 建立一個容量為 maxLen 的空字串
length String.length() → int 回傳目前字元數
charAt String.charAt(int j) → char 回傳第 j 個字元
setCharAt String.setCharAt(int j, char c) 把第 j 個字元設為 c
appendChar String.appendChar(char c) → String 在字串尾端添加字元 c，回傳自己
eraseLastChar String.eraseLastChar() → String 刪除最後一個字元，回傳自己
intValue String.intValue() → int 把字串解析成整數（如 "-42" → -42）
setInt String.setInt(int n) 把整數 n 轉成其十進位字串存入自己
dispose String.dispose() 釋放字串佔用的記憶體

1.3 String 與 Output 的關係

Output.printString(s) 就是「逐一 charAt 每個字元、再 printChar 印出」。Keyboard.readLine 則把讀到的字元一一 appendChar 組成字串。所以：

String 是「在記憶體中存放文字的容器」，Output 是「把 String 顯示到螢幕的通道」，Keyboard 是「把鍵盤輸入累積成 String 的來源」。三者合作，完成「文字的儲存、顯示與輸入」。

1.4 完整 String.jack

下面是一個可運作的 String.jack。它使用 Array.new（見下節）存放字元緩衝區，並用欄位 str（緩衝區陣列）、maxLength、length 管理。

// String.jack —— 字串類別
class String {

    field Array str;        // 字元緩衝區
    field int maxLength;    // 容量上限
    field int length;       // 目前字元數

    // 建構子：建立容量 maxLen 的空字串
    constructor String new(int maxLen) {
        let maxLength = maxLen;
        let length = 0;
        let str = Array.new(maxLen);
        return this;
    }

    // 回傳目前長度
    method int length() {
        return length;
    }

    // 回傳第 j 個字元
    method char charAt(int j) {
        return str[j];
    }

    // 設定第 j 個字元
    method void setCharAt(int j, char c) {
        let str[j] = c;
        return;
    }

    // 在尾端添加字元
    method String appendChar(char c) {
        if (length < maxLength) {
            let str[length] = c;
            let length = length + 1;
        }
        return this;
    }

    // 刪除最後一個字元
    method String eraseLastChar() {
        if (length > 0) {
            let length = length - 1;
        }
        return this;
    }

    // 把字串解析成整數
    method int intValue() {
        var int i, n, val;
        var boolean neg;
        let i = 0;
        let n = 0;
        let val = 0;
        let neg = false;
        if (length > 0) {
            if (str[0] = 45) {        // '-'
                let neg = true;
                let i = 1;
            }
            while (i < length) {
                let n = str[i] - 48;      // 字元減 '0'
                let val = val * 10 + n;
                let i = i + 1;
            }
            if (neg) { let val = -val; }
        }
        return val;
    }

    // 把整數寫成字串（十進位）
    method void setInt(int n) {
        var int i, digit, pow;
        var boolean neg;

        let neg = false;
        if (n < 0) {
            let neg = true;
            // 避免最小值取負溢位，此處先以一般情況示範
            let n = -n;
        }

        // 求得最高位權重
        let pow = 1;
        let i = n;
        while (i >= 10) {
            let pow = pow * 10;
            let i = i / 10;
        }

        // 先清空目前字串（length 歸 0；保留緩衝區）
        let length = 0;
        if (neg) {
            let str[length] = 45;     // '-'
            let length = length + 1;
        }

        // 逐位轉字元存入
        while (pow > 0) {
            let digit = n / pow;
            let str[length] = digit + 48;
            let length = length + 1;
            let n = n - digit * pow;
            let pow = pow / 10;
        }
        return;
    }

    // 釋放記憶體
    method void dispose() {
        do str.dispose();
        do Memory.dealloc(this);
        return;
    }
}

設計思路：setInt / intValue 是一對「互逆」的轉換。intValue 讀「字元→數字→累加（×10）」，setInt 用除法逐位把數字的十進位寫成字元（+48）。兩者都依賴 Math 的除法 (/)，再次體現 OS 內部的依賴鏈。

2. Array 類別：陣列的建立與生命週期

2.1 Array 是什麼

Jack 的 Array 本質上就是一塊連續記憶體，透過 Pointer/THIS 機制間接定址。Array.new(size) 就是向 Memory.alloc 取得一塊 size 字的連續空間，並回傳它的起始位址。

Jack 語言規定：Array.new 與 Array.dispose 是 OS 必須提供的、與語言綁定的特殊函式。Jack 編譯器知道「new Array(n)」應該翻譯成「呼叫 Array.new(n)」。

2.2 陣列的生命週期

new(建立)          ──►  使用中           ──►  dispose(釋放)
Array.new(n)           arr[0..n-1] 讀寫       arr.dispose()
  • 建立：let arr = Array.new(n); 向 heap 要 n 個字。
  • 使用：arr[i] 讀寫第 i 個元素（越界時語言未定義，程式要自己負責範圍）。
  • 釋放：do arr.dispose(); 把記憶體還給 Memory（dealloc）。

Array.dispose 會呼叫 Memory.dealloc(this)，把這塊空間還回 free list，之後可被合併重用。

2.3 完整 Array.jack

// Array.jack —— 陣列類別
class Array {

    // 建立大小為 size 的陣列，回傳其起始位址
    function Array new(int size) {
        var Array a;
        let a = Memory.alloc(size);
        return a;
    }

    // 釋放陣列記憶體
    method void dispose() {
        do Memory.dealloc(this);
        return;
    }
}

就這麼短！Array 本身幾乎是「薄封裝」——真正的魔法在 Memory.alloc。Array.new 回傳的是記憶體位址，而 Jack 編譯器會把 arr[i] 編譯成「從該位址偏移 i 的讀寫」。

設計思路：為什麼要單獨一個 Array 類別，而不用 Memory.alloc 就好？因為 Jack 語言規格把「陣列支援」鎖定在 Array.new / Array.dispose 這兩個特定函式上，編譯器會自動呼叫它們。OS 提供這兩個「語言內建掛鉤」，Jack 程式才能正常使用陣列語法。

3. Sys 類別：系統主控

3.1 Sys API

方法 簽名 功能說明
init Sys.init() 初始化所有 OS 類別，然後呼叫使用者的 Main.main()
halt Sys.halt() 終止程式執行（進入無窮迴圈）
wait Sys.wait(int duration) 等待 duration 毫秒（用忙迴圈延遲）
error Sys.error(int errorCode) 印出錯誤並終止程式

3.2 Sys.init：作業系統的啟動流程

開機後，Sys.init 是所有程式的真正起點。它做兩件事：

  1. 初始化 OS 類別：依賴順序呼叫各類別的 init()。
  2. 呼叫使用者的 Main.main()：把控制權交給平台的主程式。

各類別的初始化順序很重要，因為有依賴關係：

Sys.init()
   │
   ├─► Memory.init()      // 其他類別都用 peek/poke/alloc
   ├─► Math.init()        // (若需要) 若無靜態初始化可省略
   ├─► Screen.init()      // 依賴 Memory
   ├─► Output.init()      // 依賴 Memory, Screen, (Math)
   ├─► Keyboard.init()    // 依賴 Memory
   ├─► ...（String 等構造式類別無需全域 init）
   │
   └─► Main.main()        // 進入使用者主程式

Sys.init 的示意：

function void init() {
    do Memory.init();
    do Math.init();       // 若無需可留空或省略
    do Screen.init();
    do Output.init();
    do Keyboard.init();
    // 進入使用者主程式
    do Main.main();
    do Sys.halt();
    return;
}

設計思路：Sys.init 扮演「啟動載入器（boot loader）」的角色。在 Nand2Tetris 的工具鏈中，Jack 編譯器產生的 VM 程式第一條就是呼叫 Sys.init。它確定了「OS 先就位、Main 後接手」的順序——這就是整個系統的開機流程。

3.3 Sys.halt：停止

halt 進入一個「永不結束的無窮迴圈」，讓 CPU 卡在這裡（因為 Hack 沒有「停止」指令，只能用死迴圈讓它不再做有意義的事）：

function void halt() {
    while (true) { }     // 無窮迴圈
    return;
}

3.4 Sys.wait：用迴圈延遲

Hack 沒有硬體計時器、沒有「睡」系統呼叫。要「等一陣子」，唯一方法是忙迴圈（busy-wait）：反覆執行空操作，直到消耗夠多的週期。

官方 Sys.wait(duration) 用「大約每一毫秒跑一個固定次數的迴圈」來近似。因為 Hack 的執行速度是確定的（每條指令固定週期數），可以估算。

官方延遲的實作（利用「每次遞增一個變數到目標值」的迴圈）：

function void wait(int duration) {
    var int i, j;
    // duration 是毫秒數；對應的「內部迴圈次數」是固定的
    let i = 0;
    while (i < duration) {
        // 內層迴圈約消耗 1 毫秒
        let j = 0;
        while (j < 50) {        // 數值依 CPU 速度與模擬器調整
            let j = j + 1;
        }
        let i = i + 1;
    }
    return;
}

服務外層迴圈每跑一次等於過了大約 1 毫秒，因此 Sys.wait(1000) 約等於等 1 秒。

設計思路：這種「忙迴圈計時」不精確（依賴模擬器/CPU 的速度），但在 Nand2Tetris 的模擬環境中，只要把內層常數調到「讓每次外層迭代約 1ms」，對遊戲類程式已足夠。真實作業系統不會這樣浪費 CPU 等時間，但懂了運作原理後，你就理解「沒有中斷與計時器的古老電腦如何『感覺時間流逝』」。

3.5 Sys.error：錯誤處理

error(errorCode) 印出錯誤訊息（或錯誤碼）後，呼叫 halt 停止：

function void error(int errorCode) {
    do Output.printString("ERR");
    do Output.printInt(errorCode);
    do Output.println();
    do halt();
    return;
}

當某個 OS 函式偵測到錯誤（如記憶體不足）時，可呼叫 Sys.error(code)，將錯誤碼顯示給使用者並中止程式。

4.1 類別間依賴圖

把所有 OS 類別畫成依賴圖，就能看到「誰依賴誰」：

      Sys
       │
       ├─────► Main.main()
       │
       ├─────► Memory ────────┐
       │                       │
       ├─────► Math ◄─────────┤
       │                       │
       ├─────► Screen ──► Memory, Math
       │                       │
       ├─────► Output ──► Screen, Memory, Math
       │                       │
       └─────► Keyboard ──► Memory, Output, String
                                │
       String ─────► Array ────► Memory
       Array  ─────► Memory

可以看出：

  • Memory 與 Math 是底層基石（依賴最少者）。
  • String 與 Array 依賴 Memory。
  • Screen、Output、Keyboard 建立在這些基石之上。
  • Sys 位於最頂層，負責把一切初始化並啟動 Main。

設計思路：這種「分層依賴」不是偶然，而是工程設計的必然結果——先寫不依賴別人的，再寫依賴少數人的，最後寫指揮全局的。它能讓每一層都能獨立測試，也讓「作業系統」整個變成一個可管理、可除錯的整體。

5. 設計思路與實作步驟

5.1 實作步驟

  1. Array：最簡單，new 直接 Memory.alloc，dispose 直接 Memory.dealloc。先寫它，因為 String 與 Output 都用得到。
  2. String：建構子用 Array.new 配置緩衝區；實作 length、charAt、setCharAt、appendChar、eraseLastChar；接著是 intValue / setInt（依賴除法）。
  3. Sys：最後寫。init 依序初始化各類別並呼叫 Main.main；實作 halt、wait（忙迴圈）、error。
  4. 寫一支 Main.jack 整合測試所有類別。

5.2 整合驗證策略

建立一個「總驗收程式」Main.jack 來驗證整個 OS 整合運作：

// Main.jack —— 整合測試
class Main {
    function void main() {
        var String s;
        var Array arr;
        var int i, sum;

        // 1) Math
        do Output.printString("7*6=");
        do Output.printInt(Math.multiply(7, 6));    // 42
        do Output.println();

        // 2) Screen
        do Screen.drawCircle(256, 128, 60);
        do Sys.wait(500);

        // 3) String
        let s = String.new(20);
        do s.setInt(12345);
        do Output.printString(s);                    // 12345
        do Output.println();

        // 4) Array
        let arr = Array.new(10);
        let i = 0;
        while (i < 10) {
            let arr[i] = i * i;
            let i = i + 1;
        }
        // 印出 arr[4] = 16
        do Output.printInt(arr[4]);
        do Output.println();
        do arr.dispose();

        // 5) Keyboard
        do Keyboard.readInt("輸入一個整數：");

        do Sys.halt();          // 結束
        return;
    }
}

在 CPU Emulator 上執行，確認：

  • 螢幕印出正確的數學結果與字串；
  • 圓形正常繪製；
  • 陣列正確讀寫；
  • 鍵盤輸入能讀回；
  • 程式最終停在 Sys.halt。

6. 本章小結

  • String 用「緩衝區 + 長度 + 容量」表示：Array.new 配置字元緩衝；appendChar 添加、eraseLastChar 刪除、charAt/setCharAt 定址存取；intValue（字串→整數）與 setInt（整數→字串）一對互逆，都依賴除法。
  • Array 是最簡類別：Array.new = Memory.alloc（取得連續記憶體位址），dispose = Memory.dealloc（還回 free list）。它是 Jack 語言的「內建掛鉤」。
  • Sys 是系統主控：init 依序初始化各 OS 類別並呼叫 Main.main；halt 以無窮迴圈終止程式；wait 用忙迴圈近似延遲（因 Hack 無硬體計時器）；error 印出錯誤碼並停止。
  • 整個 OS 的啟動流程是：開機 → Sys.init（初始化 Memory、Math、Screen、Output、Keyboard）→ Main.main() → （結束時）Sys.halt()。
  • 類別間呈分層依賴：Memory / Math 是基石，String / Array 依賴 Memory，Screen / Output / Keyboard 建立在基石上，Sys 在最頂層指揮全局。
