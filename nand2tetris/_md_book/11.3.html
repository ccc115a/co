11.3 陣列與指標運算的 VM 指令生成

學習目標

讀完本節後，你應該能：

  • 說明 Jack 的 Array 究竟是什麼——一個把 int 當指標用的抽象層
  • 說明陣列如何透過 Memory.alloc(size) 配置出一塊連續記憶體
  • 說明陣列元素讀取與寫入的翻譯模式：base address + index 的位址運算
  • 說明 that 段（that/pointer 1）在陣列運算中的角色
  • 掌握「指標運算」的本質：把數字當位址、把它加減偏移
  • 模擬多維度陣列（用「陣列的陣列」）
  • 能親手把完整的陣列操作 Jack 程式翻譯成 VM 代碼

前言

在 11.2 節，我們看到「物件」在機器底層不過是一塊記憶體＋一只「基址指標（THIS）」。現在要處理的「陣列」其實是同一套思路的另一種表現：一段連續的記憶體＋一只用來在裡面游走的指標。

Jack 的陣列跟 C、Python 都不太一樣，它樸素到令人吃驚——沒有真正的「陣列型別」，只有一個叫 Array 的類別名，而陣列變數其實就是「儲存一個整數（記憶體位址）」的變數。也就是說：

在 Jack 裡，陣列 = 一個記憶體位址（整數）＋ 對這塊記憶體的看法。

a[i] = 5 讀起來像是在存取「第 i 個元素」，但底層它真正做的是：把 a 當成基址，算出 a + i，再去讀寫那個位置的內容。這正是指標運算——本書第一次在 Jack 層面親眼見到它。

1. 陣列宣告與配置：Array 與 Memory.alloc

1.1 宣告只是給變數一個「能放整數」的位置

var Array a;      // a 只是一個 int 變數，型別名稱叫 Array

在符號表眼裡，a 的 type 是 Array，kind 是 local（假設放在 method 內）。它本身暫不佔用陣列空間，只是一個普通的區域變數。真正的空間要等到我們呼叫 Memory.alloc 才要得到。

1.2 配置：用 Memory.alloc 換來一段記憶體

let a = Array.new(10);     // 事實上常以 Array.new 或直接 Memory.alloc 實作

Array.new(n) 只是 OS 對 Memory.alloc(n) 的一層很薄包裝。真正的核心是：

function Array.new(int size) {
    return Memory.alloc(size);   // 回傳一塊 size 格的連續記憶體起始位址
}

Memory.alloc 回傳的那個整數，就被存進 a。從此 a 這個變數「等於」這塊記憶體的起始位址。

1.3 翻譯：呼叫 alloc 並存進變數

// var Array a; ... let a = Array.new(10);

假設 a 是 local 0。翻譯：

// let a = Array.new(10);
push constant 10
call Array.new 1            // alloc(10)，回傳起始位址
pop local 0                 // a = 起始位址

或直接：

push constant 10
call Memory.alloc 1
pop local 0

現在 local 0（a）裡存著那 10 格記憶體的基址。

2. 陣列元素讀取與寫入的翻譯：base + index 運算

這是本節的重頭戲。a[i] 究竟怎麼變成 VM 指令？核心公式：

陣列元素 a[i] 的位址 = a 的值（基址） + i

VM 裡沒有真正的「乘法」，但「基址 + 索引」只是加法，簡單多了。做法是：

  1. 把基址（a 的值）推上 stack
  2. 把索引（i）推上 stack
  3. 相加，得到「目標元素位址」
  4. 依據是讀還是寫，決定下一步

2.1 寫入：a[i] = x

要寫入，需要「把目標位址當作一個指針」：把計算出的 base+i 放進 that 段指標（pointer 1），然後 pop that 0。

a[i] = x;    // 假設 a→local 0, i→local 1, x→argument 0

翻譯：

// a[i] = x;
push local 1        // i
push local 0        // a（基址）
add                 // a + i = 目標位址
pop pointer 1       // that = 目標位址
push argument 0     // x
pop that 0          // RAM[THAT + 0] = x

注意 push 的順序：先推索引、再推基址，相加結果一樣是 a+i（加法可交換）。但要小心：如果式子寫法相反會先推基址再推索引，結果仍是 a+i，無妨。

2.2 讀取：y = a[i]

讀取同樣先算出目標位址，放入 that，然後 push that 0 把內容推回 stack：

y = a[i];    // a→local 0, i→local 1, y→local 2

// y = a[i];
push local 1        // i
push local 0        // a
add                 // a + i
pop pointer 1       // that = 目標位址
push that 0         // 讀出 RAM[THAT]
pop local 2         // y

2.3 為什麼一定要先「compute base+index」再「pointer 1」？

關鍵是：that 一次只能指到一個目標。所以任何元素存取都要「現算現指」，用完立刻放下一個。你不能先設定好 that 再一次讀多個元素，因為那是把活靶子釘死。所以每次 a[i] 都得重頭：推 base、推 index、add、pop pointer 1。

設計思路：這正是「指標運算」的日常。你手上只有一只 that 指標，每次要碰哪個元素，舊得重算一遍該元素位址放進指針。雖然看起來囉嗦，但這是極簡 VM 做得到的最直白方式。

3. that 段（pointer 1 / THAT）的深入理解

回想 11.2 節：this 與 pointer 0（THIS）是同一件事——this i 就是 RAM[THIS+i]。這節的 that 與 pointer 1（THAT）完全對稱：

  • pop pointer 1 → 把值寫進 RAM[4]（THAT）
  • push pointer 1 → 讀出 RAM[4]
  • that i → 實際是 RAM[THAT + i]

差別只是「用途的慣例」：this 慣用於物件欄位，that 慣用於陣列元素。但本質上兩者都是「一段記憶體的基址指針」。

   RAM[4] (THAT)  ──►  [ e0 | e1 | e2 | ... ]   ← 陣列空間
                           that 0  that 1 ...

當我們 pop pointer 1 設好 that 指向某元素後，that 0 就是那個元素本身。偶爾也會出現 that 1、that 2……例如呼叫 String/Memory 的某些嫁接到陣列的操作，或是一次存取相鄰元素時，直接以 that 0、that 1 取用，省得重算。

4. 指標運算的本質

到這裡，我們可以點破「指標運算」的真面目：

指標 = 一個被當作記憶體位址使用的整數。指標運算 = 對這個整數做加減法（及其他算術），以得到其他記憶體位址。

在 Jack/VM 層，a + i 這個「加法」不只是在算數學，它同時是在算「哪個 RAM 格」。同一個 add 指令，在物件運算中幫我們算出欄位偏移，在陣列中幫我們算出元素位移——因為從 VM 的角度看，它們都是「基址 + 偏移」。

這也就解釋了為什麼可存取一個「動態」的索引：a[i] 裡的 i 可以是變數、可以是 i+1、甚至可以是另一個陣列的取值 j[m]。無論多複雜，最後都會化為一次 push/add/pop pointer 的組合。

5. 多維度陣列的模擬：陣列的陣列

Jack 沒有原生二維陣列，但我們可以用「陣列的陣列」模擬。概念上：

二維陣列 M[row][col] == M 是一個陣列，它的每個元素又是一個陣列。

實際建構：

var Array grid;
var int rows, cols;
let rows = 3;
let cols = 4;
let grid = Array.new(rows);            // grid[0..2] 各自要再指到一個陣列
let i = 0;
while (i < rows) {
    let grid[i] = Array.new(cols);     // 每個 row 配一個長度 cols 的陣列
    let i = i + 1;
}

5.1 存取二維元素 grid[r][c] 的翻譯

眼光放遠：grid[r][c] 分兩步：

  1. grid[r] → 得出「第 r 列的陣列基址」
  2. (那個基址)[c] → 再套一次陣列讀取

它的 VM 翻譯依 11.3 的模式疊兩層。以下假設 grid→local 0, r→local 1, c→local 2, value→local 3：

let grid[r][c] = value;

翻譯（先算出第 r 列的陣列位址，存進暫存，再寫入該列的 c 元素）：

// 第一層：算出 base = grid[r]
push local 1                // r
push local 0                // grid（基址）
add                         // grid + r
pop pointer 1               // that = &grid[r]
push that 0                 // base = grid[r]（這是一個陣列位址）
pop local 4                 // 暫存變數 base（把 r 列的陣列位址記住）

// 第二層：base[c] = value
push local 2                // c
push local 4                // base
add                         // base + c
pop pointer 1               // that = &base[c]
push local 3                // value
pop that 0                  // 寫入

let x = grid[r][c];

push local 1
push local 0
add
pop pointer 1
push that 0
pop local 4                 // base = grid[r]

push local 2
push local 4
add
pop pointer 1
push that 0
pop local 5                 // x = grid[r][c]

可以看到：多維只是把「base + index」的招式重複使用。每一次「取一個維度」就是把上一層的結果當作新的基址。這就是高階語言的 grid[r][c] 在極簡 VM 下的真面目。

6. 完整的陣列操作翻譯範例

來一個能收尾的完整例子。假設某 method 內有一段：

method void demo() {
    var Array a;
    var int i;
    let i = 0;
    let a = Array.new(3);
    while (i < 3) {
        let a[i] = i * i;      // 存平方
        let i = i + 1;
    }
    return;
}

符號表（method 的局部）：a→local 0, i→local 1。逐步翻譯：

function 宣告 + prologue（method 要設 THIS）：

function SomeClass.demo 2       // 兩個區域變數 a, i
push argument 0
pop pointer 0

let i = 0; 與 let a = Array.new(3);：

push constant 0
pop local 1                     // i = 0
push constant 3
call Array.new 1
pop local 0                     // a = 新陣列（3 格）

while 迴圈的結構：Jack 的 while (cond) { body } 翻譯成 VM 的 label / goto 循環：

label WHILE_EXP0
push local 1                    // i
push constant 3
lt                              // i < 3
not                             // !(i < 3)，為真則跳出
if-goto WHILE_END0

body: let a[i] = i*i;（i*i 用 Math.multiply）：

push local 1                    // i
push local 0                    // a
add
pop pointer 1                   // that = &a[i]
push local 1                    // i
push local 1                    // i
call Math.multiply 2            // i*i
pop that 0                      // a[i] = i*i

body: let i = i + 1; 並收尾迴圈：

push local 1
push constant 1
add
pop local 1                     // i = i + 1
goto WHILE_EXP0
label WHILE_END0
push constant 0
return

設計思路：把整個迴圈攤開，會發現「a[i] = exp」就是那組 push index / push base / add / pop pointer 1 / push exp / pop that 0 的固定舞步。熟練它，等於掌握了 Jack 陣列的全部精髓——包括你在作業（Mult, Average, Game 等）裡會用到的所有 list/table 處理。

7. 本章小結（本節）

  • Array 只是個名稱：陣列變數是一個存整數（記憶體位址）的普通變數。
  • 配置：Array.new(n) ≈ Memory.alloc(n)，回傳 n 格連續記憶體的起始位址。
  • 元素存取公式：a[i] 的位址 = a（基址） + i（索引），用一個 add 完成。
  • that 段：算出位址後 pop pointer 1 令 that 指向它，再用 that 0 讀寫該元素。
  • 指標運算本質：把整數當位址、把加減法當位址位移；物件與陣列其實是同一個道理。
  • 多維度：陣列的陣列，把「base + index」疊兩層即可。
  • 有了 11.1 的符號表、11.2 的物件翻譯、11.3 的陣列翻譯，語法分析器就能對上位生成完整的 VM 指令。
