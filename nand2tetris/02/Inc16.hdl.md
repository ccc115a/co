# Inc16 程式說明 — 16 位元遞增器

這個電路把輸入加 1：`out = in + 1`。程式計數器 PC 的「inc」功能就靠它。

## 概述

Inc16 是 Add16 的「專用化」：既然要加的是固定常數 1，就不必再提供第二個 16 位元輸入，電路自然簡化為單一輸入。它在第三章的 PC（程式計數器）與第四章 CPU 中被用來讓下一個指令位址「加一」，是最常用的純算術元件之一。

## 介面與規格

```
CHIP Inc16 {
    IN  in[16];
    OUT out[16];
}
```

規格只有一條：`out = in + 1`。二補數下，`in = 0` 時輸出 1；`in = -1`（全 1）時輸出 0（溢位回繞）；`in = 5` 時輸出 6。

## 原理

`x + 1` 的本質是把最低位元翻轉，並把進位一路往上傳：從 LSB 開始，遇到 0 就把它設為 1 並停止，遇到 1 就設為 0 並繼續往高一位進位。這正是「加一」的二進位規則。

而這個行為可以完全借用 Add16 達成：把加數固定成 `0000000000000001`，其餘位元全為 0。

## 實作細節

```hdl
PARTS:
    Add16(a=in, b[0]=true, b[1..15]=false, out=out);
```

整個電路只有一行，巧妙的點在於 `b` 這個 bus 的接法：

- `b[0]=true`：最低位固定為 1。
- `b[1..15]=false`：其餘 15 位固定為 0。
- `a=in`、`out=out` 直接接回上下層。

如此一來 `out = in + 0000000000000001 = in + 1`。注意 `b` 不必在 PARTS 中先宣告成一個具名的內部線，HDL 允許在接腳參數上直接對 bus 分段賦常數，這稱作 bus slicing 的寫法。

## 測試與驗證

`Inc16.tst` 檢查四個代表性輸入，輸出用二進位格式比對：

| in | 二補數意義 | out |
|----|-----------|-----|
| 0000000000000000 | 0 | 1 |
| 1111111111111111 | -1 | 0（溢位回繞） |
| 0000000000000101 | 5 | 6 |
| 1111111111111011 | -5 | -4 |

最後一筆驗證負數也能正確加一：`-5 → -4`，證明二補數加法無需任何符號特判。

## 延伸討論

「加常數」的硬體通常比通用加法器更省。此處為求示範簡潔而直接借用 Add16；在高效電路中，`+1` 可只用一串 OR/XOR 閘完成，延遲比完整加法器小。Inc16 日後是 PC 與 CPU 的標準配件。
