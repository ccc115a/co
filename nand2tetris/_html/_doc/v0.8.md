# hdl2js v0.8 — 版本紀錄

日期：2026-09-13（115 學年度 · 計算機結構）
對應里程碑：**M8 — 網頁版誕生：`dist/index.html` asm Emulator（純瀏覽器、零伺服器）**

## 一句話

第一次產出「人類可以雙擊開起來玩」的網頁檔：`dist/index.html` ＋ `dist/embed.js`
＋ `dist/app.js`，全部 classic `<script>`（零 module、零 node、零 server），
`file://` 直接打開就能組 HACK 組語、跑在 hackemu 上、看到 512×256 canvas 螢幕、
R0–R15、RAM 分頁瀏覽器與 PC 行程高亮。

## 本版實作內容

- **`tools/embed.js`（bundle 產生器）**：把純 ES module 的引擎檔（hackemu / hackasm /
  vm2asm / jack2vm），去掉 `export` 前綴、跳過 `import`，合併成單一 classic script；
  尾部 IIFE 把它們掛上 `window.HackVM` / `window.HackAsm` / `window.HackVm2Asm` /
  `window.HackJack2Vm`。目前引擎檔都是「無 node imports」的，所以不需要 shim。
- **`dist/index.html`**：參考 Rust 版 `_eda/web/index.html` 的版面（程式/螢幕/記憶體三欄），
  改成純前端。**`dist/app.js`**：組譯並載入、執行/暫停/Step/Reset、速度滑桿（rAF,
  steps/frame 呈對數）、方向鍵→`setKey`、`screenPixel`→canvas、RAM 分頁、組語行↔ROM
  對映的 PC 高亮。
- **踩坑**：內建示範乘法程式 `@R0 0;JMP` 是錯的——jump 目標是 `A`，`@R0` 讓 PC 回繞到
  0 整個程式重跑；改 `(END) @END 0;JMP`。VM 與 lib 行為完全一致，問題出在範例本身。
