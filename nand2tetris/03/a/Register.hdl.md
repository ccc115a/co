# Register 程式說明 — 16 位元暫存器

這個電路把 16 個 Bit 並排組成一個字（word）大小、可同步「載入」的儲存單元，是 RAM 的最小構成單位。

## 概述

Bit 記住 1 個位元；Register 記住整整 16 bit。它的行為規格與 Bit 幾乎一模一樣，只是 bus 寬度從 1 變成 16。之後的 RAM8→RAM16K 全是由 Register 組成的陣列，而 Hack CPU 的 A 暫存器、D 暫存器也各是一個 Register。

## 介面與規格

```
CHIP Register {
    IN  in[16], load;
    OUT out[16];
}
```

時序規格：

- 若 `load[t] = 1`：`out[t+1] = in[t]`（16 bit 一起寫入）。
- 否則：`out[t+1] = out[t]`（整字保持）。

關鍵在「**整字同步更新**」：16 個 Bit 共用同一條 `load`，寫入時 16 個位元一起換，不會出現一半新一半舊的狀態。這就是「暫存器是原子的」之意義。

## 原理

Register 沒新增任何邏輯，只是陣列化：把 16 個「Bit 單元」排開，彼此的 `in[i]`、`out[i]` 各取 bus 的一條線，而 `load` 是公共線，同時扇出到全部 Bit。這種「**訊號扇出（fan-out）**」在硬體裡免費 — 一條線可以驅動任意多個輸入。

```
in[16] ──┬────────────┬──────────────┬─ … → 各接 Bit 的 in[i]
load  ───┴────────────┴──────────────┴── → 同時驅動 16 個 Bit 的 load
out[i] ←──────────────────────────────── 各 Bit 的 out[i] 匯成 out[16]
```

## 實作細節

```hdl
PARTS:
    Bit(in=in[15], load=load, out=out[15]);
    Bit(in=in[14], load=load, out=out[14]);
    ...
    Bit(in=in[1],  load=load, out=out[1]);
    Bit(in=in[0],  load=load, out=out[0]);
```

- 16 行完全同構的 `Bit` 實例，沒有邏輯閘，只有「bus 拆成單線再組回去」的分工。
- 每一位的 `in[i]` 都接 `in` bus 的對應線、`out[i]` 接回 `out` bus 的對應線，`load` 一視同仁。

## 測試與驗證

`Register.tst` 用十進位格式觀察整個字。重點樣本：

| in | load | 期望 |
|----|------|------|
| 0 | 0 | out 保持初始 0 |
| 0 | 1 | out → 0 |
| -32123 | 0 | 保持（x 負數也照樣 hold） |
| -32123 | 1 | out → -32123 |
| 12345 | 1 | out → 12345 |

注意到測試值刻意同時用負數與正數，驗證「載入」與二補數無關，純粹是 16 條 bit 線的複製。所有測試都以 `tick; tock` 成對出現，呼應 DFF 的邊緣觸發語意。

## 延伸討論

- 真實 CPU 中 Register 的 `load` 由控制單元決定：當前指令要求「把 ALU 結果寫進 D」時 load=1，否則每拍都給 0。
- 本章接下來的 RAM 會把大量的 Register「分時共用」同一組 `in`/`out` bus，靠位址解碼決定哪一個被打開 — 那是記憶體架構的核心手法，Register 本身正是那個「被選中才動作」的細胞。
