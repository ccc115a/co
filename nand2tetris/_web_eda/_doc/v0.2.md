# hdl2js v0.2 — 版本紀錄

日期：2026-09-12（115 學年度 · 計算機結構）
對應里程碑：**M2 — 序列邏輯（ch03）全數通過**

## 一句話

延續 v0.1 的「HDL → JS 模擬 class」架構，把 master/slave 兩階段時序（`tick`/`tock`）
接上：內建 `DFF`（ch03a 的 `Bit`/`Register`/`RAM*`/`PC` 都從 Nand2Tetris 的慣用
DFF-based 寫法詳述），本版宣告 **第一章~第三章全部 29 個測試 PASS**（單元測試 65 個）。

## 本版實作內容

### codegen（lib/hdl/codegen.js）

- 每顆晶片補上 `sample`：先重新求值落定的 wire（cascade），有「序↔序」回饋
  （`hasFeedback`，如 CPU/Computer）時再多算一輪；最後**依 evalOrder 遞迴取樣
  有狀態的 child**（`this._pN.sample(...)`）。
- 內建 `DffChip`（`latch`/`q` 兩暫存器：`sample` 取樣 `latch`、`tock` 提交 `q`）、
  `RegChip`（16-bit A/D Register）、Screen/Keyboard 的行為 class。
- sample 階段內嵌的輸入變數用 `__c` prefix，且每個有狀態 child 包 `{ }` 區塊，
  避免同函式內重覆宣告。

### model（lib/rt/model.js）

- **關鍵修正**：`tick` = `sample + do_eval()`（Rust 版 gen.rs `Wrap::tick` 也如此）。
  若 tick 後不求值，RAM 換 address 時 `out` 會停留在上一次的整顆輸出，導致
  RAM16K/RAM4K/RAM512 讀到「舊 address 的值」而非新 address。
  （Bit/Register 沒有 address，24 個舊測試看不出差異，ch03b 一跑就現形。）
- `tock` = `tock + do_eval + time++`，維持 cycle 計數。

### elab / tst 的配套修正

- `mergeLibsList([...])`：任意數量 library 合併（ch03 需 01+02+03a+03b）。
- 確認 `.tst` 的 `tick,output; tock,output;` 與 `eval,output;` 交錯用法、
  `set address %B...` 二進位值、`time%S...` 欄位都正確銜接。
