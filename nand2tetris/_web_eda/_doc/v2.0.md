# hackjs v2.0 — 版本紀錄

日期：2026-10-02（115 學年度 · 計算機結構）
對應里程碑：**M13（新路線）— Jack 編譯器長出第二條路：VM → RISC-V，命令列＋網頁雙後端**

## 一句話

Jack 編譯器現在可以選後端：`jack → vm → HackCPU（.asm → .hack → 執行）`（舊路），
或 `jack → vm → RISCV（.s → bytecode → 執行）`（新路）。新寫的 `vm2riscv`
把 Nand2Tetris VM 翻成 RV32 組語（目標＝`riscv/_web_tools` 的 rvasm／rvemu），
連同裁剪版 OS 一起跑：Seven 在 RV32 上真正執行並從 UART 印出 `7`——這是 Hack 版
（`gen/os_src` 的 Output 是空殼）都看不到的輸出。網頁 `jack.html` 有後端選單，
網址可用 `backend=hackcpu|riscv` 指定；命令列 `jack2vm → vm2riscv → riscv_run`
同樣全線打通。

## 本版實作內容

### lib/riscv/vm2riscv.js＋cli/vm2riscv.js（VM→RV32，兩段式的第二段）

- `Vm2Rv.translate(files[, { lenient }])`，呼叫慣例對齊 `vm2asm`：多檔才寫
  bootstrap（`SP＝STACK_BASE`＋`call Sys.init`＋`ecall` 停機），`label/goto/if-goto`
  多檔加 `函式$` 前綴，函式幀沿用 Hack VM 格式（return／LCL／ARG／THIS／THAT）。
- **return 地址走 ra 壓幀**：caller 在幀頂留 placeholder，callee 序幕第一行
  `sw ra, -20(s2)` 回填（jal 寫入 ra 的正是返回位址），返回 `jalr x0, 0(t1)`，
  巢狀呼叫安全（見下「踩過的坑」第一條）。
- **內聯三類**：`Math.multiply/divide`→`mul/div`；`Output.printChar/printInt/`
  `println/printString`→UART（`ecall a7=1`，void 照推 0；OS 的 Output 是空殼，
  內聯後 print 真正看得到）；其餘 OS 呼叫只擋「未定義」的（嚴格 throw，
  lenient 照發 `jal` 並列外部表頭僅供檢視）。
- **Jack 位址模型**：Jack 的 word 位址 W（含 heap／SCREEN／KBD）經 this/that 存取時
  映射為 `MIRROR_BASE＋4W`（`slli`＋`li` 相加；pointer 持有的仍是 word 值本身），
  故 `Memory.peek/poke`、`Array`、`String` 全數可用。
- 記憶體布局（byte；程式從 0 載入須＜`0x10000`）：temp＝`0x10000`＋4i
  （`UART_BUF` 在＋32，供 printInt 暫存數字）、static＝`0x11000`＋檔序*`0x400`＋4i
  （≤32 檔，每檔 ≤256）、VM 堆疊 s1＝`0x1C000` 向上、Jack 鏡像 `0x20000`＋4W。
  真值 true＝-1；整數 32-bit 語意（Hack 原生 16-bit，小數值一致）。
- `cli/vm2riscv.js <out>.s <in>.vm […vm] [--lenient]`（輸出在前，與 `vm2asm` 同順序）。

### OS 全量可跑（gen/os_src 8 檔）

- Seven＋OS：嚴格翻譯→組譯（8873 words）→執行，UART 印 `7`。
- heap 綜合（自寫 Jack：`String.new/appendChar/printString/dispose`＋`Array.new`＋下標存取）：
  UART 印 `Hi!`＋換行＋`333`，證明 alloc／that／鏡像／printString 全鏈正確。
- Pong＋OS：嚴格翻譯＋組譯通過（14584 words；執行不崩，鍵盤恆 0 故球拍不動——見限制）。
- `cli/riscv_run.js <in>.s [--max N] [--dump A,C]`：組譯後定步執行（產物不 halt，
  永遠跑滿即停），印 `ra/s1/a0`＋`UART`＋`MEM`（預設 static 區 8 bytes）。

### 前端 jack.html 雙後端（HackCPU／RISCV）

- 頁首後端選單（預設 HackCPU）＋網址指定：`#prog=Fib&backend=riscv&run=1`
 （hash 優先於 query；切換選單／程式寫回 `#prog=X&backend=Y` 可分享）。
- HackCPU 分頁 `.vm/.asm/.hack`；RISCV 分頁 `.vm/RISCV/bytecode`；
  顯示分頁只看使用者模組（`.vm` 恆是；`RISCV` 是模組的 lenient 預覽，
  `bytecode` 需模組可獨立組譯）；`▶執行`與「送 Emulator（僅 HackCPU）」用 OS 在前的全量。
- RISCV 執行＝嚴格翻譯→rvasm 組譯→rvemu 跑滿 20 萬步，印 `ra/s1/a0`＋
  `STATIC[0..7]`＋`UART`；OS 程式可跑（含鍵盤的除外，見限制）。
- `rvasm/rvemu/rvdis/isa` 由 `tools/embed.js` 包成 `RvToolchain` IIFE
  （`window.HackRv`），**未動 `riscv/_web_tools` 一行原始碼**
  （其 `assemble` 與 `HackAsm.assemble` 同名，直接拼接會覆蓋）。

### 文件

- 本目錄範圍 `AGENTS.md`（只看 `_web_eda_riscv/`）：指令、雙後端、記憶體約定、
  rvasm 兩處坑、網址規則、版號規則。
- `lib/riscv/vm2riscv.js.md` companion（位址模型、內聯、OS 支援、限制），與程式同步。

## 踩過的坑（實作筆記，未來不要重犯）

1. **rvasm 符號版 `li` 佔位坑**：`li rd, <標籤>` pass1 固定佔 2 格，標籤位址＜2048 時
   pass2 只吐 1 word，留下 `0x00000000` 非法字（Sum 在第 4 條指令就炸）。
   解法：return 地址改走 ra 壓幀、static 改走固定數字位址，全程不用符號版 `li`
   （數字版 `li` 因 pass1 即確定大小，不受影響）。
2. **OS 自帶定義被誤殺**：初版在逐行處理時看到 `Memory.*` 就 throw，連 OS 自己的
   `Memory.alloc` 定義一起擋掉。改為翻譯結尾統一判定：只有「未定義」的 OS 呼叫才擋。
3. **embed 拼接撞名**：`vm2riscv.js` 的 `translate/trim/scope` 與 `vm2asm.js` 同名，
   併進同一作用域會覆蓋。包成 `export const Vm2Rv = (() => {...})()` 再由
   `embed.js` 匯出 `HackVm2Rv`（前例：`KEYWORDS`→`TST_KEYWORDS` 是改名，本版用 IIFE
   一勞永逸；`rvasm` 四檔同理包成 `RvToolchain`）。
4. **假警報排除**：某次 bundle eval 報 `translate` 重複宣告，查明是多行 `node -e`
   被 shell 截斷所致（`--check`＋`vm.Script`＋單行 eval 三次皆過）；另一次
   bundle-vs-lib 比對失敗，只是改完 lib 忘了重建 `dist/embed.js`——已收成回歸測試。

## 已知限制

- Keyboard 恆讀 0（rvemu 無鍵盤）：`readChar/readInt` 類（如 Average、ConvertToBin）
  會空等；`keyPressed` 非阻塞可用；Screen 寫入只進鏡像 Ram，看不到 Pong 畫面。
- 程式本體須＜64KB（Pong+OS 約 34KB）；static ≤256／檔、輸入檔 ≤32 個；
  單檔無 bootstrap（VM SP 未初始化，僅供參考）；整數 32-bit 語意。
- RISCV `▶執行`固定 20 萬步（CLI 預設相同，可 `--max` 調）：跑不完的大程式只看得到中間態。
