# hackjs 工具程式原理（`_book/`）

這系列把 `_web_eda_riscv/`（hackjs：JavaScript 版 Nand2Tetris 工具鏈）
每個工具「為什麼這樣寫」講清楚，目標是大二資工系學生：
修過計組先修課、知道 AND/OR 是什麼、寫過一點程式，就能從頭讀懂。
**不寫習題解答**，只講工具本身的原理。

## 讀法：每章都是「用法 → 完整範例 → 原理」

1. **用法**：先告訴你這支工具怎麼用——吃什麼輸入、吐什麼輸出、
   指令怎麼下（檔名都是超連結，點下去就是原始碼）。
2. **完整範例**：一份從頭到尾的真實輸入＋真實輸出（實際拿工具跑出來的，
   不是編的；太長的只截錄，但截錄處會說明）。
3. **原理**：最後才解釋它內部為什麼這樣設計。
