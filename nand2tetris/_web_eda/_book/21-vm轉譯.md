# 21 從堆疊機到暫存器機：`vm2asm`

## 用法

[`cli/vm2asm.js`](../cli/vm2asm.js)：`node cli/vm2asm.js <out>.asm <in>.vm […vm]`，
**輸出檔名在前**，多檔自動加開機碼（見原理）。

## 完整範例

輸入（VM，堆疊機：把 7 和 8 推上堆疊、相加，`push constant 7` 等三行）：

```
push constant 7
push constant 8
add
```

輸出（真實產物；每行 VM 上面加一行 `// 原文` 註解，人一眼能對照）：

```
// push constant 7
@7
D=A
@SP
A=M
M=D
@SP
M=M+1
// push constant 8
@8
D=A
@SP
A=M
M=D
@SP
M=M+1
// add
@SP
AM=M-1
D=M
A=A-1
M=D+M
```

## 原理：把「堆疊動作」展開成「暫存器＋記憶體動作」

VM 是堆疊機（只有推／彈），Hack 是暫存器機（只有 A、D，記憶體靠 `@` 指）。
規則其實只有三條：push＝「值寫進 `SP` 指的地方，`SP+1`」；pop 反向；
`add` 這種＝「彈兩個、算完、推回去」。
其他 segment 是同一招換位址：`local/argument/this/that` 是四個基址暫存器
（`LCL/ARG/THIS/THAT`），`push local 2` 即「讀 `LCL+2` 再推」；
`temp` 是固定 RAM 5–12；`pointer 0/1` 就是 THIS/THAT 本體；
`static` 用 `檔名.編號` 當符號（靠組譯器配到 RAM 16 起，天然不撞）。

[`vm2asm.js`](../lib/asm/vm2asm.js) 剩下兩個固定套路：

- `eq/gt/lt`：彈兩個相減，用 `JEQ/JGT/JLT` 跳，真值寫全 1（`-1`，
  Jack 的 true 就是全 1），假值寫 0；跳轉標號全域編號。
- 函式呼叫是五格幀：`call` 壓「回來位址」＋LCL/ARG/THIS/THAT 舊值，
  `ARG＝SP－5－參數個數`、`LCL＝SP`；`return` 把返回值寫進 `*ARG`，
  由內而外還原，最後跳回。`R13` 暫存 FRAME、`R14` 暫存 RET——
  因為還原過程中 LCL 本身一直被改，得先抄一份。
  多檔才寫的開機碼（`SP=256` 後 `call Sys.init`）叫 bootstrap；
  多檔標號加 `函式$` 前綴防相撞（C 版原樣輸出所以組不了多檔 OS，這裡修掉了）。
