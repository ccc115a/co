此前 `index.html` 只能開檔、沒有範例選單，`rvemu.html` 有範例選單、
只能貼上，兩邊鏡像不對稱。本版補齊，行為如下。

## 做了什麼

- `dist/emu-common.js`（`?v=1`→2）：新增共用 `PROGRAMS`（同 12 支 Jack 名單，
  與 `jack.html` 同名）、`OS_DIR`、`jackSources`、`compileJackVm`
  （Jack→VM，使用者模組＋OS 在前）、`fillExampleSelect`。
  `jack.js`／`browser_jack_smoke.js`／`test_vm2riscv.js` 各自的清單暫不動（P6 待收）。
- `dist/rvemu.js`（`?v=6`→7）：自有 `PROGRAMS`／`jackSources`／選單迴圈改吃共用；
  `compileExample` 瘦身為 `EC.compileJackVm`＋嚴格翻譯（其餘逐字保留）。
- `dist/app.js`（`?v=11`→12）＋`dist/index.html`：新增範例下拉選單，
  選取即 `compileJackVm`→`HackVm2Asm.translate`→填入組語區→走原 `load()` 流程；
  初始仍載入內建乘法 sample，不改變首屏行為。
- `dist/rvemu.html`＋`dist/rvemu.js`：新增 `開啟 .s…` 鈕＋隱藏 file input，
  讀檔後填入 `.s` 編輯區並走原 `load()` 流程（與 `app.js` 的 `.asm` 開檔同語意）。
- 表頭順序對齊：`index.html` 的按鈕重排為 範例 → 開檔 → 載入 → 執行 → 單步 →
  重設 → 速度，與 `rvemu.html` 一致（後者獨有的 `重編 Jack`、`上限` 保留；
  純 DOM 順序調動，邏輯零改動）。
- 四頁共用頁面切換選單順序改為 Jack 編譯器 → HACK 模擬器 → RISCV 模擬器 →
  HDL 模擬器（跟著寫程式→編譯→模擬的工作流；切換邏輯按 value，與順序無關）。

## 刻意不統一的三處

速度映射數字（Pong 物理）、記憶體面板（word 機 vs byte 鏡像）、hash 書籤格式。
另：HackCPU 後端無 ROM 上限檢查，Pong＋全 OS 超 32K 照跑（模擬器無此限制），
僅在狀態列顯示行數，不擋。
