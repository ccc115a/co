# 20 組譯器：把助憶符變成 0/1

## 用法

[`cli/hackasm.js`](../cli/hackasm.js)：`node cli/hackasm.js <Name>`
讀 `<Name>.asm`，同時寫 `.hack`（給人看）與 `.bin`（給模擬器吃）。

## 完整範例

輸入（6 行 Hack 組語，算 2+3 存進 R0）：

```
@2
D=A
@3
D=D+A
@0
M=D
```

輸出 `.hack`（真實產物，逐行對）：

```
0000000000000010
1110110000010000
0000000000000011
1110000010010000
0000000000000000
1110001100001000
```

`@2`→`000…0010`；`D=A`→`1110(110000)010(000)`；
`@3`；`D=D+A`→`1110(000010)010(000)`；`@0`；`M=D`。
[`hackasm.js`](../lib/asm/hackasm.js) 的 `C_MAP` 就是那 28 條助憶符的全表
（含 `M` 版 8 條），拼錯助憶符會在 `code2binary` 被 throw 抓到。

## 原理：查表不難，難的是符號，所以跑兩遍

真正的麻煩是**符號**：`(LOOP)` 的位址＝它是第幾條「真正的」指令，
從頭數就行；但 `@LOOP` 可能出現在 `(LOOP)` 定義**之前**（向前跳），
讀到它時還沒見過。解法是老掉牙的 **two-pass**：

- **pass1**：只數數。遇到 `(LABEL)` 登記「名字→位址」，指令行只計數不編碼。
- **pass2**：正式編碼。`@數字` 直接用；`@名字` 查表，查不到就是新變數，
  從 RAM 16 開始配（`R0–R15`、`SCREEN`、`KBD` 等預定義的不佔名額）。

對應到程式：`parseAsmLine` 去前導空白、`//` 註解；
`assemble` 回傳 `{hack（字串，每行 16 個 0/1）, bin（小端 Uint8Array）}`。
