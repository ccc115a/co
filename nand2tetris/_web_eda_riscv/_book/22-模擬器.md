# 22 假裝自己是 CPU：`hackemu`

## 用法

[`lib/vm/hackemu.js`](../lib/vm/hackemu.js) 的 `Vm` 沒有 CLI 包裝也能直接用
（純資料結構，UI 不碰核心）。拿 20 章那 6 行機器碼餵進去跑 6 步：

```
vm.loadHack('0000000000000010\n1110110000010000\n...');
vm.run(6);
// → RAM[0]=5, A=0, D=5, PC=6（真實執行結果：2+3 進了 R0）
```

[`cli/hackemu.js`](../cli/hackemu.js) 是無頭版，測試不需要畫面：

```
node cli/hackemu.js --headless prog.bin --max N [--dump A,B] [--keys F] [--trace N] [--img F]
```

`--max` 跑滿即停（程式多半不 halt，regression 都看記憶體斷言）、
`--dump A,B` 印區間、`--trace` 印執行軌跡、`--img` 存螢幕 PPM、
`--keys` 照「指令數＋按鍵」事件表餵鍵。

## 完整範例：同一招放大

[`gen/chain/`](../gen/chain/) 就是上面的 6 步放大版：Jack 的 `let x = 5`
一路翻下來，跑 5000 步後 `RAM[16]` 從 0 變成 5
（[`chain.tst`](../gen/chain/chain.tst) 在驗的就是這個）。
Pong 回歸（[`verify.sh`](../verify.sh) v0.7.1）更進一步：
`--keys` 按住左／右 3 億步，擋板位置分離＞100px——
事件表只是 `1000000 left` 這種「第幾步、按什麼」兩欄文字。

## 原理：取指、解碼、執行的無窮迴圈

CPU 每個周期只做三件事，`step()` 照抄：取 `rom[pc]`；
最高位 0 是 A 指令，1 是 C 指令（切出 `a-bit/comp(6)/dest(3)/jump(3)`）；
查 ALU 表算 16-bit 結果，按 dest 寫 A/D/M，按 jump 決定 `pc`。
全部狀態就是 `rom＋ram＋A＋D＋pc`——沒有任何系統依賴，
這也是它能跑在瀏覽器裡的原因。

兩個和 `CPU.hdl` 一致、但容易寫錯的語意：**M 寫入用更新前的 A**
（`AM=M-1` 這種又當位址又當目標的指令，程式裡先 `aOld` 存一份），
**jump 用更新後的 A**（`A=M;JMP` 跳新 A）。一前一後，順序反了
Pong 這類程式就會亂跑。

記憶體映射：RAM 共 32768 words，`16384–24575` 是螢幕（512×256，
word 的 bit15 是最左像素），`24576` 是鍵盤（`setKey` 寫鍵碼，
方向鍵 130–133）。`runUntil` 每步回報、可中途喊停；`reset` 全清。
