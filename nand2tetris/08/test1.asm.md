# test1.asm 程式說明

這是 `test1.vm` 經由 `vm2asm.c` 翻譯出來的 Hack 組合語言程式，內容正好
22 行：兩段 `push constant` 加上一段 `add`。它是最基本的「VM 指令到 Hack
指令」對照範例。

## 概述

- 來源：`test1.vm` 的三行指令被翻譯器展開成數十行 Hack 指令。
- 對應的 C 語言：`int x = 7 + 8;`
- 產出方式：`./vm2asm test1.asm test1.vm`

## 架構總覽

| 行號 | 對應 VM 指令 | 角色 |
|------|--------------|------|
| 1–8 | `push constant 7` | 把 7 壓入堆疊 |
| 9–16 | `push constant 8` | 把 8 壓入堆疊 |
| 17–22 | `add` | 取出頂兩值相加，結果壓回 |

## 原理：定址模式與堆疊

Hack 組合語言中，`@N` 的用途有二：當後面接 `D=A` 時是「載入立即值」；
當後面接 `A=M`、`M=D` 這類指令時代表「把 A 設為位址」。翻譯器正是用這
兩種語意來實現 VM 的 `push`。

堆疊的追蹤靠 `SP`（RAM 位址 0）指向「下一個空位」；`@SP / A=M` 讓 A
指向堆疊頂的空槽，`@SP / M=M+1` 讓指標推進。

## 實作細節（逐段對照）

### 第一段：push constant 7（第 1–8 行）

```
@7
D=A      // D = 7（立即值）
@SP
A=M      // A = 堆疊指標
M=D      // RAM[SP] = 7
@SP
M=M+1    // SP++
```

壓入後 `SP` 指向下一個空位，堆疊中有 `[7]`。

### 第二段：push constant 8（第 9–16 行）

同上，把值 8 放到 `SP` 所指處，堆疊變成 `[7, 8]`。

### 第三段：add（第 17–22 行）

```
@SP
AM=M-1   // 先把 SP 減一，並讓 A 指向新的堆疊頂（= 8）
D=M      // D = 8（第二個運算元）
A=A-1    // A 指回第一個運算元（= 7）
M=D+M    // RAM[原SP-2] = 7 + 8 = 15
```

`AM=M-1` 是 Hack 的組合語法：一個運算同時更改 A 與 M（也就是間接定址的
目標）與 M（指標暫存器）。執行完後堆疊只剩下一個值 15，`SP` 也正確指向
下一個空位。

## 測試與驗證

- 用 CPU Emulator 或 Hardware Simulator 載入這支 `.asm`（先經組合器組譯成
  `.hack`）執行。
- 觀察 `RAM[SP]` 之前的值：最後應為 15，而 `SP` 指向 257（256 起算，壓入兩值、
  退掉一值）。

## 延伸討論

對照注釋可看出翻譯器的「一對多」特性：3 條 VM 指令變成 22 條 Hack 指令。
Hack 沒有專用堆疊指令，一切靠 `@SP` 間接定址與 `AM=M-1` 的自動遞減來模擬，
這是理解後面所有測驗程式輸出檔（如 SimpleAdd.asm、StackTest.asm）的基礎。
