# SimpleAdd.asm 程式說明

這是 `SimpleAdd.vm` 由 `vm2asm.c` 翻譯而成的 Hack 組合語言檔。全檔共
24 行（前導空行加上翻譯器開頭的分隔註解除外），對應 3 條 VM 指令，
是同目錄 `SimpleAdd.vm` 的機器碼層面鏡像。

## 概述

- 來源：`push constant 7; push constant 8; add`
- 對應 C 語言：`int x = 7 + 8;`
- 特性：這是無 bootstrap 的單檔翻譯（翻譯器在單檔模式不自動產生 `SP=256`）。

## 架構總覽

| 註解標示 | 行號 | 功能 |
|----------|------|------|
| `// ========== File: ... ==========` | 2 | 標記此段來自哪個 `.vm` 檔 |
| `// push constant 7` | 3–10 | 壓入 7 |
| `// push constant 8` | 11–18 | 壓入 8 |
| `// add` | 19–24 | 頂兩值相加 |

## 原理

Hack 的 `@N` 指令語意由下一個指令決定：
- `@N` 後接 `D=A`：把立即值 N 放進 D。
- `@N` 後接 `A=M`：把 `RAM[N]` 當成位址載入 A（間接定址）。

堆疊用 `SP`（RAM[0]）指向「下一個空槽」。`push` 就是「寫入 `RAM[SP]` 再
`SP++`」；`add` 就是「`SP--`，取出 y，指回 x，相加寫回」，用 `AM=M-1`
合併前兩步。

## 實作細節

### push constant 7（第 3–10 行）

```
@7
D=A        // D = 7
@SP
A=M        // A = RAM[SP]（堆疊頂）
M=D        // 寫入 7
@SP
M=M+1      // SP 推進一格
```

### push constant 8（第 11–18 行）

機制完全相同，把 8 放到堆疊第二個位置，`SP` 現在指向第三個空槽。

### add（第 19–24 行）

```
@SP
AM=M-1     // 指標減一，且 A 指向新頂（= 8）
D=M        // D = 8
A=A-1      // A 指回 7
M=D+M      // RAM[舊SP-2] = 15
```

執行完畢，堆疊只剩 `RAM[256] = 15`，`SP = 257`。注意最後一步是
「把 7 的位置覆寫為 15」，堆疊餘下一個元素，符合「`add` 取出兩個、放回一個」
的語意。

## 測試與驗證

- 用 CPU Emulator 載入；`RAM[0] (SP)` 結束值應為 257，`RAM[1] (256)` 應為 15。
- 若要獨立執行需自行初始化 `SP=256`（本檔因單檔翻譯不含 bootstrap；在
  VM Emulator 中不受影響）。

## 延伸討論

翻譯器在每個區塊前以 `// push constant 7` 之類的註解保留原始 VM 指令，
讓讀者能一行行對齊「VM → Hack」。這正是本教材所有測驗 `.asm` 的共同格式：
先有 `//` 註解（原指令），緊接一串機器碼展開。
