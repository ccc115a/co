# test1.asm 程式說明

這是以 `./vm2asm test1.asm test1.vm` 產生的 Hack 組合語言原始碼，內容是 test1.vm 三條指令的完整翻譯結果。整份檔案不含註解列的「真指令」共 22 行。

## 對應關係一覽

輸出中每個區段前方都有一個 `// 原本的 VM 指令` 註解，這是 vm2asm.c 刻意保留的，方便把翻譯結果與原始 .vm 對照：

| VM 指令 | .asm 行數 | 摘要 |
|---------|-----------|------|
| push constant 7 | 1–8 | 5 條指令：值 7 → D → 堆疊頂 → SP+1 |
| push constant 8 | 9–16 | 同前，值 8 |
| add | 17–22 | 5 條指令：pop y → 就地加 x |

## 逐段解讀

### push constant 7（第 1–8 行）

```asm
@7        // A = 7（立即值）
D=A       // D = 7
@SP       // 取得 SP 暫存器位址
A=M       // A = SP 內容（堆疊頂端空位）
M=D       // RAM[SP] = 7
@SP
M=M+1     // SP = SP + 1
```

`push constant 7` 不觸碰任何記憶體段，只把常數塞到 SP 所指處。

### push constant 8（第 9–16 行）

結構完全相同，現在堆疊變成 `[7, 8]`，SP 指向 8 之上。

### add（第 17–22 行）

```asm
@SP
AM=M-1    // SP -= 1；A 同時指向 8
D=M       // D = 8，這是「右運算元」y
A=A-1     // A 指向 7
M=D+M     // M 原為 7，現在 = 7 + 8 = 15
```

注意 `AM=M-1`：一行同時完成「SP 減一」與「把 A 設成 SP 所指位址」。之後 `A=A-1` 是算出前一個堆疊元素位置。相加結果覆寫回 x 的位置，SP 不必再調整，等於 Stack 深度少一。

## 執行後狀態

- RAM[0]（SP）= 257
- RAM[256]（堆疊底）= 15
- 其他 RAM 全部保持 0

用 CPU Emulator 載入 test1.asm 即可觀察到這三個數字的變化。
