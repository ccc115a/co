# Mux16.hdl 程式說明

16 位元多工器：`for i = 0..15: out[i] = a[i] if sel == 0，否則 out[i] = b[i]`。一個選擇位元同時切換整條 16 bit bus。

## 概述

`Mux16` 是 `Mux` 的 bus 版本：16 對 1-bit 訊號線共用同一個 `sel`。第一章的 16 位元元件一律採用「1-bit 閘 ×16 展開」模式，本電路是最後一顆這種樣板的元件，之後的 4-way、8-way 版本則是以 `Mux16` 為單位逐層堆疊。

## 介面與規格

| IN/OUT | 名稱 | 寬度 |
|--------|------|------|
| IN | `a[16]` | 16 bit |
| IN | `b[16]` | 16 bit |
| IN | `sel` | 1 bit |
| OUT | `out[16]` | 16 bit |

真值表明確用整條 bus 示範（對應第四組測試值）：

| a（16 bit）    | b（16 bit）    | sel | out |
|----------------|----------------|-----|-----|
| 1010101010101010 | 0101010101010101 | 0 | 1010101010101010 |
| 1010101010101010 | 0101010101010101 | 1 | 0101010101010101 |

逐位元 `out[i] = a[i]`（sel=0）或 `b[i]`（sel=1），16 位一起翻，任一 bit 的規則都與 1-bit `Mux` 相同。

## 原理

Bitwise 選擇與 1-bit 版本完全同構，只是把數量擴展成 16：

```
out[i] = (a[i] AND NOT sel) OR (b[i] AND sel)，對所有 0 <= i <= 15
```

16 顆 `Mux` 使用相同的 `sel`，彼此平行、延遲與單顆相同。「一個控制位元管一整條 bus」是 bus 設計最重要的概念：控制線只有一根，資料線有十六根。

## 實作細節

```hdl
Mux(a=a[15], b=b[15], sel=sel, out=out[15]);
Mux(a=a[14], b=b[14], sel=sel, out=out[14]);
...
Mux(a=a[0],  b=b[0],  sel=sel, out=out[0]);
```

16 個 `Mux` 上的 `sel` 接腳全部接到同一条 `sel` 輸入；a、b 則各自取了 bus 的一個索引位元，輸出落回對應的 `out[i]`。這裡刻意「不放進兩種 bus 中間線」：每一顆 Mux 直接由外部輸入取位、直接寫回外部輸出，結構最清晰。

## 測試與驗證

執行 `Mux16.tst`，四組 `(a,b)` 各配 `sel=0`、`sel=1`：

- `(0,0)`、`(0,1234h)`、`(9876h,0)`：極端與部分歸零，驗證切換正確。
- `(1010…, 0101…)`：互補型樣，`sel` 翻轉時 out 應在兩者之間互換。

`output-list a%B1.16.1 b%B1.16.1 sel%D2.1.2 out%B1.16.1`——注意 `sel` 用十進位（`%D`）兩格輸出，其餘 16 位元二進位。與 `Mux16.cmp` 全行比對。

## 延伸討論

- 第二章 ALU 的三個輸入選擇位元（`zx`、`zy`）背後就是一排 `Mux16`；`Mux16` 也是 RAM 讀寫路徑中「選資料來源」的主力。
- 若需要「sel 切換哪顆輸入」由多個 bit 決定，就成為多路版本：`Mux4Way16`、`Mux8Way16` 用 2–3 個選擇位元組出 2³ 條輸入路線，實務上等同 RAM 的位址解碼開關。
