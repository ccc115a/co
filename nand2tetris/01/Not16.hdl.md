# Not16.hdl 程式說明

16 位元反相閘：將 16 條輸入訊號逐位元取補數，`for i=0..15: out[i] = not in[i]`。

## 概述

`Not16` 是第一顆引入 **bus（匯流排）** 概念的元件。Hack 電腦的資料字組寬度是 16 bit，因此「一整個字」的運算需要一次處理 16 條平行線。這顆閘把 16 顆 1-bit 的 `Not` 複製十六份，各自服務一個位元，對應第一章「把單一位元閘擴展成 16 位元閘」的通用模式。

## 介面與規格

| IN/OUT | 名稱 | 寬度 |
|--------|------|------|
| IN | `in[16]` | 16 bit |
| OUT | `out[16]` | 16 bit |

用 `a[15..0]` 表示從最高位（index 15）到最低位（index 0）的整條匯流排，則：

```
out[15..0] = NOT in[15..0]
```

真值表以幾個代表性的 16 位元值示範：

| in（二進位 16 bit） | out |
|---------------------|------|
| 0000000000000000 | 1111111111111111 |
| 1111111111111111 | 0000000000000000 |
| 1010101010101010 | 0101010101010101 |

逐位元運算：最左邊（最高位）的 `1` 變成 `0`，以此類推，每一位元各自獨立反相，彼此不互相影響。

## 原理

Bitwise 運算的定義就是「同索引位元各自套用 1-bit 運算」。布林代數式寫成：

```
out[i] = NOT in[i]，對所有 0 <= i <= 15
```

這 16 個 `Not` 完全平行，彼此之間沒有資料相依，因此總延遲等同單顆 `Not` 的延遲。

## 實作細節

```hdl
Not(in=in[15], out=out[15]);
Not(in=in[14], out=out[14]);
...
Not(in=in[0],  out=out[0]);
```

16 個 PARTS 全部長得一樣，只是索引不同。這是標準的「展開式（unrolled）寫法」：HDL 沒有迴圈語法，必須把 bus 的每一條線手動拆開、逐位元接線。索引從 `15` 寫到 `0` 是刻意安排的，讓最高位在檔頭、最低位在檔尾，與直覺的位序一致。

## 測試與驗證

執行 `Not16.tst`，測試腳本選了五組「每個位元都不同」的型樣：

- 全 0、全 1：驗證極端值。
- `1010101010101010`（交錯亮暗）：每位元的輸出都互補。
- `0011110011000011`、`0001001000110100`：隨機型樣，抓到任何一位接錯。

`output-list in%B1.16.1` 以無分格的 16 位元二進位輸出。比對 `Not16.cmp` 即可自動驗證。

## 延伸討論

- 第二章 ALU 的 `nx`（negate input x）控制位元就是用 `Not16` 實現「對整個 16 位元字取反」。
- 16 bit 是 Hack 的硬體寬度；若改用其他寬度（如 8 或 32），只需把 PARTS 改成對應數量即可。這種「把 1-bit 閘平行複製 n 份」的做法，是所有 bitwise 元件（`And16`、`Or16`、`Mux16`…）的共同骨幹。
