# Mux8Way16.hdl 程式說明

八路 16 位元多工器：三條選擇位元 `sel[2..0]` 從八條 16-bit bus（`a`…`h`）中挑出一條輸出。

## 概述

`Mux8Way16` 是多路多工器的最終版：`sel[3]`（3 bit）編出 2³ = 8 種選擇碼。它**重用**兩顆 `Mux4Way16` 當作子電路，再補一層 `Mux16`，把「4 選 1 ×2 組 → 2 選 1」堆成三層樹。這是 Nand2Tetris 第一章「分層組合」精神的極致示範：功能愈大，電路反而愈由小元件重組而成。

## 介面與規格

| IN/OUT | 名稱 | 寬度 |
|--------|------|------|
| IN | `a`…`h` | 各 16 bit |
| IN | `sel[3]` | 3 bit |
| OUT | `out[16]` | 16 bit |

真值表：

| sel（二進位） | 輸出 |
|---|---|
| 000 | a |
| 001 | b |
| 010 | c |
| 011 | d |
| 100 | e |
| 101 | f |
| 110 | g |
| 111 | h |

索引約定同 `Mux4Way16`：`sel[0]` 為 LSB、`sel[2]` 為 MSB。例如 `sel=101` 即二進位 5，輸出 f。

## 原理

「八選一」沿用「先分組、再對決」的樹狀思路，但把樹加高一層：

- 第一葉：排 `a…d` 成「上組」，`e…h` 成「下組」。
- 第一層：兩顆 `Mux4Way16` 各用 `sel[0..1]`（低兩位）在自己的四人組內挑一位。
- 第二層：一顆 `Mux16` 用 `sel[2]`（最高位）決定上組還是下組勝出。

位址位的分工剛好對應選擇碼的三個位元——**從 LSB 往上，位元 0、1 管分組內四人，位元 2 管跨組**。以 `sel=100`（二進位，MSB=1）為例：`sel[0..1]=00` 使上組挑出 a、下組挑出 e，最後 `sel[2]=1` 選下組 → out=e，正好是選擇碼 4。

布林視角：這顆電路實作一個 3 位元位址 → 8 條資料匯流排的去碼器 + 資料選擇器的合體，延遲為三層 `Mux16` 累加。

## 實作細節

```hdl
Mux4Way16(a=a, b=b, c=c, d=d, sel=sel[0..1], out=outad);
Mux4Way16(a=e, b=f, c=g, d=h, sel=sel[0..1], out=outeh);
Mux16(a=outad, b=outeh, sel=sel[2], out=out);
```

- 第一顆 `Mux4Way16` 輸出 `outad`：由 `sel[0]`、`sel[1]` 從 a…d 選一。
- 第二顆同理輸出 `outeh`：從 e…h 選一。
- 第三顆 `Mux16` 以最高位 `sel[2]` 從 `outad` / `outeh` 擇一 → `out`。

注意兩處語法特色：`sel[0..1]` 是 **bus slicing**，把 `sel[3]` 切成「保留低兩位」的 2 位子匯流排直接餵給 `Mux4Way16` 的 `sel[2]` 接腳——HDL 允許把多 bit 線截段當成較窄 bus 使用；`Mux16` 則只要單一位 `sel[2]`。命名 `outad`、`outeh` 代表「涵蓋 a…d」「涵蓋 e…h」。

## 測試與驗證

執行 `Mux8Way16.tst`：

- 前半段：全 0 輸入，`set sel 0..7`（十進位）8 次，驗證不管選誰輸出都為 0。
- 後半段：八條互異的非零 bus（`0001001000110100`、`0010001101000101`…），再對 `sel=0..7` 逐次輸出，確認每次吐出恰為對應輸入。

`output-list a..h ... sel%B2.3.2 out%B1.16.1`：`sel` 3 格二進位、bus 各 16 格。與 `Mux8Way16.cmp` 全行比對。通過代表「三顆元件接線正確、位址解碼正確」。

## 延伸討論

- 一般化：2^n 路多工器需要 n 條選擇線、n+1 層遞迴（葉子本身是葉子情況）。`Mux8Way16 = 2×(Mux4Way16) + 1×(Mux16)`，而規格上也可以寫成第七層 `Mux8Way16` 內再堆 4 顆 `Mux16`……讀者可試試「唯一顆顆自己拼」與「重用既有元件」的兩種寫法，體會階層設計對可讀性與錯誤偵錯的差別。
- 第三章的 RAM 記憶體陣列（如 RAM8 = 8 個 Register + 選擇器）正好是 `DMux8Way` 配 `Mux8Way16` 對偶使用：一個分資料出去（解多工器），一個收資料回來（多工器），兩者共用同一組位址位元。
