# 00 總覽：一句話講完整件事

## 這個專案在做什麼

拿 Jack 高階語言寫的程式（例如 Pong），一路翻成機器聽得懂的東西，
最後在「假的電腦」（模擬器）上跑起來；同時也能從硬體描述語言（HDL）
搭出真的數位電路邏輯，並用同樣的模擬器驗證。全部用 JavaScript 寫，
Node 命令列和瀏覽器網頁共用同一套核心（[`lib/`](../lib/)）。

## 三條線，一個骨架

所有工具其實只做三種事，排列組合而已：

1. **翻譯**：A 語言翻成 B 語言（Jack→VM、VM→組合語言、組合語言→機器碼）。
2. **轉換**：圖狀結構攤平成可執行的順序（HDL 接線圖→求值順序→JS 程式）。
3. **模擬**：假裝自己是 CPU，一條一條執行機器碼（`hackemu`、`rvemu`、
   HDL 產生的模擬程式都是這一種）。

兩條主線管線長這樣：

```
HackCPU：.jack → VM → 組語(.asm) → 機器碼(.hack) → hackemu 執行
RISCV ：.jack → VM → RV組語(.s) → rvasm 組譯 → rvemu 執行
硬體線：.hdl → 解析 → 詳述 → 產生JS → 吃 .tst 測資驗證
```

後面每章都照「用法 → 完整範例 → 原理」寫：先給你指令和真實輸出，
再解釋內部設計。

## 一個例子走全程（[`gen/chain/`](../gen/chain/)）

[`Main.jack`](../gen/chain/Main.jack) 只有三行有意義：`static int x;`
`let x = 5;` 然後無窮迴圈。它被翻成 VM（[`Main.vm`](../gen/chain/vm/Main.vm)
的 `push constant 5; pop static 0`），再翻成 Hack 組語，再編成 0/1 機器碼
（[`chain.hack`](../gen/chain/chain.hack)），最後餵給 HDL 搭出來的整台
`Computer` 模擬——`RAM[16]` 從 0 變成 5。
[`chain.tst`](../gen/chain/chain.tst) 就是這整件事的自動驗證（[70 章](70-語料與驗證.md)）。
[`gen/sum/`](../gen/sum/) 是同一條鏈的 1+…+10＝55 版。
