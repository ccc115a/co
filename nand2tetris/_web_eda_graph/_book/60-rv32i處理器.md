# 60 自研 RV32I 處理器（`Riscv32i/`）

## 用法

[`Riscv32i/`](../Riscv32i/) 是一顆用 HDL 從零搭起的單週期 RV32I，
跑法和 14 章完全一樣，只是換個目錄、換個測資：

```
node cli/hdl2js.js --dir ../01 --dir ../02 --dir ../03/a --dir ../03/b \
  --dir ../05 --dir Riscv32i --test Riscv32i/sum10.tst
```

```
PASS Riscv32i/sum10.cmp
==== 結果：1 通過，0 失敗 ====
```

`--dir` 照樣疊函式庫（01、02 的閘＋`Riscv32i` 自己的 32-bit 零件）；
`--test` 挑測資：[`rv32i.tst`](../Riscv32i/rv32i.tst) 是 60 條指令的綜合測資，
[`sum10.tst`](../Riscv32i/sum10.tst) 是 1+…+10 的記憶體示範。
在 [`hdl.html`](../dist/hdl.html) 選「06 RV32I 處理器」章節跑的是同一批。

## 完整範例

輸入分兩種檔案。第一種是測資 [`sum10.tst`](../Riscv32i/sum10.tst) 全文
（10 條指令的小程式，37 個周期跑完；先 `set dbgRd 1` 讓 `dbgReg` 欄
跟著累加器 `x1`，所以中間和全看得到）：

```
load rv32i.hdl,
output-file sum10.out,
compare-to sum10.cmp,
output-list pc%X1.8.1 dbgReg%D1.10.1 RAM32W[16]%D1.10.1 time%S0.6.1;

ROM32 load sum10.hack,
set dbgRd 1,
repeat 45 { tick, tock, output; }
set dbgRd 0, eval, output;
...
```

第二種是測資吃的機器碼 [`sum10.hack`](../Riscv32i/sum10.hack) 全文
（10 行，來自 [`sum10.asm`](../Riscv32i/sum10.asm) 的 10 條組語：
`addi×4` 開場、`add/addi/blt` 迴圈、`sw/lw` 存取、`halt` 收尾，
由 `Riscv32/asm.js` 組譯，助憶符只加不改舊版）：

```
00000000000000000000000010010011
00000000000100000000000100010011
00000000101000000000000110010011
00000000101100000000001000010011
00000000001000001000000010110011
00000000000100010000000100010011
11111110010000010100111101100011
00000000000100000010100000100011
00000001000000000010001010000011
00000000000000000000000001111111
```

輸出是 52 行的表（[`sum10.cmp`](../Riscv32i/sum10.cmp)，截錄中間和出現處）：

```
|    pc    |   dbgReg   | RAM32W[16] | time  |
| 00000001 |          0 |          0 |1      |
| 00000005 |          1 |          0 |5      |
| 00000005 |          3 |          0 |8      |
| 00000005 |          6 |          0 |11     |
```

`dbgReg` 走出 `0→1→3→6→…→55`——正是 1、1+2、1+2+3……的縮時攝影；
`mem[16]` 在 `sw` 退休那刻變 55，最後 `HALT` 凍結在 `pc=9`。

## 原理：單週期資料通路（[`rv32i.hdl`](../Riscv32i/rv32i.hdl)，60 行）

```hdl
R32(in=pcNext, load=pcLoad, out=pc);
ROM32(address=pc[0..14], out=instr);
...
RvDec(instr=instr, rd=rd, rs1=rs1, rs2=rs2, imm=imm, ctl=ctl);
RF32(a1=rs1, a2=rs2, a3=dbgRd, rd=rd, wd=wbData, we=ctl[0],
     d1=r1, d2=r2, d3=dbgReg);
...
RvAlu(a=aX, b=bX, fn=ctl[12..15], y=aluY);
RvBr(a=r1, b=r2, f3=instr[12..14], taken=brTaken);
...
RAM32W(in=r2, load=ctl[1], address=aluY[0..14], out=memOut);
```

- **IF**：PC（`R32`）→ `ROM32` 取指；`pcSeq＝pc＋1`、`pcTgt＝pc＋imm` 先算好。
- **ID**：[`RvDec.hdl`](../Riscv32i/RvDec.hdl) 拆出 `rd/rs1/rs2/imm/ctl`，
  自有 `ctl[15:0]` 編碼（`0 regW｜1 memW｜…｜8 halt｜9 branch｜10 jal｜
  11 jalr｜12..15 aluFn`）；`RF32` 讀 `r1/r2`（第三讀口專供除錯）。
- **EX**：A 選（`r1/imm/pc`，LUI／AUIPC 用）× B 選（`r2/imm`）→ `RvAlu`；
  `RvBr` 判六種分支；JALR 目標＝`r1＋imm`。
- **MEM／WB**：`SW` 寫 `r2`；`aluY`／`memOut`／`pcSeq`（link）三選一寫回。
- **HALT**（opcode `1111111`）：黏住 `halted`，`pcLoad` 歸零凍結 PC。

指令集：R 型全 10 種、I 型移位與 `slti/sltiu`、LW/SW、LUI/AUIPC、
JAL/JALR、六種分支；省略 LB/LH/LBU/LHU/SB/SH、FENCE/ECALL
（word 定址簡化，同 RV32S，檔頭有載明）。

## 子元件與兩個陷阱

- [`RvAlu.hdl`](../Riscv32i/RvAlu.hdl)：`sub` 經 `a＋(~b)＋1`；
  **`slt/sltu` 借同一條減法取借位**（解到二者時把 `subsel` 一併拉起，
  否則 `ltU/ltS` 全錯）；`aluFn` 中 `xor` 的 bit0＝0、`sll` 的 bit1＝0，
  寫 OR 樹時不可多收。
- [`RvSh32.hdl`](../Riscv32i/RvSh32.hdl)：桶式移位器，右移五級
  （1/2/4/8/16），**SLL 經 bit 反轉走同一條右移鏈**；
  `FILL＝arith&a[31]`（SRA），`sh` 取 `b[4:0]`。
- [`RvBr.hdl`](../Riscv32i/RvBr.hdl)：`eq/ltS` 取自 `Cmp32`，
  `ltU＝~cout` 另起一顆加法器；六種 `funct3` 各一條 AND 再 OR。
- **JALR 不可清 LSB**：byte 版回跳位址恆偶數，`& ~1` 無害；
  word 定址下奇數 PC 合法（link＝35），清掉跳錯一格。
- **AUIPC 要拿 `immU`**：`imm` 多工器 `sel0` 須含 `eqAU`
  （`sel0＝S/B｜U｜AU`），否則拿到 J 型立即數（`auipc x24,1` 變 26）。
  上游 `Dec` 同式子，但 `prog1` 只測 `auipc x25,0` 故沒爆。
- 20 個 32 位元基礎元件自 `Riscv32/_lib` 原樣拷貝
  （[`Mux32`](../Riscv32i/Mux32.hdl)、[`Add32c`](../Riscv32i/Add32c.hdl)、
  [`Cmp32`](../Riscv32i/Cmp32.hdl)…），**不依賴該目錄**；
  設計血淚另見 [`rv32i.hdl.md`](../Riscv32i/rv32i.hdl.md)。
