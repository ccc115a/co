# 50 網頁是怎麼跑起來的

## 用法：四個頁面，四種開法

[`dist/`](../dist/) 四個頁面都是 `file://` 雙擊即開，不用伺服器：

| 頁面 | 開啟 | 作用 |
|---|---|---|
| [`index.html`](../dist/index.html) | 直接開（內建乘法範例）或 `#asm=<組語>`／`#file=<語料key>` | 組語模擬器：組譯→執行→看螢幕 |
| [`hdl.html`](../dist/hdl.html) | 章節選單，或 `#case=../05/CPU&run=1` 直達自動跑 | 批次跑 `.tst`（和 14 章 CLI 同引擎） |
| [`jack.html`](../dist/jack.html) | 頁首切 HackCPU／RISCV，或 `#prog=Fib&backend=riscv&run=1` | 雙後端編譯器 |
| [`rvemu.html`](../dist/rvemu.html) | 範例選單，或 `#prog=Pong&run=1` | 互動 RV 模擬器 |

## 完整範例：地基三件套的載入順序

每個頁面 `<head>` 尾巴都長這樣（[`hdl.html`](../dist/hdl.html) 真實截錄，
`?v=` 是快取版號，改了對應 `.js` 就＋1，否則瀏覽器快取會讓你除錯到懷疑人生）：

```html
<script src="corpus.js?v=14"></script>
<script src="hdl-rt.js?v=10"></script>
<script src="embed.js?v=14"></script>
<script src="hdl.js?v=12"></script>
```

1. **[`corpus.js`](../dist/corpus.js)**：[`tools/gen_corpus.js`](../tools/gen_corpus.js)
   跑出 `→ dist/corpus.js（188 檔）`——把各章 `.hdl/.tst/.cmp/.hack`
   （跳過要人按鍵的；不含 `.bin`）加 Jack `.jack` 全打包成
   `window.HACKJS_CORPUS`（檔名→全文的 map）。沒有伺服器，檔案只能內嵌。
2. **[`hdl-rt.js`](../dist/hdl-rt.js)**：`HACKJS_FS`／`HACKJS_PATH` shim——
   把語料 map 扮成檔案系統（`readFileSync` 查 map＋記憶體 overlay 接住
   寫出的 `.out`；`readdirSync` 從 key 前綴反推目錄）。`lib/` 裡
   `import fs` 的檔，打包時一律改掛這兩個全域。
3. **[`embed.js`](../dist/embed.js)**：[`tools/embed.js`](../tools/embed.js)
   把 `lib/` 去 `import`、剝 `export`，拼成一支 classic script；
   RV 四檔包獨立 IIFE 防同名互蓋；最後匯出
   `HackVM/HackAsm/HackVm2Asm/HackVm2Rv/HackRv/HackJack2Vm/HackHdl`
   到 `window`。

## 原理：各頁面只是同一引擎的不同皮膚

- [`app.js`](../dist/app.js)（`index`）：組譯→`Vm` 跑→canvas 畫螢幕；
  和 `jack.html` 有跨視窗送組語協議（`hackjs-*`）。
- [`hdl.js`](../dist/hdl.js)：章節選單（01／02／03ab／04／05／全鏈路／RV32I）
  ＋自訂三欄，`runCase` 走和 CLI 相同的 elab→產生碼→`new Function`→比對，
  結果進表格、✓／✗ 橫幅。
- [`jack.js`](../dist/jack.js)：顯示分頁只看使用者模組；`▶執行`與送模擬器
  用 OS 在前的全量；RISCV 的全量 `.s` 經 `rvjs-*` 送到 `rvemu.html`。
- [`rvemu.js`](../dist/rvemu.js)：12 支 Jack 範例現場編成 `.s`，可執行／
  單步（PC 高亮只動 class，不重建上萬行列表）／重設；暫存器、STATIC、
  UART、SCREEN 鏡像（逐 word 讀一次展 16 像素）全可看；
  速度桿約 316–10 萬步／幀（預設 60 即 1 萬步／幀，Pong 每幀約走一格，
  太快會一秒 Game Over）；上限 `0`＝無限跑；按鍵寫 KBD 鏡像，放開歸零
  （Pong 擋板會動就靠這個）。
