對應規劃：`_doc/plan3.x.md` 的 P5。只動介面文字與參數解析，不動引擎；
數值預設維持原值（場景不同，僅集中列表，不統一數值）。

## 改了什麼

- 新增 `cli/cliutil.js`（`usageError`／`needVal`／`parseNonNeg`／
  `parseRange`／`parseMax`；`A,B` 十進位／0x 十六進位皆可）。
- `cli/hackemu.js`：英文用法→中文用法字串（含既有但未記載的 `[--img F]`）；
  用法報錯 exit 2→1；`--max`／`--dump`／`--trace`／`--keys`／`--img`
  缺值、未知 `-` 選項、`--max` 非正整數改為乾淨報錯（舊行為是吞掉變
  NaN 或 TypeError 崩潰）；`--dump` 接受 0x（與 riscv_run 對齊）；
  `--trace 0` 仍合法（沿用舊語意：不追蹤）。
- `cli/riscv_run.js`：改吃共用解析（訊息逐字不變，僅 `--dump` 報錯的
  `A,C`→`A,B`）；報表前綴 `MEM[`→`RAM[`（P5 二選一決議；位址照舊用
  十六進位 byte 位址，與 Hack 的十進位 word 號並存，理由見 AGENTS）。
- `cli/hdl2js.js`：用法報錯 exit 2→1（4 處；`--help` 維持 0，測資失敗維持 1）。
- 文件同步：AGENTS（用法行＋步數預設對照表＋`RAM[` 決議）、
  README（CLI 表 `A,B`／RAM）、`_book/41`（範例輸出兩行）。
