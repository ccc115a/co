# hdl2js v0.1 — 版本紀錄

日期：2026-09-12（115 學年度 · 計算機結構）
對應里程碑：**M1 — 組合電路（ch01 + ch02）全數通過**

## 一句話

hackjs 以「Verilator 精神」把 Nand2Tetris 的 `.hdl` 電路描述**轉譯成 JavaScript**
（由 `new Function` 即時載入、零建置），再搭配內建的 `.tst` 執行器跑官方測資並做
逐位元比對。本版（v0.1）宣告組合電路里程碑完成：**第一章、第二章全部 21 個測試 PASS**，
單元測試 53 個全過。

## 資料流

```
<top>.hdl (+BUILTIN Nand/DFF/…) ──parse──▶ AST ──elab──▶ ElabChip 圖
                                                          │
<hdl2js> 載入 .tst，取得 script.load                     ▼
（等於 --top，取 .hdl 檔名）              codegen.generateJs（逐 chip：
                                          wire 展開成 setBits 合併 + 內建 class）
                                                          │
                                            new Function(src) 得 Top class
                                                          ▼
                                 TopModel（setInput/getOutput/tick/tock）
                                                          │
              run(model, script, baseDir, out) ◀─────────┘  → .out ↔ .cmp 比對
```

## 本版實作內容

### lib/hdl/ast.js + parser.js（.hdl 前端）

- 完整 parser：`CHIP`、`IN`/`OUT`、bus 語法（`a[16]`）、`PARTS:`、subchip
  連線（單 pin / bus slice / 常數 `true`/`false`）。
- `Range`：`Whole`/`Bit`/`Slice`（欄位用 `lo0/hi0`，避開 `lo()` method 同名衝突）。
- 可解析 ch01+ch02 全部 21 個 `.hdl`。

### lib/hdl/elab.js（詳述）

- 內建晶片：`Nand`/`DFF`/`ARegister`/`DRegister`/`ROM32K`/`Screen`/`Keyboard`
  （v0.1 只走 Nand 路徑，其餘為 v0.2/v0.3 預留）。
- **多驅動 wire**：支援「子輸出分切寫入」（`Not16` 的 16 個 `Not` 各寫 `out[i]`）；
  位元範圍重疊 → 視為 bug 報錯。
- **OUT 全覆蓋檢查**：輸出必須被完全驅動，避免預設值悄悄成為答案。
- 拓樸排序（前向參考允許）＋組合迴圈偵測（同時讀寫同一 wire）。
- `mergeLibsList([...])`：任意數量 library 合併（`mergeLibs` 只吃兩個）。

### lib/rt/fmt.js + tst.js（執行期）

- `.cmp` 格式：`|a.Bin/D/..|`、表頭置中、`%S` 的 `time` 特殊欄、
  未定義值整欄 `*`（含 outM 在 writeM=0 時）。
- `.tst` 子集：`load`、`output-file`、`compare-to`、`output-list`、
  `set`/`eval`/`tick`/`tock`/`output`、`repeat {}`、`while {}`、
  `<chip> load <file>`（v0.3 用），`//` 註解、`,`/`;`/`{}` 分隔、`"..."` 字串。

### lib/rt/model.js（TopModel）

- 包裝產出 class：`setInput`（pin 名或 `RAM[i]`）、`getOutput`（輸出/輸入/探測）、
  `doEval`/`tick`/`tock`/`loadRom`；`outM` 在 `writeM==0` 時回 `undefined` → 印 `*`。

### lib/hdl/codegen.js（HDL → JS）

- 每顆晶片 → class：`eval`（組合輸出）、`sample`/`tock`（master-slave）、
  `probe_whole`/`probe_indexed`、`set_whole`/`set_probe`、`load_program`。
- 產出完全自足：inline `setBits(w,lo,n,val) + Nand/DFF/Reg/Rom32K/Screen/Keyboard class`，
  `.js` 開頭沒有 import；`new Function` 或存成 ESM（`--keep`）皆可。
- `setBits` 遵守不可變 Number 語義：回傳新值，不只改位元。

### 踩過的坑（實作筆記）

1. `mergeLibs` 只收兩個參數——跑 ch03 測試時第三個被忽略，改成 `mergeLibsList`。
2. `builtinOf` 用 `Builtin[name]` 查不到 `DFF`（enum 鍵是 `Dff`）；加反向表
   `BUILTIN_NAME`，比照 Rust 的 `n::of` 做**確切字串**比對。
3. `e.chips[0]` 是第一個被解析的**子晶片**，不是 top（top 在 `e.chips[e.top]`）。
4. 本地語料與官方差異：`And16.hdl` 用 16 個 `And`、`And.hdl` 是 2 顆 Nand、
   `HalfAdder/FullAdder` 在 `02/`（不在 01）、ALU 有 8 個 in pin。
   測試據此校正，不要硬套官方章節配置。
5. `codegen` 產樣例區塊要包 `{ }`，否則多個有狀態 child 的 `let __c0` 撞名。
6. 產出 ESM（`asModule`）不能過 `new Function`（有 `export` 字句）——分開處理。
7. `center`/`dataLine` 對 ASCII 計寬即可；`undefined` 也要視為未定義（`*`）。
