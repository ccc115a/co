# hackjs v2.1 — 版本紀錄

日期：2026-10-02（115 學年度 · 計算機結構）
對應：v2.0 雙後端的互動延伸——**RISCV 模擬器 獨立頁**

## 一句話

`dist/rvemu.html` 是仿 `index.html` 三欄的 RV32 互動 Emulator：12 支 Jack 範例
（含 Pong）在頁內現場編成 `.s`，可執行／單步（PC 高亮）／重設，看 x0–x31、
STATIC、UART；SCREEN 取 Jack 位址鏡像渲染，◀▶▲▼ 按鍵寫入 KBD 鏡像——
Pong 的擋板在 RV32 上真的會動（鍵盤恆 0 的空等問題就此繞過，
`readChar` 類仍除外，見限制）。`file://` 雙擊即開，零新增建置步驟。

## 本版實作內容

- **新頁 `dist/rvemu.html`＋`dist/rvemu.js`**（仿 `index.html/app.js` 版面與慣例）：
  - ① `.s` 編輯器＋機器碼列表（rvasm `listing` 反組譯，PC 高亮；執行中只動
    class 不重建列表，Pong 14k 行不卡）。
  - ② SCREEN canvas（512×256，讀 Jack SCREEN 鏡像 `0x20000`＋4W，bit15 最左）、
    暫存器（PC／steps／halted／exit＋ra／s1／a0＋x0–x31 ABI 別名）、
    UART 主控台（`Output.print*` 從這裡出來）、按鍵列。
  - ③ 記憶體 word dump（預設 STATIC／stack／heap 鏡像／SCREEN 鏡像，前後頁＋起點長度）。
- **範例＝jack.html 同款 12 支**：選取即 `Jack→VM→RV32` 現場編譯（needsOS 的 OS 在前、
  嚴格翻譯；`[重編 Jack ▸]` 同理；編輯器可直接改 `.s` 再`[組譯並載入]`）。
  自訂 `.s` 貼上天然支援（同頁編輯器就是入口）。
- **執行語意**：rAF 迴圈＋速度滑桿（與 `app.js` 同公式）＋上限步數（預設 20 萬，
  跑滿即停是正常的）；halt（`ecall`）提早停並報 exit；單步＋重設
  （重載 words，記憶體回到乾淨狀態）。
- **鍵盤注入**：按鍵（◀▶▲▼␣按鈕＋實體方向鍵／空白鍵）`pointerdown` 寫 Jack 鍵碼
  進 KBD 鏡像 `0x38000`，放開（`pointerup/leave/keyup`）歸零；多鍵記 held 取最後者
  （與 `app.js` 同邏輯）。Pong 實測：按住左／右 300 萬步，bat 最小 x＝86／382
  （分離 296＞100 門檻，收成 `test_vm2riscv.js` 回歸測試），左右牆分別停 0／511。
- **書籤**：`#prog=Pong[&run=1]`（query `?prog=` 亦可）；切範例寫回 `#prog=`。
- **三頁 header 互連**：`index/hdl/jack` 加 `RISCV 模擬器` 連結，
  `rvemu.html` 連回三頁。
- **jack.html 送 RISCV 模擬器橋接**（v1.1 Hack 橋接的對稱版）：RISCV 模式的
  模擬器按鈕改為「在 RISCV 模擬器跑 ▸」，把 `▶執行` 用的同一份全量 `.s`
  經 `rvjs-load` 送進 `rvemu.html`（`rvjs-ready`／`rvjs-ping` 握手，
  與 `hackjs-*` 共用一台橋接狀態機）；`rvemu.html` 收到即載入自跑。
  12 支範例全數在 RV 上跑成功（`test_vm2riscv.js` 新增全範例 5 萬步不崩回歸）。
- **四頁導覽改選單＋標題統一**：頁首散落的連結改成共用 `#nav` 切換選單
  （HACK 模擬器／HDL 模擬器／Jack 編譯器／RISCV 模擬器）；
  `jack.html ⇄ rvemu.html` 互切時攜帶 `#prog=`；四頁 `<title>`＋`h1` 統一為
  `nand2tetris — <頁名>`。`verify.sh` 的互連斷言同步改認選單 `value=`。
- **零 bundle 變更**：只用既有 `HackJack2Vm/HackVm2Rv/HackRv/HACKJS_CORPUS`，
  `tools/embed.js`、`dist/embed.js`、`corpus.js` 都沒動；新檔 `rvemu.js?v=1` 起跳。

## 踩過的坑（實作筆記）

1. `rvemu.run({maxSteps})` 超步即 throw——Emulator 頁一律手寫 `step()` 迴圈，
   檢查 `halted` 提早停（`riscv_run.js` CLI 同理）。
2. `Emulator.reset()` 不清記憶體但 `loadWords` 會重設 pc／uart／halted——
   Reset 按鈕＝重載 words（回到乾淨的資料 Ram），不是 `reset()`。
3. Pong 14k 行列表每幀 `innerHTML` 重建會卡——PC 高亮只動 `.cur` class，
   捲動只在單步／載入時做。

## 配套工程

- `node --check dist/rvemu.js`；無頭 DOM harness（/tmp 驗完即刪，未進版控）在 Node 跑
  真實 `dist/*.js`：預設 Sum 載入（269 行／213 words）、Seven 自動跑 UART＝`7`、
  Pong 編譯執行＋按鍵注入（KBD 鏡像 `0x82`→放開歸零）、Step／Reset／自訂 `.s`
  跑到 halt（exit＝42）。
- 既有回歸照過：`test_vm2riscv.js` 28/28（本版未動 `lib/`）。

## 驗收

```
file:// 直開 dist/rvemu.html：
  選 Sum → [執行] → STATIC[0]＝5050
  選 Seven → UART 印 7
  選 Pong → [執行] 後按 ◀ ▶，擋板左右移動（SCREEN 鏡像即時重繪）
  #prog=Pong&run=1 直開即跑
```

## 已知限制

- `readChar/readInt`（Average、ConvertToBin）仍會空等：按鍵注入只解決
  `keyPressed` 輪詢式讀鍵，一次一字元的阻塞讀等不到「輸入整行」。
- SCREEN 是單色點陣（Jack 原生語意），無灰階／色彩；canvas CSS 放大，像素顆粒感屬正常。
- 自訂 `.s` 含未定義標籤即組譯報錯（與 `rvasm` CLI 一致）；範例一律走嚴格翻譯，
  失敗（理論上不應發生）顯示訊息不崩頁。
