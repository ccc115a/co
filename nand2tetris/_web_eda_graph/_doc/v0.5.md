# hdl2js v0.5 — 版本紀錄

日期：2026-09-13（115 學年度 · 計算機結構）
對應里程碑：**M5 — 工具鏈三巨頭＋e2e chain，40/40 全綠**

## 一句話

補完整條「高階語言 → 機器碼」工具鏈：`hackasm`（組譯器）、`vm2asm`（VM→HACK）、
`jack2vm`（Jack 編譯器）全部 **byte 相容** C/Rust 既有實作；並用它們把 `gen/chain`
的 Main.jack＋Sys.jack 一路編到 `chain.hack`、跑在 `Computer.hdl` 全機模擬上，
`RAM16K[16]=5` 與 Rust e2e 完全一致。

## 本版實作內容

### 三個編譯器（都在 `lib/` + `cli/`）

| 引擎 | oracle | byte 相容驗證 |
|---|---|---|
| `lib/asm/hackasm.js` | `06/asm.cpp` | add/sum `.bin` 與 06/ 交付物 byte 相同 |
| `lib/asm/vm2asm.js` | `08/vm2asm.c` | 15 個單檔 + 多檔（bootstrap）案例全部 `cmp` 相同 |
| `lib/jack/jack2vm.js` | `11/c/jack2vm.c` | 11 支 `.jack`（含 Pong 5 檔）全部逐字元相同 |

- `jack2vm` 的 C oracle 用 ASan 版本在 macOS spawn 會炸（`asan_init` crash），比對時
  以 `gcc -O2` 無 sanitizer 重建副本當 oracle。
- 移植時刻意保留 C 版的**全部怪癖**以求 byte 相容：
  - vm2asm 每行 VM 前加 `// ...` 註解行、多檔（>1）才寫 bootstrap、
    `// ========== File: <傳入路徑字串> ==========` 標頭用原樣路徑。
  - jack2vm 的 label 編號器（`WHILE_EXP#/WHILE_END#/IF_FALSE#/IF_END#`）跨函式累計、
    `true→constant 0 + not`、字串走 `String.new`/`String.appendChar`、算術 `* /` 走
    `Math.multiply/divide`、`varName.meth()` 依符號表解析型別前綴。
  - 段名映射沿用 `symbol_kind_map`：field→`this`、static→`static`、arg→`argument`、
    var→`local`（SK 順序即索引）。
- 每個 CLI 都維持與既有 `build.sh`/`Makefile` 一致的慣例：
  `hackasm <Name>`（讀 `.asm` 寫 `.hack`+`.bin`）、
  `vm2asm <out>.asm <in>.vm [...]`（多檔自動 bootstrap）、
  `jack2vm <Name.jack|目錄>`（原文在旁建 `output/`）。

### e2e chain（`verify.sh` 新區段）

```
Main.jack + Sys.jack
   → jack2vm    → vm/Main.vm + vm/Sys.vm
   → vm2asm     → chain.asm（含 bootstrap，共 275 行）
   → hackasm    → chain.hack（242 列）
   → hdl2js 跑 chain.tst（Computer.hdl、ROM32K load、repeat 5000）
   期望 RAM16K[16] = 5（Main.x 第一個 static）
```
- 產出的 `chain.hack` 與 `_eda/gen/chain/chain.hack` **byte 相同**；`chain.tst` 結果
  `PASS`（5 全達標）。
- `gen/chain/`（含 Main/Sys/Tst/Cmp）直接對拷 Rust 的同名語料當本地 corpus。
