# hdl2js v0.6 — 版本紀錄

日期：2026-09-13（115 學年度 · 計算機結構）
對應里程碑：**M6 — hackemu 虛擬機核心（headless）＋與 hdl2js 交叉驗證**

## 一句話

`lib/vm/hackemu.js` 純 JS HACK 虛擬機核心完成：一次週期一條指令、RAM/SCREEN/KBD
記憶體映射、.bin/.hack 載入、`screen_pixel`/`set_key` 供圖形與鍵盤用；headless CLI
跑 `chain.bin` 50 萬條後的每個狀態都與 Rust oracle **一字不差**。

## 本版實作內容

- `HackVMCore`…不，就一個 `Vm` class（`rom: Uint16Array`、`ram: Uint16Array(32768)`、
  `a/d/pc/cycles`）：
  - `loadBin`（u16 LE bytes）/ `loadHack`（16 位元文字行）/ `reset`。
  - `step()`：A-inst 載 `A`；C-inst 依 `a-bit + comp + dest + jump` 運算，
    **M 寫入用「更新前」的 A、jump 用「更新後」的 A**（CPU.hdl 語意，
    `AM=M-1`、`A=M;JMP` 由此成立）。
  - `run(n)` / `runUntil(n, f)`（診斷熱點/死迴圈）。
  - `screenPixel(row,col)`：bit15=最左畫素；`setKey(code)`＝按住鍵。
- `cli/hackemu.js` headless：`--headless <file> [--max N] [--dump A,B] [--keys FILE] [--trace N]`，
  輸出格式對齊 Rust main.rs（`loaded`/`before`/`after`/`RAM[0..16]`/`RAM[16] static:`/dumps/trace ring）。
  `--keys` 腳本（`INSTR_COUNT KEY [down|up]`）在指令計數器基準注入按鍵。
- **踩坑**：JS `dest & 2 !== 0` 被解成 `dest & (2 !== 0)`＝`dest&1`，D 目標永遠寫不進去；
  已全部改成 `(dest & 2) !== 0`（相等運算子優先序高於位元 AND）。
