# hdl2js v0.9 — 版本紀錄

日期：2026-09-13（115 學年度 · 計算機結構）
對應里程碑：**M9 — `hdl.html` 批次 HDL 模擬（純瀏覽器，把 lib/hdl + lib/rt 整條管線搬進網頁）**

## 一句話

官方 `HardwareSimulator` 的「批次測資跑分」現在可以在瀏覽器跑：`dist/hdl.html` 從
`window.HACKJS_CORPUS`（內嵌語料 121 檔 = ch01~ch05＋gen/chain 的 `.hdl/.tst/.cmp/.hack`）
挑章節、挑案例、按「執行」，`HackHdl` 引擎現場 codegen＋`new Function` 編譯＋跑 `.tst`
＋逐位元比對 `.cmp`；「自訂貼上」模式則把使用者貼的 `.hdl/.tst/.cmp` 掛進合併程式庫，
不需要伺服器。

## 本版實作內容

- **bundle 手段升級（tools/embed.js）**：embed.js 之前只吃「無 import 的純 module」；
  現在偵測哪個 lib 有 `node:fs`/`node:path` import，在合併結果頂部注入一次
  `const fs = globalThis.HACKJS_FS; const path = globalThis.HACKJS_PATH;`。所以同一個
  `dist/embed.js`（11 個 lib：vm/asm/jack/ＨDL 管線）在 Node 用原始 fs、在瀏覽器用 shim。
- **`tools/gen_corpus.js` → `dist/corpus.js`**：把 `../01 ../02 ../03/a ../03/b ../05
  ../04/mult ../04/fill gen/chain` 的 `.hdl/.tst/.cmp/.hack` 打包成
  `window.HACKJS_CORPUS = { './…': '…' }`。跳過互動測資（`Memory.tst`、`Keyboard.tst`、
  `Mult.tst`、`Fill.tst`——需要人工按鍵，batch 跑不了 ○▽○）。
- **`dist/hdl-rt.js`（fs/path shim）**：vfs overlay——`readdirSync/readFileSync` 讀
  corpus，`writeFileSync/mkdirSync` 寫進記憶體 map（`.tst` 跑出來的 `.out` 就存在這），
  另外當 `read()`（codegen `Rom32KChip.load` 的既有 hook）。路徑聚合成前綴展開，
  `withFileTypes` 的 `isDirectory/isFile` 也照算。
- **`dist/hdl.html`＋`dist/hdl.js`**：鏡像 Rust `_eda/web/hdl.html` 版面——①來源
  （`.hdl/.tst/.cmp` 三個文字區）②執行結果（`.out` 表格＋banner＋錯誤 log）。
  內建模式：章節清單 → 案例清單 → 自動帶入對應原始碼（`.hdl` 找到對應檔名，
  沒有的就空白，例如 ch04/chain 只載 ROM）；自訂模式：預填 And9 範例，跑之前把
  貼上的 `.hdl` `parseHdl` 進合併庫、`.cmp` 掛到 script 的 `compareTo`，`run()`
  統一走 `.out/.cmp` 比對，比對失敗會 throw「!!! 比對失敗」→ banner ✗。
- **踩坑一：全域撞名**：11 個 lib 併成同一作用域後，`lib/rt/tst.js` 與
  `lib/jack/jack2vm.js` 各自宣告 `const KEYWORDS` → `SyntaxError`。改成
  `TST_KEYWORDS`（只此一處真衝突；其餘「撞名」都是縮排 function 內區域變數）。
- **踩坑二：語料沒有 Nand.hdl**：`Nand` 是 `elab.Builtin`，`../01` 目錄裡沒有這個檔，
  測試想當然以 `../01/Nand.hdl` 為語料 key 直接 assert undefined。改用 `And.hdl`。
- **踩坑三（此版無）：** 無。
