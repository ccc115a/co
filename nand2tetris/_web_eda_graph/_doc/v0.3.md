# hdl2js v0.3 — 版本紀錄

日期：2026-09-12（115 學年度 · 計算機結構）
對應里程碑：**M3 — 整台電腦（ch05）8/8 全數通過**

## 一句話

把 CPU（ARegister/DRegister 內建暫存器）、Memory（RAM16K + Screen + Keyboard）、
ROM32K（可載入 `.hack`）組合起來：`CPU.tst`/`CPU-external.tst` 與六支
`Computer*`（Add/Max/Rect 的 internal + external）**8/8 PASS**；單元測試 73 個全綠。

## 本版實作內容

### model（lib/rt/model.js）

- **`getOutput` 改用 `PinRef.parse` 路由**（對照 Rust `Wrap::get_output`）：
  - Whole：exact 輸出 pin → `getOut`；exact 輸入 pin → `getIn`；否則 `probe_whole`。
  - Bit（`[i]`）：`probe_indexed`。
  - 舊版用 `replace(/\[\d+\]$/)` + regex 猜測命中名稱，`DRegister[]`（空索引＝整根
    暫存器）對不到也會悄悄回 undefined。

### tst（lib/rt/tst.js）

- `parseOutputListFields` 容許**小寫格式字**（官方測試 `output-list` 寫
  `%b`/`%d`，與 `%S`/`%B` 混用）：`kc = s[p].toUpperCase()` 後分派。

### codegen（lib/hdl/codegen.js）

- `ROM32K.load` 不再仰賴 ESM 沒有的 `require`，改走
  **`globalThis.HACKJS_FS.read(path)` hook**（回傳 null = 讀不到，視為直接給內容）：
  - Node CLI：`cli/hdl2js.js` 在啟動時注入 fs 版。
  - Node 測試：`test/test.js` 同樣注入（同一顆 codegen，兩種 host 各自給檔案系統）。
  - 瀏覽器版（v0.9 起）：改成查內嵌語料 map。

### 互動測試排除

- `Memory.tst` 有 `while out <> 75 { echo "按住 K…" }` 兩段，**必須真人按鍵盤**，
  自動化會空轉 10 萬次才崩。Rust 版 `verify.sh` 的處理就是「明確列 8 支 `.tst`、
  根本不放 Memory.tst」；本版同法：
  - `collectTst` 遇到 `Memory.tst` 直接跳過（`--dir` 掃描模式不卡）。
  - `verify.sh`/`test.sh` 與這個真正的坑：ch05 區段用**與 Rust 相同的明確清單**。
  - `test/test.js` 的新增 CLI describe「ch05 8/8」也照同一張清單。

## 驗收

```
bash verify.sh
  node --test              → 73 tests、73 pass
  ch01~03 全部 .tst        → 29 通過 / 0 失敗
  ch05 8 支（CPU×2 + Computer×6）→ 8 通過 / 0 失敗
```

- 除 bug 路徑回顧：全機首次測試看到「PC 在動但 A/D=0」→ 揪出 ES 模組下
  `require` 不可用的引子（ROM 其實沒載到）、`output-list` 小寫格式字、`DRegister[]`
  探測路由三個點。
