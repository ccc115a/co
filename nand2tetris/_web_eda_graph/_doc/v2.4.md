# hackjs v2.4 — 版本紀錄

日期：2026-10-03（115 學年度 · 計算機結構）
對應里程碑：**M14 — 用 hackHDL 設計 RV32I 單週期處理器 `rv32i`**

## 一句話

`Riscv32i/` 是本目錄自有的 RV32I 單週期處理器（`rv32i.hdl`＋解碼/ALU/
移位器/分支器＋60 指令綜合測資），`rv32i.tst` 跑完 32 個暫存器全中、
控制流（六種分支、前後跳、JAL/JALR 往返、HALT 凍結）逐行驗過；
命令列 `hdl2js` 通過後收進 web HDL 模擬器當 `06 RV32I 處理器` 範例，
瀏覽器同一路徑亦 PASS。

## 本版實作內容

### 處理器設計（`Riscv32i/`，word 定址，程式格式與 `Riscv32/RV32S` 相容）

- `rv32i.hdl`（頂層，單週期）：
  `R32（PC）→ ROM32 → RvDec → RF32 → RvAlu/RvBr → RAM32W → 寫回`。
  介面同 `Rv32_1`（`dbgRd[5]`／`pc/dbgReg`＋`RAM32W[i]` 探測），`.tst` 寫法照抄。
- 新元件：`RvDec`（自有 `ctl[15:0]` 編碼）、`RvAlu`（11 種運算）、
  `RvSh32`（桶式移位器：右移五級＋SLL 經 bit 反轉共鏈）、
  `RvBr`（六種分支）、`Zero32i`；閘級基礎複用 `../01、../02`，
  另 18 個 32 位元元件自 `Riscv32/_lib` 原樣拷貝（不依賴該目錄，
  CLI 與 web 皆自給自足）。
- 指令集：R 型全 10 種、I 型移位與 `slti/sltiu`、LW/SW、LUI/AUIPC、
  JAL/JALR、六種分支、HALT；省略 LB/LH/LBU/LHU/SB/SH、FENCE/ECALL
  （word 定址簡化，同 RV32S，檔頭有載明）。

### 測資（`rv32i_prog.asm`→`.hack`→`rv32i.tst/cmp`）

- `Riscv32/asm.js` 加新助憶符（`sll/srl/sra/slt/sltu`、
  `slli/srli/srai/slti/sltiu`、`bltu/bgeu`，只加不改；
  `Riscv32/verify.sh` 4/4 照過，舊 `.bin` 逐位元相同）。
- 60 指令：移位邊界（`sra(-3)`、`srli` 大數）、slt 有號/無號對照、
  `lui+addi` 組 `0x12345678`、`auipc`、後跳迴圈（負 B 位移）、
  JAL/JALR 往返並中途探測 link（`x30=35`、`x29=39`）、`x0` 寫入忽略、
  HALT 凍結；結尾掃 `x0..x31`＋`mem[4/8/12]`。
- 程式檔用 `.hack` 副檔名（32 位元 binary 行）：`ROM32 load` 吃的是
  binary 行 parser，CLI（fs）與 web（語料 map）共用同一檔；
  `.bin` 不進語料（`gen_corpus.js` 的 `EXTS` 沒收）。

### 前端（`dist/hdl.html` 的 `06 RV32I 處理器`）

- `tools/gen_corpus.js` 的 `DIRS` 加 `Riscv32i`（語料 153→182 檔）、
  `dist/hdl.js` 章節選單加一項；`tools/browser_smoke.js` 同步加目錄
  （42/42，含 `Riscv32i/rv32i.cmp`）。
- `?v=` 版號：`corpus.js`→v11（四頁一起加）、`hdl.js`→v11。
- `verify.sh` 加 v2.4 區段：`.asm` 重組 `.bin` 並與 committed `.hack`
  比對一致，再跑 `rv32i.tst`（嚴格全回歸）。

## 踩過的坑（實作筆記，未來不要重犯）

1. **JALR 不可清 LSB**：word 定址下奇數 PC 合法（link＝35），`& ~1`
   會跳錯一格；`Rv32_1` 同樣直接省略（companion 有載明）。
2. **AUIPC 要拿 `immU`**：`imm` 多工器 `sel0` 須含 `eqAU`
  （`sel0＝S/B｜U｜AU`），否則拿到 J 型立即數（`auipc x24,1` 變 26）。
   上游 `Dec` 同式子但 `prog1` 只測 `auipc x25,0`（兩者皆 0）故沒爆。
3. **`slt/sltu` 要借減法器的借位**：`RvAlu` 的 `cout` 平時是加法進位，
   解到 `slt/sltu` 須把 `subsel` 拉起（`~b`＋`cin＝1`），否則全錯。
4. **`aluFn` 的 bit0/bit1 別多收**：`xor` 的 bit0＝0、`sll` 的 bit1＝0；
   多收一項就變成隔壁運算（`xor` 變 `add`、`sll` 變 `sra`）。
5. **`.tst` 分段時序要含跳轉**：`repeat 35` 結尾 PC 是 57 不是 35
  （中間 `jal` 跳過），link 探測看的是暫存器值不是 PC。

- 單週期、一週期一條指令；無管線（`Rv32_5` 在 `Riscv32/`）。
