# add.asm 範例程式說明

計算 `RAM[0] = 2 + 3` 的迷你 Hack 組合語言程式，來自 Nisan & Schocken 一書第 4 章、
也是第 6 章組譯器（`asm.cpp`）的標準測試輸入檔。6 條指令，示範 A 指令、C 指令以及
它們的第一種形式（`d=comp`）。

## 概述

- 目的：把常數 2 與 3 相加，結果寫入 RAM[0]。
- 地位：這是整條工具鏈的第一塊踏腳石——`./asm add` 組譯、`./vm add.bin` 執行、
  `./dasm add.bin` 反組譯，全部用這支小程式驗證。
- 程式很短，但涵蓋全部基礎：`@常數`（A 指令）、`D=A`、`D=D+A`、`M=D`（C 指令的三種寫法）。

## 對應的 C 語言版本

```c
RAM[0] = 2 + 3;      /* 語意上等價 */
```

或更明確對照暫存器與記憶體：

```c
int D, A, M[65536];
A = 2;  D = A;        /* @2 ; D=A  */
A = 3;  D = D + A;    /* @3 ; D=D+A */
A = 0;  M[A] = D;     /* @0 ; M=D   */
```

## 逐行說明

| 行 | 指令 | 動作 | 結果 |
|----|------|------|------|
| 1 | `@2` | A 指令：`A = 2` | A=2 |
| 2 | `D=A` | C 指令：`D = A`（ALU 選 A，寫入 D） | D=2 |
| 3 | `@3` | `A = 3` | A=3 |
| 4 | `D=D+A` | `D = D + A = 2 + 3` | D=5 |
| 5 | `@0` | `A = 0`（準備當位址） | A=0 |
| 6 | `M=D` | `RAM[A] = RAM[0] = D = 5` | RAM[0]=5 |

使用的「欄位」幾乎都是最簡單型：dest 只用 `D` 與 `M`，comp 只用 `A`、`D+A`、`D`，
沒有 jump（jump 留 `000`）。是學習 C 指令編碼的最小範例。

## 編碼與位元配置

組譯器對 6 條指令的輸出（`./asm add`）：

| 位址 | 指令 | 16 位元機器碼 | 十六進位 |
|------|------|----------------|----------|
| 0 | `@2` | `0000000000000010` | 0x0002 |
| 1 | `D=A` | `1110110000010000` | 0xec10 |
| 2 | `@3` | `0000000000000011` | 0x0003 |
| 3 | `D=D+A` | `1110000010010000` | 0xe090 |
| 4 | `@0` | `0000000000000000` | 0x0000 |
| 5 | `M=D` | `1110001100001000` | 0xe308 |

以 `D=D+A` 驗算編碼 `1110 0000 1001 0000`：`111`（C 標記）＋ `a=0`（對 A 運算）
＋ `0000010`（comp=D+A，見 cMap）＋ `010`（dest=D）＋ `000`（無跳躍）＝ 完全吻合。

## 測試與驗證

```
make
./asm add        # 產生 add.hack、add.bin，印出上面表格
./vm  add.bin    # 執行
```

執行追蹤最後一段（）：

```
PC=0003 I=E090 A=0003 D=0005 ...     ← D=2+3=5
PC=0005 I=E308 A=0000 D=0005 m[A]=0005=0005   ← RAM[0]=5
exit program !
```

`m[A]=0005`（十進位 5）正是 `RAM[0]=5`。若用第 4 章 Hardware Simulator 載入
`add.hack`，`RAM[0]` 也會變成 5，驗證兩條路線一致。

## 延伸討論

- 相加結果存在 **D 暫存器**而非記憶體，`M=D` 前還要先 `@0` 把 A 設為位址——
  這提醒初學者：Hack 的「記憶體存取」永遠繞著 A 暫存器轉（`RAM[A]` 寫成 `M`）。
- `@2` 與 `@3` 是**常數 A 指令**，位元直接內嵌 15 位元值；若寫 `@i` 這類符號，
  就要靠組譯器查符號表（見 sum.asm）。
- 本書第 5 章的計算機一開機就從 ROM 位址 0 執行，這支程式正好佔用 0..5 六個連續位址。
