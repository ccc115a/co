# Main.jack 程式說明 — Fib（無 OS 案例）

以**迭代法**計算費氏數列第 20 項 F(20) = 6765，全程不需要任何 OS 服務。

## 概述

- 費氏數列：F(0)=0、F(1)=1、F(n)=F(n-1)+F(n-2)。
- 迭代法：只保留最近兩項 `a`、`b`，一次一個 `+`，迴圈 2..20。
- 答案寫進 `static int result` ＝ `RAM[16]`。

## 架構總覽

```
Sys.init ──▶ Main.init（迭代 20 次）──▶ Main.loop（無窮迴圈）
```

## 原理

```jack
let n = 20;
let a = 0;   // F(0)
let b = 1;   // F(1)
let i = 2;
while (i < 21) {           // i = 2..20
    let t = a + b;         // F(i)
    let a = b;             // 滑動
    let b = t;
    let i = i + 1;
}
let result = b;            // F(20) = 6765
```

- 用 `i < 21` 取代「`i <= 20`」——本編譯器的二元比較只有 `<`（與 `>` `=`），
  沒有 `<=`，這是刻意示範「用嚴格不等號組出閉區間迴圈」。
- F(20)=6765 仍在 15-bit 有號範圍內（<32767），不會溢位。

## 變數一覽

| 變數 | 型別 | 用途 |
|------|------|------|
| `result` | static int | 答案 6765（＝ `RAM[16]`） |
| `a`, `b` | local int | 下滑的兩項 |
| `t` | local int | 暫存下一項 |
| `i` | local int | 迴圈計數器 |

## 測試與驗證

```bash
./target/debug/hackemu --headless <Fib.bin> --max 1000000
# RAM[16] static: 6765
```

## 延伸討論

- 想看在無 OS 下溢位會發生什麼：把 `n` 改大（例如 F(46)=1836311903）會 wrap 成負數。
- 這個迴圈結構（計數、滑動）正是「節省記憶體版費氏」的教學原型，跟「遞迴版」
  （F(n)=F(n-1)+F(n-2) 兩路呼叫）對照，可觀察呼叫深度與重複計算的差別。
