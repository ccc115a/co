# Main.jack 程式說明 — GCD（無 OS 案例）

用**輾轉相除法（減法版）**求 gcd(1386, 3213) = 63，全程只用 `-`、`>`、`=` 與 `~`。

## 概述

- 輾轉相除法的「減法版」：一直把大的減小的，直到兩數相等，那個數就是 gcd。
- 名義上的「除法版」要取餘數，但本編譯器沒有 `%`（也沒有 OS 的 `Math`），
  所以改用連減——其實歐幾里得演算法最早的形態就是減法。
- 答案寫進 `static int result` ＝ `RAM[16]`。

## 架構總覽

```
Sys.init ──▶ Main.init（減法輾轉相除）──▶ Main.loop（無窮迴圈）
```

## 原理

```jack
let a = 1386;
let b = 3213;
while (~(a = b)) {     // a ≠ b 就繼續
    if (a > b) { let a = a - b; }
    else       { let b = b - a; }
}
let result = a;        // 63
```

- `~(a = b)` 是「`a ≠ b`」：`=` 比較產生 true/false（0/1），`~`（not）反轉。
- 只有減法與比較，正好踩在「無 OS＝不可用 `* / %`」的紅線上。

## 變數一覽

| 變數 | 型別 | 用途 |
|------|------|------|
| `result` | static int | 答案 63（＝ `RAM[16]`） |
| `a` | local int | 被減數／結果之一 |
| `b` | local int | 被減數／結果之二 |

## 測試與驗證

```bash
./target/debug/hackemu --headless <GCD.bin> --max 1000000
# RAM[16] static: 63
```

## 延伸討論

- 減法版在大數差很多時會慢（一次只減一個）。加速方式：`while (a > b) { a = a - b; }`
  或除法版——但那需要取餘，而 `%` 得靠 OS 或自製。
- `~` 使用者注意：它把「比較結果」取反得到「不等」。若想寫 `a ≠ b` 這種常見條件，
  這是無 OS 下唯一寫法（本編譯器無 `not` 運算子以外的布林專用符號）。
