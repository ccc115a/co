## 一句話

整套工具鏈（jack2vm → vm2asm → hackasm → hackemu）第一次跑「作業系統」等級的程式：
`gen/os_src`（裁剪版 OS 的 8 個 .jack）＋ `gen/os/Main.jack`（show app）開機後，
`Memory.poke`/`Math.multiply`/`Screen.drawPixel` 全部驗證通過；Pong 對方向鍵有反應、
逐模組單測（Math/String/Screen/Heap）的結果陣列與 Rust oracle **逐位元一致**。

## 本版實作內容

- **vm2asm 多檔 label 前綴**：多檔（bootstrap）模式下 `label/goto/if-goto` 輸出為
  `函式$label`（跟上牌 `_eda/vm2asm`）。單檔保持與 08/vm2asm.c byte 相容。
  原因：C oracle 原樣輸出 label，兩個檔各自 `WHILE_EXP2` 就相撞——C 工具鏈根本組不了
  多檔 OS；Rust 版改進，我們也跟上。新增單元測試驗證 `A.f$WHILE_EXP0` 與 `B.g$WHILE_EXP0`
  並存。
- **CLI jack2vm 只吃 `.jack`**：`d.includes('.jack')` 會連 `Ball.jack.md`（AI 文件）也編譯，
  整個 Pong 目錄第一次編就炸；改成 `d.endsWith('.jack')`。
- **hackemu `--img` 反色修正**：Rust 的 PPM 是「位元=1 → 黑 `0`、位元=0 → 白 `255`」；
  我一開始寫反，畫出整片白的 Pong。修正後 PPM 與 Rust **byte 相同**。
- **Rust 檔案內建的 `RAM[n..=m]: [a, b]` 格式**：dump/RAM[0..16]/RAM[16] static 全部照 Rust
  輸出一字不差。
