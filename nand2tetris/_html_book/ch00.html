HackHDL 一句話入門

Hack 硬體描述語言描述「晶片」之間怎麼接線。一個晶片由三段組成：

CHIP 晶片名 {
    IN  a, b;          // 輸入腳位
    OUT out;           // 輸出腳位
    PARTS:
      子晶片1(腳位=訊號, …);
      子晶片2(腳位=訊號, …);   // 依序定義，可向前「留線路」然後往後接
}
連線語意
  • Nand(a=a, b=b, out=n) → 把 a、b 接到 Nand 的輸入，Nand 的輸出取名為 n。
  • Not(in=n, out=out) → 把剛才的 n 接進 Not、再輸出成晶片的 out。
  • 「取名」就是用一條導線 wire 串起來；同一條導線可以被多次作為輸入（扇出 fan-out）。

Nand 是由 CMOS 電晶體直接實作的「原生閘」——所有其他布林函數（AND、OR、XOR…）都可以只用 Nand 拼出來，這就是第一章 ch01 的全部工作。

為什麼這樣設計？（Nand2Tetris 精神）

  • 漸進抽象：閘 → 晶片 → 機器語言 → VM → 高階語言 → 作業系統，每一層只需要上一層。
  • 全部動手：不用死背，把理論做出來、再拿標準測試驗證。
  • 閘極簡：課程刻意只用 Nand 與 DFF 兩個原始元件，其餘全部自己搭。
