第 1 章布林邏輯

給你無限多顆 Nand 閘，請設計出 15 個邏輯晶片。請按照順序做—— 後面的元件正是「用前面的元件組合」出來的，這樣也最省思考。

本練習的規矩
  • 只能使用 Nand 以及自己已完成的晶片，不得偷用其他原生閘。
  • 每一題都內建標準「.tst 測試檔」：按 ▶ 執行 .tst 模擬器會把輸入設好、 一、一比對輸出。PASS 才算完成。
  • 卡上的程式碼是〈教師版答案〉，你可以：直接跑（驗證）、清掉重寫、改壞了再按「↺ 重設解答」。
習題 01Not — 反閘 not(x) = nand(x, x)

把一個輸入接到 Nand 的兩個輸入各一次。Nand(a,b) 在 a=b 時行為正好是「反相」。

習題 02And — 及閘 and(x,y) = not( nand(x,y) )

先把 Nand(a,b) 算出來，再用剛剛的 Not 反一次，就是 And。

習題 03Or — 或閘 or(x,y) = not( not(x) and not(y) )

迪摩根定律：OR 就是把兩個「都不成立」再否掉。用兩顆 Not 加一顆 And。

習題 04Xor — 互斥或閘 xor(x,y) = and(x, not y) or and(not x, y)

「兩邊不同才為 1」。有一個經典接法：nand(a,b) 與 or(a,b) 再 and。 你能看懂為什麼嗎？（提示：Nand 只在「全 1」錯；Or 只在「全 0」錯。）

習題 05Mux — 二選一多工器 out = (sel=0: a) 或 (sel=1: b)
selout
0a
1b

多工器是「開關」：某一路永遠可以算出來，只是你要挑其中一邊。標準解：And(not sel, a) 與 And(sel, b) 再 Or。

習題 06DMux — 一對二解多工器 (a,b) = (sel=0: (in,0)) 或 (sel=1: (0,in))
selab
0in0
10in

Mux 是把資料「選進」，DMux 是把資料「送向」。把輸入只送到被選中的那一路。

習題 07Not16 — 16 位元反閘 out[i] = not( in[i] )

16 顆 Not 各管一個 bit。這樣整條匯流排一次反過來。

位元對位元的 And，16 顆 And。

同上，16 顆 Or。

習題 10Mux16 — 16 位元二選一 out[i] = mux( x[i], y[i], sel )

一個共用 sel 控制 16 個位元——這是 CPU 裡「資料路徑切換」的常客。

習題 11Or8Way — 八輸入或閘 out = or( in[0..7] )

「任一 bit 為 1 就輸出 1」：這在判斷「這個數是否為零／非零」時非常有用（第 2 章 ALU 會用到）。

在 _web_eda 開新視窗執行 ↗
習題 12Mux4Way16 — 四選一多工器 用兩階 Mux16：mux16( mux16(a,b), mux16(c,d) )

sel[0] 選左右成對，sel[1] 再從兩個中間挑一個。練習「把一維選擇拆成多維」。

在 _web_eda 開新視窗執行 ↗
習題 13Mux8Way16 — 八選一多工器 mux16( mux4way16(a..d), mux4way16(e..h) )

把 8 個輸入切成兩個四選一，再用 sel 的最高位選邊。多層 Mux 樹是組合電路的常見模式。

在 _web_eda 開新視窗執行 ↗
習題 14DMux4Way — 一對四解多工器 dmux(in, sel) → a b c d

兩顆 DMux 級聯：先依 sel[1] 分成兩組，再各依 sel[0] 決定送哪個輸出。空下的輸出要送 0。
