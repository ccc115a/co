第 8 章VM 第二部：函式與控制流

在 ch07 的堆疊上再加三招：label / goto / if-goto（程式流程）， 以及 function / call / return（函式呼叫）。做完這章，Hack 就有了「子程式」能力。

控制流的四條指令

VM 指令翻譯成
label X(X) 標記目前位址
goto X@X ; 0;JMP
if-goto X彈掉堆疊頂端，非零才跳：=0 就 skip
function f n推 n 個 0 的 local + 建 frame
call f k推回傳位址＋各指標 → 轉到 f（k 個引數）
return回復 caller 的 SP/LCL/ARG/THIS/THAT，跳到回傳位址
關鍵畫面請記住「五件套」：RET、LCL、ARG、THIS、THAT—— call 時依序推上堆疊、return 時再依序倒回來。本章的冒煙測試 NestedCall / FibonacciElement 就是驗證它們正確。

本 repo 的實現與工具

示範：SimpleFunction（function / return）

課程標準 FunctionCalls/SimpleFunction/SimpleFunction.vm——一支「純函式」： 沒人呼叫它，但 function 仍會把 local 清成 0、return 仍會把結果放回 ARG[0]。

想驗證「真的做了 function call 的來龍去脈」？在 repo 裡跑 bash all2asm.sh， 其中 FunctionCalls/FunctionCall 系列的 .tst/.cmp 就是用官方程式逐格檢查「五件套」的正確性。
