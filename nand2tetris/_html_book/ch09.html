第 9 章高階語言：Jack

組語太苦了。本章介紹課程自帶的高階語言 Jack： 它像 Java 的迷你版，編譯後就是你學過一學期的那條鏈：Jack → VM → 組語 → 機器碼。

Jack 一句話

  • 強型別、以類別(class)為單位：int / boolean / char 與陣列、字串（經由 OS）。
  • 三種副程式：function（靜態）、constructor（建構子）、method（方法，帶 this）。
  • 控制流：if / else、while、let、do 陳述式。
  • 記憶體管理真的由你自己的 OS 處理（Memory.alloc / deAlloc，Ch12）。

範例：Seven.jack

class Main {
    function void main() {
        do Output.printInt(7);   // 印出 7
        return;
    }
}

它大概會被編譯成這樣（示意）：函式序言建立 frame → 把 7 當成引數推上堆疊 → call Output.printInt 1。 你可以想像編譯器逐個 token 走一遍——那就是 Ch10/Ch11 的工作。
