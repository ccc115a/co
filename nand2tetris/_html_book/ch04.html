Hack 的兩種指令

指令格式做的事
A 指令@value把 15 位元數值放入 A 暫存器（下一條可用 M=RAMA）
C 指令dest = comp ;jump計算 ALU 輸出並送入 dest，再視旗標決定是否跳轉
記憶體對映（Hack 肌理一定要記住）
  • R0–R15 ＝ RAM[0..15]（第 6 章起 R0 也叫 SP）。
  • SCREEN ＝ 16384，螢幕 512×256 畫素，從 RAM[16384] 開始、每列 32 個 word。
  • KBD ＝ 24576，讀它會得到目前被按鍵的編碼（沒按＝0）。
  • M ＝ 記憶體中 A 目前指向的那一格，M=… 就是「寫進 RAM[A]」。

習題一：Mult.asm — 乘法 R2 = R0 × R1

📖 電子書對照：§4.4

用「重複加法」實現：R2 從 0 開始，每圈 R1 加一次、R0 減一次， 直到 R0 ≤ 0 為止。面板已把輸入預設為 R0=3、R1=5：組譯 → 執行，看看最後 R2 是不是 15。

習題二：Fill.asm — 螢幕反白控制

📖 電子書對照：§4.3

無窮迴圈：偵測 KBD —— 有按鍵就把整個螢幕寫 -1（全黑），沒按鍵就寫 0（全白）。 這支程式永遠不會「跑完」，你要觀察的是執行過程中 SCREEN 的變化：

  1. 先「Run」讓它跑一圈（也可以 Step 逐條走）。
  2. 在「KBD」輸入格填 97（字元 a 的編碼）→ 按「設鍵」→ 再 Run。
  3. 看畫布：黑底部分就是「被反白」的畫素。
  4. 把 KBD 改回 0 → 設鍵 → Run，螢幕又會清回來。
