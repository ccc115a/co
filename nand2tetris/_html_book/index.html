計算機結構：從 Nand 到 Tetris

金門大學資訊工程系 · 115 學年度 · 授課教師 陳鍾誠
互動式習題教材：每一章都有「可執行的」習題——邏輯閘就在瀏覽器裡模擬、 組語當場組譯與執行、Jack 程式整條編譯到底。全部純瀏覽器運作（file:// 即可直接開啟）。
👉 左側邊欄可隨時跳轉章節；每個習題卡右上角勾「我會了」即可追蹤進度（存於本機瀏覽器）。 各章順著做，後面的元件都建立在前面設計好的元件之上。

章節目錄

第 0 章

導論：Nand2Tetris 與 HackHDL

課程地圖、Hack 硬體描述語言入門、一切從 Nand 開始。
第 1 章

布林邏輯

十分鐘做出 Not、And、Or、Xor、Mux…15 個邏輯閘，全部可當場模擬驗證。
第 2 章

算術單元

半加器 → 全加器 → 16 位元加法器 → 遞增器 → ALU，逐步組出算術邏輯單元。
第 3 章

記憶單元

DFF 給定，做出 Bit、Register、RAM8→RAM16K，以及程式計數器 PC。
第 4 章

機器語言

Hack 組語 A/C 指令，親手組譯、逐步執行乘法 Mult 與螢幕反白 Fill。
第 5 章

計算機結構

Memory 模組、HackCPU，以及把整台電腦串起來——本章是補齊整條硬體線的關鍵。
第 6 章

組譯器

組語 → 機器碼：兩遍式組譯（符號表＋編碼表），看看 add.asm / sum.asm 怎麼變成 0 與 1。
第 7 章

VM：堆疊與算術

虛擬機中間碼 push/pop 與算術指令怎麼底層對映到記憶體分段與堆疊。
第 8 章

VM：函式與控制流

function / call / return 的組語翻譯，看 return-address、ARG、LCL 如何被安排。
第 9 章

高階語言

當我們擁有 Stack Machine 之後，為什麼還需要高階語言？從 Square 專案看起。
第 10 章

編譯器

詞法、語法、符號表、程式產生：Jack 編譯器的五階段管線如何把程式吃得乾乾淨淨。
第 11 章

Jack 語言與編譯器

選一個現成 Jack 程式，一條龍編譯到 VM、組語、機器碼，然後在你的瀏覽器裡「跑」起來。
第 12 章

作業系統

最後一塊拼圖：用 Jack 實作記憶體動態配置、字串、輸出螢幕與數學函式等標準程式庫。

使用工具

本教材的互動引擎直接沿用課程既有、由 JS 實作的 Nand2Tetris 工具鏈（_web_eda）， 故下開啟你還有三套獨立的網頁工具可用：

  • 組語 Emulator — 貼 .asm 立即組譯、逐步執行、看螢幕。
  • HDL 批次模擬器 — 內建全部章節語料，一次跑完一整支 .tst。
  • Jack 全鏈路 — 編譯 Jack 程式到可玩的網頁遊戲。
小提醒：若瀏覽器開啟 file:// 頁面沒出現模擬面板，多半是檔案相對路徑 （../_web_eda/dist/…）被改動；請確認 _web_eda/dist/corpus.js 等檔案存在。
