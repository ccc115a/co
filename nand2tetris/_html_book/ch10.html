第 10 章編譯器：語法分析

編譯器分四個互相隔離的階段——本單位的設計走得越乾淨，後續越好做。 本章先做「前半段」：把 Jack 原始碼切成符號、再證實語法正確。

中心概念：語法樹（XML）
  • Jack 用「令牌標籤」描述程式：<keyword> class </keyword>、<identifier> Main </identifier>。
  • 「文法規則」→ 一張遞迴下降的 parser，如變數宣告：type varName (, varName)* ;。
  • 寫出 JackAnalyzer（或 JackTokenizer＋CompilationEngine），跑你的語料，輸出 .xml，再用書附的 XML 比較器對答案。

本 repo 的 Jacobs 語法分析器實驗

  • 10/_PyJackAnalyzer：Python 寫的 JackAnalyzer（tokenizer＋compilation engine）。
  • 10/{ArrayTest, Square, ExpressionlessSquare}：教材程式，供 parser 吃（比對 hint .xml）。
  • 課程 SS17 的心法：這是「解析出結構」，先不管「計算結果」——後半段（語意＋生成）在 Ch11 一起做。
提示：若你的 tokenizer 輸出的 .xml 一直對不上，多半是「註解、字串、底線字元、巢狀 `()`」邊界的處理； 建議先做出獨立的 tokenizer 測驗，再疊 parser。
