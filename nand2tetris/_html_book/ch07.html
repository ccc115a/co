第 7 章VM 第一部：堆疊與算術

📖 電子書對照：§7.1、§7.2、§7.3、§7.4　(電子書目錄)

現在把高度拉起來一層：寫一支「虛擬機」語言 vm2asm，把抽象的 VM 指令翻譯成真正能跑的 Hack 組語。 本章只做 push / pop（八個記憶體區段）與堆疊算術。

神聖的八個區段

區段位址算法例
constant直接就是常數push constant 17 推 17
local / argument / this / thatbase + i，base 存 RAM[1..4]pop local 0
temp5 + ipop temp 6 → RAM[11]
pointer3 / 4（就是 THIS/THAT）pop pointer 1
static16 + i（每個 .vm 檔配 16 格）pop static 3 → RAM[19]

堆疊：資料一律從 RAM[256] 往上堆。SP（RAM[0]）永遠指著「下一個空位」。

本 repo 的實現與工具

  • C/C++：07/vm2asm.c（與 08 共用）。建構：bash build.sh → ./vm2asm。 注意參數順序：vm2asm <輸出>.asm <輸入>.vm。
  • 一次跑全部：bash all2asm.sh；單一檔案：./vm2asm.sh <BaseName>。
  • JS（本教材互動）：_web_eda 的 HackVm2Asm，就是下方面板。
