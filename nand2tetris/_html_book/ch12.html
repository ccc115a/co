最後一章：寫一個真的能在你自己 Hack 電腦上跑的 OS——而且是用你上章寫的 Jack 編譯器寫的。 做完這章，整條 Nand2Tetris 鏈正式封頂。

八個 OS 類別

類別職責關鍵常式
Memory堆積記憶體分配alloc / deAlloc / peek / poke
Array陣列配置new / dispose
Math數學運算mult / div / sqrt / max / min
String字串、字元轉換new / length / charAt / intValue / appendChar
Output文字輸出（65536 個半 byte）printChar / printInt / printString
Screen圖形畫面控制drawPixel / drawLine / drawRectangle / clearScreen
Keyboard鍵盤輸入readChar / readLine / readInt
Sys系統服務init / wait / halt

本 repo 的語料

  • 12/*.jack：八個 OS 類別完整原始碼（每支都附 .md 講解）。
  • 12/*Test：針對各類別的測試程式（如 MathTest、MemoryTest）。
  • _web_eda/gen/os_src/*.jack：網頁版編譯器內建的 OS 語料，就是上面 Ch11 各程式的「含 OS」來源。

驗收心法
  • MemoryTest、MathTest 等測試檔就是你的驗收單：全數 PASS 代表 OS 完成。
  • 「螢幕全黑但不動」通常是 Screen 或 Keyboard 的問題；「數值錯」大多是 Math/Integer 轉換。
  • 把 Ch11 的 Square / Pong 丟給「你自己的 OS + 編譯器」跑，就是整個 Nand2Tetris 的最終 demo。
