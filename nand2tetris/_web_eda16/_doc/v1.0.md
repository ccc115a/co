# hdl2js v1.0 — 版本紀錄

日期：2026-09-13（115 學年度 · 計算機結構）
對應里程碑：**M10 — `jack.html` 全鏈路編譯器＋三頁打包完成（零伺服器）**

## 一句話

`dist/jack.html` 是「跟 Rust `hackserve` 同功能的 Jack 全頁」：直接拿瀏覽器裡的
`HackJack2Vm`/`HackVm2Asm`/`HackAsm`/`HackVM` 四顆引擎，把 `.jack → .vm →
.asm → .hack → 執行` 整條管線現場跑完，四個階段產物（.vm/.asm/.hack/執行結果）
用 tab 展開。內建 12 支程式全部能編譯、組譯、執行；`chain` 的 oracle `RAM[16]=5`
與 CLI/Rust 一字不差。至此 `dist/` 三頁（index/hdl/jack）互相連節，`file://`
雙擊即開，達到 plan.md 的「全語言貼上＋三頁打包」目標。

## 本版實作內容

- **語料擴充（tools/gen_corpus.js）**：corpus 從 121 → 152 檔。新增 `../11/jack/<P>`
  （needsOS 的 Seven/Average/ComplexArrays/ConvertToBin/Square/Pong）、
  `../11/jackNoOs/<P>`（Sum/Factorial/Fib/GCD/PrimeUnder100，自帶 Sys）、
  `gen/os_src`（裁剪版 OS 8 檔，供 needsOS 程式在瀏覽器端即時編譯）、
  `gen/chain`（虛擬 e2e 的 Main+Sys）。共 31 支 `.jack`。
- **`dist/jack.html`＋`dist/jack.js`**：
  - 內建模式：程式選單（12 支）＋「含作業系統」勾選（needsOS 自動鎖定）。
    檔案 tab 顯示該程式所有 `.jack`，點選看原始碼。
  - 自訂模式：可以加/刪檔（檔名要 `.jack` 結尾），每檔獨立存進 `HACKJS_FS`
    overlay（`custom/<名>.jack`），預設 `Main.jack`；勾 withOS 則先編譯
    `gen/os_src`。
  - 管線與 `tools/browser_jack_smoke.js` / CLI 同一套：`compileJack`（回傳行陣列，
    要 `.join('\n')＋'\n'`）→ `translate([{path,src}])`（多檔自動 bootstrap，
    OS 檔排序在前 → `Sys.init` 開機）→ `assemble`（文字＋bin）→
    `new Vm().loadHack(hack)` 跑 N 步。
  - 產物 tab：`.vm`（逐檔標註 `// File:`）、`.asm`、`.hack`、`▶執行`
    （PC + RAM[0..16] + RAM[16]）。ROM 超過 32K 只警告不擋（模擬器可跑，
    實機 `@x` 只有 15 位址位元）。
- **三頁互導**：`index.html` header 加 HDL 模擬器／Jack 編譯器連結；
  `hdl.html`（原有）＋`index.html` 指向 `jack.html`。
- **踩坑**：
  - `compileJack` 回傳的是 `.vm` 行陣列（不是字串），接 `translate` 前要
    `join('\n')`——之前 test.js 就有這個慣用法，這版抄錯了兩次（OS 迴圈與
    程式迴圈分兩行，Edit 只改到一處）。
  - `ComplexArrays`＋OS 組出來 ROM 33166 words 超過硬體 32K——頁面若硬 throw
    會把這支官方程式判死，改「警告不擋」。
