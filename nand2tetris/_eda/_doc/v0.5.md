# Rust 工具鏈 v0.5 — Jack 編譯器 + VM→ASM 轉換器（全鏈路通過）

日期：2026-09-10（115 學年度 · 計算機結構）
對應里程碑：**M5 — Jack → VM → HACK ASM → .hack → 整台電腦模擬，全鏈路跑通**

## 一句話

本版在 workspace（`_eda/`）新增兩個 Rust crate：**`jack2vm`**（Jack → HACK VM
組合語言，ch11）與 **`vm2asm`**（VM → HACK 組語，ch07/08），並硬化 `hackasm`
CLI。三者接成完整工具鏈 —— `Jack → .vm → .asm → (hackasm) .hack`，最後把
`.hack` 載入 hdl2rs 的 **Computer.hdl 全閘層模擬器**執行：一支會把 static 變數
`Main.0`（hackasm 分配至 RAM[16]）設成 5、再進入無窮迴圈的 Jack 程式，模擬
5000 ticktock 後 **RAM16K[16] == 5 穩定不變，PASS**。

Rust 版兩個轉換器與課程 C 版（`08/vm2asm.c`、`11/c/jack2vm.c`）**逐位元
（byte）相容**：07/08 全部 17 個 VM 輸入、11/jack 全部 11 支 Jack 程式，
C 版與 Rust 版輸出 `diff` 為零。

## 目錄（workspace `_eda/`）

- 由 4 個 crate → **6 個**：`hackasm` / `hackhdl` / `hackrt` / `hdl2rs` / **`vm2asm`** / **`jack2vm`**。
- `vm2asm/`：`lib.rs`（轉換核心 + 單元測試）+ `main.rs`（CLI）。
- `jack2vm/`：`lib.rs`（編譯核心 + 單元測試）+ `main.rs`（CLI）。

## 本版實作內容

### `vm2asm`（VM → HACK 組語，ch07/08）

移植 `08/vm2asm.c` 為 Rust，目標**逐位元相容**：

- 指令：stack 算術（add/sub/neg/and/or/not/eq/gt/lt）、push/pop
  （constant/local/argument/this/that/temp/pointer/static）、
  label/goto/if-goto、function/call/return。檔案頭
  `// ========== File: <argv 原樣> ==========`、每行 `// <line>` 註解、靜態段
  以 `{current_file}.{index}` 引用 —— 全部照 C。
- **全域計數器**：eq/gt/lt 的 `TRUE_{n}`/`END_{n}` 與 call 的 `{func}$ret.{n}`
  在 C 是 `static int`（跨檔案累積）；Rust 用**單一共享 `Writer`**（`translate_into`
  寫進共用 writer，不另起新的），避免「每檔歸零」造成多檔案 case 的標記錯位。
- CLI：`vm2asm <output.asm> <file1.vm|dir> [file2.vm …]`；超過一個 VM 檔自動加
  `SP=256` + `call Sys.init 0` bootstrap（與 C 的 `argc>…` 判定一致）。
- 相容性驗證：07 全部 6 檔 + 08 全部 11 檔（含 NestedCall、FibonacciElement、
  StaticsTest 等多檔案例），C 與 Rust 輸出 byte-identical（`cmp` 零差異）。

### `jack2vm`（Jack → VM，ch11）

移植 `11/c/jack2vm.c`（897 行）為 Rust，同樣 byte 相容：

- **註解/空白處理**照 C：先整份移除區塊/行註解（不支援巢狀 `/* */`，非字串
  感知，`"//"` 字串字面值照刪——與 C 一致），再 lexer 出 token。
- token：symbol / 關鍵字 / 常數 / 字串 / identifier；`compile_class →
  compile_subroutine → statements → expression/term → …` 的遞迴下降結構照搬。
- **do 的 pop temp**：`do expr;` 把 `call` 結果 `pop temp 0`（`TEMP_RETURN=0`）；
  陣列 `let a[i] = …` 的臨時位址用 `TEMP_ARRAY=1`。
- 標籤命名 `WHILE_EXP{n}`/`WHILE_END{n}`/`IF_FALSE{n}`/`IF_END{n}` 為**每檔全域
  計數器**（編號直接寫進格式字串，先 `new_label()` 曾誤回傳 `"L{n}"` 造成
  `WHILE_EXPL0` 之類的錯名，已修）。
- 符號表：`static/this/argument/local`；bootstrap `Sys.init` 由 linker 決定
  （jack2vm 不管，與 C 一致）。
- CLI：`jack2vm [-o <outdir>] <file.jack|dir>`；**只收 `*.jack` 後綴**（C 用
  `strstr(".jack")` 會把 `.jack.md` 也編進去，這是 C 的 bug，Rust 不相沿）；
  預設輸出到來源目錄 `output/`（C 相容），`-o` 可換位置。
- 相容性驗證：11/jack 共 11 支 Jack 程式（Seven/Average/ComplexArrays/
  ConvertToBin/Pong×4/Square×3），**單檔模式**逐支與 C 比較，byte-identical。

### `hackasm` CLI（`_eda/hackasm/src/main.rs`）

hackasm 原本只有 lib；補上命令列：`hackasm <in.asm> [out.hack] [--bin]`。
輸出 `.hack` 文字（每行 16-bit 0/1），加 `--bin` 再寫 little-endian u16 二進位檔。
`@Main.0` 之類的 static 符號照 pass2 慣例從 RAM[16] 起配。

### 全鏈路 e2e（`_eda/gen/chain/`）

```
Main.jack + Sys.jack
  └─ jack2vm → Main.vm + Sys.vm
       └─ vm2asm → chain.asm       （含 SP=256 + call Sys.init 0 bootstrap）
             └─ hackasm → chain.hack  （242 條指令）
                    └─ hdl2rs Computer.hdl 全閘層模擬
                          └─ RAM16K[16] = 5 穩定，PASS
```

- `Main.jack`：`static int x;` + `let x = 5;`（`pop static 0` → `@Main.0`），
  進入 `while (true) {}` 無窮迴圈。
- `Sys.jack`：`Sys.init` 依序 `do Main.init(); do Main.loop();`。
- `chain.tst`：`ROM32K load chain.hack`，`output-list RAM16K[16]`，
  `repeat 5000 { tick, tock, output }`。RAM[16] 由 0 → 5 後維持 5 直到 end；
  `.cmp` 為驗證過的穩定輸出快照（與 Mult-hw 的 golden 做法一致）。

## 本版遇到的坑（處理過程）

1. **C 的 ASan 建置在子程序會 crash**：`11/c/build.sh`（`-fsanitize=address`）
   與 `gcc` atexit 的 `AddressSanitizer` 在 macOS 子程序執行時炸。改用 **plain
   `gcc -O2`** 編 oracle（`/tmp/coracle/{jack2vm,vm2asm}`），與 Rust 比對照常。
2. **`$ret.{n}` 多檔錯位**：第一版 `translate` 逐檔呼叫 `translate_file`（各自
   `Writer::new()`），return_count/label_count 每檔歸零 → NestedCall、
   FibElement、StaticsTest 全「ret.0 重複」。改成 `translate_into(&mut wr, …)`
   共用 counter 後逐一 byte 相等。
3. **`vm2asm <out> <in>` 至少 2 參數**：CLI 檢查誤寫 `args.len() < 3`，單檔
   永遠被拒；改 `< 2`。
4. **標籤格式錯名**：`new_label()` 回 `"L{n}"` 又包在 `format!("WHILE_EXP{}")`
   外層 → `WHILE_EXPL0`；改 `next_label_num()` 直接取計數值寫進格式字串。
5. **單元測試期望寫錯**（3 處）：`while` 計數從 0 起、無 else 的 `if` **不產生**
   `goto`、字串連結 `appendChar` 之後才是 `call String.new 1` —— 皆為「測試錯、
   實作對」，逐個校正（對照 C 版實際輸出）。
6. **C 的兩條怪癖**：dir 模式用 `strstr(".jack")` 誤吃 `.jack.md`（Rust 只認
   後綴）；檔案不存在時**靜默略過**（Rust 報錯）—— 比對腳本因此多出假 DIFF，
   釐清後以「相同有效 argv」重跑。
7. **C oracle 覆蓋了 git 追蹤的 `11/jack/*/output/*.vm` 參考檔**：比對完
   `git checkout --` 還原、刪掉多餘的 `Seven/output/Main.jack.vm`，工作樹淨化。
