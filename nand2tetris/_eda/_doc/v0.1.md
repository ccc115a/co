# hdl2rs v0.1 — 版本紀錄

日期：2026-09-10（115 學年度 · 計算機結構）
對應里程碑：**M1 — 組合電路（ch01 + ch02）全數通過**

## 一句話

hdl2rs 以「Verilator 精神」把 Nand2Tetris 的 `.hdl` 電路描述**轉譯成 Rust**，編譯成
獨立模擬程式，直接跑官方 `.tst` / `.cmp` 測試並做逐位元比對。
本版（v0.1）宣告組合電路里程碑完成：**第一章、第二章全部 21 個測試 PASS**。

## 目錄（workspace `_eda/`）

```
_eda/
├─ Cargo.toml    workspace 根（members: hackhdl, hackrt, hdl2rs）
├─ hackhdl/      .hdl parser + AST + elaboration（選路、拓撲排序、OUT 全覆蓋檢查）
├─ hackrt/       執行期：.tst 解析器 + 模擬 runner + .cmp 格式化
├─ hdl2rs/       CLI：讀 .hdl → 產出獨立 Rust crate → cargo build → 跑測試
├─ _doc/         版本紀錄（本檔）
├─ verify.sh     一鍵驗證（cargo test + ch01/ch02 全部 .tst）
└─ gen/          產出 crate 的暫存目錄（跑完即清空，除非 --keep）
```

## 資料流

```
<top>.hdl (+BUILTIN) ──parse──▶ AST ──elab──▶ ElabChip 圖
                                             │
hackrt::parse_script(.tst) ◀───load─────┐    ▼
                                       │  gen.rs codegen（逐 chip 展開 wire + set_bits）
                                       ▼
                             gen/<Top>_sim/  ──cargo build──▶ <Top>_sim
                                       ▲
hackrt::run(model, script) ◀───────────┘  ◀── argv[1] = <script>.tst
```

## 本版實作內容

### hackhdl（.hdl 前端）

- 完整 parser：`CHIP` 宣告、`IN`/`OUT`、bus 範圍語法（`a[16]`）、`PARTS`、
  subchip 連線（單 pin / bus slice / OfSlash 全線）。
- **多驅動 wire**：支援「子輸出分切寫入」慣用法——
  - `Not16`：16 個 `Not` 各寫 `out[i]`（位元範圍互不重疊即合法）；
  - `ALU`：`out=o2` / `out=out` 全線 + `out[0..7]=outLow` / `out[8..15]=outHigh` /
    `out[15]=ng` 的**輸出扇出**。
  目的位元範圍若有重疊則視為 bug 回報。
- **OUT 全覆蓋檢查**：晶片的 `OUT` pin 必須被 inputs 或 subchip 輸出完全涵蓋，
  避免 `0u16` 預設值悄悄成為答案。
- **拓撲排序**：wire 的驅動者→讀取者形成 DAG，先算線路再合併到 `OUT`；
  偵測組合回圈一律報錯。
- 內建晶片：`Nand`（真理表）、`Dff`（v0.1 僅回傳 `q`，未實作 tick/tock 語意）。

### hackrt（執行期）

- `.tst` 解析器：`load` / `output-file` / `compare-to` / `output-list` /
  `set` / `eval` / `tick` / `tock` / `output` / `clear` / `while` / `repeat` /
  `echo`；支援 `//` 註解、`;` `,` `{` `}` 分隔、`"..."` 字串常數、
  `PinRef[]`（位元 subindex，內部探測留待 M3 使用）。
- `.cmp` 格式化與官方硬體模擬器逐位元一致：
  - `Bin`（`%B`）：右對齊、零填滿；
  - `Dec`：有號 16 位元、右對齊；
  - `time`（`%S`）：左對齊，字樣 `0`/`0+`/`1`/`1+`…；
  - `constant` 由資料列取代，undefined 以 `*` 表列。
- runner：輸出 `.out`、與 `.cmp` 比對、逐行印出不符處、回報 PASS/FAIL 統計。

### hdl2rs（CLI + codegen）

- CLI（clap）：`--dir`（可重複）/ `--test` / `--top` / `--out` / `--keep`。
- codegen：對整個 ElabChip 圖逐一展開成 Rust，wire 以 `u16` + `set_bits`/`get_bits`
  切割組合；每個測試產出**獨立 crate**（`gen/<Top>_sim/`），以絕對路徑依賴
  `hackrt`，`Cargo.toml` 內含 `[workspace]` 以免被當成非成員 crate。
- 執行流程：讀 `.tst` → 取 `load` 的 top → `elab` → 產出 crate →
  `cargo build --quiet` → 執行模擬程式（`argv[1]` = `.tst`）→ 比對 → 清理。

## 本版遇到的坑（處理過程）

1. `.tst` 有 `//` 註解 → lexer 先移除註解（保留字串內字元）。
2. 官方 `.tst` 以 `,` `;` 分隔指令，`output-list` 內不含逗號 →
   lexer 把 `, ; { }` 全部當分隔符，`"..."` 字串內不受影響。
3. `output-list` 常列出**輸入 pin** → `get_output` 對輸入 pin fallback 回 `ins`。
4. 子晶片輸出 merge 曾寫死 `__o.out` → 改為依「子晶片輸出 pin 名」
   （如 `DMux` 的 `a`/`b`）取欄位。
5. `cargo` 會把 package 名（san 後的 `ALU_nostat_sim`）當 bin 名，
   但 CLI 曾用原始 chip 名拼路徑 → 統一用 `gen::pin_san` 後綴 `_sim`。
6. 時間只到 `%S`：tick/tock 尚未造成語意分歧（M2 才需要）。
