# 7.3 資料重用（Data Reuse）策略與 Dataflow 架構優化

## 資料重用的重要性

### 為什麼要資料重用

```
資料重用的動機：
┌─────────────────────────────────────────────────┐
│  問題：                                          │
│  深度學習運算需要大量資料                       │
│  但外部記憶體頻寬是瓶頸                        │
│                                                  │
│  範例（矩陣乘法）：                              │
│  C[M][N] = A[M][K] × B[K][N]                   │
│                                                  │
│  計算量：2×M×N×K FLOPs                         │
│  資料量：(M×K + K×N) 個元素                   │
│                                                  │
│  每個 A 元素被重用 N 次                        │
│  每個 B 元素被重用 M 次                        │
│                                                  │
│  若將重用資料保留在片上：                        │
│  → 外部記憶體存取大幅減少                    │
│  → 效能瓶頸獲得舒緩                           │
└─────────────────────────────────────────────────┘
```

### 資料重用類型

```
資料重用類型：
┌─────────────────────────────────────────────────┐
│  1. 時間重用（Temporal Reuse）                  │
│     - 同一資料在不同時間被重用                 │
│     - 需將資料保留在片上                       │
│                                                  │
│  2. 空間重用（Spatial Reuse）                   │
│     - 不同運算單元同時使用同一資料             │
│     - 需將資料傳遞給多個單元                   │
│                                                  │
│  3. 輸入重用（Input Reuse）                     │
│     - 輸入資料被多個權重重用                   │
│                                                  │
│  4. 權重重用（Weight Reuse）                    │
│     - 權重資料被多個輸入重用                   │
│                                                  │
│  5. 輸出重用（Output Reuse）                    │
│     - 部分結果被累加重用                       │
└─────────────────────────────────────────────────┘
```

## 記憶體層級與重用

### 重用與記憶體層級

```
資料重用與記憶體位置：
┌─────────────────────────────────────────────────┐
│  重用次數越多，應使用越快的記憶體：              │
│                                                  │
│  ┌───────────────────────┬──────────────────┐   │
│  │  記憶體類型            │  重用策略        │   │
│  ├───────────────────────┼──────────────────┤   │
│  │  暫存器（最快）       │  高重用資料      │   │
│  │  片上 SRAM            │  中重用資料      │   │
│  │  L2 Cache             │  低重用資料      │   │
│  │  外部記憶體（最慢）   │  一次性資料      │   │
│  └───────────────────────┴──────────────────┘   │
│                                                  │
│  原則：                                          │
│  - 重用次數多的資料放高層                       │
│  - 重用次數少的資料放低層                       │
│  - 目標：最小化外部記憶體存取                 │
└─────────────────────────────────────────────────┘
```

## 資料重用矩陣

### Matrix of Reuse

```
資料重用分析：
┌─────────────────────────────────────────────────┐
│  用一個表格分析不同資料的重用次數：              │
│                                                  │
│  矩陣乘法 C = A × B                              │
│                                                  │
│  ┌────────────┬──────────────┬──────────────┐  │
│  │ 資料        │ 重用方式      │ 重用次數      │  │
│  ├────────────┼──────────────┼──────────────┤  │
│  │ A[M][K]    │ 每個元素      │ N 次         │  │
│  │            │ 被 B 重用     │              │  │
│  │ B[K][N]    │ 每個元素      │ M 次         │  │
│  │            │ 被 A 重用     │              │  │
│  │ C[M][N]    │ 累加部分和    │ K 次         │  │
│  └────────────┴──────────────┴──────────────┘  │
│                                                  │
│  用途：                                          │
│  - 決定哪個資料應放暫存器                      │
│  - 決定哪個資料應放片上 SRAM                  │
│  - 決定資料搬運順序                            │
└─────────────────────────────────────────────────┘
```

## Dataflow 架構

### 何謂 Dataflow

```
Dataflow 架構：
┌─────────────────────────────────────────────────┐
│  定義：                                          │
│  資料流動的方式決定運算如何執行與重用            │
│                                                  │
│  決定因素：                                      │
│  1. 哪個資料固定在片上                          │
│  2. 哪個資料流動傳遞                            │
│  3. 資料如何在 PE 間流動                        │
│  4. 部分和在哪裡累加                          │
│                                                  │
│  不同 Dataflow：                                 │
│  - Weight-Stationary                          │
│  - Output-Stationary                          │
│  - Input-Stationary                            │
│  - Row-Stationary                              │
│  - No-Local-Reuse                              │
└─────────────────────────────────────────────────┘
```

## 三種基本 Dataflow 詳解

### 1. Weight-Stationary（權重固定）

```
Weight-Stationary Dataflow：
┌─────────────────────────────────────────────────┐
│  特性：                                          │
│  - 權重固定在 PE                               │
│  - 輸入在 PE 間流動                           │
│  - 部分和在 PE 間流動                         │
│                                                  │
│  重用：                                          │
│  - 每個權重重用 N 次（所有輸入）              │
│  - 權重在片上重用                              │
│  - 記憶體搬運：主要搬輸入                     │
│                                                  │
│  適合：                                          │
│  - 權重較小的運算                              │
│  - 卷積（權重可完全放片上）                  │
│                                                  │
│  優點：                                          │
│  - 權重搬運最少                                │
│  - 適合權重度高的層                          │
│                                                  │
│  缺點：                                          │
│  - 輸入需多次搬運                              │
│  - 部分和流動影響延遲                        │
└─────────────────────────────────────────────────┘
```

### 2. Output-Stationary（輸出固定）

```
Output-Stationary Dataflow：
┌─────────────────────────────────────────────────┐
│  特性：                                          │
│  - 輸出（部分和）固定在 PE                      │
│  - 權重與輸入在 PE 間流動                    │
│                                                  │
│  重用：                                          │
│  - 部分和重用（累加）在你的 PE                 │
│  - 輸出不需搬運                              │
│                                                  │
│  適合：                                          │
│  - 輸出資料量大的運算                          │
│  - 全連接層、矩陣乘法                    │
│                                                  │
│  優點：                                          │
│  - 輸出累加無需搬運部分和                     │
│  - 減少部分和流動的延遲                      │
│                                                  │
│  缺點：                                          │
│  - 權重和輸入都需要流動                      │
│  - 權重搬運較頻繁                              │
└─────────────────────────────────────────────────┘
```

### 3. Input-Stationary（輸入固定）

```
Input-Stationary Dataflow：
┌─────────────────────────────────────────────────┐
│  特性：                                          │
│  - 輸入固定在 PE                               │
│  - 權重與部分和在 PE 間流動                 │
│                                                  │
│  重用：                                          │
│  - 每個輸入被所有權重重用                     │
│  - 輸入重用次數高                              │
│                                                  │
│  適合：                                          │
│  - 輸入資料量大的運算                          │
│  - 卷積（輸入影像大）                         │
│                                                  │
│  優點：                                          │
│  - 輸入搬運最少                                │
│  - 適合輸入密集型運算                          │
│                                                  │
│  缺點：                                          │
│  - 部分和流動需要累加器                      │
│  - 控制邏輯較複雜                              │
└─────────────────────────────────────────────────┘
```

## 資料重用優化策略

### 分塊（Tiling）重用

```
Tiling 重用策略：
┌─────────────────────────────────────────────────┐
│  矩陣乘法 C = A × B 分塊：                       │
│                                                  │
│  Without Tiling：                                │
│  - 每個 A 元素讀取一次 → 使用 N 次              │
│  - 需要從外部記憶體讀取 N-1 次額外資料        │
│                                                  │
│  With Tiling（使用片上 SRAM）：                  │
│  ┌─────────────┐  ┌─────────────┐               │
│  │  Tile A      │  │  Tile B      │              │
│  │  (T×K)       │  │  (K×T)       │              │
│  └─────────────┘  └─────────────┘               │
│  - A Tile 載入片上，重用 T 次                  │
│  - B Tile 載入片上，重用 T 次                  │
│  - 大幅減少外部記憶體存取                      │
│                                                  │
│  效果：                                          │
│  - 外部記憶體存取從 O(N) 降到 O(N/T)          │
└─────────────────────────────────────────────────┘
```

### 暫存器重用

```
暫存器重新利用：
┌─────────────────────────────────────────────────┐
│  暫存器重用技巧：                                │
│                                                  │
│  ┌──────────────────────────────────────────┐   │
│  │  1. 循環展開（Loop Unrolling）           │   │
│  │     - 多個乘累加在暫存器中完成          │   │
│  │     - 減少記憶體往返                     │   │
│  │                                          │   │
│  │  2. 資料打包                            │   │
│  │     - 多個元素放入同一暫存器            │   │
│  │     - 例如：4 個 FP16 放入 64-bit       │   │
│  │                                          │   │
│  │  3. 軟體管線化                          │   │
│  │     - 預先載入下一循環的資料            │   │
│  │     - 隱藏記憶體延遲                    │   │
│  └──────────────────────────────────────────┘   │
└─────────────────────────────────────────────────┘
```

## 針對卷積的資料重用

### 卷積的重用特性

```
卷積重用：
┌─────────────────────────────────────────────────┐
│  卷積運算：                                      │
│  O[y][x] = Σ W[k1][k2] × I[y+k1][x+k2]        │
│                                                  │
│  重用分析：                                      │
│  - 權重重用：每個權重被所有輸出重用            │
│  - 輸入重用：相鄰輸出共享輸入像素重疊          │
│                                                  │
│  重疊範例：                                      │
│  ┌──────────────┐                                │
│  │ O[y][x] 需要  │→ I[y..y+k][x..x+k]        │
│  │ O[y][x+1]需要│→ I[y..y+k][x+1..x+1+k]    │
│  │              │   （重疊 k-1 個像素）      │
│  └──────────────┘                                │
│                                                  │
│  優化：                                          │
│  - 輸入行可被多次重用                         │
│  - 使用行緩衝器（Line Buffer）               │
│  - 權重常駐片上                                  │
└─────────────────────────────────────────────────┘
```

### 行緩衝器策略

```
行緩衝器（Line Buffer）：
┌─────────────────────────────────────────────────┐
│  卷積中的行緩衝器：                              │
│                                                  │
│  ┌──────────────────────────────────────────┐   │
│  │  輸入影像流動：                          │   │
│  │  ┌────────────────────────────────────┐ │   │
│  │  │ Buffer Row 0 │                     │ │   │
│  │  │ Buffer Row 1 │  重疊區域           │ │   │
│  │  │ Buffer Row 2 │                     │ │   │
│  │  └────────────────────────────────────┘ │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  效果：                                          │
│  - 只有新的一行需要從外部搬運                │
│  - 其餘行從片上緩衝重用                        │
│  - 外部記憶體存取大幅減少                    │
│                                                  │
│  適合卷積核 K=3：                              │
│  - 只需 3 行緩衝                              │
│  - 每次移動一個像素                          │
└─────────────────────────────────────────────────┘
```

## Dataflow 的選擇

### 不同層的策略

```
不同層的 Dataflow 選擇：
┌─────────────────────────────────────────────────┐
│  1. 卷積層：                                    │
│     - 權重重用高 → Weight-Stationary          │
│     - 或輸入重用 → Input-Stationary           │
│     - 依影像大小決定                          │
│                                                  │
│  2. 全連接層：                                  │
│     - 輸出重用 → Output-Stationary            │
│     - 權重/輸入平衡                          │
│                                                  │
│  3. 注意力層：                                  │
│     - 每次運算資料不同                        │
│     - 重用較低 → 需更高效搬運               │
│     - 使用混合策略                            │
└─────────────────────────────────────────────────┘
```

可配置 Dataflow：

## 效能評估

### 資料重用效能影響

```
重用策略效能影響：
┌─────────────────────────────────────────────────┐
│  假設矩陣乘法（M=N=K=1024）：                    │
│                                                  │
│  無重用策略（最差）：                            │
│  - 每個元素從外部記憶體讀取                   │
│  - 外部存取 = 2×1024³ = 2G 次                 │
│  - 頻寬成為絕對瓶頸                            │
│                                                  │
│  有 Tiling（Tile=32×32）：                      │
│  - 每個 Tile 載入片上                        │
│  - 外部存取 = (1024/32)² × 2×32²×1024        │
│  - 減少 32 倍                                 │
│                                                  │
│  有完整重用（理想）：                            │
│  - 外部存取 = 3×1024² = 3M 次                 │
│  - 減少 ~682 倍                                │
└─────────────────────────────────────────────────┘
```

## 本章小結

- 資料重用透過保留重用資料在片上減少外部記憶體存取
- 重用分為時間重用與空間重用等多種類型
- Dataflow 架構決定誰固定、誰流動、在哪累加
- 三種基本 Dataflow：Weight/Output/Input-Stationary
- 卷積可透過行緩衝器實現高效重用
- Tiling 與暫存器重用是關鍵優化技術
- 可配置 Dataflow 針對不同層選擇最佳策略
