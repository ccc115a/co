# 7.2 Ping-Pong Buffer 與 Direct Memory Access (DMA) 控制器

## Ping-Pong Buffer 概述

### 為什麼需要 Ping-Pong Buffer

```
Ping-Pong Buffer 的動機：
┌─────────────────────────────────────────────────┐
│  問題：                                          │
│  運算單元需要持續的資料流動                     │
│  但資料搬運（從外部記憶體）有延遲            │
│                                                  │
│  若一次只使用單一緩衝區：                       │
│  ┌────────────────────────────────────────┐     │
│  │  時間：  [載入]→[運算]→[載入]→[運算]  │     │
│  │          │←── 等待 ──→│                │     │
│  │  運算單元空閒等待載入                    │     │
│  └────────────────────────────────────────┘     │
│                                                  │
│  解法：Ping-Pong Buffer                         │
│  ┌────────────────────────────────────────┐     │
│  │  時間：  [載入A]→[運算A]→[載入A]─→     │     │
│  │          [載入B]  [載入B]  [運算B]──  │     │
│  │  運算與載入重疊，無空閒                │     │
│  └────────────────────────────────────────┘     │
└─────────────────────────────────────────────────┘
```

### Ping-Pong Buffer 結構

```
Ping-Pong Buffer 架構：
┌─────────────────────────────────────────────────┐
│                                                  │
│              Ping-Pong Buffer                     │
│  ┌──────────────────────────────────────────┐   │
│  │            Buffer A                       │   │
│  │         (資料區 0)                        │   │
│  └──────────────────────────────────────────┘   │
│  ┌──────────────────────────────────────────┐   │
│  │            Buffer B                       │   │
│  │         (資料區 1)                        │   │
│  └──────────────────────────────────────────┘   │
│                  ↕        ↕                    │
│            DMA 寫入   運算單元讀取             │
│                  ↕        ↕                    │
│   ┌───────────────┐  ┌───────────────┐         │
│   │   外部記憶體   │  │   運算單元     │         │
│   └───────────────┘  └───────────────┘         │
│                                                  │
│  運作原理：                                      │
│  1. DMA 寫入 Buffer A                           │
│  2. 同時運算單元讀取 Buffer B                   │
│  3. Buffer A 填滿後切換                        │
│  4. DMA 寫入 Buffer B（同時運算 Buffer A）     │
│  5. 循環往復                                    │
└─────────────────────────────────────────────────┘
```

### Ping-Pong 控制邏輯

```
Ping-Pong 控制：
┌─────────────────────────────────────────────────┐
│  狀態機：                                        │
│                                                  │
│         ┌──────────┐  Buffer A 滿              │
│         │  A 載入   │──────────────→            │
│         │  /B 運算  │                          │
│         └──────────┘←──────────────Buffer B 空│
│              ↑              │                  │
│              │              ↓                  │
│         ┌──────────┐  Buffer B 滿              │
│         │  B 載入   │──────────────→            │
│         │  /A 運算  │                          │
│         └──────────┘←──────────────Buffer A 空│
│                                                  │
│  切換時機：                                      │
│  - 緩衝區填滿/使用完畢                        │
│  - 由 DMA 控制器與運算單元協調                │
└─────────────────────────────────────────────────┘
```

## DMA 控制器

### DMA 的基本功能

```
DMA 控制器功能：
┌─────────────────────────────────────────────────┐
│  1. 記憶體間資料搬運                            │
│     - 外部記憶體 → 片上記憶體                 │
│     - 片上記憶體 → 外部記憶體                 │
│     - 片上記憶體 → 片上記憶體                 │
│                                                  │
│  2. 減少 CPU/控制器負擔                       │
│     - 不需處理器參與每個位元組傳輸            │
│     - 處理器只需發起命令                      │
│                                                  │
│  3. 支援平行搬運                                │
│     - 多通道 DMA                              │
│     - 同時搬運不同資料                        │
│                                                  │
│  4. 支援多種模式                                │
│     - 線性搬運                                │
│     - 2D/3D 搬運（Tile 搬運）                │
│     - 分散/聚集（Scatter/Gather）            │
└─────────────────────────────────────────────────┘
```

### DMA 運作流程

```
DMA 傳輸流程：
┌─────────────────────────────────────────────────┐
│  1. 配置 DMA 描述符（Descriptor）               │
│     - 來源位址                                 │
│     - 目的位址                                 │
│     - 傳輸長度                                 │
│     - 搬運模式                                 │
│                                                  │
│  2. 啟動 DMA                                    │
│     - 處理器寫入 DMA 控制暫存器               │
│     - DMA 開始傳輸                             │
│                                                  │
│  3. DMA 執行傳輸                                │
│     - 自動從來源讀取資料                      │
│     - 自動寫入目的地址                        │
│     - 不占用處理器資源                        │
│                                                  │
│  4. 傳輸完成通知                                │
│     - 產生中斷                                 │
│     - 設置完成標誌                            │
│     - 處理器可繼續後續工作                    │
└─────────────────────────────────────────────────┘
```

### DMA 描述符

```
DMA 描述符格式：
┌─────────────────────────────────────────────────┐
│  ┌─────────────────────────────────────────┐   │
│  │  來源位址（Source Address）            │   │
│  ├─────────────────────────────────────────┤   │
│  │  目的位址（Destination Address）       │   │
│  ├─────────────────────────────────────────┤   │
│  │  傳輸長度（Transfer Length）           │   │
│  ├─────────────────────────────────────────┤   │
│  │ 爆衝控制（Burst Control）             │   │
│  ├─────────────────────────────────────────┤   │
│  │  搬運模式（Transfer Mode）             │   │
│  ├─────────────────────────────────────────┤   │
│  │  下一個描述符指標（Next Descriptor）    │   │
│  └─────────────────────────────────────────┘   │
│                                                  │
│  特性：                                          │
│  - 描述符可形成鏈結串列（Linked List）         │
│  - 一次可配置多個傳輸作業                     │
│  - 支援自動執行下一個傳輸                     │
└─────────────────────────────────────────────────┘
```

## 硬體實現

### DMA 控制器結構

```
DMA 控制器硬體：
┌─────────────────────────────────────────────────┐
│              DMA Controller                      │
│  ┌──────────────────────────────────────────┐   │
│  │   ┌────────┐  ┌────────┐  ┌────────┐    │   │
│  │   │ 通道 0  │  │ 通道 1  │  │ 通道 2 │    │   │
│  │   │        │  │        │  │        │    │   │
│  │   └────────┘  └────────┘  └────────┘    │   │
│  └──────────────────────────────────────────┘   │
│        │               │             │          │
│        ↓               ↓             ↓          │
│  ┌──────────────────────────────────────────┐   │
│  │          仲裁器（Arbiter）                │   │
│  │    決定哪個通道優先使用匯流排            │   │
│  └──────────────────────────────────────────┘   │
│        │                                        │
│        ↓                                        │
│  ┌──────────────────────────────────────────┐   │
│  │          匯流排介面                         │   │
│  │     連接外部記憶體與片上記憶體          │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  各通道特性：                                    │
│  - 優先權（Priority）                          │
│  - 傳輸模式                                    │
│  - 狀態暫存器                                  │
└─────────────────────────────────────────────────┘
```

### 多通道 DMA

```
多通道同時傳輸：
┌─────────────────────────────────────────────────┐
│  ┌──────────────────────────────────────────┐   │
│  │ 時間  通道 0（權重）  通道 1（輸入）     │   │
│  │  ──────────────────────────────────────  │   │
│  │  0    搬運 W0→Buf     搬運 X0→Buf       │   │
│  │  1    搬運 W1→Buf     搬運 X1→Buf       │   │
│  │  2    搬運 W2→Buf     搬運 X2→Buf       │   │
│  │  ...                                    │   │
│  │  完成「權重+輸入」平行搬運              │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  好處：                                          │
│  - 同時載入不同的資料                          │
│  - 「流水線」（Pipeline）式搬運             │
│  - 最大化頻寬利用率                            │
│                                                  │
│  挑戰：                                          │
│  - 需要頻寬仲裁                              │
│  - 各通道之間的同步                          │
└─────────────────────────────────────────────────┘
```

## 應用在工作負載

### 矩陣乘法流水線

```
矩陣乘法 + 流水線：
┌─────────────────────────────────────────────────┐
│                                                  │
│  使用 Ping-Pong + DMA：                          │
│                                                  │
│  ┌──────────────────────────────────────────┐   │
│  │  步驟                                       │   │
│  │  1. DMA 載入權重區塊到 Buf A              │   │
│  │  2. DMA 載入輸入區塊到 Buf B              │   │
│  │  3. 運算 Buf A × Buf B                    │   │
│  │  4. 同時 DMA 載入下一批到 Buf A/B        │   │
│  │  5. 重複                                   │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  效能：                                          │
│  - 運算時間與搬運時間重疊                     │
│  - 理想情況：利用率 100%                      │
│  - 大幅提升吞吐量                             │
└─────────────────────────────────────────────────┘
```

### 卷積操作

```
卷積中的 Ping-Pong：
┌─────────────────────────────────────────────────┐
│  卷積特徵：                                      │
│  - 輸入影像大型                                │
│  - 權重小型（如 3×3×3×N）                    │
│                                                  │
│  策略：                                          │
│  - 權重常駐 Scratchpad（不需頻繁搬運）        │
│  - 輸入按區塊搬運（Ping-Pong）               │
│                                                  │
│  ┌──────────────────────────────────────────┐   │
│  │  時序：                                   │   │
│  │  載入輸入塊0 → 運算 → 載入輸入塊1 → 運算 │   │
│  │              ↑ 重疊 ↑                    │   │
│  │  輸入塊0載入與前次運算重疊               │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  效果：                                          │
│  - 隱藏輸入搬運延遲                           │
│  - 權重只載入一次                              │
│  - 卷積吞吐量提升                            │
└─────────────────────────────────────────────────┘
```

## 效能分析

### 時間線對比

```
有/無 Ping-Pong 比較：
┌─────────────────────────────────────────────────┐
│  無 Ping-Pong：                                  │
│  ┌─────┬─────┬─────┬─────┬─────┐                │
│  │載入<│運算  │載入<│運算  │...  │                │
│  │等待 │     │等待 │     │     │                │
│  └─────┴─────┴─────┴─────┴─────┘                │
│  總時間 = 搬運時間 + 運算時間（串行）          │
│                                                  │
│  有 Ping-Pong：                                  │
│  ┌─────────────────────────────────────────┐    │
│  │載入A│運算A│運算B│運算C│...              │    │
│  │     │載入B│載入C│載入D│                  │    │
│  └─────────────────────────────────────────┘    │
│  總時間 ≈ max(搬運, 運算)（並行）             │
│                                                  │
│  效能提升：                                      │
│  理想情況：2 倍（完全重疊）                    │
│  實際情況：1.5-1.9 倍（受頻寬限制）            │
└─────────────────────────────────────────────────┘
```

### 瓶頸分析

```
Ping-Pong 的瓶頸：
┌─────────────────────────────────────────────────┐
│  1. 緩衝區大小                                  │
│     - 太小：無法容納整個 Tile                  │
│     - 太大：浪費片上面積                       │
│                                                  │
│  2. 外部記憶體頻寬                              │
│     - 若搬運速度 < 運算速度：                  │
│       → 仍然受記憶體限制                     │
│                                                  │
│  3. DMA 通道數                                  │
│     - 太多：倍增頻寬需求                       │
│     - 太少：無法充分重疊                       │
│                                                  │
│  4. 控制開銷                                    │
│     - 需要同步機制                            │
│     - 中斷/標誌處理                            │
└─────────────────────────────────────────────────┘
```

## 本章小結

- Ping-Pong Buffer 使用雙緩衝區實現搬運與運算重疊
- DMA 控制器自動搬運資料，減少處理器負擔
- DMA 支援多通道、多模式（線性、2D/3D、分散/聚集）
- Ping-Pong 與 DMA 結合可隱藏記憶體搬運延遲
- 矩陣乘法與卷積可有效利用此技術
- 效能受緩衝區大小與外部頻寬限制
