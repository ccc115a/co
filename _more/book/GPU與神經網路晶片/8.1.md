# 8.1 HBM2e / HBM3e / HBM4 技術規格與介面協定

## HBM 技術背景

### 為什麼需要 HBM

```
記憶體頻寬的瓶頸：
┌─────────────────────────────────────────────────┐
│  問題：                                          │
│  AI 運算需要極高的記憶體頻寬                    │
│  傳統 DRAM（DDR）無法滿足                      │
│                                                  │
│  ┌──────────────────────────────────────────┐   │
│  │  需求 vs 供應：                          │   │
│  │  - AI 運算需求：2-10 TB/s               │   │
│  │  - DDR5 供應：~50-80 GB/s               │   │
│  │  - GDDR6 供應：~100-400 GB/s            │   │
│  │  - HBM3 供應：~1.6-3.3 TB/s             │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  HBM 的優勢：                                    │
│  - 極高頻寬（TB/s 等級）                       │
│  - 低功耗（降低資料傳輸功耗）                 │
│  - 緊湊體積（3D 堆疊）                        │
└─────────────────────────────────────────────────┘
```

### HBM 的演進

```
HBM 世代演進：
┌─────────────────────────────────────────────────┐
│  HBM1（2015）                                   │
│    - 頻寬：128 GB/s/stack                      │
│    - 首個商用 HBM                              │
│                                                  │
│  HBM2（2016）                                   │
│    - 頻寬：256 GB/s/stack                      │
│    - 容量提升                                  │
│                                                  │
│  HBM2e（2019）                                 │
│    - 頻寬：307 GB/s/stack                      │
│    - 廣泛用於 GPU                             │
│                                                  │
│  HBM3（2020）                                   │
│    - 頻寬：410-819 GB/s/stack                  │
│    - 首次引入 Pseudo-Channel                 │
│                                                  │
│  HBM3e（2022）                                 │
│    - 頻寬：520-1200 GB/s/stack                 │
│    - 用於 H200 等旗艦晶片                     │
│                                                  │
│  HBM4（2024-2025）                            │
│    - 頻寬：665-1330 GB/s/stack                 │
│    - 更高的容量密度                           │
└─────────────────────────────────────────────────┘
```

## HBM 基本結構

### 3D 堆疊結構

```
HBM 堆疊結構：
┌─────────────────────────────────────────────────┐
│                                                  │
│  ┌──────────────────────────────────────────┐   │
│  │          DRAM Die 7（最頂層）            │   │
│  ├──────────────────────────────────────────┤   │
│  │          DRAM Die 6                      │   │
│  ├──────────────────────────────────────────┤   │
│  │          DRAM Die 5                      │   │
│  ├──────────────────────────────────────────┤   │
│  │          DRAM Die 4                      │   │
│  ├──────────────────────────────────────────┤   │
│  │          DRAM Die 3                      │   │
│  ├──────────────────────────────────────────┤   │
│  │          DRAM Die 2                      │   │
│  ├──────────────────────────────────────────┤   │
│  │          DRAM Die 1                      │   │
│  ├──────────────────────────────────────────┤   │
│  │          Logic Die（底層）               │   │
│  │    - 測試                          │   │
│  │    - ECC                           │   │
│  │    - 通道管理                    │   │
│  └──────────────────────────────────────────┘   │
│            ↑           ↑                        │
│           TSV        Microbump                  │

│                                                  │
│  通過 TSV（矽穿孔）連接所有 Die         │

```

### HBM3e 新特性

```
HBM3e 創新：
┌─────────────────────────────────────────────────┐
│  1. Pseudo-Channel 架構                        │
│     - 每個 Channel 分為 2 個                   │
│     - 增加平行度                                │
│     - 降低延遲                                  │
│                                                  │
│  2. 錯誤校正強化                                │
│     - 額外的 ECC 位元                          │
│     - 增強可靠性                                │
│                                                  │
│  3. 改善的功耗管理                              │
│     - 更低的工作電壓                          │
│     - 深度睡眠模式                            │
│                                                  │
│  4. 更高的密度                                  │
│     - 8-12 到 16 層堆疊                      │
│     - 更高容量                                  │
└─────────────────────────────────────────────────┘
```

## 通道介面

### HBM 資料匯流排

```
HBM 介面協定：
┌─────────────────────────────────────────────────┐
│  介面信號：                                      │
│  ┌──────────────────────────────────────────┐   │
│  │  資料：DQ[127:0]（128-bit/Channel）     │   │
│  │  地址：ADD[9:0]（行位址）               │   │
│  │        BA[7:0]（Bank 位址）             │   │
│  │  控制：CS, RAS, CAS, WE                  │   │
│  │  定時：DQS（資料選通）                  │   │
│  │  能力：CS_n（Chip Select）              │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  信令：                                          │
│  - 使用差分信令（Differential）              │
│  - 高速 PCB 佈局要求                          │
│  - 透過中介層（Interposer）連接               │
└─────────────────────────────────────────────────┘
```

### HBM 與 GPU 的連接

```
GPU-HBM 連接：
┌─────────────────────────────────────────────────┐
│                                                  │
│  ┌──────────────────────────────────────────┐   │
│  │              GPU Die                    │   │
│  └──────────────────────────────────────────┘   │
│               │   （Microbump）               │
│  ┌──────────────────────────────────────────┐   │
│  │          中介層（Interposer）           │   │
│  │  ┌──────────┐    ┌──────────┐           │   │
│  │  │ HBM Stack│    │ HBM Stack│           │   │
│  │  └──────────┘    └──────────┘           │   │
│  └──────────────────────────────────────────┘   │
│               │                                │
│  ┌──────────────────────────────────────────┐   │
│  │           封裝基板（Substrate）         │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  連接關鍵點：                                    │
│  - 使用 CoWoS 封裝技術                       │
│  - Microbump 連接 GPU 與 Interposer          │
│  - TSV 將 HBM 連到 Interposer                  │
└─────────────────────────────────────────────────┘
```

### 功耗與能效

```
HBM 能效分析：
┌─────────────────────────────────────────────────┐

```

## 本章小結

- HBM 透過 3D 堆疊實現極高的記憶體頻寬
- TSV 技術連接垂直堆疊的 DRAM Die
- HBM2e、HBM3e、HBM4 代表世代的演進
- Pseudo-Channel 增加平行度降低延遲
- HBM 透過中介層（Interposer）與 GPU 連接
- HBM 是現代 AI 加速器的標準記憶體方案
