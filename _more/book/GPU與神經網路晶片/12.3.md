# 12.3 AI 晶片的功耗、散熱挑戰與液冷（Liquid Cooling）技術

## AI 晶片的功耗挑戰

### AI 算力的電力需求

```
AI 晶片功耗快速成長：
┌─────────────────────────────────────────────────┐
│  單一加速器的功耗趨勢：                          │
│  ┌──────────────────────────────────────────┐   │
│  │  GPU/加速器  │  功耗       │  年份      │   │
│  ├──────────────────────────────────────────┤   │
│  │  A100       │  400W       │  2020      │   │
│  │  H100 SXM   │  700W       │  2022      │   │
│  │  B200       │  1000W+     │  2024      │   │
│  │  GB200 機櫃 │  120kW      │  2020s後期 │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  AI 資料中心的電力增長：                          │
│  - 單一 AI 叢集可達 100MW-1GW                  │
│  - 供電與散熱成為重大瓶頸                  │
│  - 全球資料中心耗電比率持續升高            │
└─────────────────────────────────────────────────┘
```

### 為何功耗如此巨大

```
功耗來源分析：
┌─────────────────────────────────────────────────┐
│  1. 動態功耗：                                  │
│     P_dynamic = α × C × V² × f               │
│     - α：活動因子（切換頻率）              │
│     - C：電容（負載）                        │
│     - V：電壓                                  │
│     - f：頻率                                  │
│     → 電壓影響最大（平方項）              │
│                                                  │
│  2. 靜態功耗：                                  │
│     - 漏電流（小尺寸製程嚴重）              │
│     - 即使未運算也消耗電能              │
│                                                  │
│  3. AI 工作負載特性：                          │
│     - 大規模平行計算（大量單元啟動）        │
│     - 長時間滿載運行（訓練）                │
│     - 記憶體持續讀寫                      │
│                                                  │
│  → 所有能量最終都轉為熱                    │
└─────────────────────────────────────────────────┘
```

### 功耗的效能影響

```
功耗與效能：
┌─────────────────────────────────────────────────┐
│  ┌──────────────────────────────────────────┐   │
│  │  高功耗 → 高熱 → 高溫                   │   │
│  │     │                                     │   │
│  │     ↓                                     │   │
│  │  性能下降（電子遷移率降低）              │   │
│  │  → 晶片可能降頻（Thermal Throttling）    │   │
│  │  → MFU 與吞吐量受影響                  │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  能量效率指標：                                  │
│  - FLOPS/Watt（效能每瓦）                  │
│  - 常用於比較 AI 加速器                      │
│  - 資料中心更重視 Wall-clock 效能          │
│                                                  │
│  結論：                                          │
│  功耗會直接影響整體系統效能    │
│  散熱成為「算力」的一部分      │
└─────────────────────────────────────────────────┘
```

## 散熱技術基礎

### 熱傳導原理

```
散熱的物理原理：
┌─────────────────────────────────────────────────┐
│  熱傳遞三種方式：                                │
│  1. 熱傳導（Conduction）                        │
│     - 晶片 → 散熱器（固體接觸）            │
│                                                  │
│  2. 對流（Convection）                          │
│     - 散熱器 → 空氣/液體（流體）          │
│                                                  │
│  3. 輻射（Radiation）                           │
│     - 表面 → 環境（電磁波）              │
│                                                  │
│  熱阻抗路徑：                                    │
│  Chip → TIM（熱介質） → 散熱器 → 流體 → 環境     │
│                                                  │
│  TJ（接面溫度，結點）限制：                     │
│  - 矽晶片通常需 < 100-105°C                   │
│  - 超過會加速老化或損壞                    │
└─────────────────────────────────────────────────┘
```

### 空氣冷卻的限制

```
風冷（空氣冷卻）極限：
┌─────────────────────────────────────────────────┐
│  風冷優點：                                      │
│  - 技術成熟、成本低                          │
│  - 維護簡單                                │
│                                                  │
│  風冷限制：                                      │
│  - 空氣比熱低、熱導係數低                │
│  - 散熱鰭片面積有限                    │
│  - 噪音與風扇功耗                          │
│  - 機架密度受限                          │
│                                                  │
│  風冷能應付的上限：                              │
│  - 單晶片約 300-400W 以下                    │
│  - 超過這個功耗難以風冷                    │
│                                                  │
│  → 高功耗 AI 晶片（700W+）必須液冷        │
└─────────────────────────────────────────────────┘
```

## 液冷技術深入

### 液冷基本原理

```
液冷（Liquid Cooling）優勢：
┌─────────────────────────────────────────────────┐
│  液體 vs 空氣熱性質比較：                        │
│  ┌──────────────────────────────────────────┐   │
│  │  流體    │  熱導係數（W/mK）│ 比熱      │   │
│  ├──────────────────────────────────────────┤   │
│  │  空氣    │  ~0.026         │  1.0      │   │
│  │  水      │  ~0.6           │  4.2      │   │
│  │  氟化液  │  ~0.07          │  1.1      │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  水比空氣：                                      │
│  - 熱導係數高 20 倍                         │
│  - 比熱高 4 倍                                │
│  → 熱傳輸效率遠高於風冷                  │
│                                                  │
│  液冷系統基本組成：                              │
│  - 冷板（Cold Plate）貼在晶片                  │
│  - 流體循環帶走熱                  │
│  - 散熱排（Radiator/熱交換器）排出熱          │
│  - 泵浦（Pump）推動循環                  │
└─────────────────────────────────────────────────┘
```

### 液冷技術形式

```
液冷三種形式：
┌─────────────────────────────────────────────────┐
│  1. 冷板液冷（Cold Plate）                    │
│  ┌──────────────────────────────────────────┐   │
│  │  晶片 → [冷板] → 管路（水流走熱）        │   │
│  │          （間接冷卻，晶片不接觸液體）     │   │
│  └──────────────────────────────────────────┘   │
│  - 最安全、最普遍                          │
│  - 與風冷類似，但用液體當散熱介質        │
│  - 可冷卻 700W+ 的單芯                  │
│                                                  │
│  2. 浸沒式液冷（Immersion）                  │
│  ┌──────────────────────────────────────────┐   │
│  │  將整個伺服器浸入介電液（不導電）        │   │
│  │  [伺服器] ↓                              │   │
│  │  [  介電液槽  ] ← 泡在液體中          │   │
│  └──────────────────────────────────────────┘   │
│  - 直接接觸液體（介電液不導電）          │
│  - 效率最高                                │
│  - 成本與維護較高                        │
│                                                  │
│  3. 噴射/噴霧液冷                        │
│  - 用噴嘴直接噴液到晶片                │
│  - 高效但複雜                        │
└─────────────────────────────────────────────────┘
```

### 兩相冷卻

```
兩相（Phase-Change）冷卻：
┌─────────────────────────────────────────────────┐
│  原理：                                          │
│  - 液體吸收熱 → 蒸發成氣體（吸收潛熱）    │
│  - 氣體在冷凝器 → 凝結回液體                │
│                                                  │
│  ┌──────────────────────────────────────────┐   │
│  │  [晶片] → 液汽化（吸收大量熱）→ [冷凝] │   │
│  │                                    ↓     │   │
│  │                             回流為液體   │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  - 汽化潛熱遠大於比熱（效率更高）          │
│  - 適用超高密度與超高功耗場景              │
│  - 技術較複雜                              │
└─────────────────────────────────────────────────┘
```

### PUE 與能效

```
PUE 指標（Power Usage Effectiveness）：
┌─────────────────────────────────────────────────┐
│  PUE = 資料中心總功耗 / IT 設備功耗            │
│                                                  │
│  理想 = 1.0（所有電都用於計算）                │
│  ├──────────────────────────────────────────┤   │
│  │  傳統風冷      │  PUE 1.3-2.0          │   │
│  │  高效風冷      │  PUE 1.1-1.3          │   │
│  │  液冷          │  PUE 1.0-1.15         │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  液冷價值：                                      │
│  - 降低 PUE（省散熱耗電）                  │
│  - 可回收熱能（區域供暖等）              │
│  - 支撐超高功耗密度機櫃                    │
└─────────────────────────────────────────────────┘
```

## 未來方向

### 先進散熱技術

```
下一代散熱技術：
┌─────────────────────────────────────────────────┐
│  1. 微流道（Microchannel）                      │
│     - 晶片內嵌超細流道                    │
│     - 直接散熱（貼近發熱源）              │
│                                                  │
│  2. 兩相直Cold Plate                      │
│     - 冷板內直接汽化                      │
│     - 效率更高                            │
│                                                  │
│  3. 液態金屬散熱                            │
│     - 高熱導係數的液態金屬（如鎵）        │
│     - 用於 TIM 或對流介質                │
│                                                  │
│  4. 片上熱管理（Thermal Management on Chip）     │
│     - 動態能力管理（DVFS）               │
│     - 熱感測 + 動態調度                    │
│                                                  │
│  5. 3D 封裝與散熱整合                     │
│     - 3D 堆疊的熱路徑設計              │
│     - 嵌入式微流道                    │
└─────────────────────────────────────────────────┘
```

### 動態功耗管理

```
動態功耗/熱管理：
┌─────────────────────────────────────────────────┐
│  1. DVFS（動態電壓頻率調整）                  │
│     - 依負載調整電壓與頻率              │
│     - 節能或峰值效能切換                │
│                                                  │
│  2. Clock Gating / Power Gating            │
│     - 關閉閒置電路                          │
│     - 顯著靜態功耗節省                  │
│                                                  │
│  3. 熱感知排程（Thermal-Aware Scheduling)        │
│     - 避免熱點集中                          │
│     - 平衡溫度分布                      │
│                                                  │
│  4. 晶片內分散熱源                        │
│     - 設計階段均勻功耗分佈              │
│     - 避免局部過熱                    │
└─────────────────────────────────────────────────┘
```

## 本章小結

- AI 加速器功耗快速攀升（H100 700W、B200 1000W+）
- 功耗主要來自動態與靜態功耗，最終全轉為熱
- 高溫會降低性能並可能觸發降頻（Thermal Throttling）
- 風冷極限約 300-400W，高功耗必須液冷
- 液冷形式包含冷板、浸沒式與兩相冷卻
- 液冷可降低 PUE，支援超高密度機櫃
- 未來走向：微流道、片上熱管理與動態功耗管理
- 散熱與功耗已成為 AI 算力擴展的關鍵因素
