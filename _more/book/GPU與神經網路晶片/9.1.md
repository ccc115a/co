# 9.1 Processing-In-Memory (PIM) 與 Compute-In-Memory (CIM)

## 為什麼需要近存計算

### 記憶體牆的困境

```
記憶體搬運的成本：
┌─────────────────────────────────────────────────┐
│  問題：                                          │
│  在傳統架構中，資料需要                 │
│  從記憶體搬運到運算單元                       │
│                                                  │
│  能量成本比較：                                  │
│  ┌──────────────────────────────────────────┐   │
│  │  操作               │  能量（相對）      │   │
│  ├──────────────────────────────────────────┤   │
│  │  ALU 運算（加法）  │  1×                │   │
│  │  SRAM 讀取         │  3-10×            │   │
│  │  DRAM 讀取         │  30-50×           │   │
│  │  DRAM 寫入         │  50-100×          │   │
│  │  外部傳輸（移動）   │  100-1000×        │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  結論：                                          │
│  - 資料搬運比運算貴得多                       │
│  - 應該減少資料搬運                          │
│  - 把運算移到資料附近                        │
└─────────────────────────────────────────────────┘
```

### 近存計算的理念

```
近存計算理念：
┌─────────────────────────────────────────────────┐
│  傳統架構：                                      │
│  ┌──────────┐   搬運   ┌──────────┐            │
│  │ 記憶體   │────────→│  運算單元 │            │
│  └──────────┘         └──────────┘            │
│       ↑                    │                   │
│       └────────────────────┘                   │
│          搬運（貴）                              │
│                                                  │
│  近存計算：                                      │
│  ┌──────────────────────────┐                   │
│  │  記憶體 + 運算單元       │                   │
│  │  ┌──────────┐  ┌──────┐ │                   │
│  │  │ 記憶體   │←→│   運算 │ │                   │
│  │  └──────────┘  └──────┘ │                   │
│  └──────────────────────────┘                   │
│       ↓ 減少搬運                                 │
│                                                  │
│  兩大方向：                                      │
│  - PIM：運算單元靠近記憶體                     │
│  - CIM：直接用記憶體做運算                     │
└─────────────────────────────────────────────────┘
```

## Processing-In-Memory (PIM)

### PIM 定義

```
PIM（Processing-In-Memory）：
┌─────────────────────────────────────────────────┐
│  定義：                                          │
│  在記憶體晶片內或附近加入運算邏輯              │
│                                                  │
│  特點：                                          │
│  - 記憶體與運算分離（在晶片內）               │
│  - 邏輯與記憶體在同一個封裝/基板              │
│  - 減少資料搬運距離                          │
│                                                  │
│  PIM 的層級：                                    │
│  1. 運算單元在同一 DRAM 晶片內                 │
│  2. 運算單元在 HBM 的 Logic Die               │
│  3. 運算單元在記憶體控制器附近                │
└─────────────────────────────────────────────────┘
```

### PIM 架構

```
PIM 架構示意：
┌─────────────────────────────────────────────────┐
│              PIM 晶片                             │
│  ┌──────────────────────────────────────────┐   │
│  │            DRAM Bank 陣列                │   │
│  │  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐      │   │
│  │  │Bank0│ │Bank1│ │Bank2│ │Bank3│ ...  │   │
│  │  └──┬──┘ └──┬──┘ └──┬──┘ └──┬──┘      │   │
│  │     └───┬────┴────┬───┴────┘          │   │
│  │       ┌─┴─────────┴─┐                  │   │
│  │       │  運算單元    │                  │   │
│  │       │ (MAC/ALU)   │                  │   │
│  │       └─────────────┘                  │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  特點：                                          │
│  - 運算單元可直接讀取 Bank 資料                │
│  - 不經外部匯流排                            │
│  - 頻寬極高（Bank 內平行）                    │
└─────────────────────────────────────────────────┘
```

### PIM 的特性

```
PIM 特性分析：
┌─────────────────────────────────────────────────┐
│  優勢：                                          │
│  ✓ 頻寬高（Bank 內平行存取）                   │
│  ✓ 能量效率高（短距離傳輸）                   │
│  ✓ 減少記憶體搬運                              │
│                                                  │
│  挑戰：                                          │
│  ✗ 記憶體密度受影響（加了運算單元）           │
│  ✗ DRAM 製程不適合高效運算單元                │
│  ✗ 熱問題（記憶體與運算同時發熱）            │
│  ✗ 製造成本增加                              │
│  ✗ 記憶體廠商不熟悉邏輯設計                  │
└─────────────────────────────────────────────────┘
```

## Compute-In-Memory (CIM)

### CIM 定義

```
CIM（Compute-In-Memory）：
┌─────────────────────────────────────────────────┐
│  定義：                                          │
│  直接在記憶體單元中執行運算                    │
│  （通常在類比域進行）                           │
│                                                  │
│  核心概念：                                      │
│  - 利用記憶體單元的物理特性做運算              │
│  - 例如：利用電流的累加做矩陣乘法            │
│  - 不需將資料搬出記憶體                      │
│                                                  │
│  與 PIM 的區別：                                │
│  - PIM：運算單元放在記憶體旁                  │
│  - CIM：記憶體本身就是運算單元                │
└─────────────────────────────────────────────────┘
```

### 類比 CIM（Analog CIM）

```
類比 CIM 原理：
┌─────────────────────────────────────────────────┐
│  電阻式記憶體（RRAM/ReRAM）做乘法：              │
│                                                  │
│  ┌──────────────────────────────────────────┐   │
│  │     輸入電壓（X）                         │   │
│  │        ↓                                  │   │
│  │  ┌──────────────┐                        │   │
│  │  │ 記憶體單元    │→ 電導（G = 權重W）   │   │
│  │  └──────────────┘                        │   │
│  │        ↓                                  │   │
│  │  輸出電流（I = X × G）                   │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  矩陣-向量乘法：                                 │
│  利用基爾霍夫定律（Kirchhoff's Law）：           │
│                                                  │
│  I_j = Σ_i (X_i × G_ij)                       │
│                                                  │
│  輸出電流 = 每個乘積的電流的總和（並行累加）   │
│  → 直接完成矩陣乘法，無需獨立乘法器           │
└─────────────────────────────────────────────────┘
```

### CIM 矩陣運算

```
CIM 交叉開關陣列：
┌─────────────────────────────────────────────────┐
│  Crossbar Array：                                │
│                                                  │
│      電壓 X0  X1  X2  X3                        │
│          │   │   │   │                          │
│       ┌──┴───┴───┴───┐                         │
│  I0 ← │ G00 G10 G20 G30│  ← MUX 讀取          │
│  I1 ← │ G01 G11 G21 G31│                       │
│  I2 ← │ G02 G12 ...   │                       │
│  I3 ← │ G03          │                       │
│       └─────────────────┘                      │
│                                                  │
│  每個交點是一個記憶體單元（權重）              │
│  垂直：輸入電壓（activations）                 │
│  水平：輸出電流（outputs）                    │
│                                                  │
│  I = X × G（一次完成矩陣乘法）                │
│  O(1) 時間複雜度（平行）                       │
└─────────────────────────────────────────────────┘
```

### 記憶體技術比較

```
CIM 使用的記憶體技術：
┌─────────────────────────────────────────────────┐
│  技術     │  可程式性 │  精度  │  能耗  │ 成熟度│
├─────────────────────────────────────────────────┤
│  SRAM    │  可        │  高    │  低   │ 高   │
│  RRAM    │  可        │  中    │  極低 │ 中   │
│  ReRAM   │  可        │  中    │  極低 │ 中   │
│  PCM     │  可        │  低    │  中   │ 低   │
│  Flash   │  可        │  中    │  低   │ 高   │
└─────────────────────────────────────────────────┘

考慮因素：
- 精度：類比運算精度有限
- 可重寫性：訓練後需更新權重
- 耐用性：重寫次數限制
- 一致性：單元間的一致性
```

## PIM vs CIM

### 比較表格

```
PIM vs CIM 比較：
┌─────────────────────────────────────────────────┐
│  特性      │  PIM           │  CIM              │
├─────────────────────────────────────────────────┤
│  運算位置  │  記憶體旁       │  記憶體內部       │
│  運算域    │  數位          │  類比/數位      │
│  精度      │  高（數位）    │  中（類比誤差）   │
│  頻寬      │  高            │  極高             │
│  能量效率  │  高            │  極高             │
│  靈活性    │  高            │  低（受限）       │
│  製程相容  │  較好          │  需特殊記憶體   │
│  成熟度    │  較成熟        │  實驗階段       │
│  應用      │  矩陣運算       │  矩陣運算        │
│           │  一般運算       │  （推論為主）    │
└─────────────────────────────────────────────────┘
```

## 挑戰與未來

### 技術挑戰

```
PIM/CIM 挑戰：
┌─────────────────────────────────────────────────┐
```

## 本章小結

- 資料搬運比運算更耗能量與延遲，促使近存計算興起
- PIM 在記憶體附近加入運算單元，減少搬運距離
- CIM 直接在記憶體單元中執行運算（常為類比）
- CIM 交叉開關陣列可一次完成矩陣乘法
- PIM 精度較高但 CIM 能量效率更高
- 仍面臨精度、製程、軟體等挑戰
