# 3.4 案例分析：NVIDIA Hopper (H100/H200) 與 Blackwell 架構解析

## NVIDIA Hopper 架構概述

### H100 SXM 規格

```
NVIDIA H100 SXM5 規格：
┌─────────────────────────────────────────────────┐
│  製程：TSMC 4N                                   │
│  晶片面積：814 mm²                               │
│  電晶體數：800 億                               │
│                                                  │
│  CUDA 核心：16896 個                            │
│  Tensor Core：528 個（第 4 代）                 │
│                                                  │
│  記憶體：                                         │
│  - HBM3：80 GB                                  │
│  - 頰寬：3.35 TB/s                              │

│                                                  │
│  效能：                                           │
│  - FP64：34 TFLOPS                              │

│  - FP8 Tensor Core：3,958 TFLOPS                │

```

### Hopper 架構創新

```
Hopper 主要創新：
┌─────────────────────────────────────────────────┐
│  1. FP8 Tensor Core                             │
│     - 支援 FP8 E4M3 與 E5M2 格式               │
│     - 效能比 FP16 提升 2 倍                     │
│     - 支援動態範圍調整                          │
│                                                  │
│  2. Transformer Engine                           │
│     - 自動管理 FP8/FP16 混合精度                │
│     - 動態調整張量縮放因子                      │
│     - 優化 Transformer 模型效能                 │
│                                                  │
│  3. DPX 指令                                    │
│     - 加速動態規劃（Dynamic Programming）       │
│     - 如 Smith-Waterman、Needleman-Wunsch       │
│     - 效能提升 7 倍                             │
│                                                  │
│  4. 結構化稀疏支援                              │
│     - 2:4 稀疏模式                              │
│     - 效能提升 2 倍（對稀疏模型）               │
│                                                  │
│  5. NVLink 4.0                                  │
│     - 900 GB/s 雙向頻寬                         │
│     - 支援多達 256 個 GPU 互連                  │
└─────────────────────────────────────────────────┘
```

```
第 4 代 Tensor Core 運算：
┌─────────────────────────────────────────────────┐
│  支援精度：                                      │
│  ┌─────────────────────────────────────────┐   │

│  │  動態縮放 ← 精度監控 ← 輸出張量       │   │

└─────────────────────────────────────────────────┘
```

## 本章小結

- H100 是 NVIDIA Hopper 架構的旗艦產品，引入 FP8 Tensor Core 與 Transformer Engine
- H200 在 H100 基礎上升級至 HBM3e，提供更大的記憶體容量與頻寬
- Blackwell 架構採用雙 Die 設計，支援 FP4 格式，大幅提升效能
- NVLink 4.0/5.0 提供 GPU 間高速互連，支援大規模平行運算
- 這些技術共同推動 AI 訓練與推論的效能邊界
