# 12.2 類腦計算（Neuromorphic Computing）與事件驅動架構

## 類腦計算簡介

### 何謂類腦計算

```
從大腦學習計算架構：
┌─────────────────────────────────────────────────┐
│  大腦 vs 傳統數位計算機：                        │
│  ┌──────────────────────────────────────────┐   │
│  │  特性     │  大腦        │  數位計算機   │   │
│  ├──────────────────────────────────────────┤   │
│  │  處理模式 │  事件驅動    │  時脈驅動    │   │
│  │  記憶體   │  突觸（結合）│  分離記憶體  │   │
│  │  細胞     │  神經元      │  邏輯閘      │   │
│  │  同步     │  非同步      │  同步       │   │
│  │  功耗     │  極低（20W）│  高          │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  類腦計算目標：                                  │
│  模擬神經元的計算方式          │
│  - 稀疏事件驅動（只有發生事件才運算）    │
│  - 記憶體與計算結合（突觸可塑）          │
│  - 低功耗、低延遲                  │
└─────────────────────────────────────────────────┘
```

### 與深度學習的關係

```
類腦計算 vs 深度學習：
┌─────────────────────────────────────────────────┐
│  深度學習：                                      │
│  - 以矩陣運算為主（GEMM）                    │
│  - 需要大量平行運算                      │
│  - 需要高精度權重                    │
│  - 功耗高但精度高                      │
│                                                  │
│  類腦計算：                                      │
│  - 以脈衝（Spike）為主                  │
│  - 事件驅動，稀疏計算                    │
│  - 低精度權重也可以                │
│  - 極低功耗                        │
│                                                  │
│  差異：                                          │
│  - 深度學習注重「精確數學」           │
│  - 類腦計算注重「節省能量」           │
│  - 兩者各有適用場景              │
└─────────────────────────────────────────────────┘
```

## 脈衝神經網路（Spiking Neural Network）

### 脈衝神經元模型

```
Spiking Neuron 模型：
┌─────────────────────────────────────────────────┐
│  脈衝神經元原理：                                │
│  - 接收脈衝輸入（Spike Train）                │
│  - 累積膜的電位（Membrane Potential）    │
│  - 超過閾值時，產生輸出脈衝（Fire）     │
│  - 之後重置（Reset）                    │
│                                                  │
│  常見模型：                                      │
│  1. LIF（Leaky Integrate-and-Fire）             │
│     - 漏電整合觸發模型                    │
│     - 最常用、計算簡單                │
│                                                  │
│  2. Hodgkin-Huxley（HH）                    │
│     - 生物學精確模型                  │
│     - 計算複雜，適合生物模擬          │
│                                                  │
│  脈衝時間編碼：                                  │
│  - Rate Coding：以脈衝頻率表示訊息                │
│  - Temporal Coding：以脈衝時間表示訊息            │
│  - 讓資訊以「事件」而非「數值」傳遞        │
└─────────────────────────────────────────────────┘
```

### 事件驅動計算

```
事件驅動架構：
┌─────────────────────────────────────────────────┐
│  傳統（Clock-Driven）：                          │
│  - 每個時脈週期都執行                        │
│  - 即使輸入沒變化也算                     │
│  - 大量浪費計算                            │
│                                                  │
│  ┌──────────────────────────────────────────┐   │
│  │  Input:  0    0    0    1    0    1    0  │   │
│  │  運算：  ×    ×    ×    ✓    ×    ✓    ×  │   │
│  │          （全都算）                     │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  事件驅動（Event/Spike-Driven）：                │
│  - 輸入有變化（Spike 到達）才運算        │
│  - 閒置時不消耗能量                     │
│  - 天然稀疏                  │
│                                                  │
│  ┌──────────────────────────────────────────┐   │
│  │  Input:  0    0    0    1    0    1    0  │   │
│  │  運算：                                    │   │
│  │          （只在脈衝時觸發）             │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  優點：                                          │
│  - 大幅省電（閒置即節能）                │
│  - 低延遲（事件觸發立即處理）              │
│  - 適合邊緣/嵌入式應用                │
└─────────────────────────────────────────────────┘
```

## 類腦晶片架構

### 硬體設計

```
類腦晶片基本架構：
┌─────────────────────────────────────────────────┐
│  ┌──────────────────────────────────────────┐   │
│  │     核心處理單元（Neuron Cores）        │   │
│  │  ┌──────┐  ┌──────┐  ┌──────┐         │   │
│  │  │NCore0│  │NCore1│  │NCore2│  ...    │   │
│  │  └──┬───┘  └──┬───┘  └──┬───┘         │   │
│  │     └────┬────┘    └────┬────────┐     │   │
│  │          └────── 互連網路 ───────┘      │   │
│  │  ┌──────────────────────────────┐       │   │
│  │  │  突觸記憶體（Synapse SRAM/RRAM）│       │   │
│  │  │  （事件路由 + 突觸權重）       │       │   │
│  │  └──────────────────────────────┘       │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  要點：                                          │
│  - 計算與記憶體結合（突觸就近）            │
│  - 事件路由網路（傳遞 Spikes）            │
│  - 非同步電路（無中央時脈）              │
└─────────────────────────────────────────────────┘
```

### 記憶體整合

```
記憶體與計算整合：
┌─────────────────────────────────────────────────┐
│  傳統：記憶體與處理器分離                        │
│  類腦：突觸權重就近存儲                        │
│                                                  │
│  儲存技術：                                      │
│  ┌──────────────────────────────────────────┐   │
│  │  技術    │  優點              │  缺點    │   │
│  ├──────────────────────────────────────────┤   │
│  │  SRAM   │  快、成熟          │  密度低  │   │
│  │  RRAM   │  密度高、非揮發     │  持久性  │   │
│  │  Memristor│ 可模擬突觸可塑性 │  成熟度  │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  突觸可塑性（STDP）：                            │
│  - 局部學習機制（不需全局誤差反傳）          │
│  - 透過脈衝時序調整權重                  │
│  - 特別適合無監督/線上學習            │
└─────────────────────────────────────────────────┘
```

## 與傳統 AI 晶片的比較

### 優劣勢比較

```
類腦 vs 傳統 AI 晶片比較：
┌─────────────────────────────────────────────────┐
│  特性     │  類腦         │  傳統（GPU/NPU）    │
├─────────────────────────────────────────────────┤
│  計算模式 │  事件/脈衝     │  時脈/矩陣         │
│  精度     │  低（類比）    │  高（數位）        │
│  功耗     │  極低          │  中高             │
│  程式性   │  較難        │  成熟（CUDA 等）    │
│  資料型態 │  稀疏脈衝    │  稠密張量          │
│  成熟度   │  研究/早期     │  商業化           │
│  AI 任務  │  原型任務    │  大規模實務         │
└─────────────────────────────────────────────────┘
```

### 適用場景

```
類腦計算適合場景：
┌─────────────────────────────────────────────────┐

│  3. 線上學習                                  │
│     - STDP 無監督學習                  │
│     - 環境適應性                             │
│                                                  │
│  4. 類腦介面（BCI）                        │
```

## 前沿與挑戰

### 挑戰

```
類腦計算挑戰：
┌─────────────────────────────────────────────────┐
│  1. 精度不足：                                  │

│  2. 程式與工具鏈薄弱：                    │
│     - 缺乏成熟的程式框架                    │
│     - 缺乏標準化工具                        │
│     - 難以與現有深度學習生態整合          │
│                                                  │
│  3. 大規模化困難：                        │
│     - 路由網路的擴展                      │
│     - 晶片間脈衝通訊效率                │
│                                                  │
│  4. 缺乏殺手級應用：                    │
│     - 尚無商業化的重大突破                │
│                                                  │
│  5. 基準測試體系缺乏：                  │
│     - 難與深度學習標準化比較          │
└─────────────────────────────────────────────────┘
```

## 本章小結

- 類腦計算模擬大腦神經元的脈衝（Spike）與事件驅動運算
- 核心是脈衝神經網路（SNN）與突觸可塑性（STDP）
- 事件驅動架構在閒置時幾乎零功耗，極適合邊緣應用
- 代表系統：Intel Loihi、IBM TrueNorth、BrainScaleS 等
- 類腦晶片將計算與記憶體結合（突觸、RRAM）
- 目前仍主要在研究階段，缺乏殺手級應用與標準工具鏈
- 未來可能以「混合架構」或「邊緣超低功耗」切入應用
