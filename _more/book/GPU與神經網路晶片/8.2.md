# 8.2 Interconnect（互連）技術：NVLink、PCIe Gen 5/6 與 CXL 協定

## 互連的基本概念

### 為什麼需要高速互連

```
互連的重要性：
┌─────────────────────────────────────────────────┐
│  單顆晶片的限制：                                │
│  - 運算效能有瓶頸                             │
│  - 記憶體容量有限                             │
│  - 功耗與散熱限制                             │
│                                                  │
│  多晶片協作的優勢：                              │
│  - 運算能力疊加                              │
│  - 記憶體容量擴展                            │
│  - 分散處理                                  │
│                                                  │
│  互連的關鍵指標：                                │
│  1. 頻寬（Bandwidth）                         │
│  2. 延遲（Latency）                           │
│  3. 拓撲（Topology）                          │
│  4. 功耗                                      │
│  5. 可擴展性（Scalability）                  │
└─────────────────────────────────────────────────┘
```

### 互連層級

```
互連層級：
┌─────────────────────────────────────────────────┐
│  1. 晶片內互連（On-Chip）                       │
│     - 匯流排、Mesh 網路                       │
│     - 連接 SM、記憶體控制器                   │
│                                                  │
│  2. 晶片間互連（Chip-to-Chip）                  │
│     - NVLink、UCIe                           │
│     - 連接多個 GPU/加速器                    │
│                                                  │
│  3. 板級互連（Board）                           │
│     - PCIe、CXL                              │
│     - 連接 CPU、GPU、記憶體                  │
│                                                  │
│  4. 系統/機架級互連（System）                  │
│     - 乙太網路、InfiniBand                   │
│     - 連接多台伺服器                        │
└─────────────────────────────────────────────────┘
```

## NVLink 技術

### NVLink 概述

```
NVLink：
┌─────────────────────────────────────────────────┐
│  定義：                                          │
│  NVIDIA 專有的 GPU 間高速互連                    │
│                                                  │
│  用途：                                          │
│  - GPU 到 GPU 的高速通訊                      │
│  - GPU 到 CPU 的高速通訊                      │
│  - 多 GPU 系統的擴展                          │
│                                                  │
│  優勢 vs PCIe：                                  │
│  - 更高頻寬                                     │
│  - 更低延遲                                     │
│  - 支援 GPU 直接記憶體存取（GPU-to-GPU DMA） │
│  - 不需經過 CPU 中介                        │
└─────────────────────────────────────────────────┘
```

### NVLink 世代演進

```
NVLink 世代：
┌─────────────────────────────────────────────────┐
│  世代    │  年份  │  總頻寬（雙向）  │  代表GPU │
├─────────────────────────────────────────────────┤
│  NVLink1 │  2016  │  160 GB/s      │  P100    │
│  NVLink2 │  2017  │  300 GB/s      │  V100    │
│  NVLink3 │  2020  │  600 GB/s      │  A100    │
│  NVLink4 │  2022  │  900 GB/s      │  H100    │
│  NVLink5 │  2024  │  1800 GB/s     │  B200    │
└─────────────────────────────────────────────────┘
```

### NVLink 硬體實作

```
NVLink 硬體結構：
┌─────────────────────────────────────────────────┐
│  NVLink 連結結構：                               │
│  ┌──────────────────────────────────────────┐   │
│  │        GPU 0                  GPU 1     │   │
│  │  ┌────────────┐          ┌────────────┐ │   │
│  │  │ NVLink Port│←────────→│ NVLink Port│ │   │
│  │  │  Link 0-11 │          │  Link 0-11 │ │   │
│  │  └────────────┘          └────────────┘ │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  H100 配置：                                     │
│  - 18 個 NVLink 通道（Lanes）                  │
│  - 每通道：100 GB/s 雙向                       │
│  - 總頻寬：900 GB/s 雙向                       │
│                                                  │
│  信令：                                          │
│  - 使用高速差分序列                    │
│  - 每 Lane 25 Gbps 資料速率                  │
│  - 多 Lane 平行傳輸（Link Aggregation）       │
└─────────────────────────────────────────────────┘
```

### NVSwitch

```
NVSwitch 交換機：
┌─────────────────────────────────────────────────┐
│  功能：                                          │
│  - 全對全（All-to-All）交換                   │
│  - 任意 GPU 之間直接通訊                      │
│                                                  │
│  ┌──────────────────────────────────────────┐   │
│  │                 NVSwitch                 │   │
│  │  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐        │   │
│  │  │GPU0 │ │GPU1 │ │GPU2 │ │GPU3 │        │   │
│  │  └─┬───┘ └─┬───┘ └─┬───┘ └─┬───┘        │   │
│  │    └────────┴───────┴────────┘             │   │
│  │             交換矩陣                      │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  H100 集群：                                     │
│  - DGX H100：8 GPU + 4 NVSwitch               │
│  - 完全連通的 NVLink fabric                   │
│  - 總互連頻寬：7.2 TB/s                       │
└─────────────────────────────────────────────────┘
```

### NVLink vs PCIe

```
NVLink vs PCIe 比較：
┌─────────────────────────────────────────────────┐
│  特性          │   NVLink 4    │   PCIe Gen5    │
├─────────────────────────────────────────────────┤
│  總頻寬（雙向）│  900 GB/s    │  128 GB/s      │
│  延遲          │  低（~0.5-1µs)│  中（~1-2µs）  │
│  功耗/Lane     │  較低         │  較高          │
│  拓撲          │  點對點/交換   │  樹狀/點對點  │
│  GPU 通訊      │  直接         │ 需經 CPU      │
│  使用場景      │  多 GPU 擴展  │  一般 I/O     │
└─────────────────────────────────────────────────┘

NVLink 相比 PCIe 優勢：
- 頻寬高 ~7 倍
- 延遲低
- 支援 GPU 直接通訊，不經 CPU
```

## PCIe 技術

### PCIe 概述

```
PCIe（PCI Express）：
┌─────────────────────────────────────────────────┐
│  定義：                                          │
│  高速序列計算機擴展匯流排標準                  │
│                                                  │
│  用途：                                          │
│  - 連接各種周邊設備（GPU、SSD、網卡）        │
│  - GPU 與 CPU 之間的通訊                      │
│  - 系統內部的主資料傳輸介面                  │
│                                                  │
│  結構：                                          │
│  - 點對點（Point-to-Point）串行連接          │
│  - 多通道（Lanes）組成一個連結               │
│  - 樹狀拓撲                                  │
└─────────────────────────────────────────────────┘
```

### PCIe 世代演進

```
PCIe 世代：
┌─────────────────────────────────────────────────┐
│  世代    │  每 Lane 速率  │  ×16 總頻寬（雙向）│
├─────────────────────────────────────────────────┤
│  Gen 1  │  2.5 GT/s     │  8 GB/s           │
│  Gen 2  │  5.0 GT/s     │  16 GB/s          │
│  Gen 3  │  8.0 GT/s     │  32 GB/s          │
│  Gen 4  │  16 GT/s      │  64 GB/s          │
│  Gen 5  │  32 GT/s      │  128 GB/s         │
│  Gen 6  │  64 GT/s      │  256 GB/s         │
└─────────────────────────────────────────────────┘
```

### PCIe Gen 5/6 特性

```
PCIe Gen 5 特性：
┌─────────────────────────────────────────────────┐
│  - 32 GT/s 每通道                            │
│  - ×16 提供 128 GB/s 雙向                    │
│  - 前向糾錯（FEC）提升可靠性                │
│  - 脈衝幅調變（PAM4）信令                   │
│                                                  │
│  PCIe Gen 6 特性：                              │
│  - 64 GT/s 每通道                            │
│  - ×16 提供 256 GB/s 雙向                    │
│  - 使用 PAM4 信令                            │
│  - 前向糾錯（FEC）                           │
│  - 與原生 Gen 5 相容                         │
└─────────────────────────────────────────────────┘
```

### PCIe 拓撲

```
PCIe 樹狀拓撲：
┌─────────────────────────────────────────────────┐
│              CPU（Root Complex）                 │
│                         │                        │
│             ┌───────────┼───────────┐            │
│             │           │           │            │
│        ┌────┴────┐ ┌───┴───┐ ┌───┴────┐         │
│        │  GPU 0  │ │ SSD   │ │ 網卡   │         │
│        └─────────┘ └───────┘ └────────┘         │
│                                                  │
│  特性：                                          │
│  - 根聯合（Root Complex）管理               │
│  - 逐層擴展（具有 Switch）                  │
│  - 主機為中心                              │
│                                                  │
│  限制：                                          │
│  - GPU 間通訊需經 CPU（除非使用 NVLink）    │
│  - 頻寬共享於同一個根埠                   │
└─────────────────────────────────────────────────┘
```

## CXL 協定

### CXL 概述

```
CXL（Compute Express Link）：
┌─────────────────────────────────────────────────┐
│  定義：                                          │
│  開放標準的高速互連協定                        │
│  基於 PCIe 實體層                            │
│                                                  │
│  目標：                                          │
│  - 解決 AI 時代的記憶體擴展需求              │
│  - 高效能的記憶體共享                        │
│  - 異質計算的統一編程模型                    │
│                                                  │
│  CXL 的三大協定：                               │
│  1. CXL.io（I/O 協定）                        │
│  2. CXL.cache（快取協定）                     │
│  3. CXL.mem（記憶體協定）                     │
└─────────────────────────────────────────────────┘
```

### CXL 類型

```
CXL 設備類型：
┌─────────────────────────────────────────────────┐
│  類型    │  支援協定          │  用途            │
├─────────────────────────────────────────────────┤
│  Type 1  │  CXL.io + CXL.cache│  智慧型網卡     │
│  Type 2  │  CXL.io+CXL.cache  │  GPU、加速器    │
│          │  +CXL.mem          │  （可存取宿主） │
│  Type 3  │  CXL.io + CXL.mem  │  記憶體擴展     │
│          │                    │  （CXL-DRAM）  │
└─────────────────────────────────────────────────┘
```

### CXL.mem 記憶體擴展

```
CXL 記憶體擴展：
┌─────────────────────────────────────────────────┐
│  CXL Type 3 設備：                               │
│                                                  │
│  ┌──────────────────────────────────────────┐   │
│  │              CPU（主機）                │   │
│  │   ┌────────────────────────────────┐    │   │
│  │   │   主記憶體（DDR5）             │    │   │
│  │   └────────────────────────────────┘    │   │
│  └─────────────────────┬────────────────────┘   │
│                        │ CXL                    │
│  ┌─────────────────────┴────────────────────┐   │
│  │              CXL 記憶體擴展              │   │
│  │      （CXL-DRAM 控制器）                │   │
│  │   ┌────────────────────────────────┐    │   │
│  │   │   擴展記憶體（DDR/CXL DRAM）   │    │   │
│  │   └────────────────────────────────┘    │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  應用：                                          │
│  - AI 工作負載的記憶體擴充                    │
│  - 記憶體池化                                  │
│  - 系統間記憶體共享                          │
└─────────────────────────────────────────────────┘
```

### CXL 優勢

```
CXL 的優勢：
┌─────────────────────────────────────────────────┐
│  1. 記憶體擴展                                  │
│     - 突破單一 CPU 的記憶體限制               │
│     - 支援大型模型                            │
│                                                  │
│  2. 記憶體池化                                  │
│     - 多節點共享記憶體資源                    │
│     - 動態分配給不同工作負載                  │
│                                                  │
│  3. 低延遲                                      │
│     - 與主記憶體延遲接近                      │
│     - 優於網路儲存                            │
│                                                  │
│  4. 統一編程模型                                │
│     - 對程式透明                              │
│     - 記憶體一致性                            │
└─────────────────────────────────────────────────┘
```

## 本章小結

- NVLink 是 NVIDIA 專有 GPU 間高速互連，頻寬遠高於 PCIe
- PCIe 是通用 I/O 標準，Gen5/6 持續提升頻寬
- CXL 提供低延遲記憶體擴展與共享功能
- NVSwitch 實現多 GPU 完全互連
- 不同互連技術適用於不同層級與場景
- 互連已成為 AI 系統效能的重要瓶頸與突破點
