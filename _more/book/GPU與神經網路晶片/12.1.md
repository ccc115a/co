# 12.1 光學計算與光子 AI 晶片（Optical/Photonic Computing）

## 光子計算簡介

### 為何需要光學計算

```
電子計算的瓶頸：
┌─────────────────────────────────────────────────┐
│  1. 摩爾定律放緩                              │
│     - 電晶體縮小的物理極限                    │
│     - 漏電流與熱問題                          │
│                                                  │
│  2. 功耗問題                                  │
│     - 數據傳輸與計算的耗能大                │
│     - 大量運算單元帶動散熱成本            │
│                                                  │
│  3. 頻寬瓶頸                                │
│     - 電子互連的頻寬受限                    │
│     - 銅導線的傳輸距離受限                │
│                                                  │
│  光子計算的動機：                                │
│  - 光傳輸不產生電阻熱                      │
│  - 光可平行傳輸多個波長                  │
│  - 光的速度（傳播）不受電阻限制          │
└─────────────────────────────────────────────────┘
```

### 光子計算基本原理

```
光子矩陣運算：
┌─────────────────────────────────────────────────┐
│  核心：以光代替電子進行矩陣乘法        │
│                                                  │
│  ┌──────────────────────────────────────────┐   │
│  │  光學向量-矩陣乘法（Optical VMM）：    │   │
│  │                                          │   │
│  │  輸入向量 x → 光訊號（多色或多通道）    │   │
│  │              ↓                          │   │
│  │  加權矩陣 W → 光學元件（相位/強度調變）    │   │
│  │              ↓                          │   │
│  │  輸出向量 y = Wx → 光偵測器            │   │
│  │                                          │   │
│  │  透過「光干涉」、「光散射」等方式       │   │
│  │  一次完成整個矩陣乘法                  │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  優勢：                                          │
│  - 矩陣乘法以「光速」進行（非零延遲極小）        │
│  - 平行性高（不同波長同時運算）                │
│  - 功耗遠低於電子（無充放電）                  │
└─────────────────────────────────────────────────┘
```

## 光子計算的技術路線

### 干涉型（Interferometric）

```
干涉型光子計算（MZI 網路）：
┌─────────────────────────────────────────────────┐
│  Mach-Zehnder Interferometer（MZI）：           │
│  ┌──────────────────────────────────────────┐   │
│  │  輸入光 → [分束器] → II → [MZI] → 輸出   │   │
│  │              │      │                    │   │
│  │              └──────┘                    │   │
│  │  透過相位調控，實現 2×2 複數矩陣       │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  大矩陣網路：                                    │
│  - 多層 MZI 串聯成網格（Mesh）            │
│  - 可實現任意 unitary 矩陣               │
│  - 例如三角陣列（三角形 MZI 結構）        │
│                                                  │
│  代表：                                          │
│  - MIT/Google（Lightmatter、Luxtera）           │
│  - 透過「分解」任意矩陣為 MZI 網格          │
│                                                  │
│  優勢：                                          │
│  - 精確可重構的矩陣                  │
│  - 支援任意權重（透過相位）              │
│  劣勢：                                          │
│  - 規模上限受限（晶片大小）              │
│  - 波長穩定與熱漂移問題：                  │
│  - 相位誤差與耦合效率          │
└─────────────────────────────────────────────────┘
```

### 散射型（Scattering）

```
散射型光子計算（散射介質）：
┌─────────────────────────────────────────────────┐
│  散射介質計算：                                  │
│  ┌──────────────────────────────────────────┐   │
│  │  輸入光 → 散射介質 → 輸出光                │   │
│  │           （隨機散射/多路徑）             │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  特點：                                          │
│  - 利用光在介質中多重散射形成映射        │
│  - 透過調整介質參數「訓練」矩陣            │
│                                                  │
│  代表：                                          │
│  - 隨機散射計算（Random Scattering）            │
│  - 光學「隨機投影」        │
│                                                  │
│  劣勢：                                          │
│  - 精度較低                              │
│  - 難以精確控制權重                  │
│  - 主要用於低精度/隨機構造            │
└─────────────────────────────────────────────────┘
```

### 共振型（Resonant）

```
共振型光子計算（MRR 網路）：
┌─────────────────────────────────────────────────┐
│  Microring Resonator（MRR）：                   │
│  ┌──────────────────────────────────────────┐   │
│  │  輸入光 → [MRR] → 輸出光（透過共振調控） │   │
│  │                                          │   │
│  │  MRR 對特定波長產生共振                  │   │
│  │  調控共振強度 = 調整權重                  │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  特點：                                          │
│  - 波長分波多工（WDM）平行運算          │
│  - 每個環對應一個權重                  │
│  - 晶片尺寸緊湊                          │
│                                                  │
│  劣勢：                                          │
│  - 熱敏感度高                        │
│  - 誤差較大、穩定性要求高              │
└─────────────────────────────────────────────────┘
```

## 光電混合架構

### 光電混合系統

```
光電子混合架構：
┌─────────────────────────────────────────────────┐
│  全光子計算仍有挑戰：                            │
│  - 非線性是光子的弱項（Activation 難實現）     │
│  - 記憶體仍用電子（RRAM、SRAM 等）            │
│                                                  │
│  實際路線：光電混合                                │
│  ┌──────────────────────────────────────────┐   │
│  │  電子部分：                              │   │
│  │  - 數位邏輯（控制、Activation）         │   │
│  │  - 記憶體（權重、中間結果）             │   │
│  │  - 類比數位轉換器（ADC/DAC）            │   │
│  │                                          │   │
│  │  光子部分：                              │   │
│  │  - 矩陣乘法（線性運算）                  │   │
│  │  - 高速資料傳輸（光互連）                │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  分工：                                          │
│  - 線性運算（GEMM）給光                     │
│  - 非線性運算（ReLU 等）給電               │
│  - 中間資料透過 ADC/DAC 轉換            │
└─────────────────────────────────────────────────┘
```

### 光互連（Photonic Interconnect）

```
光互連技術：
┌─────────────────────────────────────────────────┐
│  光互連是較成熟的應用：                          │
│  - 資料中心使用光纖互連                      │
│  - 晶片間傳輸用矽光子                      │
│  - GPU 叢集、AI 伺服器大量導入            │
│                                                  │
│  優勢：                                          │
│  - 高速（100G/400G 甚至更高）               │
│  - 低延遲                              │
│  - 低功耗（比電子傳輸更省）                │
│  - 長距離（幾公里）                        │
│                                                  │
│  代表：                                          │
│  - NVLink 光互連（NVIDIA）                   │
│  - 矽光互連在 GPU 叢集中的應用          │
│  - Optical Switch（光交換機）              │
└─────────────────────────────────────────────────┘
```

## 光子 AI 晶片的挑戰

### 技術挑戰

```
光子計算瓶頸：
┌─────────────────────────────────────────────────┐
│  1. 精度問題                                  │
│     - 光學類比計算的誤差較大              │
│     - 難以達到數位計算的精度              │
│     - 需要校準與重構                      │
│                                                  │
│  2. 非線性難題                                │
│     - Activation（ReLU、sigmoid）難用光實現│
│     - 光是非線性的（吸收、增益）有限  │
│     - 需要光電轉換                        │
│                                                  │
│  3. 熱穩定性                                │
│     - 光子元件對溫度敏感                  │
│     - 需要溫度控制                         │
│     - 影響精度與穩定性                  │
│                                                  │
│  4. 製造與整合                              │
│     - 矽光子製程成熟度不足                │
│     - 與電子製程整合困難                  │
│     - 成本仍高                            │
│                                                  │
│  5. 設計工具缺乏                              │
│     - 光子 EDA 工具不成熟                │
│     - 設計流程複雜                        │
└─────────────────────────────────────────────────┘
```

## 光子計算的未來

### 與 AI 的結合

```
光子計算 + AI 展望：
┌─────────────────────────────────────────────────┐
│  1. 光學矩陣乘法加速器                          │
│     - 專為 GEMM 設計的光學引擎              │

│  2. 光學互連加速 AI 叢集                │
│     - 多 GPU 高速互連（光）                │
│     - 減少網路延遲與功耗              │
│                                                  │
│  3. 光學記憶體                        │
│     - 光學儲存（光電轉換）              │

│                                                  │
│  結論：                                          │
│  - 光計算短期內不會取代電子                    │
│  - 但會成為互連與特定運算的加速器    │
│  - 結合混合架構最有可能近期實現      │

```

## 本章小結

- 光子計算以光代替電子進行矩陣運算，可大幅降低功耗與延遲
- 技術路線包含干涉型（MZI）、散射型（MRR 等）與共振型
- 光對於矩陣乘法（線性運算）有先天優勢，但非線性運算困難
- 光電混合架構（光互連 + 電子記憶體）是近期務實路線
- 光互連技術已在資料中心與 AI 叢集商業化
- 光子 AI 晶片仍有精度、熱穩定、製造整合等挑戰
- 前瞻：光計算 3-5 年內可能成為 AI 加速的互補技術
