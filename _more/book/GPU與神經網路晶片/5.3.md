# 5.3 控制邏輯、PE（Processing Element）單元與資料對齊（Data Alignment）

## PE 單元深入設計

### PE 資料路徑

```
PE 完整資料路徑：
┌─────────────────────────────────────────────────┐
│              PE 資料路徑                         │
│                                                  │
│  ┌─────────┐      ┌─────────┐                   │
│  │ a_in    │→→→→→ 乘法器  │←←←←←│ b_in      │
│  │ (8/16bit)│      │(MUL)   ││bout│ (8/16bit)│
│  └──┬──────┘      └────┬────┘   └─────────┘   │
│     │a_out              ↓product               │
│     │            ┌─────────┐                   │
│     └→→→→→→→→→→ │ 加法器  │←←┌─────────┐    │
│                   │(ADD)    │  │ acc_in  │    │
│                   └────┬────┘  └─────────┘    │
│                        ↓sum                   │
│                   ┌─────────┐                   │
│                   │暫存器    │→→→ acc_out       │
│                   │(Register)│                  │
│                   └─────────┘                   │
│                                                  │
│  資料寬度：                                      │
│  - 乘法器輸入：WIDTH×WIDTH                     │
│  - 乘法結果：2×WIDTH                            │
│  - 累加器：2×WIDTH（通常）                     │
└─────────────────────────────────────────────────┘
```

### PE 設計考慮

```
PE 設計關鍵因素：
┌─────────────────────────────────────────────────┐
│  1. 資料寬度選擇                                │
│     - WIDTH=8（INT8 專用）                     │
│     - WIDTH=16（FP16/BF16 專用）               │
│     - 可配置（支援多種精度）                    │
│                                                  │
│  2. 累加器寬度                                  │
│     - 需要防止溢位                             │
│     - 通常為輸入的 2 倍                        │
│     - 支援飽和運算                            │
│                                                  │
│  3. 捨入模式                                    │
│     - 定點：截斷或捨入                        │
│     - 浮點：IEEE 754 標準                      │
│                                                  │
│  4. 啟用/停用（Enable）                         │
│     - 支援稀疏運算                            │
│     - 節省動態功耗                            │
└─────────────────────────────────────────────────┘
```

## 資料對齊（Data Alignment）

### 資料對齊的意義

```
資料對齊重要性：
┌─────────────────────────────────────────────────┐
│  1. 記憶體效率                                  │
│     - 對齊可減少記憶體事務                     │
│     - 提升頻寬利用率                           │
│                                                  │
│  2. 死動陣列正確性                              │
│     - 輸入資料必須按時脈對齊                   │
│     - 權重需要正確載入到對應 PE                │
│                                                  │
│  3. 硬體效率                                    │
│     - 對齊避免多次讀取                         │
│     - 減少邏輯資源                             │
└─────────────────────────────────────────────────┘
```

### 對齊規則

```
資料對齊規則：
┌─────────────────────────────────────────────────┐
│  1. 陣列大小對齊                                │
│     輸入矩陣維度必須與死動陣列維度對齊          │
│                                                  │
│  範例：                                          │
│  死動陣列：128×128                              │
│  輸入矩陣：K×K（K 需為 128 的倍數）           │
│                                                  │
│  若 K=200：                                     │
│  - 不足 128 的倍數                              │
│  - 需要 Padding 到 256                         │
│  - 填充 0 值                                    │
│                                                  │
│  2. 資料類型對齊                                │
│     INT8 資料：需 1-byte 對齊                  │
│     FP16 資料：需 2-byte 對齊                  │
│     FP32 資料：需 4-byte 對齊                  │
│                                                  │
│  3. 塊對齊                                     │
│     大矩陣需分割成死動陣列大小的塊               │
│     每塊獨立處理后再合併                        │
└─────────────────────────────────────────────────┘
```

### Padding 策略

```
Padding 範例：
┌─────────────────────────────────────────────────┐
│  原始矩陣（7×7）：                               │
│  ┌───┬───┬───┬───┬───┬───┬───┐                │
│  │a11│a12│a13│a14│a15│a16│a17│                │
│  ├───┼───┼───┼───┼───┼───┼───┤                │
│  │a21│a22│...                                  │
│  └───┴───┴───┴───┴───┴───┴───┘                │
│                                                  │
│  Padding 到 8×8（死動陣列 8×8）：               │
│  ┌───┬───┬───┬───┬───┬───┬───┬───┐             │
│  │a11│a12│a13│a14│a15│a16│a17│ 0 │             │
│  ├───┼───┼───┼───┼───┼───┼───┼───┤             │
│  │a21│a22│...│a27│ 0 │                      │
│  ├───┼───┼───┼───┼───┼───┼───┼───┤             │
│  │...│...│...│...│...│...│...│ 0 │             │
│  ├───┼───┼───┼───┼───┼───┼───┼───┤             │
│  │a71│a72│a73│a74│a75│a76│a77│ 0 │             │
│  ├───┼───┼───┼───┼───┼───┼───┼───┤             │
│  │ 0 │ 0 │ 0 │ 0 │ 0 │ 0 │ 0 │ 0 │             │
│  └───┴───┴───┴───┴───┴───┴───┴───┘             │
│                                                  │
│  填充方式：                                      │
│  - 右邊與底部補 0                                │
│  - 不影響計算結果                                │
│  - 增加少許冗餘                                  │
└─────────────────────────────────────────────────┘
```

## 資料搬運與對齊

### 輸入資料流

```
輸入資料流時序：
┌─────────────────────────────────────────────────┐
│  #    輸入資料注入                              │
│  0    | x[0][0] |                               │
│  1    | x[1][0] | x[0][1] |                     │
│  2    | x[2][0] | x[1][1] | x[0][2] |           │
│  3    | x[3][0] | x[2][1] | x[1][2] | x[0][3] | │
│  ...                                            │
│                                                  │
│  對齊要求：                                      │
│  - 每個時脈注入 N 個資料                        │
│  - 資料需按時脈對齊                             │
│  - 對齊延遲由控制邏輯處理                      │
└─────────────────────────────────────────────────┘
```

### 輸出資料收集

```
輸出資料收集：
┌─────────────────────────────────────────────────┐
│  #    輸出資料收集                              │
│  7    | y[0][0] |                               │
│  8    | y[1][0] | y[0][1] |                     │
│  9    | y[2][0] | y[1][1] | y[0][2] |           │
│  10   | y[3][0] | y[2][1] | y[1][2] | y[0][3] | │
│  ...                                            │
│                                                  │
│  收集方式：                                      │
│  - 先收集到暫存區                              │
│  - 對齊後再搬到記憶體                          │
│  - 控制邏輯管理時序                            │
└─────────────────────────────────────────────────┘
```

## 硬體實作考量

### Pipeline 設計

```
PE Pipeline 階段：
┌─────────────────────────────────────────────────┐
│  階段 0：暫存器（輸入）                         │
│  階段 1：乘法（MUL）                            │
│  階段 2：加法（ADD）                            │
│  階段 3：暫存器（輸出）                         │
│                                                  │
│  每階段用 1 個時脈週期                          │
│  總延遲：4 個時脈週期（初填）                  │
│  之後每週期輸出一個結果                        │
└─────────────────────────────────────────────────┘
```

### 時序圖

```
死動陣列時序圖：
┌─────────────────────────────────────────────────┐
│  時脈   │  PE動作                               │

```

## 稀疏性與對齊

### 稀疏資料處理

```
稀疏資料對齊：
┌─────────────────────────────────────────────────┐
│  稀疏矩陣：                                      │
│  ┌───┬─┬───┬─┬───┬─┬                            │
│  │1.0│0│0.5│0│0.25│0│...                         │
│  └───┴─┴───┴─┴───┴─┴                            │
│                                                  │
│  問題：                                          │
│  - 零值佔用 PE 資源                            │
│  - 浪費運算面積                                │
│                                                  │
│  解法：                                          │
│  - 壓縮稀疏行（CSR）重新排列                   │
│  - 使用遮罩跳過零值                            │
│  - 加入元資料標記                              │
│                                                  │
│  對齊影響：                                      │
│  - 稀疏資料需要特殊對齊                        │
│  - 控制邏輯需處理變長資料                      │
└─────────────────────────────────────────────────┘
```

## 本章小結

- PE 是死動陣列的基本運算單元，包含乘法、加法、累加器
- 控制邏輯負責指令解碼、資料流控制、時序管理
- 資料對齊是死動陣列正確運作的關鍵
- Padding 用於將矩陣對齊到死動陣列大小
- Pipeline 設計影響資料吞吐量
- 稀疏資料需要特殊處理策略
