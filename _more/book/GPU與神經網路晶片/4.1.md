# 4.1 CUDA 核心概念：Grids, Blocks, Threads 與記憶體映射

## CUDA 程式模型概述

CUDA（Compute Unified Device Architecture）是 NVIDIA 的平行運算平台與程式模型，允許開發者利用 GPU 進行通用運算。

### CUDA 執行模型

```
CUDA 執行層級：
┌─────────────────────────────────────────────────┐
│                  Grid（網格）                    │
│  ┌─────────────────────────────────────────────┐│
│  │           Block (0,0)                        ││
│  │  ┌─────┬─────┬─────┬─────┐                 ││
│  │  │ T0  │ T1  │ T2  │ T3  │                 ││
│  │  ├─────┼─────┼─────┼─────┤                 ││
│  │  │ T4  │ T5  │ T6  │ T7  │                 ││
│  │  └─────┴─────┴─────┴─────┘                 ││
│  └─────────────────────────────────────────────┘│
│  ┌─────────────────────────────────────────────┐│
│  │           Block (1,0)                        ││
│  │  ┌─────┬─────┬─────┬─────┐                 ││
│  │  │ T0  │ T1  │ T2  │ T3  │                 ││
│  │  ├─────┼─────┼─────┼─────┤                 ││
│  │  │ T4  │ T5  │ T6  │ T7  │                 ││
│  │  └─────┴─────┴─────┴─────┘                 ││
│  └─────────────────────────────────────────────┘│
│  ┌─────────────────────────────────────────────┐│
│  │           Block (0,1) ...                   ││
│  └─────────────────────────────────────────────┘│
└─────────────────────────────────────────────────┘

Grid：由多個 Block 組成的執行群組
Block：由多個 Thread 組成的工作單元
Thread：最小的執行單位
```

## Thread 索引系統

### 內建變數

```
CUDA 內建變數：

│     - threadIdx.z：Z 維度                       │
│                                                  │
│  2. blockIdx（區塊索引）                        │

│     - blockIdx.y：Y 維度                       │
│     - blockIdx.z：Z 維度                       │
│                                                  │
│  3. blockDim（區塊維度）                        │
│     - blockDim.x：X 維度大小                   │

│     - blockDim.z：Z 維度大小                   │
│                                                  │

│     - gridDim.z：Z 維度大小                    │
```

### 全域執行緒索引計算

```
全域執行緒索引：
┌─────────────────────────────────────────────────┐
│  1D 配置：                                      │
│  tid = blockIdx.x * blockDim.x + threadIdx.x   │
│                                                  │
│  2D 配置：                                      │
│  tid_x = blockIdx.x * blockDim.x + threadIdx.x │
│  tid_y = blockIdx.y * blockDim.y + threadIdx.y │
│  tid = tid_y * gridDim.x * blockDim.x + tid_x  │
│                                                  │
│  3D 配置：                                      │
│  tid_x = blockIdx.x * blockDim.x + threadIdx.x │
│  tid_y = blockIdx.y * blockDim.y + threadIdx.y │
│  tid_z = blockIdx.z * blockDim.z + threadIdx.z │
│  tid = (tid_z * gridDim.y * blockDim.y +       │
│         tid_y) * gridDim.x * blockDim.x +      │
│         tid_x                                   │
└─────────────────────────────────────────────────┘
```

### 範例：向量加法

```cpp
// 向量加法 CUDA 程式
__global__ void vector_add(float *a, float *b, float *c, int n) {
    int tid = blockIdx.x * blockDim.x + threadIdx.x;
    
    if (tid < n) {
        c[tid] = a[tid] + b[tid];
    }
}

int main() {
    int n = 1024;
    int block_size = 256;
    int grid_size = (n + block_size - 1) / block_size;
    
    // 啟動 kernel
    vector_add<<<grid_size, block_size>>>(d_a, d_b, d_c, n);
    
    return 0;
}
```

```
執行配置：
- Grid Size：4 個 Blocks
- Block Size：256 個 Threads
- 總 Threads：1024 個

索引分佈：
Block 0: Thread 0-255 → 處理 a[0]-a[255]
Block 1: Thread 0-255 → 處理 a[256]-a[511]
Block 2: Thread 0-255 → 處理 a[512]-a[767]
Block 3: Thread 0-255 → 處理 a[768]-a[1023]
```

## 資料傳輸

### Host-Device 資料傳輸

```cpp
// 資料傳輸函數
cudaError_t cudaMemcpy(void *dst, const void *src, 
                       size_t count, cudaMemcpyKind kind);

// 方向：
// cudaMemcpyHostToDevice：CPU → GPU
// cudaMemcpyDeviceToHost：GPU → CPU
// cudaMemcpyDeviceToDevice：GPU → GPU
// cudaMemcpyHostToHost：CPU → CPU（不建議）

// 使用範例
float *h_array = new float[1024];  // Host 記憶體
float *d_array;                      // Device 記憶體

cudaMalloc(&d_array, 1024 * sizeof(float));           // 分配
cudaMemcpy(d_array, h_array, 1024 * sizeof(float),    // 複製
           cudaMemcpyHostToDevice);

// 執行 kernel...
cudaMemcpy(h_array, d_array, 1024 * sizeof(float),    // 讀回
           cudaMemcpyDeviceToHost);

cudaFree(d_array);  // 釋放
```

### 統一記憶體（Unified Memory）

```cpp
// 統一記憶體：自動管理 Host-Device 資料同步
float *u_array;

// 分配統一記憶體
cudaMallocManaged(&u_array, 1024 * sizeof(float));

// 初始化（在 CPU 端）
for (int i = 0; i < 1024; i++) {
    u_array[i] = i;
}

// 執行 kernel（自動遷移資料）
kernel<<<grid, block>>>(u_array, 1024);

// 使用結果（自動同步）
cudaDeviceSynchronize();
float sum = u_array[0];

cudaFree(u_array);
```

## Kernel 啟動配置

### 啟動語法

```cpp
// Kernel 啟動語法
kernel<<<gridDim, blockDim, sharedMem, stream>>>(args...);

// 參數說明：
// gridDim：網格維度（Block 數量）
// blockDim：Block 維度（每 Block 的 Thread 數量）
// sharedMem：動態共享記憶體大小（可選，預設 0）
// stream：CUDA Stream（可選，預設 0）
```

### 啟動配置範例

```cpp
// 1D 配置
kernel<<<(N + 255) / 256, 256>>>(args);

// 2D 配置
dim3 block(16, 16);  // 256 threads/block
dim3 grid((width + 15) / 16, (height + 15) / 16);
kernel<<<grid, block>>>(args);

// 3D 配置
dim3 block(8, 8, 8);  // 512 threads/block
dim3 grid((dimX + 7) / 8, (dimY + 7) / 8, (dimZ + 7) / 8);
kernel<<<grid, block>>>(args);
```

### 配置限制

```
CUDA 啟動限制：
┌─────────────────────────────────────────────────┐
│  1. 每 Block Thread 數                          │
│     - 最大：1024                               │
│     - 建議：256 或 512                         │
│     - 必須為 32 的倍數（Warp 對齊）           │
│                                                  │
│  2. 每 Grid Block 數                            │
│     - X 維度最大：2³¹ - 1                      │
│     - Y, Z 維度最大：65535                     │
│                                                  │
│  3. 每 SM Block 數                              │
│     - 最多 32 個 Blocks                        │
│     - 受資源限制（暫存器、共享記憶體）         │
│                                                  │
│  4. 每 SM Thread 數                             │
│     - 最多 2048 個 Threads                     │
│     - H100：最多 1536 個（48 warps）           │
└─────────────────────────────────────────────────┘
```

## 記憶體存取模式

### 全域記憶體存取

```cpp
// 全域記憶體存取
__global__ void global_access(float *data, int n) {
    int tid = blockIdx.x * blockDim.x + threadIdx.x;
    
    if (tid < n) {
        // 連續存取模式（良好）
        float value = data[tid];
        
        // 跨步存取模式（不佳）
        // float value = data[tid * stride];
    }
}
```

### 共享記憶體存取

```cpp
// 共享記憶體使用
__global__ void shared_memory_example(float *input, float *output) {
    __shared__ float s_data[256];
    
    int tid = threadIdx.x;
    int gid = blockIdx.x * blockDim.x + threadIdx.x;
    
    // 從全域記憶體載入到共享記憶體
    s_data[tid] = input[gid];
    __syncthreads();  // 確保所有執行緒完成載入
    
    // 在共享記憶體中進行運算
    // （避免 Bank Conflict）
    float value = s_data[tid];
    
    // 寫回全域記憶體
    output[gid] = value;
}
```

### 常數記憶體存取

```cpp
// 常數記憶體
__constant__ float c_coefficients[256];

__global__ void constant_access(float *data, int n) {
    int tid = blockIdx.x * blockDim.x + threadIdx.x;
    
    if (tid < n) {
        // 從常數記憶體讀取（有快取）
        float coeff = c_coefficients[tid % 256];
        data[tid] *= coeff;
    }
}

// 主機端設定常數記憶體
void setup_constants() {
    float h_coeff[256];
    // 初始化 h_coeff...
    cudaMemcpyToSymbol(c_coefficients, h_coeff, 256 * sizeof(float));
}
```

## 同步操作

### Block 內同步

```cpp
// __syncthreads()：Block 內執行緒同步
__global__ void block_sync_example(float *data) {
    __shared__ float s_data[256];
    
    int tid = threadIdx.x;
    
    // 步驟 1：所有執行緒載入資料
    s_data[tid] = data[tid];
    __syncthreads();  // 等待所有執行緒完成
    
    // 步驟 2：所有執行緒使用已載入的資料
    float sum = s_data[tid] + s_data[(tid + 1) % 256];
    __syncthreads();  // 確保所有執行緒完成
    
    // 步驟 3：寫回結果
    data[tid] = sum;
}
```

### Grid 級同步

```cpp
// Grid 級同步需要使用不同 kernel 啟動或 Device Synchronization
__global__ void kernel1(float *data) {
    // 步驟 1 的運算...
}

__global__ void kernel2(float *data) {
    // 步驟 2 的運算...
}

// 主機端
kernel1<<<grid, block>>>(data);
cudaDeviceSynchronize();  // 確保 kernel1 完成
kernel2<<<grid, block>>>(data);
cudaDeviceSynchronize();
```

## 本章小結

- CUDA 使用 Grid → Block → Thread 三層執行模型
- 內建變數提供執行緒索引與區塊資訊
- 記憶體空間包括 Global、Constant、Texture、Shared、Local、Registers
- 記憶體存取模式影響效能，應避免 Bank Conflict 與跨步存取
- 同步操作透過 __syncthreads() 實現 Block 內同步
