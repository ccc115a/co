## 前言

上一節，我們學會讓 Hack 在螢幕上畫圖——但那是像素的世界。人類要讀的是**文字**。想像你在玩一個數獨遊戲：畫格線很簡單（`drawLine` 就能畫），但「把數字 5 寫進格子裡」就麻煩了——除非有文字引擎。

同樣地，讓使用者輸入也不是硬體直接給的。Hack 的鍵盤是**記憶體映射**的：某個位址存著「剛剛按下的鍵的掃描碼」，掃描碼是數字（如 `97` 表示 `a`），不是「字元」本身。我們需要 `Output`（把文字畫上螢幕）與 `Keyboard`（把鍵盤掃描碼讀成可用的字元/字串/整數）這兩個類別。

本節我們做兩件事：

1. **`Output`**：管理一個「文字游標」，把字元（透過字型表）逐字畫到螢幕上，處理換行、捲動。
2. **`Keyboard`**：讀取鍵盤狀態，把掃描碼映射成字元，並提供 `readChar` / `readLine` / `readInt` 等高階輸入。

兩者搭配，電腦終於能「說人話、聽人話」。

## 1. Output 類別的 API

`Output` 提供的類別方法：

| 方法 | 簽名 | 功能說明 |
|------|------|----------|
| `init` | `Output.init()` | 初始化文字輸出位置到左上角 |
| `moveCursor` | `Output.moveCursor(int row, int column)` | 把游標移到第 `row` 列、第 `column` 欄 |
| `printChar` | `Output.printChar(char c)` | 在游標位置打印字元 `c`，並前進游標 |
| `printString` | `Output.printString(String s)` | 依序打印字串 `s` 的每個字元 |
| `printInt` | `Output.printInt(int i)` | 打印整數 `i` 的十進位表示 |
| `println` | `Output.println()` | 換行（新行） |
| `backSpace` | `Output.backSpace()` | 後退一格（擦掉一個字元） |

螢幕是 256 列 × 512 欄像素；若每個字元佔 **8 像素寬 × 11 像素高**，則可以容納的「字元格」是：

- 水平：`512 / 8 = 64` 個欄位（columns，0..63）
- 垂直：`256 / 11 = 23` 個列（rows，0..22）

所以 `moveCursor(row, column)` 的 `row` 在 0..22、`column` 在 0..63。

## 2. 字型表：每個字元 11 行 × 8 位元

### 2.1 什麼是字型表

為了把字元 `A` 畫上螢幕，我們需要知道「`A` 長什麼樣」。這就是**字型表（font map）** 的用途：一張「字元 → 位元圖」的對照表。

每個字元在螢幕上佔 **8 像素寬 × 11 像素高**。Nand2Tetris 用**每字元 11 個 16 位元字**來表示，但只用到每字元的低 8 位（8 像素寬）。也就是說：

```
字元 'A' 由 11 行組成，每一行是一個 8 位元的 bit-map：
  行 0:  00010000   (最上方一列，只有中間一個點)
  行 1:  00111000
  行 2:  01101100
  ...
  行 10: 00000000
```

### 2.2 位元圖的意義

每一行的 8 個位元（bit 0..bit 7）對應該行「左到右」的 8 個像素。位元為 1 → 該像素是前景色（黑），0 → 背景（白）。

Nand2Tetris 的字型表 `Output.font[]` 是一個 `Array`，每個字元佔 11 個連續項目。字元 `c` 的第 `i` 行，就存放在 `Output.font[c * 11 + i]`。

### 2.3 字型表怎麼畫

把字元畫上螢幕的步驟：

1. 取出該字元的 11 行位元圖。
2. 對每一行 `i`（0..10），把它畫到螢幕的 `(row*11 + i)` 那一列像素、`column*8` 那一段 8 像素範圍。
3. 位元 `j` 為 1 → 把該像素畫黑；為 0 → 畫白（或忽略，視背景）。

例如在格子 `(row, column)` 畫 `A` 的第一行：像素 `y = row*11 + 0`，像素 `x0 = column*8` 起，往右最多 8 個像素對應 8 個位元。

> **設計思路**：為什麼 8 像素寬卻用 16 位元存放？因為 Hack 的字是 16 位元，用整個字存一行（只用低 8 位）比「一個位元一個位元擠」更簡單，且 16 位元字剛好對齊記憶體存取。這是以些微空間換取存取簡單的設計。

下面畫「字元的第一個像素列」的示意（`A`，寬 8、高 11）：

```
Column:  0 1 2 3 4 5 6 7
行0:     0 0 0 1 0 0 0 0     → 0x08
行1:     0 0 1 1 1 0 0 0     → 0x1C
行2:     0 1 1 0 1 1 0 0     → 0x36
行3:     1 0 0 0 0 0 1 0     → 0x82
行4:     1 1 1 1 1 1 1 0     → 0xFE   ← 中間橫槓
行5:     1 0 0 0 0 0 1 0     → 0x82
行6:     1 0 0 0 0 0 1 0     → 0x82
行7:     1 0 0 0 0 0 1 0     → 0x82
行8:     1 0 0 0 0 0 1 0     → 0x82
行9:     1 0 0 0 0 0 1 0     → 0x82
行10:    0 0 0 0 0 0 0 0     → 0x00
```

把這 11 個位元組（0x08, 0x1C, 0x36, 0x82, 0xFE, ...）依序放進字型表，就定義了 `A`。

### 2.4 Jack 語言的字元表示

Jack 需要把字元 `'A'` 轉成它的 ASCII 碼 65。Jack 提供內建的字元常數 `'A'`，並用 `String` 類別的操作（`charAt`）取得字元。字元在 Jack 中其實就是 0..127 的整數（ASCII）。

## 3. 把字元畫上螢幕：printChar

`printChar` 是 Output 的核心。它把字元畫在目前游標所在格子，並把游標向右移動一格（或換行）。

```
function void printChar(char c) {
    var int i, j, charAddr, line, x, y;
    var int column, row;

    // 取得目前游標位置（row: 0..22, column: 0..63）
    let row = cursorRow;
    let column = cursorCol;

    // 取得這個字元的字型表起始位址
    let charAddr = font + c * 11;   // 字元 c 的第 0 行

    // 對每一行（垂直）
    let i = 0;
    while (i < 11) {
        let line = Memory.peek(charAddr + i);   // 這行的 16 位元位元圖
        // 畫 8 個像素
        let x = column * 8;
        let y = row * 11 + i;
        let j = 0;
        while (j < 8) {
            // 檢查第 j 個位元（由左到右）
            let bitMask = 1 << (7 - j);   // bit7 = 最左
            if (line & bitMask) {
                do Screen.drawPixel(x + j, y);
            }
            let j = j + 1;
        }
        let i = i + 1;
    }

    // 換行 / 捲動處理
    // 若此格是最後一欄，則換行
    if (column = 63) {
        do println();
    } else {
        // 直接把游標前進一格
        let cursorCol = column + 1;
    }
    return;
}
```

為了效率，真正的 `Output` 不會逐像素呼叫 `drawPixel`，而是直接寫入螢幕記憶體（一次寫一個 16 位元字的前 8 位）。但上述「逐像素」版本清楚地展示了「字元如何變成螢幕上的點」，是理解原理的最好切入點。官方版本會用 `Memory.poke` 直接寫，速度更快。

### 3.1 涵蓋「印出控制字元」

`printChar` 也要處理特殊字元：

- `'\n'`（換行碼 10? 或 `'\n'`）：實際上的換行由 `println()` 處理；若 `printChar` 收到換行符，就呼叫 `println`。
- `'\b'`（倒退碼）：呼叫 `backSpace`。

官方 `Output.printChar` 開頭會判斷：

```
if (c = '\n') { do println(); return; }
if (c = '\b') { do backSpace(); return; }
```

這樣高階的 `printString` 才能處理字串中的換行與倒退。

## 4. printString、printInt、println、backSpace、moveCursor

### 4.1 printString

逐字元呼叫 `printChar`：

```
function void printString(String s) {
    var int i, len, c;
    let len = s.length();
    let i = 0;
    while (i < len) {
        let c = s.charAt(i);
        do printChar(c);
        let i = i + 1;
    }
    return;
}
```

### 4.2 printInt

把整數的十進位數字依序打印。方法是「從最高位到個位」：可以先算出位數，或利用除法逐步取出每一位。

```
function void printInt(int i) {
    var int n, digit, pow, d;

    if (i < 0) {
        do printChar('-');
        let i = -i;
    }
    // 找出最大位數權重：10^k <= i
    let pow = 1;
    let n = i;
    while (n >= 10) {     // 小心：n 可能為負/溢位，見下方說明
        let pow = pow * 10;
        let n = n / 10;
    }
    // 從最高位印到個位
    let n = i;
    while (pow > 0) {
        let digit = n / pow;          // 目前最高位的數字
        do printChar(digit + 48);     // 轉成 ASCII 數字（'0' = 48）
        let n = n - digit * pow;
        let pow = pow / 10;
    }
    return;
}
```

> **設計思路**：`digit + 48` 因為 ASCII 中 `'0'`=48、`'1'`=49、... `'9'`=57，所以「數字 digit」+ 48 就得到對應 ASCII。`printInt` 依賴 `Math` 的除法，再一次說明 OS 類別間的依賴鏈。**注意 16 位元溢位問題**：極大數值的 `pow*10` 可能溢位，實務上需小心，這裡先掌握原理。

### 4.3 println

把游標移到下一列開頭；若已是最後一列（row=22），則**捲動**（把整份文字上移一列，最下面清空）。簡化版：

```
function void println() {
    var int row, col;
    let row = cursorRow;
    let col = cursorCol;
    // 若已在最下一列，捲動螢幕
    if (row < 22) {
        let cursorRow = row + 1;
    } else {
        // 捲動：把第 1..22 列往上移，清空最後一列
        do scrollUp();
        // cursorRow 不變（仍在最後一列，但內容已上移）
    }
    let cursorCol = 0;
    return;
}
```

### 4.4 backSpace

把游標往回一格，並擦掉那個字元：

```
function void backSpace() {
    var int col, row;
    let row = cursorRow;
    let col = cursorCol;
    if (col > 0) {
        // 往回一欄
        let cursorCol = col - 1;
        // 擦掉該字元：把該格子清成空白
        do moveCursor(row, cursorCol);
        do printChar(' ');  // 印空白覆蓋
        do moveCursor(row, cursorCol);
    } else if (row > 0) {
        // 回到上一列最後一欄（簡化：回到上一列行首）
        let cursorRow = row - 1;
        let cursorCol = 63;
    }
    return;
}
```

### 4.5 moveCursor

直接設定游標座標並把游標恆定位置（官方還會在上一個位置畫一個下底線游標）。簡化版只設座標：

```
function void moveCursor(int row, int column) {
    // 範圍限制
    var int r, c;
    let r = row;
    let c = column;
    if (r < 0) { let r = 0; }
    if (r > 22) { let r = 22; }
    if (c < 0) { let c = 0; }
    if (c > 63) { let c = 63; }
    let cursorRow = r;
    let cursorCol = c;
    return;
}
```

## 5. Keyboard 類別的 API

`Keyboard` 提供的類別方法：

| 方法 | 簽名 | 功能說明 |
|------|------|----------|
| `keyPressed` | `Keyboard.keyPressed() → int` | 回傳目前被按下鍵的掃描碼；沒按時回傳 0 |
| `readChar` | `Keyboard.readChar() → char` | 等待使用者按一個鍵，回傳對應字元（並無回顯於螢幕，接受後回傳） |
| `readLine` | `Keyboard.readLine(String message) → String` | 顯示提示字串，讀取一行使用者輸入，回傳該行（最後按 Enter） |
| `readInt` | `Keyboard.readInt(String message) → int` | 顯示提示字串，讀取一行並解析成整數回傳 |

### 5.1 鍵盤掃描碼

Hack 鍵盤是記憶體映射的：位址 `KBD = 24576`。讀 `RAM[24576]` 即得到「目前被按下鍵的掃描碼」。掃描碼對應表（部分）：

| 掃描碼 | 鍵 |
|--------|-----|
| 32 | `space`（空格） |
| 48..57 | `0`..`9` |
| 65..90 | `A`..`Z`（注意是**大寫**） |
| 128..135 | `F1`..`F8` 等 |
| 130,131,132,133 | 方向鍵 |

特別注意：**掃描碼大寫字母 `A`..`Z`，不是小寫**。Hack 鍵盤無論 CapsLock，按 `a` 都會給 `65`（大寫 `A`）。因此 `readChar` 常需要把大寫映射成小寫（若想要小寫的話）。這是掃描碼處理的常見細節。

> **設計思路**：掃描碼與 ASCII 並不完全一致——例如字母是大寫。`Keyboard` 的職責之一就是把「掃描碼」轉成「應用程式想用的字元」。`readChar` 可以做這種映射，或讓應用程式自己決定。

## 6. keyPressed 與 readChar

### 6.1 keyPressed

最底層：讀記憶體映射位址 24576：

```
function int keyPressed() {
    return Memory.peek(24576);
}
```

`Memory.peek(24576)` 回傳目前掃描碼；若無鍵按下則為 0。

### 6.2 readChar

等待按下一個鍵，按住不放直到放開（避免重複），再回傳字元：

```
function char readChar() {
    // 等待按鍵按下
    while (keyPressed() = 0) { }     // 空迴圈：等 keyPressed 非 0

    // 取得掃描碼
    var int c;
    let c = keyPressed();

    // 等待放開（避免重複觸發）
    while (keyPressed() = c) { }

    // 轉成字元（此處保留掃描碼；若要小寫可做映射）
    return c;
}
```

> **設計思路**：上方的「等待放開」很重要——如果不等放開，程式可能把「同一次長按」誤判成多次輸入。這是處理實體鍵盤的「彈跳/重複」問題的樸素解法。

`readChar` 是否需要把回傳的字元**回顯（echo）** 到螢幕？這取決於設計：單鍵回應的遊戲不需要；而要輸入文字時，讀取的過程由 `readLine` 負責把每個字元 echo 並管理倒退。

## 7. readLine：讀取一整行

`readLine(message)` 先印出提示字串，然後逐字元讀取，直到使用者按下 **Enter**（`\n`）。每個字元要回顯並支持倒退（Backspace）。

```
function String readLine(String message) {
    var String line;
    var char c;

    do Output.printString(message);   // 印提示

    let line = String.new(0);         // 產生空字串（見 12.5 節）

    while (true) {
        let c = readChar();

        if (c = '\n') {               // Enter → 結束
            do Output.println();
            return line;
        }
        if (c = '\b') {               // 倒退
            if (line.length() > 0) {
                // 去掉最後一個字元
                let line = eraseLastChar(line);
                do Output.backSpace();
            }
        } else {
            // 一般字元：加到字串，並回顯
            let line = append(line, c);
            do Output.printChar(c);
        }
    }
    return line;
}
```

在 Jack 中操作字串會用到 `String` 的方法（`appendChar`、`eraseLastChar`、`length`），這些在 12.5 節會寫。這裡先看到 `readLine` 的整體流程：**提示 → 逐字讀 → echo → 支援倒退 → Enter 結束**。

## 8. readInt：讀取整數

`readInt` = `readLine` 的結果，再用字串轉整數：

```
function int readInt(String message) {
    var String s;
    var int result, i, len, digit, neg;

    let s = readLine(message);

    let result = 0;
    let neg = false;
    let i = 0;
    let len = s.length();

    if (len > 0) {
        if (s.charAt(0) = '-') {
            let neg = true;
            let i = 1;
        }
        while (i < len) {
            let digit = s.charAt(i) - 48;   // 字元 → 數字
            let result = result * 10 + digit;
            let i = i + 1;
        }
    }
    if (neg) { let result = -result; }
    return result;
}
```

> **設計思路**：`readInt` 把「字串轉整數」（如 `"123"` → 123）自行用累加實作：`result = result*10 + digit`。它依賴 `String.charAt`、`length`。這再度說明：`Keyboard` 依賴 `Output`（印提示）與 `String`（讀字串）。

## 9. 完整的 Output.jack 與 Keyboard.jack

### 9.1 Output.jack 完整版

我把核心方法串起來（省略完整字型表資料，以註解說明）：

```
// Output.jack —— 文字輸出引擎
class Output {

    static Array font;        // 字型表（64 字元 × 每字元 11 行）
    static int cursorRow;     // 0..22
    static int cursorCol;     // 0..63

    // 初始化：清螢幕、游標回左上角、載入字型表
    function void init() {
        var int i;
        let cursorRow = 0;
        let cursorCol = 0;
        // 建構字型表 array（128 字元 × 11 行）
        let font = Array.new(128 * 11);
        // 填入字型位元圖（此處略，實際有 128 字元的完整資料）
        do fillFont();
        do Screen.init();
        return;
    }

    // 設定游標位置
    function void moveCursor(int row, int column) {
        var int r, c;
        let r = row;  let c = column;
        if (r < 0) { let r = 0; }
        if (r > 22) { let r = 22; }
        if (c < 0) { let c = 0; }
        if (c > 63) { let c = 63; }
        let cursorRow = r;
        let cursorCol = c;
        return;
    }

    // 打印一個字元
    function void printChar(char c) {
        var int i, j, line, charBase, y, xMask;

        // 換行與倒退
        if (c = '\n') { do println(); return; }
        if (c = '\b') { do backSpace(); return; }

        // 取出字元位元圖
        let charBase = 0 + c * 11;   // 字元 c 在 font 中的起始
        let i = 0;
        while (i < 11) {
            let line = Memory.peek(font + charBase + i);
            // 畫每一像素列（8 像素寬）
            let y = cursorRow * 11 + i;
            let xMask = 1 << 7;      // 從最左位開始
            let j = 0;
            while (j < 8) {
                if (line & xMask) {
                    do Screen.drawPixel(cursorCol * 8 + j, y);
                }
                let xMask = xMask >> 1;   // 右移（注意：Hack 使用算術右移）
                let j = j + 1;
            }
            let i = i + 1;
        }

        // 前進游標
        if (cursorCol = 63) {
            do println();
        } else {
            let cursorCol = cursorCol + 1;
        }
        return;
    }

    // 打印字串
    function void printString(String s) {
        var int i, n;
        let n = s.length();
        let i = 0;
        while (i < n) {
            do printChar(s.charAt(i));
            let i = i + 1;
        }
        return;
    }

    // 打印整數
    function void printInt(int i) {
        var int n, pow, digit;
        if (i < 0) {
            do printChar('-');
            let i = -i;
        }
        // 求最大位數權重
        let pow = 1;
        let n = i;
        while (n >= 10) {
            let pow = pow * 10;
            let n = n / 10;
        }
        while (pow > 0) {
            let digit = i / pow;
            do printChar(digit + 48);
            let i = i - digit * pow;
            let pow = pow / 10;
        }
        return;
    }

    // 換行（含捲動）
    function void println() {
        if (cursorRow < 22) {
            let cursorRow = cursorRow + 1;
        } else {
            do scrollUp();
        }
        let cursorCol = 0;
        return;
    }

    // 捲動：把游標以上的文字上移一列
    function void scrollUp() {
        var int i, j;
        // 複製每一列到上一列（以像素為單位搬移 11 列）
        // 此處為簡化說明，用「清空最後一列 + 重印」示意
        // 實際官方用記憶體搬移，這裡以最簡方式示意
        let i = 0;
        while (i < 512) {
            let j = 0;
            while (j < 245) {
                do Memory.poke(16384 + (j*512+i)/16, 0);  // 佔位示意
                let j = j + 1;
            }
            let i = i + 1;
        }
        return;
    }

    // 後退一格
    function void backSpace() {
        if (cursorCol > 0) {
            let cursorCol = cursorCol - 1;
        } else if (cursorRow > 0) {
            let cursorRow = cursorRow - 1;
            let cursorCol = 63;
        }
        return;
    }
}
```

> **補充說明**：真正的 `Output.jack` 字型表包含 128 個字元的完整位元圖（那一大段 `do Memory.poke(font+i, ...)` 的初始化）。因篇幅，本書以「載入字型表」佔位，實作時填入每個字元的 11 行資料。`scrollUp` 的實際官方實作會以「整列記憶體搬移」完成，速度遠快於逐像素示範。

### 9.2 Keyboard.jack 完整版

```
// Keyboard.jack —— 鍵盤輸入引擎
class Keyboard {

    // 回傳目前被按下鍵的掃描碼
    function int keyPressed() {
        return Memory.peek(24576);
    }

    // 讀取一個字元（等待按下與放開）
    function char readChar() {
        var int c;
        // 等按下
        while (keyPressed() = 0) { }
        let c = keyPressed();
        // 等放開
        while (keyPressed() = c) { }
        // 轉為字元回傳（掃描碼在 ASCII 範圍可直接使用）
        return c;
    }

    // 讀取一行（帶提示）
    function String readLine(String message) {
        var String line;
        var char c;

        do Output.printString(message);

        let line = String.new(0);

        while (true) {
            let c = readChar();
            if (c = '\n') {
                do Output.println();
                return line;
            }
            if (c = '\b') {
                do Output.backSpace();
                if (line.length() > 0) {
                    let line = line.eraseLastChar();
                }
            } else {
                do line.appendChar(c);
                do Output.printChar(c);
            }
        }
        return line;
    }

    // 讀取一個整數（帶提示）
    function int readInt(String message) {
        var String s;
        var int result, i, n, digit;
        var boolean neg;

        let s = readLine(message);
        let neg = false;
        let result = 0;
        let i = 0;
        let n = s.length();

        if (n > 0) {
            if (s.charAt(0) = '-') {
                let neg = true;
                let i = 1;
            }
            while (i < n) {
                let digit = s.charAt(i) - 48;
                let result = result * 10 + digit;
                let i = i + 1;
            }
        }
        if (neg) { let result = -result; }
        return result;
    }
}
```

這裡用到 `String` 的方法：`new`、`length`、`charAt`、`appendChar`、`eraseLastChar`——這些正是 12.5 節 `String.jack` 要實作的。

## 10. 設計思路與實作步驟

### 10.1 實作步驟

1. **先寫 `Output.init`**：建立字型表 array，載入所有字元的位元圖，清螢幕。
2. **再寫 `printChar`**：把字元畫上螢幕（每一行位元圖 → 8 個像素）。這是 Output 重頭戲。
3. **寫 `printString`、`printInt`、`println`、`backSpace`、`moveCursor`**：建構在高階輸出。
4. **寫 `Keyboard.keyPressed`**：讀記憶體映射位址 24576。
5. **寫 `readChar`**：等待按下與放開。
6. **寫 `readLine` / `readInt`**：依賴 `String` 與 `Output`。

## 11. 本章小結

- **`Output`** 提供文字輸出：`printChar`、`printString`、`printInt`、`println`、`moveCursor`、`backSpace`，管理一個「文字游標」（0..22 列 × 0..63 欄）。
- **字型表（font map）** 是「字元 → 位元圖」的對照：每個字元由 11 行 × 8 位元的位元圖表示，因此可容納 64 欄 × 23 列文字。
- `printChar` 把字元的 11 行位元圖逐行畫進螢幕記憶體；`printInt` 用除法逐位拆出十進位數字並加 48 轉 ASCII。
- **`Keyboard`** 讀記憶體映射位址 24576 得到掃描碼；`keyPressed` 回傳目前掃描碼。
- `readChar` 處理「等待按下 / 等待放開」以避免重複觸發；`readLine` 逐字讀取並支援倒退、Enter 結束；`readInt` 把讀到的字串解析成整數。
- 鍵盤掃描碼是**大寫字母**，應用端需自行映射大小寫。
- `Keyboard` 依賴 `Output`（印提示）與 `String`（字串操作），再次體現 OS 類別間緊密的依賴合作。

有了輸出與輸入，Hack 已經能「對話」了。但我們還缺少幾樣「地基」：字串究竟怎麼在記憶體中表示、陣列如何建立、以及這個作業系統**該如何在啟動時把所有類別初始化**。這些正是下一節 `String`、`Array`、`Sys` 要解決的。
