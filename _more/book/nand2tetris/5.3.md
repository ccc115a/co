# 5.3 構建完整電腦：Computer 晶片與執行循環

## 前言

恭喜你！經過前面所有章節的學習與實作，我們已經分別完成了 CPU、記憶體、ROM 等關鍵模組。現在，是時候將這些零件組裝成一台完整的電腦了。`Computer` 晶片是整個 Hack 架構的最高層模組，它將 CPU、記憶體和 ROM 三大元件透過匯流排連接在一起，形成一個可以自我運作的完整系統。這不僅僅是一個晶片——它就是一台電腦。

---

## Computer 晶片的三大組成部分

Computer 晶片由三個核心模組構成：

### 1. ROM32K（唯讀記憶體）

- 容量：32K 個 16-bit 字
- 功能：儲存要執行的程式（機器碼）
- 特性：程式運行期間只能讀取，不能寫入
- 當前指令透過 `instruction` 訊號輸出給 CPU

### 2. CPU（中央處理器）

- 功能：解碼指令、執行運算、控制資料流動
- 輸入：`instruction`（來自 ROM）、`inM`（來自 Memory）、`reset`
- 輸出：`outM`、`writeM`、`addressM`（連接 Memory）、`pc`（連接 ROM）

### 3. Memory（記憶體系統）

- 功能：儲存程式運行時的資料，提供螢幕與鍵盤介面
- 輸入：`in`（來自 CPU 的 outM）、`load`（來自 CPU 的 writeM）、`address`（來自 CPU 的 addressM）
- 輸出：`out`（連接 CPU 的 inM）

---

## 取指-解碼-執行循環（Fetch-Decode-Execute）

這是所有電腦運作的基本節奏，也是理解 Computer 晶片最重要的概念：

### 循環的三個階段

```
┌─────────────────────────────────────────────────────┐
│                    取指（Fetch）                      │
│  ROM 根據 PC 輸出的位址，提供對應位置的指令            │
│  instruction = ROM[PC]                               │
├─────────────────────────────────────────────────────┤
│                    解碼（Decode）                     │
│  CPU 分析指令位元：                                    │
│    - 判斷是 A-指令還是 C-指令                          │
│    - 提取 ALU 控制碼、目標暫存器、跳躍條件              │
├─────────────────────────────────────────────────────┤
│                    執行（Execute）                    │
│  CPU 根據解碼結果：                                    │
│    - 驅動 ALU 執行運算                                │
│    - 將結果寫入目標暫存器或記憶體                       │
│    - 根據條件更新 PC                                   │
└─────────────────────────────────────────────────────┘
         │
         ▼
    回到取指階段（PC 已更新）
```

### 每個時脈週期的動作

在 Hack 電腦中，每個時脈週期（tick）會完成一次完整的循環：

1. **ROM 輸出指令**：ROM 根據 PC 當前值輸出 16-bit 指令
2. **CPU 解碼執行**：CPU 分析指令，產生控制信號，驅動 ALU
3. **記憶體讀寫**：若 C-指令的 d3=1，CPU 將結果寫入 Memory
4. **PC 更新**：CPU 根據跳躍條件決定 PC 是遞增還是跳轉

這個循環以時脈頻率不斷重複，從程式第一條指令一直執行到程式結束或被重設。

---

## rom 輸入即指令匯流排

Computer 晶片有一個特殊的輸入：`rom32k[16]`。這個輸入代表從外部 ROM 載入的指令資料。在實際運作中：

- ROM32K 在時脈邊緣根據 PC 值採樣，輸出對應位置的 16-bit 指令
- 這個指令透過 `instruction` 訊號傳遞給 CPU
- CPU 根據指令內容決定下一步動作

這種設計使得 Computer 晶片可以透過替換 ROM 中的程式來執行不同的任務，而不需要改變硬體結構。

## Computer HDL 實作

以下是完整的 `Computer.hdl` 實作：

```hdl
// Hack 電腦：完整的電腦系統
// 檔案：Computer.hdl

CHIP Computer {
    IN  reset;

    PARTS:

    // ============================================================
    // ROM32K：儲存程式
    // ============================================================
    // ROM 的輸出即為當前指令
    // 位址由 CPU 的 pc 輸出決定
    ROM32K(in=cpu_pc, out=instruction);

    // ============================================================
    // CPU：中央處理器
    // ============================================================
    // CPU 接收：
    //   instruction — 來自 ROM 的當前指令
    //   inM         — 來自 Memory 的資料
    //   reset       — 重設信號
    // CPU 輸出：
    //   outM        — 要寫入 Memory 的資料
    //   writeM      — Memory 寫入使能
    //   addressM    — Memory 位址
    //   pc          — 程式計數器（連回 ROM）
    CPU(
        instruction=instruction,
        inM=memory_out,
        reset=reset,
        outM=cpu_outM,
        writeM=cpu_writeM,
        addressM=cpu_addressM,
        pc=cpu_pc
    );

    // ============================================================
    // Memory：記憶體系統
    // ============================================================
    // Memory 接收：
    //   in      — 來自 CPU 的資料
    //   load    — 寫入使能
    //   address — 存取位址
    // Memory 輸出：
    //   out     — 讀取的資料（連回 CPU 的 inM）
    Memory(
        in=cpu_outM,
        load=cpu_writeM,
        address=cpu_addressM,
        out=memory_out
    );
}
```

### 設計思路與實作步驟

1. **先建立記憶體迴路**：CPU 的 `addressM` 和 `outM` 連接到 Memory，Memory 的 `out` 連回 CPU 的 `inM`
2. **加入程式儲存**：ROM32K 的輸出連接到 CPU 的 `instruction` 輸入
3. **形成完整迴路**：CPU 的 `pc` 連接到 ROM32K 的位址輸入，形成取指迴路
4. **加入重設**：`reset` 訊號連接到 CPU，讓程式可以從位址 0 重新開始

### 時序與執行流程

```
時間軸：
────────────────────────────────────────────────────────

T=0（reset=1）：
  CPU 接收到 reset 信號
  PC 被重設為 0
  ROM 輸出 ROM[0] 的指令
  開始執行程式

T=1（reset=0）：
  CPU 完成第一條指令的解碼執行
  PC 递增（或跳轉）
  ROM 輸出下一個位址的指令

T=2, 3, 4, ...：
  不斷重複 取指→解碼→執行 循環
  直到程式結束或再次 reset
```

### 為什麼這代表「一台電腦」

Computer 晶片之所以代表一台完整的電腦，是因為它具備了計算機的所有本質特徵：

1. **儲存程式（Stored Program）**：程式與資料都儲存在記憶體中，可以被修改
2. **自動執行**：一旦啟動，電腦會自動取指、解碼、執行，不需要人工干預
3. **通用性**：透過改變 ROM 中的程式，同一台硬體可以執行任何任務
4. **輸入輸出**：透過 Memory 的 Screen 和 Keyboard 與外部世界互動
5. **條件控制**：支援條件跳躍，使程式可以做出決策

這正是 John von Neumann 在 1945 年提出的儲存程式電腦概念的完整實現。從 NAND 閘到這裡，我們用了不到十個步驟，就建造出了一台功能完整的電腦——這正是 Nand2Tetris 課程的魅力所在。

- 三大模組透過三組訊號形成迴路：指令迴路（ROM→CPU）、資料迴路（CPU↔Memory）、位址迴路（CPU→ROM/Memory）
- 取指-解碼-執行循環是電腦運作的核心節奏
