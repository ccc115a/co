# 1.2 深度學習運算特徵：矩陣乘法（GEMM）與張量（Tensor）計算

## 深度學習的核心運算

深度學習模型的訓練與推論，本質上是大量數學運算的組合。其中，矩陣乘法（General Matrix Multiply, GEMM）佔據了絕大部分的計算量，是神經網路運算的核心。

### 為什麼矩陣乘法如此重要？

神經網路的基本運算可以表示為：

```
Y = f(WX + b)
```

其中：
- **W**：權重矩陣（Weight Matrix）
- **X**：輸入向量/矩陣（Input）
- **b**：偏置向量（Bias）
- **f**：活化函數（Activation Function）

這個運算的核心是矩陣乘法 **WX**，其計算複雜度為 O(n³)（對於 n×n 矩陣），隨著模型規模增大，計算量呈立方成長。

## 矩陣乘法的運算特性

### 1. 計算密度（Arithmetic Intensity）

GEMM 運算具有極高的計算密度，即每次記憶體存取可執行大量運算：

```
計算密度 = 運算次數 / 記憶體存取次數
```

例如，對於一個 1024×1024 的矩陣乘法：
- 運算次數：2 × 1024³ ≈ 2 GFLOPS
- 記憶體存取：3 × 1024² × 4 bytes ≈ 12 MB（假設 FP32）
- 計算密度：約 166 FLOPS/byte

這種高計算密度的特性，使得 GEMM 運算適合在具有高頻寬記憶體的平行處理器上執行。

### 2. 平行性（Parallelism）

矩陣乘法具有天然的平行性：

```
C[i][j] = Σ(A[i][k] * B[k][j])  // 對於所有 i, j
```

每個輸出元素 C[i][j] 的計算相互獨立，可同時執行。這使得 GEMM 非常適合 SIMD（單指令多資料）或 SIMT（單指令多執行緒）架構。

### 3. 資料重用（Data Reuse）

在矩陣乘法中，輸入矩陣的元素會被多次重用：

- 矩陣 A 的每一行被重用 N 次（N 為矩陣 B 的列數）
- 矩陣 B 的每一列被重用 M 次（M 為矩陣 A 的行數）

這種資料重用特性，可透過快取記憶體（Cache）或暫存器（Register）來減少記憶體存取次數。

## 張量（Tensor）計算

### 張量的基本概念

張量是向量和矩陣的高維推廣：

| 維度 | 名稱 | 範例 |
|------|------|------|
| 0 | 標量（Scalar） | 5.0 |
| 1 | 向量（Vector） | [1, 2, 3] |
| 2 | 矩陣（Matrix） | [[1,2], [3,4]] |
| 3+ | 張量（Tensor） | 3D 數組、4D 數組等 |

### 深度學習中的張量

在深度學習框架（如 TensorFlow、PyTorch）中，資料以張量形式表示：

```
# 影像批次（Batch）
input_tensor.shape = (batch_size, height, width, channels)
                   = (32, 224, 224, 3)  # 例如：32 張 RGB 影像

# 卷積層權重
weight_tensor.shape = (out_channels, in_channels, kernel_h, kernel_w)
                    = (64, 3, 3, 3)  # 例如：64 個 3×3 卷積核

# 全連接層權重
fc_weight.shape = (out_features, in_features)
                = (1024, 512)
```

### 張量運算的類型

1. **逐元素運算（Element-wise）**：加法、乘法、活化函數等
2. **歸約運算（Reduction）**：求和、平均、最大值等
3. **矩陣運算**：矩陣乘法、轉置、逆矩陣等
4. **卷積運算**：2D/3D 卷積、深度可分離卷積等
5. **注意力運算**：自注意力機制中的 Q×K^T 和 Softmax

## GEMM 在神經網路中的應用

### 1. 全連接層（Fully Connected Layer）

```
output = weight @ input + bias
# shape: (out_features, in_features) @ (in_features, batch_size)
```

### 2. 卷積層（Convolutional Layer）

卷積運算可轉換為 GEMM 運算（im2col 轉換）：

```
# 將輸入影像展開為矩陣
input_matrix = im2col(input, kernel_size)

# 執行矩陣乘法
output = weight_matrix @ input_matrix
```

### 3. 注意力機制（Attention Mechanism）

Transformer 中的自注意力運算：

```
# Q, K, V 為查詢、鍵、值矩陣
attention_weights = softmax(Q @ K^T / sqrt(d_k))
output = attention_weights @ V
```

## 硬體優化策略

### 1. 分塊矩陣乘法（Tiled Matrix Multiply）

將大矩陣分割為小區塊，利用暫存器或共享記憶體提升資料重用：

```c
// 分塊矩陣乘法的偽代碼
for (int i = 0; i < N; i += TILE_SIZE) {
    for (int j = 0; j < N; j += TILE_SIZE) {
        for (int k = 0; k < N; k += TILE_SIZE) {
            // 載入區塊到共享記憶體
            // 執行區塊矩陣乘法
            // 結果寫回全域記憶體
        }
    }
}
```

### 2. 混合精度運算

使用低精度格式（如 FP16、BF16、INT8）提升運算吞吐量，同時保持模型精度。

### 3. 稀疏矩陣加速

利用神經網路中的稀疏性（如 ReLU 產生的零值），跳過零值運算以提升效率。

## 本章小結

- 矩陣乘法（GEMM）是深度學習的核心運算，具有高計算密度與平行性
- 張量是深度學習中資料的基本表示形式
- 卷積、全連接、注意力等運算本質上都可轉換為 GEMM
- 硬體設計應針對 GEMM 的特性進行優化（分塊、混合精度、稀疏加速）
