# 2.3 NPU 與 ASIC 的本質：Systolic Array（脈動陣列）與資料流架構

## NPU 與 ASIC 的定義

### NPU（Neural Processing Unit）

NPU 是專門為神經網路運算設計的處理器，優化矩陣乘法、卷積等運算：

```
NPU 設計特點：
┌─────────────────────────────────────────┐
│              NPU 架構                    │
│  ┌─────────────────────────────────────┐│
│  │         控制單元                     ││
│  │    （簡化的指令解碼與調度）          ││
│  └─────────────────────────────────────┘│
│  ┌─────────────────────────────────────┐│
│  │      運算陣列                        ││
│  │    ┌───┬───┬───┬───┐               ││
│  │    │PE │PE │PE │PE │ ← 漣動陣列    ││
│  │    ├───┼───┼───┼───┤               ││
│  │    │PE │PE │PE │PE │               ││
│  │    └───┴───┴───┴───┘               ││
│  └─────────────────────────────────────┘│
│  ┌─────────────────────────────────────┐│
│  │      片上記憶體（SRAM）              ││
│  │    （大容量、高頻寬）                ││
│  └─────────────────────────────────────┘│
└─────────────────────────────────────────┘
```

### ASIC（Application-Specific Integrated Circuit）

ASIC 是針對特定應用設計的客製化積體電路：

| 類型 | 說明 | 範例 |
|------|------|------|
| 全客製 ASIC | 完全針對單一應用設計 | Google TPU |
| 半客製 ASIC | 使用標準單元庫 | 多數 NPU |
| 可重構 ASIC | 結合 ASIC 與 FPGA 特性 | 部分 AI 加速器 |

## Systolic Array（脈動陣列）基礎

### 核心概念

脈動陣列是一種二維陣列處理器，資料在處理元素（PE）間有節奏地流動，如同心臟跳動將血液泵送至全身：

```
脈動陣列運作示意：
      B[0]   B[1]   B[2]   B[3]
        ↓      ↓      ↓      ↓
      ┌────┐ ┌────┐ ┌────┐ ┌────┐
A[0]→ │PE00│→│PE01│→│PE02│→│PE03│→ C[0]
      └────┘ └────┘ └────┘ └────┘
        ↓      ↓      ↓      ↓
      ┌────┐ ┌────┐ ┌────┐ ┌────┐
A[1]→ │PE10│→│PE11│→│PE12│→│PE13│→ C[1]
      └────┘ └────┘ └────┘ └────┘
        ↓      ↓      ↓      ↓
      ┌────┐ ┌────┐ ┌────┐ ┌────┐
A[2]→ │PE20│→│PE21│→│PE22│→│PE23│→ C[2]
      └────┘ └────┘ └────┘ └────┘
        ↓      ↓      ↓      ↓
      A[3]→ ┌────┐ ┌────┐ ┌────┐ ┌────┐
            │PE30│→│PE31│→│PE32│→│PE33│→ C[3]
            └────┘ └────┘ └────┘ └────┘
```

### PE（Processing Element）結構

每個 PE 包含：

```
PE 結構：
┌─────────────────────────────────┐
│              PE                  │
│  ┌─────────────────────────┐   │
│  │      乘法器 (MUL)       │   │
│  └─────────────┬───────────┘   │
│                ↓               │
│  ┌─────────────────────────┐   │
│  │      加法器 (ADD)       │   │
│  └─────────────┬───────────┘   │
│                ↓               │
│  ┌─────────────────────────┐   │
│  │      暫存器 (ACC)       │   │
│  └─────────────────────────┘   │
│                                 │
│  輸入：a, b                     │
│  輸出：a (傳播), b (傳播), c (結果)│
└─────────────────────────────────┘

運算：c = c + a × b
```

## 資料流模式

### 1. Weight-Stationary（權重固定）

權重固定在 PE 中，輸入與部分和在陣列中流動：

```
時間步 1：
┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐
│ W00 │ │ W01 │ │ W02 │ │ W03 │  權重固定
└──┬──┘ └──┬──┘ └──┬──┘ └──┬──┘
   ↓       ↓       ↓       ↓
 X0→┌─────┐┌─────┐┌─────┐┌─────┐
    │ P00 ││ P01 ││ P02 ││ P03 │
    └─────┘└─────┘└─────┘└─────┘

時間步 2：
┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐
│ W00 │ │ W01 │ │ W02 │ │ W03 │  權重仍固定
└──┬──┘ └──┬──┘ └──┬──┘ └──┬──┘
   ↓       ↓       ↓       ↓
 X1→┌─────┐┌─────┐┌─────┐┌─────┐
    │ P10 ││ P11 ││ P12 ││ P13 │
    └─────┘└─────┘└─────┘└─────┘
```

**優點**：最小化資料搬運
**缺點**：需要載入完整權重矩陣

### 2. Output-Stationary（輸出固定）

輸出固定在 PE 中，權重與輸入流動：

```
時間步 1：
    X0→┌─────┐┌─────┐┌─────┐┌─────┐
       │ P00 ││ P01 ││ P02 ││ P03 │→ Y0
       └─────┘└─────┘└─────┘└─────┘
         ↑       ↑       ↑       ↑
       ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐
       │ W00 │ │ W10 │ │ W20 │ │ W30 │  權重流動
       └─────┘ └─────┘ └─────┘ └─────┘

時間步 2：
    X1→┌─────┐┌─────┐┌─────┐┌─────┐
       │ P00 ││ P01 ││ P02 ││ P03 │→ Y0
       └─────┘└─────┘└─────┘└─────┘
         ↑       ↑       ↑       ↑
       ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐
       │ W01 │ │ W11 │ │ W21 │ │ W31 │
       └─────┘ └─────┘ └─────┘ └─────┘
```

**優點**：減少部分和的搬運
**缺點**：輸出需要等待完整計算

### 3. Input-Stationary（輸入固定）

輸入固定在 PE 中，權重與部分和流動：

```
時間步 1：
    W0→┌─────┐
       │ P00 │
       └──┬──┘
          ↓
    X0→┌─────┐┌─────┐┌─────┐┌─────┐
       │ P00 ││ P01 ││ P02 ││ P03 │
       └─────┘└─────┘└─────┘└─────┘
          ↓       ↓       ↓       ↓
       ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐
       │ ACC │ │ ACC │ │ ACC │ │ ACC │  部分和流動
       └─────┘ └─────┘ └─────┘ └─────┘
```

**優點**：適合特定運算模式
**缺點**：控制邏輯較複雜

## 實際案例：Google TPU

### TPU v1 架構

```
TPU v1 架構簡圖：
┌─────────────────────────────────────────────────┐
│                    TPU v1                        │
│  ┌─────────────────────────────────────────────┐│
│  │         256×256 MAC 陣列                    ││
│  │    ┌─────┐ ┌─────┐ ┌─────┐     ┌─────┐    ││
│  │    │ MAC │ │ MAC │ │ MAC │ ... │ MAC │    ││
│  │    └─────┘ └─────┘ └─────┘     └─────┘    ││
│  │         （共 65,536 個 MAC）                ││
│  └─────────────────────────────────────────────┘│
│  ┌─────────────────────────────────────────────┐│
│  │         統一緩衝區（Unified Buffer）        ││
│  │              28 MB SRAM                      ││
│  └─────────────────────────────────────────────┘│
│  ┌─────────────────────────────────────────────┐│
│  │         累加器（Accumulators）               ││
│  │              4 MB                            ││
│  └─────────────────────────────────────────────┘│
│  ┌─────────────────────────────────────────────┐│
│  │         指令解碼器與控制邏輯                  ││
│  └─────────────────────────────────────────────┘│
└─────────────────────────────────────────────────┘
```

### TPU v2/v3 改進

| 特性 | TPU v1 | TPU v2 | TPU v3 |
|------|--------|--------|--------|
| 精度 | INT8 | FP16/BF16 | FP16/BF16 |
| 陣列大小 | 256×256 | 128×128 | 128×128 |
| MAC 數量 | 65,536 | 16,384 | 16,384 |
| 峰值效能 | 92 TOPS | 46 TFLOPS | 123 TFLOPS |
| 記憶體 | 28 MB | 8 GB HBM | 32 GB HBM |
| 散熱 | 風冷 | 液冷 | 液冷 |

### TPU v4/v5 改進

| 特性 | TPU v4 | TPU v5e | TPU v5p |
|------|--------|---------|---------|
| 陣列配置 | 128×128 | 多個小型陣列 | 多個小型陣列 |
| 峰值效能 | 275 TFLOPS | 197 TFLOPS | 459 TFLOPS |
| HBM 容量 | 32 GB | 16 GB | 95 GB |
| HBM 頰寬 | 1.2 TB/s | 800 GB/s | 2.76 TB/s |
| 互連 | ICI | ICI | ICI |

## 資料流架構（Dataflow Architecture）

### 與傳統架構的差異

```
傳統控制流架構（Control Flow）：
┌─────────────────────────────────────────┐
│  控制器 → 指令記憶體 → 指令解碼 → 運算  │
│                                          │
│  特點：指令驅動，順序執行                │
└─────────────────────────────────────────┘

資料流架構（Dataflow）：
┌─────────────────────────────────────────┐
│  資料可用 → 觸發運算 → 產生新資料        │
│                                          │
│  特點：資料驅動，自然平行                │
└─────────────────────────────────────────┘
```

### 資料流圖範例

```
矩陣乘法 C = A × B 的資料流圖：

A[0] ──────────┐
               ↓
            ┌─────┐
B[0] ──────→│ MUL │───→ ┌─────┐
            └─────┘     │ ADD │───→ C[0]
A[1] ──┐                └─────┘
       ↓
    ┌─────┐
B[1] ──→│ MUL │───→ ┌─────┐
        └─────┘     │ ADD │
                    └─────┘
```

## NPU 的優勢

### 1. 能效比（Efficiency）

| 設備 | FP32 | FP16 | INT8 | 功耗 |
|------|------|------|------|------|
| CPU | 1 TFLOPS | 2 TFLOPS | 4 TOPS | 150 W |
| GPU | 20 TFLOPS | 80 TFLOPS | 160 TOPS | 300 W |
| NPU | - | 30 TFLOPS | 100 TOPS | 15 W |

### 2. 延遲（Latency）

NPU 針對特定運算優化，可實現更低的推論延遲：

```
ResNet-50 推論延遲：
- CPU（Intel Xeon）：~50 ms
- GPU（NVIDIA T4）：~5 ms
- NPU（Google Coral）：~2 ms
- 專用 ASIC（Groq）：~0.1 ms
```

### 3. 面積效率

NPU 在相同晶片面積下可提供更高的 AI 運算效能：

```
運算密度（TOPS/mm²）：
- CPU：~0.01 TOPS/mm²
- GPU：~0.1 TOPS/mm²
- NPU：~1-10 TOPS/mm²
- 專用 ASIC：~10-100 TOPS/mm²
```

## 本章小結

- NPU 是專門為神經網路運算設計的處理器
- ASIC 是針對特定應用客製化的積體電路
- 脈動陣列透過 PE 間的資料流動實現高效矩陣運算
- 三種資料流模式：Weight-Stationary、Output-Stationary、Input-Stationary
- Google TPU 是脈動陣列的經典實現
- 資料流架構透過資料驅動實現自然平行
