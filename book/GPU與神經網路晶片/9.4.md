# 9.4 晶圓級晶片（Wafer-Scale Engine）：Cerebras 架構剖析

## 為什麼需要晶圓級晶片

### 傳統晶片的限制

```
傳統晶片問題：
┌─────────────────────────────────────────────────┐
│  1. 光罩限制                                    │
│     - 單次曝光的最大晶片尺寸受限              │
│     - 通常限制在 ~800 mm²（如 H100）          │
│                                                  │
│  2. 互連瓶頸                                    │
│     - 多晶片需透過封裝/網路連接              │
│     - 頻寬受限、延遲增加                    │
│                                                  │
│  3. 記憶體距離                                │
│     - 大型晶片的記憶體需外接                 │
│     - 片上 SRAM 有限                          │
│                                                  │
│  4. 巨大模型的記憶體需求                      │
│     - 百億/千億參數模型                      │
│     - 需要極大的片上儲存                    │
└─────────────────────────────────────────────────┘
```

### 晶圓級晶片的理念

```
晶圓級晶片（Wafer-Scale）：
┌─────────────────────────────────────────────────┐
│  核心理念：                                      │
│  不使用光罩切割，直接利用整片晶圓              │
│                                                  │
│  ┌──────────────────────────────────────────┐   │
│  │        整片 12 吋晶圓                     │   │
│  │  ┌────┬────┬────┬────┬────┬────┐        │   │
│  │  │Core│Core│Core│Core│Core│Core│        │   │
│  │  ├────┼────┼────┼────┼────┼────┤        │   │
│  │  │Core│Core│Core│Core│Core│Core│        │   │
│  │  ├────┼────┼────┼────┼────┼────┤        │   │
│  │  │Core│Core│Core│Core│Core│Core│        │   │
│  │  │... │... │... │... │... │... │        │   │
│  │  └────┴────┴────┴────┴────┴────┘        │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  優勢：                                          │
│  - 極大面積（幾乎整片晶圓）                  │
│  - 片上互連完整（無需外部網路）              │
│  - 巨大的片上 SRAM                            │
└─────────────────────────────────────────────────┘
```

## 製造挑戰

### 良率問題

```
晶圓級製造挑戰：
┌─────────────────────────────────────────────────┐
│  1. 良率問題                                    │
│     - 整片晶圓任何缺陷都影響                    │
│     - 需要冗餘（Redundancy）設計              │
│                                                  │
│  2. 缺陷容忍                                    │
│     - 佈局需繞過缺陷區塊      │
│     - 需設計冗餘核心與互連                  │
│                                                  │
│  3. 測試                                        │
│     - 整片晶圓測試困難                    │
│     - 需特別的測試方法                  │
│                                                  │
│  4. 熱與功耗管理                                │
│     - 整片功耗極高（~100 kW）               │
│     - 需液冷散熱系統                      │
│                                                  │
│  5. 封裝                                        │
│     - 整片晶圓封裝困難                  │
│     - 需特殊封裝方案                    │
└─────────────────────────────────────────────────┘
```

### 冗餘設計

```
冗餘設計策略：
┌─────────────────────────────────────────────────┐
│  冗餘核心：                                      │
│  ┌──────────────────────────────────────────┐   │
│  │  ┌────┐ ┌────┐ ┌────┐ ┌────┐           │   │
│  │  │ C  │ │ C  │ │ C* │ │ C  │ ← 缺陷核心│   │
│  │  └────┘ └────┘ └────┘ └────┘           │   │
│  │   │        │                       │    │   │

│  - 佈局時保留冗餘核心                        │
│  - 測試後停用缺陷核心                        │
│  - 透過互連重路由繞過                      │
│                                                  │
│  效果：                                          │
│  - 提升有效良率                              │
│  - 幾乎整片晶圓可用                        │
└─────────────────────────────────────────────────┘
```

## 本章小結

- 晶圓級晶片利用整片晶圓做單一晶片
- WSE-3 擁有 90 萬核心、44 GB 片上 SRAM
- 網格互連實現核心間高速通訊
- 片上大記憶體讓模型權重常駐片上
- 需要冗餘設計克服良率問題
- 液冷系統應對 ~100 kW 功耗
- 是 AI 晶片的顛覆性架構方向
