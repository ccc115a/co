# 5.1 脈動陣列運作機制：Weight-Stationary vs. Output-Stationary vs. Input-Stationary

## 脈動陣列（Systolic Array）基礎

### 起源與概念

脈動陣列由 H. T. Kung 於 1978 年提出，目的在於透過規則的資料流動，最大化資料重用並減少記憶體存取。

```
脈動陣列核心概念：
┌─────────────────────────────────────────────────┐
│  1. 規則的資料流動                              │
│     - 資料如同心臟跳動般在 PE 間流動           │
│     - 每個時脈週期傳遞資料                     │
│                                                  │
│  2. 資料重用                                   │
│     - 權重或輸入在 PE 間被反覆使用             │
│     - 減少記憶體存取次數                       │
│                                                  │
│  3. 局部性                                     │
│     - PE 只與相鄰 PE 通訊                      │
│     - 避免長距離通訊                           │
└─────────────────────────────────────────────────┘
```

### 基本結構

```
脈動陣列基本結構：
┌─────────────────────────────────────────────────┐
│                                                  │
│     B[0]   B[1]   B[2]   B[3]                   │
│       ↓      ↓      ↓      ↓                    │
│     ┌────┐ ┌────┐ ┌────┐ ┌────┐                 │
│ A[0]→│PE00│→│PE01│→│PE02│→│PE03│→ 輸出         │
│     └────┘ └────┘ └────┘ └────┘                 │
│       ↓      ↓      ↓      ↓                    │
│     ┌────┐ ┌────┐ ┌────┐ ┌────┐                 │
│ A[1]→│PE10│→│PE11│→│PE12│→│PE13│→ 輸出         │
│     └────┘ └────┘ └────┘ └────┘                 │
│       ↓      ↓      ↓      ↓                    │
│     ┌────┐ ┌────┐ ┌────┐ ┌────┐                 │
│ A[2]→│PE20│→│PE21│→│PE22│→│PE23│→ 輸出         │
│     └────┘ └────┘ └────┘ └────┘                 │
│       ↓      ↓      ↓      ↓                    │
│     ┌────┐ ┌────┐ ┌────┐ ┌────┐                 │
│ A[3]→│PE30│→│PE31│→│PE32│→│PE33│→ 輸出         │
│     └────┘ └────┘ └────┘ └────┘                 │
│                                                  │
│  水平方向：權重或部分和流動                     │
│  垂直方向：輸入資料流動                         │
└─────────────────────────────────────────────────┘
```

## PE（Processing Element）結構

### PE 基本功能

```
PE 結構：
┌─────────────────────────────────────────────────┐
│              Processing Element                  │
│  ┌─────────────────────────────────────────────┐│
│  │          乘法器（Multiplier）                ││
│  │    a_in × b_in → product                   ││
│  └────────────────────┬────────────────────────┘│
│                       ↓                        │
│  ┌─────────────────────────────────────────────┐│
│  │          累加器（Accumulator）               ││
│  │    acc + product → new_acc                  ││
│  └────────────────────┬────────────────────────┘│
│                       ↓                        │
│  ┌─────────────────────────────────────────────┐│
│  │          輸出暫存器                          ││
│  └─────────────────────────────────────────────┘│
│                                                  │
│  接口：                                          │
│  - a_in / a_out：輸入資料傳遞                   │
│  - b_in / b_out：權重傳遞                       │
│  - acc_in / acc_out：部分和傳遞                 │
│  - sum_out：最終結果輸出                        │
└─────────────────────────────────────────────────┘
```

### PE 運算

```
PE 單步運算：
C = C + A × B

步驟：
1. 從左方接收 A
2. 從上方接收 B
3. 執行乘法：A × B
4. 加上累加器值：C + A × B
5. 更新累加器
6. 將 A 傳遞到右方（或下方）
7. 將 B 傳遞到下方（或右方）
8. 若是最後一次累加，輸出結果
```

## 三種資料流模式

### 1. Weight-Stationary（權重固定）

```
Weight-Stationary 模式：
┌─────────────────────────────────────────────────┐
│  權重（B）固定在 PE 中                          │
│  輸入（A）與部分和在陣列中流動                  │
│                                                  │
│  初始化：                                        │
│  將權重矩陣載入 PE                             │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐                   │
│  │ W00│ │ W01│ │ W02│ │ W03│  ← 權重固定      │
│  └────┘ └────┘ └────┘ └────┘                   │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐                   │
│  │ W10│ │ W11│ │ W12│ │ W13│                   │
│  └────┘ └────┘ └────┘ └────┘                   │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐                   │
│  │ W20│ │ W21│ │ W22│ │ W23│                   │
│  └────┘ └────┘ └────┘ └────┘                   │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐                   │
│  │ W30│ │ W31│ │ W32│ │ W33│                   │
│  └────┘ └────┘ └────┘ └────┘                   │
│                                                  │
│  執行：                                          │
│  輸入 X 從上方注入，在陣列中流動                │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐                   │
│  ↓ X0  ↓ X1  ↓ X2  ↓ X3                        │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐                   │
│  │PE00│→│PE01│→│PE02│→│PE03│→ C[0]            │
│  └────┘ └────┘ └────┘ └────┘                   │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐                   │
│  │PE10│→│PE11│→│PE12│→│PE13│→ C[1]            │
│  └────┘ └────┘ └────┘ └────┘                   │
│                                                  │
│  特點：                                          │
│  - 權重載入成本高                              │
│  - 適合權重重用率高（如卷積）                   │
│  - 權重不需頻繁更新                           │
└─────────────────────────────────────────────────┘
```

### 2. Output-Stationary（輸出固定）

```
Output-Stationary 模式：
┌─────────────────────────────────────────────────┐
│  輸出（C）固定在 PE 中                          │
│  權重（B）與輸入（A）在陣列中流動              │
│                                                  │
│  執行：                                          │
│  權重從左方流入，輸入從上方流入                │
│                                                  │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐                   │
│  │PE00│ │PE01│ │PE02│ │PE03│  ← 輸出固定      │
│  └┬───┘ └┬───┘ └┬───┘ └┬───┘                  │
│   │   B00  │   B01  │                            │
│   ↓        ↓        ↓                           │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐                   │
│  │PE10│ │PE11│ │PE12│ │PE13│                   │
│  └┬───┘ └┬───┘ └┬───┘ └┬───┘                  │
│   │       │       │       │                     │
│  A0 A1  A2  A3                                  │
│                                                  │
│  特點：                                          │
│  - 輸出無需流動                                │
│  - 適合輸出資料重用                             │
│  - 需要處理部分和的累加                        │
└─────────────────────────────────────────────────┘
```

### 3. Input-Stationary（輸入固定）

```
Input-Stationary 模式：
┌─────────────────────────────────────────────────┐
│  輸入（A）固定在 PE 中                          │
│  權重（B）與部分和（C）在陣列中流動            │
│                                                  │
│  執行：                                          │
│  權重從上方流入，部分和從左方流入              │
│                                                  │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐                   │
│  │PE00│ │PE10│ │PE20│ │PE30│  ← 輸入固定      │
│  └┬───┘ └┬───┘ └┬───┘ └┬───┘                  │
│   │       │       │       │                     │
│  B0     B1     B2     B3                        │
│   │       │       │       │                     │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐                   │
│  │PE01│ │PE11│ │PE21│ │PE31│                   │
│  └┬───┘ └┬───┘ └┬───┘ └┬───┘                  │
│   │       │       │       │                     │
│  B0     B1     B2     B3                        │
│                                                  │
│  特點：                                          │
│  - 輸入無需流動                                │
│  - 適合輸入資料重用                             │
│  - 控制邏輯較複雜                              │
└─────────────────────────────────────────────────┘
```

## 三種模式的比較

### 特性比較表

```
三種模式比較：
┌─────────────────────────────────────────────────┐
│  特性       │  Weight-S │ Output-S │ Input-S  │
├─────────────────────────────────────────────────┤
│  固定資料   │  權重     │  輸出    │  輸入    │
│  移動資料   │  輸入+部分和│ 權重+輸入│ 權重+部分和│
│  權重載入   │  高       │  低      │  中      │
│  輸出搬運   │  中       │  無      │  中      │
│  控制複雜度 │  低       │  中      │  高      │
│  適用場景   │  卷積     │  全連接  │  序列     │
│  資料重用   │  權重重用 │  輸出重用│  輸入重用│
└─────────────────────────────────────────────────┘
```

### 效能分析

```
資料重用分析：
┌─────────────────────────────────────────────────┐
│  假設矩陣乘法：M×N×K（M=N=K=512）             │
│                                                  │
│  1. Weight-Stationary：                         │
│     每個權重重用 N 次                           │
│     記憶體存取 = M×K（載入權重）+ N×K（輸入） │
│     = 262144 + 262144 = 524288 次              │
│                                                  │
│  2. Output-Stationary：                         │
│     每個輸出重用一次                            │
│     = M×K + K×N + M×N = 786432 次              │
│                                                  │
│  3. Input-Stationary：                          │
│     每個輸入重用 N 次                           │
│     = M×N + M×K = 524288 次                    │
└─────────────────────────────────────────────────┘
```

## 脈動陣列實作範例

### RTL 風格的 PE 設計

```
PE 硬體描述（Verilog 風格）：
module PE #(parameter WIDTH = 8)
    (input  wire [WIDTH-1:0] a_in,
     input  wire [WIDTH-1:0] b_in,
     input  wire [2*WIDTH-1:0] acc_in,
     output reg  [WIDTH-1:0] a_out,
     output reg  [WIDTH-1:0] b_out,
     output reg  [2*WIDTH-1:0] acc_out,
     input  wire clk, rst);

    wire [2*WIDTH-1:0] product;
    wire [2*WIDTH-1:0] sum;

    assign product = a_in * b_in;
    assign sum = acc_in + product;

    // 累加與傳遞
    always @(posedge clk) begin
        if (rst) begin
            acc_out <= 0;
        end else begin
            acc_out <= sum;
        end
    end

    // 資料傳遞
    always @(posedge clk) begin
        a_out <= a_in;
        b_out <= b_in;
    end
endmodule
```

### C 語言模擬

```c
// 脈動陣列模擬
#include <stdio.h>
#include <stdlib.h>

void systolic_mm(int A[4][4], int B[4][4], int C[4][4]) {
    // 初始化累加器
    int acc[4][4] = {0};
    
    // 逐時脈週期模擬
    for (int t = 0; t < 7; t++) {
        // Weight-Stationary 模式
        for (int i = 0; i < 4; i++) {
            for (int j = 0; j < 4; j++) {
                int a_val = 0, b_val = 0;
                
                // 注入輸入
                if (t - j >= 0 && t - j < 4 && i < 4) {
                    a_val = A[t-j][i];  // 垂直流動
                }
                if (t - i >= 0 && t - i < 4 && j < 4) {
                    b_val = B[j][t-i];  // 權重固定（載入）
                }
                
                // 累加
                if (t - i - j >= 0 && t - i - j < 4) {
                    acc[i][j] += a_val * (b_val != 0 ? b_val : 
                                          (t - i < 4 ? B[j][t-i] : 0));
                }
            }
        }
    }
    
    // 輸出
    for (int i = 0; i < 4; i++)
        for (int j = 0; j < 4; j++)
            C[i][j] = acc[i][j];
}
```

## 實際晶片實作

### Google TPU v1

```
Google TPU v1 的脈動陣列：
┌─────────────────────────────────────────────────┐
│  TPU v1 使用 Weight-Stationary 模式              │
│  256×256 的 MAC 陣列                            │
│                                                  │
│  權重：                                          │
│  - 預先載入權重到 PE                           │
│  - 等待輸入資料流動                            │
│                                                  │
│  輸入：                                          │
│  - 從 Unified Buffer 載入                       │
│  - 垂直流動                                     │
│                                                  │
│  輸出：                                          │
│  - 部分和水平流向                               │
│  - 最後累加結果寫入累加器                      │
│                                                  │
│  效能：                                          │
│  每次運算：256×256 乘法/時脈                   │
│  以 700 MHz 計算：~92 TOPS（INT8）             │
└─────────────────────────────────────────────────┘
```

## 脈動陣列的優缺點

### 優點

```
脈動陣列優點：
┌─────────────────────────────────────────────────┐
│  1. 高資料重用                                  │
│     - 減少記憶體存取                            │
│     - 提升能效比                                │
│                                                  │
│  2. 規則結構                                    │
│     - 易於 VLSI 實現                           │
│     - 可擴展性高                                │
│                                                  │
│  3. 高運算密度                                  │
│     - 大量乘法單元並行運作                     │
│     - 高 TOPS 效能                              │
│                                                  │
│  4. 局部通訊                                    │
│     - 只與相鄰 PE 通訊                         │
│     - 減少繞線負擔                            │
└─────────────────────────────────────────────────┘
```

### 缺點

```
脈動陣列缺點：
┌─────────────────────────────────────────────────┐
│  1. 硬訊息流動                                  │
│     - 資料必須按時脈節奏移動                   │
│     - 難以處理非規則運算                       │
│                                                  │
│  2. 利用率受限                                  │
│     - 填滿與排空需要額外時間                   │
│     - 小矩陣利用率低                           │
│                                                  │
│  3. 資料對齊要求                                │
│     - 需要精確的資料對齊                       │
│     - 稀疏資料難以處理                         │
│                                                  │
│  4. 靈活性低                                    │
│     - 難以實現複雜的控制流動                   │
│     - 主要是規則運算                           │
└─────────────────────────────────────────────────┘
```

## 本章小結

- 脈動陣列透過規則的資料流動實現高效矩陣運算
- 三種資料流模式各有優缺點，適用於不同場景
- Weight-Stationary 適合權重重用高的運算（如卷積）
- Output-Stationary 適合全連接層
- Input-Stationary 適合序列資料處理
- Google TPU 使用 Weight-Stationary 模式
