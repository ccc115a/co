# 6.2 低精度矩陣乘法硬體設計（ALU 轉型與縮放因子管理）

## 低精度矩陣乘法的動機

### 效能需求

```
低精度矩陣乘法的優勢：
┌─────────────────────────────────────────────────┐
│  1. 運算吞吐量提升                              │
│     FP32 → FP16：效能 ×2                       │
│     FP16 → FP8：效能 ×2                        │
│     FP8 → FP4：效能 ×2                         │
│                                                  │
│  2. 記憶體需求下降                              │
│     FP32 → FP16：記憶體 ÷2                     │
│     FP16 → FP8：記憶體 ÷2                      │
│                                                  │
│  3. 能效比提升                                  │
│     - 相同功耗產出更多運算                      │
│     - 減少晶片面積                             │
│                                                  │
│  4. 頻寬需求下降                                │
│     - 每個元素用更少的位元                     │
│     - 減少記憶體傳輸                           │
└─────────────────────────────────────────────────┘
```

### 硬體設計挑戰

```
硬體設計挑戰：
┌─────────────────────────────────────────────────┐
│  1. 動態範圍管理                                │
│     - 低精度格式範圍有限                       │
│     - 需要縮放來避免溢位                      │
│                                                  │
│  2. 累加器設計                                  │
│     - 輸入精度低，但累加需要高精度             │
│     - 需要保留更多位元來防止溢位              │
│                                                  │
│  3. 控制邏輯                                    │
│     - 需要管理縮放因子                        │
│     - 需要處理格式轉換                        │
│                                                  │
│  4. 精度監控                                  │
│     - 需要偵測精度蒸發                        │
│     - 必要時動態調整                           │
└─────────────────────────────────────────────────┘
```

## ALU 硬體設計

### 低精度乘法器

```
乘法器設計比較：
┌─────────────────────────────────────────────────┐
│  FP32 乘法器：                                  │
│  ┌─────────────────────────────────────────┐   │
│  │  24-bit × 24-bit 整數乘法             │   │
│  │  + 指數加法（8-bit）                  │   │
│  │  + 正規化（Normalization）             │   │
│  │  + 捨入（Rounding）                   │   │
│  │  面積：~5000 µm²                     │   │
│  └─────────────────────────────────────────┘   │
│                                                  │
│  FP16 乘法器：                                  │
│  ┌─────────────────────────────────────────┐   │
│  │  11-bit × 11-bit 整數乘法             │   │
│  │  + 指數加法（5-bit）                  │   │
│  │  面積：~1200 µm²                     │   │
│  │  面積比FP32減少~75%                   │   │
│  └─────────────────────────────────────────┘   │
│                                                  │
│  INT8 乘法器：                                  │
│  ┌─────────────────────────────────────────┐   │
│  │  8-bit × 8-bit 整數乘法               │   │
│  │  無指數處理                            │   │
│  │  面積：~500 µm²                       │   │
│  │  面積比FP32減少~90%                   │   │
│  └─────────────────────────────────────────┘   │
└─────────────────────────────────────────────────┘
```

### 乘法器並行化

```
並行化策略：
┌─────────────────────────────────────────────────┐
│  單一 FP32 乘法器佔用的面積：                   │
│  ┌────────────────────┐                        │
│  │   FP32 MUL        │                        │
│  │   ~5000 µm²       │                        │
│  └────────────────────┘                        │
│                                                  │
│  改為 2 個 FP16 乘法器：                        │
│  ┌───────────┐  ┌───────────┐                  │
│  │ FP16 MUL  │  │ FP16 MUL  │                  │
│  │ ~1200 µm² │  │ ~1200 µm² │                  │
│  └───────────┘  └───────────┘                  │
│  → 總面積：2400 µm²（更少）                    │
│  → 吞吐量：2 倍                                │
│                                                  │
│  改為 4 個 INT8 乘法器：                        │
│  ┌───────┐ ┌───────┐ ┌───────┐ ┌───────┐      │
│  │ INT8  │ │ INT8  │ │ INT8  │ │ INT8  │      │
│  │ 500µm²│ │ 500µm²│ │ 500µm²│ │ 500µm²│      │
│  └───────┘ └───────┘ └───────┘ └───────┘      │
│  → 總面積：2000 µm²                             │
│  → 吞吐量：4 倍                                │
└─────────────────────────────────────────────────┘
```

## 縮放因子（Scale）管理

### 為什麼需要縮放

```
縮放的必要性：
┌─────────────────────────────────────────────────┐
│  FP16 範圍：~6×10^-5 到 65504                  │
│  FP8 E4M3 範圍：~4×10^-2 到 448               │
│  FP4 範圍：有限                                 │
│                                                  │
│  問題：矩陣乘法的中間結果可能超過範圍           │
│                                                  │
│  例如：                                          │
│  輸入：a = 100, b = 5（都在範圍內）            │
│  乘積：a × b = 500                              │
│  - FP8 E4M3：需要縮放                          │
│  - FP16：可表示                                │
│  - 累加多個：更可能溢位                        │
│                                                  │
│  縮放策略：                                      │
│  ab = (a × s_a) × (b × s_b) / (s_a × s_b)    │
└─────────────────────────────────────────────────┘
```

### Block-wise 縮放

```
塊級縮放（Block-wise）：
┌─────────────────────────────────────────────────┐
│  矩陣分塊：                                      │
│  ┌─────────────────────────────────────────┐   │
│  │  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐  │   │
│  │  │ B0   │ │ B1   │ │ B2   │ │ B3   │  │   │
│  │  │s=1.2 │ │s=0.8 │ │s=0.5 │ │s=1.5 │  │   │
│  │  └──────┘ └──────┘ └──────┘ └──────┘  │   │
│  └─────────────────────────────────────────┘   │
│                                                  │
│  每個塊有自己的縮放因子                        │
│  縮放因子儲存在元資料區域                      │
│                                                  │
│  優點：                                          │
│  - 更高的精度（每個塊獨立優化）               │
│  - 適應資料分佈                              │
│                                                  │
│  缺點：                                          │
│  - 元資料開銷                                 │
│  - 需要額外硬體處理                          │
└─────────────────────────────────────────────────┘
```

### 縮放因子硬體實現

```
縮放因子硬體設計：
┌─────────────────────────────────────────────────┐
│  縮放路徑：                                      │
│                                                  │
│  輸入資料 ─→ 縮放單元 ─→ 低精度儲存            │
│                │                                │
│           ┌────┴─────┐                          │
│           │ 縮放因數 │                          │
│           │ 暫存器   │                          │
│           └──────────┘                          │
│                                                  │
│  處理流程：                                      │
│  1. 計算最大值                                  │
│  2. 決定縮放因子                                │
│  3. 乘以縮放因子                                │
│  4. 量化到目標格式                              │
│  5. 儲存縮放因子                                │
│                                                  │
│  運算後：                                        │
│  1. 讀取縮放因子                                │
│  2. 累加結果乘以縮放因子                        │
│  3. 還原原始範圍                                │
└─────────────────────────────────────────────────┘
```

## 累加器設計

### 高低精度累加

```
累加器精度設計：
┌─────────────────────────────────────────────────┐
│  問題：                                          │
│  輸入為 INT8，累加超過 255 會溢位               │
│                                                  │
│  解法：使用高精度累加器                         │
│                                                  │
│  INT8 乘法（8×8=16-bit）                       │
│  ┌────────────┐                                 │
│  │  16-bit 積 │                                │
│  └─────┬──────┘                                 │
│        ↓                                        │
│  ┌────────────┐  ┌────────────┐                 │
│  │  累加器    │  │ 32-bit     │                 │
│  │ +16-bit    │→│ 累加結果   │                 │
│  └────────────┘  └────────────┘                 │
│                                                  │
│  累加器位元數：                                  │
│  - 16 + log2(累加次數)                         │
│  - 累加 256 次：16+8 = 24 位                   │
│  - 累加 65536 次：16+16 = 32 位                │
│  - 通常使用 32-bit 累加器                      │
└─────────────────────────────────────────────────┘
```

### 高精度累加器結構

```
32-bit 累加器設計：
┌─────────────────────────────────────────────────┐
│  32-bit 累加器：                                 │
│  ┌───────────────────────────────────────────┐  │
│  │              Adder (+32)                  │  │
│  │  a_in(32) ─→─⊕←── b_in(32)              │  │
│  │                │                          │  │
│  │                ↓                          │  │
│  │            D 暫存器                       │  │
│  │           (32-bit)                        │  │
│  │                │                          │  │
│  │            acc_out                        │  │
│  └───────────────────────────────────────────┘  │
│                                                  │
│  特性：                                          │
│  - 可累加 2^16 個 16-bit 乘積                  │
│  - 可累加 2^24 個 8-bit 乘積                   │
│  - 支援飽和（Saturate）模式                   │
│  - 支援捨入（Round）模式                      │
└─────────────────────────────────────────────────┘
```

## 格式轉換硬體

### FP32 → FP16 轉換

```
FP32 → FP16 轉換：
┌─────────────────────────────────────────────────┐
│  轉換流程：                                      │
│                                                  │
│  ┌────────────────────────────┐                 │
│  │  FP32 輸入（32-bit）       │                 │
│  └────────────┬───────────────┘                 │
│               ↓                                │
│  ┌────────────────────────────┐                 │
│  │  1. 檢查範圍               │                 │
│  │     - 太大 → 溢位處理      │                 │
│  │     - 太小 → 下溢處理      │                 │
│  └────────────┬───────────────┘                 │
│               ↓                                │
│  ┌────────────────────────────┐                 │
│  │  2. 指數轉換               │                 │
│  │     8-bit → 5-bit          │                 │
│  │     調整偏差（127→15）     │                 │
│  └────────────┬───────────────┘                 │
│               ↓                                │
│  ┌────────────────────────────┐                 │
│  │  3. 尾數轉換               │                 │
│  │     23-bit → 10-bit        │                 │
│  │     執行捨入               │                 │
│  └────────────┬───────────────┘                 │
│               ↓                                │
│  ┌────────────────────────────┐                 │
│  │  FP16 輸出（16-bit）       │                 │
│  └────────────────────────────┘                 │
│                                                  │
│  硬體成本：                                      │
│  - ~300 個邏輯閘                              │
│  - 可並行處理                                  │
└─────────────────────────────────────────────────┘
```

## 混合精度運算硬體

### 混合精度矩陣乘法

```
混合精度矩陣乘法流程：
┌─────────────────────────────────────────────────┐
│  輸入（FP32）                                   │
│     ↓                                           │
│  轉換為 FP16（硬體轉換）                        │
│     ↓                                           │
│  FP16 矩陣乘法（Tensor Core）                  │
│     ↓                                           │
│  FP32 累加（累加器）                            │
│     ↓                                           │
│  輸出（FP32）                                   │
│                                                  │
│  好處：                                          │
│  - 乘法用低精度（快）                          │
│  - 累加用高精度（準確）                        │
│  - 避免精度累積損失                            │
└─────────────────────────────────────────────────┘
```

## 精度監控與動態調整

### 精度監控硬體

```
精度監控機制：
┌─────────────────────────────────────────────────┐
│  監控指標：                                      │
│  1. 最大值偵測                                  │
│     - 追蹤輸入/輸出的最大值                    │
│     - 判斷是否接近溢位                        │
│                                                  │
│  2. 稀疏度偵測                                  │
│     - 計算非零值比例                          │
│     - 判斷是否有太多零值                      │
│                                                  │
│  3. 異常偵測                                    │
│     - 偵測 NaN/Inf 出現                       │
│     - 偵測精度異常蒸發                        │
│                                                  │
│  動態調整策略：                                  │
│  - 若偵測到精度問題：                          │
│    使用更高精度                                │
│  - 若效能允許：                                │
│    使用更低精度                                │
└─────────────────────────────────────────────────┘
```

## 效能與功耗分析

```
低精度硬體效益：
┌─────────────────────────────────────────────────┐
│  運算效能提升：                                  │
│  ┌─────────────────────────────────────────┐   │
│  │  精度  │  乘法器面積  │  吞吐量／面積   │   │
│  ├─────────────────────────────────────────┤   │
│  │  FP32  │  1×          │  1×             │   │
│  │  FP16  │  0.25×       │  4×             │   │
│  │  INT8  │  0.1×        │  10×            │   │
│  │  FP8   │  0.12×       │  8×             │   │
│  └─────────────────────────────────────────┘   │
│                                                  │
│  功耗降低：                                      │
│  - 動態功耗：與電容及切換率成正比              │
│  - 低精度減少位元切換                          │
│  - 整體功耗降低 30-50%                        │
└─────────────────────────────────────────────────┘
```

## 本章小結

- 低精度矩陣乘法透過減少位元提升吞吐量與能效
- 乘法器面積隨精度降低而大幅縮小
- 縮放因子管理是低精度運算的關鍵
- 累加器需要使用高精度防止溢位
- 混合精度可兼顧效能與準確性
- 動態精度監控可在運行時調整
