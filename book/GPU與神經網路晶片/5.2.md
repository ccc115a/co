## TPU v1 詳細分析

### 設計目標與哲學

```
TPU v1 設計目標：
┌─────────────────────────────────────────────────┐
│  使用情境：                                      │
│  - 推論（Inference）專用                       │
│  - 運行已訓練好的模型                          │
│  - 需要低延遲、高吞吐量                        │
│                                                  │
│  設計哲學：                                      │
│  - 犧牲靈活性換取效能                          │
│  - 只支援必要的運算                            │
│  - 簡化控制邏輯                                │
└─────────────────────────────────────────────────┘
```

### TPU v1 微架構

```
TPU v1 微架構：
┌─────────────────────────────────────────────────┐
│              TPU v1 架構                         │
│  ┌─────────────────────────────────────────────┐│
│  │          控制單元                            ││
│  │    （簡化指令集，CISC 風格）                 ││
│  └────────────────────┬────────────────────────┘│
│                       ↓                        │
│  ┌─────────────────────────────────────────────┐│
│  │         死動陣列（Systolic Array）           ││
│  │         256 × 256 = 65,536 MACs            ││
│  │    ┌─────────────┐  ┌─────────────┐        ││
│  │    │ 權重快取     │  │ 中間資料     │        ││
│  │    │ (Weight)     │  │ (Data)       │        ││
│  │    └─────────────┘  └─────────────┘        ││
│  └────────────────────┬────────────────────────┘│
│                       ↓                        │
│  ┌─────────────────────────────────────────────┐│
│  │         累加器（Accumulators）               ││
│  │    ┌─────────────────────────────────────┐  ││
│  │    │ 256 × 256 的累加暫存器              │  ││
│  │    └─────────────────────────────────────┘  ││
│  └────────────────────┬────────────────────────┘│
│                       ↓                        │
│  ┌─────────────────────────────────────────────┐│
│  │         Unified Buffer（28 MB）              ││
│  │    - 儲存輸入與輸出資料                    ││
│  │    - 高頻寬存取                            ││
│  └─────────────────────────────────────────────┘│
│                       ↓                        │
│  ┌─────────────────────────────────────────────┐│
│  │       Activation Unit（活化函數單元）        ││
│  │    - ReLU, Sigmoid                          ││
│  │    - 可在資料流出前處理                    ││
│  └─────────────────────────────────────────────┘│
└─────────────────────────────────────────────────┘
```

### TPU v1 關鍵設計

```
TPU v1 關鍵設計決策：
┌─────────────────────────────────────────────────┐
│  1. 使用 INT8                                  │
│     - 圖8 位元精度足以處理推論                 │
│     - 運算密度提升                             │
│     - 記憶體需求減少                           │
│                                                  │
│  2. 權重回用                                   │
│     - Weight-Stationary 模式                  │
│     - 權重固定於 PE                           │
│     - 輸入資料流動                             │
│                                                  │
│  3. 無指令快取                                 │
│     - 只有少數指令類型                        │
│     - 節省晶片面積                            │
│                                                  │
│  4. 大 Unified Buffer                          │
│     - 28 MB SRAM                               │
│     - 減少 HBM 存取                           │
│     - 高頻寬 (125 GB/s)                       │
└─────────────────────────────────────────────────┘
```

## TPU v2/v3 分析

### TPU v2 改進

```
TPU v2 主要改進：
┌─────────────────────────────────────────────────┐
│  1. 支援訓練                                  │
│     - 需要反向傳播                            │
│     - 更高的精度（FP16/BF16）                 │
│                                                  │
│  2. 死動陣列尺寸減小                           │
│     - 128×128（從 256×256）                   │
│     - 減少面積，提升頻率                     │
│                                                  │
│  3. 加入 HBM                                  │
│     - 8 GB 高頻寬記憶體                       │
│     - 解決記憶體瓶頸                          │
│                                                  │
│  4. 加入互連                                  │
│     - 可擴展到多晶片                          │
│     - 支援大規模模型                          │
└─────────────────────────────────────────────────┘
```

### TPU v2 架構差異

```
TPU v1 vs v2 架構比較：
┌─────────────────────────────────────────────────┐
│           │    TPU v1      │   TPU v2           │
├─────────────────────────────────────────────────┤
│  用途     │    推論       │  訓練+推論        │
│  精度     │    INT8       │  FP16/BF16        │
│  陣列     │    256×256   │  128×128          │
│  MACs     │    65,536    │  16,384           │
│  記憶體   │    28 MB SRAM │  8 GB HBM        │
│  離線記憶體 │    無      │  有               │
│  互連     │    無        │  可擴展           │
│  挑戰     │    無        │  軟體複雜度       │
└─────────────────────────────────────────────────┘
```

### TPU v3 改進

```
TPU v3 主要改進：
┌─────────────────────────────────────────────────┐
│  1. 效能提升                                   │
│     - 從 45 提升至 123 TFLOPS                  │
│     - 傳入脈動陣列的資料頻寬增加              │
│                                                  │
│  2. 記憶體升級                                 │
│     - HBM 從 8 GB 提升至 32 GB                │
│     - 記憶體頰寬從 600 提升至 900 GB/s        │
│                                                  │
│  3. 功耗增加                                   │
│     - 從 280 W 提升至 450 W                    │
│     - 液冷散熱                                │
└─────────────────────────────────────────────────┘
```

## TPU v4 分析

### TPU v4 創新

```
TPU v4 主要創新：
┌─────────────────────────────────────────────────┐
│  1. 光互連（Optical Interconnect）              │
│     - 雷射光連接（Laser-Based）                │
│     - 降低互連功耗                             │
│     - 支援更大規模集群                         │
│                                                  │
│  2. 液冷散熱                                   │
│     - 直接液冷（Direct Liquid Cooling）        │
│     - 提升功率密度                             │
│                                                  │
│  3. 動態切片（Dynamic Slicing）               │
│     - 依負載動態調整資源                      │
│     - 提升利用率                              │
│                                                  │
│  4. 稀疏支援                                   │
│     - 結構化稀疏加速                          │
│     - 提升能效比                              │
└─────────────────────────────────────────────────┘
```

## 本章小結

- Google TPU 從 v1 到 v6 持續演進，從推論專用發展為訓練/推論全能
- 死動陣列是 TPU 的核心計算結構
- 每代 TPU 都針對效能、能效比、記憶體進行優化
- 光互連與液冷是 v4 以後的關鍵技術
- TPU 與 GPU 在設計哲學上有所不同
