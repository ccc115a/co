# 9.3 Chiplet（小晶片）架構與 UCIe 介面標準

## Chiplet 概述

### 什麼是 Chiplet

```
Chiplet 概念：
┌─────────────────────────────────────────────────┐
│  定義：                                          │
│  將大型單晶片分割為多個小晶片（Chiplet）         │
│  透過先進封裝整合成一個系統                      │
│                                                  │
│  ┌──────────────────────────────────────────┐   │
│  │  單一大型晶片（Monolithic）:             │   │
│  │  ┌────────────────────────────────────┐ │   │
│  │  │                                    │ │   │
│  │  │         大型 Die（成本高）         │ │   │
│  │  │                                    │ │   │
│  │  └────────────────────────────────────┘ │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  Chiplet 方案：                                  │
│  ┌──────────────────────────────────────────┐   │
│  │  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐   │   │
│  │  │Die A │ │Die B │ │Die C │ │Die D │   │   │
│  │  │ CPU  │ │ GPU  │ │ I/O  │ │ SRAM │   │   │
│  │  └──┬───┘ └──┬───┘ └──┬───┘ └──┬───┘   │   │
│  │     └────────┴────┬────┴────────┘       │   │
│  │            封裝整合（先進封裝）          │   │
│  └──────────────────────────────────────────┘   │
└─────────────────────────────────────────────────┘
```

### Chiplet 的動機

```
Chiplet 的優點：
┌─────────────────────────────────────────────────┐
│  1. 製程最佳化                                  │
│     - 每個 Chiplet 用最適合的製程             │
│     - 邏輯用先進製程，I/O 用成熟製程         │
│                                                  │
│  2. 良率提升                                    │
│     - 小晶片良率高                            │
│     - 單一缺陷影響範圍小                      │
│                                                  │
│  3. 成本降低                                    │
│     - 避免大晶片的低良率成本                  │
│     - 重複使用已驗證的 Chiplet                │
│                                                  │
│  4. 加速開發                                    │
│     - 不同團隊平行開發                       │
│     - 可重複使用IP                           │
│                                                  │
│  5. 靈活性                                      │
│     - 組合不同功能的 Chiplet                  │
│     - 快速適應不同市場需求                  │
└─────────────────────────────────────────────────┘
```

## Chiplet 設計

### 系統分割策略

```
Chiplet 分割考量：
┌─────────────────────────────────────────────────┐
│  分割原則：                                      │
│                                                  │
│  1. 功能分割                                    │
│     - CPU/Chiplet                            │
│     - GPU/Chiplet                            │
│     - 記憶體控制器 Chiplet                  │
│     - I/O Chiplet                            │
│                                                  │
│  2. 通訊需求                                    │
│     - 通訊密集的部分應放同一 Chiplet         │
│     - 減少跨 Chiplet 通訊                  │
│                                                  │
│  3. 製程需求                                    │
│     - 同製程的部分放一起                    │
│                                                  │
│  4. 熱管理                                    │
│     - 高功耗部分分散放置                    │
│                                                  │
│  5. 良率                                      │
│     - 大面積分割成多個小面積                │
└─────────────────────────────────────────────────┘
```

### AMD Chiplet 案例

```
AMD Zen 系列 Chiplet 架構：
┌─────────────────────────────────────────────────┐
│  AMD EPYC（伺服器）：                            │
│  ┌──────────────────────────────────────────┐   │
│  │  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐   │   │
│  │  │ CCD  │ │ CCD  │ │ CCD  │ │ CCD  │   │   │
│  │  │ (Zen)│ │ (Zen)│ │ (Zen)│ │ (Zen)│   │   │
│  │  ├──────┤ ├──────┤ └──────┘ └──────┘   │   │
│  │  │ CCX  │ │ CCX  │  (多達 12 CCD)      │   │
│  │  └──────┘ └──────┘                     │   │
│  │                    │                    │   │
│  │  ┌─────────────────┴─────────────────┐ │   │
│  │  │        I/O Die（IOD）             │ │   │
│  │  │   - 記憶體控制器                  │ │   │
│  │  │   - PCIe 控制器                   │ │   │
│  │  │   - Infinity Fabric 互連          │ │   │
│  │  └───────────────────────────────────┘ │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  優點：                                          │
│  - CCD 用先進製程（7nm/5nm）                  │
│  - I/O Die 用較成熟製程（14nm/12nm）          │
│  - 成本降低、良率提升                        │
└─────────────────────────────────────────────────┘
```

## Chiplet 互連

### 互連需求

```
Chiplet 互連需求：
┌─────────────────────────────────────────────────┐
│  頻寬需求：                                      │
│  - CPU 間通訊：>100 GB/s                       │
│  - GPU 多 Die：> TB/s（如 Blackwell）          │
│  - 記憶體：高頻寬                            │
│                                                  │
│  延遲需求：                                      │
│  - 資料一致性要求高                          │
│  - 需要低延遲互連                            │
│                                                  │
│  功耗限制：                                      │
│  - 每 bit 傳輸功耗要低                       │
│  - 單位面積效率要高                          │
└─────────────────────────────────────────────────┘
```

### 互連介面方案

```
Chiplet 互連方案：
┌─────────────────────────────────────────────────┐
│  1. 私有介面                                    │
│     - AMD Infinity Fabric                     │
│     - Intel EMIB                             │
│     - NVIDIA NVLink-C2C                     │
│                                                  │
│  2. 開放標準介面                                │
│     - UCIe（Universal Chiplet Interconnect）  │
│     - 開放、通用                              │
│                                                  │
│  3. 橋接介面                                    │
│     - EMIB（Embedded Multi-die Interconnect）│
│     - 矽橋（Silicon Bridge）                 │
└─────────────────────────────────────────────────┘
```

## UCIe 標準

### UCIe 概述

```
UCIe（Universal Chiplet Interconnect Express）：
┌─────────────────────────────────────────────────┐
│  定義：                                          │
│  開放、通用的 Chiplet 互連標準                  │
│                                                  │
│  目的：                                          │
│  - 建立統一的 Chiplet 互連介面                │
│  - 讓不同廠商的 Chiplet 能互相配合            │
│  - 建立開放的 Chiplet 生態系                  │
│                                                  │
│  公布：                                          │
│  - 2022 年公布 UCIe 1.0                        │
│  - 由 Intel、AMD、Arm、TSMC 等共同制定        │
│  - 顛覆傳統專有互連技術                      │
└─────────────────────────────────────────────────┘
```

### UCIe 架構

```
UCIe 堆疊：
┌─────────────────────────────────────────────────┐
│              UCIe 協定堆疊                       │
│  ┌──────────────────────────────────────────┐   │
│  │          應用層（協議）                   │   │
│  │  - PCIe / CXL / 流式協議                │   │
│  └──────────────────────────────────────────┘   │
│  ┌──────────────────────────────────────────┐   │
│  │        Die-to-Die Adapter（對接層）       │   │
│  │  - 連結管理                              │   │
│  │  - 未知錯誤處理                        │   │
│  │  - 連結培訓                              │   │
│  └──────────────────────────────────────────┘   │
│  ┌──────────────────────────────────────────┐   │
│  │        Physical Layer（實體層）          │   │
│  │  - 遵循 2.5D/3D 封裝                    │   │
│  │  - 標準介面（凸塊/TSV）               │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  兩種封裝選項：                                  │
│  - 標準封裝（2D，中介層）                    │
│  - 先進封裝（2.5D/3D，更高密度）            │
└─────────────────────────────────────────────────┘
```

### UCIe 規格

```
UCIe 規格：
┌─────────────────────────────────────────────────┐
│  標準封裝（Standard Package）：                  │
│  - 線間距（Pitch）：100-130 µm                │
│  - 每 mm 每層：約 40-80 D2D 接頭              │
│  - 頻寬密度：~11-18 Gbps/mm                    │
│  - 達成：低成本、廣泛適用                    │
│                                                  │
│  先進封裝（Advanced Package）：                  │
│  - 線間距：25-55 µm                           │
│  - 每 mm：約 300-700 D2D 接頭                 │
│  - 頻寬密度：~165-550 Gbps/mm                  │
│  - 達成：高頻寬、高密度                      │
│                                                  │
│  資料速率：                                      │
│  - 標準封裝：4/8/16/24/32 GT/s               │
│  - 先進封裝：4/8/16/24/32 GT/s               │
└─────────────────────────────────────────────────┘
```

### UCIe 優勢

```
UCIe 的價值：
┌─────────────────────────────────────────────────┐
│  ✓ 開放標準（非專有）                          │
│  ✓ 多供應商互通性                            │
│  ✓ 降低開發成本                              │
│  ✓ 加速生態系發展                            │
│  ✓ 支援多種佈局與封裝                        │
│  ✓ 支援多個協議（PCIe/CXL 等）               │
│                                                  │
│  挑戰：                                          │
│  ✗ 標準化需要時間                            │
│  ✗ 成熟度仍不足                              │
│  ✗ 效能與專有介面仍有差距                    │
│  ✗ 廠商傾向用私有方案兼得最佳效能          │
└─────────────────────────────────────────────────┘
```

## 挑戰與未來

### Chiplet 的挑戰

```
Chiplet 挑戰：
┌─────────────────────────────────────────────────┐
│  1. 測試困難                                    │
│     - 組裝後難以測試內部                      │
│     - 需要可測試性設計（DFT）                │
│                                                  │
│  2. 可靠性                                    │
│     - 多晶片連接點的可靠性                  │
│     - 熱應力                                  │
│                                                  │
│  3. 供電網路                                  │
│     - 各 Chiplet 供電整合                    │
│     - 電壓/頻率管理                          │
│                                                  │
│  4. 時序與同步                                │
│     - 跨 Chiplet 的時序同步                 │
│     - 時脈分配                              │
│                                                  │
│  5. 軟體支援                                  │
│     - 系統需感知 Chiplet 架構              │
│     - 作業系統與虛擬化支援                  │
└─────────────────────────────────────────────────┘
```

### 未來趨勢

```
Chiplet 未來方向：
┌─────────────────────────────────────────────────┐
│  1. UCIe 標準普及                              │
│     - 成為 Chiplet 互連的市場標準            │
│                                                  │
│  2. 3D Chiplet                                │
│     - 垂直堆疊的 Chiplet                    │
│     - 更高密度整合                          │
│                                                  │
│  3. 光學互連                                  │
│     - 光學 Chiplet 連接                    │
│     - 更高頻寬、更低延遲                  │
│                                                  │
│  4. AI 專用 Chiplet                          │
│     - 預先驗證的 AI 加速 Chiplet            │
│     - 快速組裝 AI 系統                      │
└─────────────────────────────────────────────────┘
```

## 本章小結

- Chiplet 將大型單晶片分割為多個小晶片
- 每個 Chiplet 用最佳製程提升良率與成本效益
- AMD、Intel、NVIDIA 已採用 Chiplet 架構
- UCIe 是開放的 Chiplet 互連標準
- UCIe 支援 2D（標準）與 2.5D/3D（先進）封裝
- Chiplet 加速 AI 晶片創新，但仍有挑戰
