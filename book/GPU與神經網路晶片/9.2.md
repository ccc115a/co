# 9.2 2.5D/3D 先進封裝：CoWoS、InFO 與 TSV（矽穿孔）技術

## 先進封裝的動機

### 為什麼需要先進封裝

```
先進封裝動機：
┌─────────────────────────────────────────────────┐
│  1. 摩爾定律放緩                                │
│     - 單一晶片整合困難                        │
│     - 需要異質整合                          │
│                                                  │
│  2. AI 晶片的規模                              │
│     - 需要大面積晶片（如 H100 814mm²）        │
│     - 需要大量記憶體（HBM）                  │
│     - 需要頻繁且高速的資料通訊             │
│                                                  │
│  3. 成本考量                                    │
│     - 大晶片良率低                          │
│     - 分割成小晶片再封裝更划算              │
│                                                  │
│  4. 性能需求                                    │
│     - 縮短晶片間通訊距離                    │
│     - 提升頻寬、降低功耗                    │
└─────────────────────────────────────────────────┘
```

### 封裝技術演進

```
封裝技術演進：
┌─────────────────────────────────────────────────┐
│  2D 封裝（傳統）：                               │
│  ┌────────────┐  ┌────────────┐  ┌────────────┐│
│  │  Die A     │  │  Die B     │  │  Die C     ││
│  │ (RDAM)     │  │ (Logic)    │  │ (RDAM)     ││
│  └─────┬──────┘  └─────┬──────┘  └─────┬──────┘│
│        └────────────┬───┴──────────┬───┘       │
│                 封裝基板（PCB）                │
│         （長距離、慢速）                        │
│                                                  │
│  2.5D 封裝：                                      │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐         │
│  │HBM   │ │ GPU  │ │ HBM  │ │ HBM  │         │
│  └──┬───┘ └──┬───┘ └──┬───┘ └──┬───┘         │
│     └─────────┴────┬────┴─────────┘            │
│                Interposer（中介層）              │
│              （短距離、高速）                   │
│-------------------------------------------------│
│                 封裝基板                        │
│                                                  │
│  3D 封裝：                                        │
│        ┌──────┐  上層 Die                       │
│        ├──────┤                                 │
│        ├──────┤  TSV 垂直連接                   │
│        ├──────┤                                 │
│        └──────┘  底層 Die                       │
└─────────────────────────────────────────────────┘
```

## TSV（矽穿孔）技術

### TSV 原理

```
TSV（Through-Silicon Via）：
┌─────────────────────────────────────────────────┐
│  定義：                                          │
│  穿透矽晶片的垂直導電孔                        │
│                                                  │
│  ┌──────────────────────────────────────────┐   │
│  │            Die（矽晶片）                   │   │
│  │  ┌────────────────────────────────────┐  │   │
│  │  │  TSV  │            │     TSV      │  │   │
│  │  │ (銅)  │            │     (銅)     │  │   │
│  │  └───────┴────────────┴─────────────┘  │   │
│  │      ↑ 上下端有連接焊點                  │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  特性：                                          │
│  - 直徑：5-50 µm（依應用）                   │
│  - 深度：穿透整個晶片厚度（50-100 µm）       │
│  - 材質：銅（Cu）                          │
│  - 隔離：使用氧化層隔離                      │
└─────────────────────────────────────────────────┘
```

### TSV 製造流程

```
TSV 製程：
┌─────────────────────────────────────────────────┐
│  主要步驟：                                      │
│  1. 蝕刻（Etching）                           │
│     - 雷射或深反應離子蝕刻（DRIE）           │
│     - 在矽基板打出垂直孔                     │
│                                                  │
│  2. 絕緣（Insulation）                        │
│     - 沉積氧化層（SiO2）                    │
│     - 防止與矽短路                          │
│                                                  │
│  3. 種子層（Seed Layer）                      │
│     - 沉積障壁層（Barrier）                │
│     - 沉積銅種子層                          │
│                                                  │
│  4. 電鍍（Electroplating）                   │
│     - 用銅填滿 TSV 孔                       │
│                                                  │
│  5. CMP 平坦化                                │
│     - 去除多餘的銅                          │
│     - 平坦化表面                            │
│                                                  │
│  6. 連接                                        │
│     - 製作 Microbump                        │
└─────────────────────────────────────────────────┘
```

### TSV 的優勢與挑戰

```
TSV 分析：
┌─────────────────────────────────────────────────┐
│  優勢：                                          │
│  ✓ 垂直連接（高度密集）                      │
│  ✓ 短連接距離（低延遲）                      │
│  ✓ 高頻寬                                │
│  ✓ 低功耗                              │
│                                                  │
│  挑戰：                                          │
│  ✗ 製造成本高                              │
│  ✗ 熱管理困難（垂直堆疊熱聚集）            │
│  ✗ 測試困難                                │
│  ✗ 機械應力                                │
│  ✗ 需要後端處理（TSV）增加複雜度          │
└─────────────────────────────────────────────────┘
```

## 2.5D 封裝

### CoWoS 技術（TSMC）

```
CoWoS（Chip-on-Wafer-on-Substrate）：
┌─────────────────────────────────────────────────┐
│  定義：                                          │
│  TSMC 的 2.5D 先進封裝技術                     │
│                                                  │
│  ┌──────────────────────────────────────────┐   │
│  │  ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐   │   │
│  │  │HBM │ │HBM │ │GPU │ │HBM │ │HBM │   │   │
│  │  └─┬──┘ └─┬──┘ └──┬─┘ └─┬──┘ └─┬──┘   │   │
│  │    └─────┴────────┴────┴─────────┘     │   │
│  │          Si Interposer                 │   │
│  │       （矽中介層，含 TSV）              │   │
│  ├──────────────────────────────────────────┤   │
│  │             封裝基板（Substrate）       │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  特點：                                          │
│  - 使用矽中介層（Silicon Interposer）        │
│  - 中介層含高密度佈線（RDL）                │
│  - 透過 TSV 連接上下層                      │
│  - 晶片間通訊距離短、頻寬高              │
└─────────────────────────────────────────────────┘
```

### CoWoS 用於 AI 晶片

```
CoWoS 應用：
┌─────────────────────────────────────────────────┐
│  NVIDIA H100：                                   │
│  - 使用 CoWoS 封裝                            │
│  - 1 個 GPU Die + 6 個 HBM                    │
│  - 中介層連接 GPU 與 HBM                    │
│                                                  │
│  ┌──────────────────────────────────────────┐   │
│  │   HBM HBM HBM  GPU  HBM HBM HBM         │   │
│  │     └───┬───┴────┬────┴───┬──┘         │   │
│  │          Si Interposer                  │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  AMD MI300X：                                    │
│  - 使用 CoWoS                                   │
│  - 多個 Chiplet + 8 個 HBM3                   │
│  - 總記憶體 192 GB                            │
│                                                  │
│  優勢：                                          │
│  - GPU-HBM 直接連接（高頻寬）                │
│  - 短距離（低延遲）                          │
│  - 整合多個異質元件                          │
└─────────────────────────────────────────────────┘
```

### CoWoS 尺寸演進

```
CoWoS 世代：
┌─────────────────────────────────────────────────┐
│  世代        │  中介層尺寸（mm）  │  應用        │
├─────────────────────────────────────────────────┤
│  CoWoS-S 1.5│  30×30           │  V100      │
│  CoWoS-S 2.0│  50×50           │  A100      │
│  CoWoS-S 2.5│  60×60           │  H100      │
│  CoWoS-S 3.0│  70×70+          │  B200      │
└─────────────────────────────────────────────────┘

趨勢：
- 中介層面積不斷增大
- 可容納更多 HBM 與更大 GPU
- 良率與成本平衡是挑戰
```

## InFO 技術（TSMC）

### InFO 概述

```
InFO（Integrated Fan-Out）：
┌─────────────────────────────────────────────────┐
│  定義：                                          │
│  TSMC 的扇出型（Fan-Out）封裝技術                │
│                                                  │
│  ┌──────────────────────────────────────────┐   │
│  │  ┌───────┐  ┌───────┐                   │   │
│  │  │ Die A │  │ Die B │                   │   │
│  │  └───┬───┘  └───┬───┘                   │   │
│  │      └────┬─────┘                        │   │
│  │           │ RDL（扇出佈線）              │   │
│  │  ┌─────────────────────────────┐        │   │
│  │  │     封裝體（Molding）         │        │   │
│  │  └─────────────────────────────┘        │   │
│  └──────────────────────────────────────────┘   │
│                                                  │
│  特點：                                          │
│  - 不需矽中介層（成本較低）                  │
│  - 使用 RDL 佈線                              │
│  - 適合中等整合密度                        │
│  - 多用於智慧型手機晶片（Apple 等）        │
└─────────────────────────────────────────────────┘
```

### InFO vs CoWoS

```
InFO vs CoWoS 比較：
┌─────────────────────────────────────────────────┐
│  特性      │  InFO           │  CoWoS           │
├─────────────────────────────────────────────────┤
│  中介層    │  無（用 RDL）   │  矽中介層       │
│  佈線密度  │  中             │  高             │
│  成本      │  較低           │  較高           │
│  頻寬      │  中             │  高             │
│  適用      │  行動裝置       │  高階 AI 晶片   │
│  TSV      │  無             │  有             │
└─────────────────────────────────────────────────┘
```

## 3D 封裝

### 3D 堆疊

```
3D 封裝（晶片垂直堆疊）：
┌─────────────────────────────────────────────────┐
│  ┌──────────────────────────────────────────┐   │
│  │          Logic Die（上層）               │   │
│  ├──────────────────────────────────────────┤   │
│  │          SRAM Die                        │   │
│  ├──────────────────────────────────────────┤   │
│  │          DRAM Die                        │   │
│  ├──────────────────────────────────────────┤   │
│  │          Logic Die（底層）               │   │
│  └──────────────────────────────────────────┘   │
│           │TSV││TSV││TSV││TSV│               │   │
│                                                  │
│  3D 優勢：                                      │
│  - 密度最高                                    │
│  - 垂直通訊距離最短                          │
│  - 異質整合（Logic+SRAM+DRAM）                │
│                                                  │
│  3D 挑戰：                                      │
│  - 散熱困難（垂直堆疊）                      │
│  - 製造複雜度極高                            │
│  - 測試困難                                  │
│  - 成本極高                                  │
└─────────────────────────────────────────────────┘
```

```
│  │  DRAM Die 7（頂層）                     │   │
│  ├──────────────────────────────────────────┤   │
│  │  DRAM Die 6                              │   │
│  ├──────────────────────────────────────────┤   │

│  - HBM 本身 3D 堆疊                           │
```


## 本章小結

- 先進封裝是 AI 晶片滿足面積、頻寬、記憶體需求的關鍵
- 2.5D 封裝使用矽中介層連接多個晶片
- CoWoS 是 TSMC 主要的 2.5D 技術，用於 AI 晶片
- InFO 是扇出型封裝，成本較低
- TSV 實現垂直連接（3D）
- HBM 結合了 2.5D 與 3D 封裝
- 異質整合透過 Chiplet 提升設計靈活性
