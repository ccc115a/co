## 第 1–30 天：通用底座

- 目標：跑通 18.1–18.4 所有範例（本目錄 `../ch18`），整理進個人 dotfiles。
- 目標：默寫 RV32I 六種格式＋ABI 暫存器表，不看書畫出來。
- 目標：在 Spike 或 QEMU 修一個小 bug 或補一份文件並送 PR，留下開源足跡。

  能向他人解釋 `-march`（硬體有什麼）vs `-mabi`（軟體怎麼用）。
