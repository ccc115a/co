# 開源 RISC-V 核心 upstream（對應 7.1–7.3 剖析對象）

只收連結與一句話定位，未複製其程式碼；版本與參數以各倉庫 README 為準。

- PicoRV32 — <https://github.com/YosysHQ/picorv32>：Clifford Wolf 的單檔極簡 RV32 教學核心。
- Ibex — <https://github.com/lowRISC/ibex>：lowRISC 維護的兩級管線工業級嵌入式小核心。
- Rocket Chip — <https://github.com/chipsalliance/rocket-chip>：Berkeley 的 Chisel 核心產生器＋TileLink SoC 框架。
- BOOM — <https://github.com/riscv-boom/riscv-boom>：建於 Rocket 框架上的亂序超純量研究核心。
