# 3.3 記憶體存取指令（Load/Store）

> CPU 不能直接對記憶體做運算，只能先載入（Load）到暫存器、算完再存回（Store）。本節是 Load-Store 架構（Load-Store Architecture）的心臟。

## 開場動機：為什麼不允許 `add (mem), reg`？

x86 允許 `add [eax], ebx`（記憶體直接參與運算），但代價是管線要處理「運算中途等記憶體」的複雜停頓。RISC-V 堅持：**運算只在暫存器之間，記憶體只由 Load/Store 碰**。管線因此乾淨，載入延遲（Load-use Hazard）也只需一種轉發策略（見 5.3 節）。

## 核心講解：Load/Store 全表

### 載入指令（I-type，opcode 0000011，funct3 區分寬度）

| 指令 | 語意 | funct3 | 寬度/擴展 |
|------|------|--------|-----------|
| `lb rd, offset(rs1)` | 位元組載入，有號擴展（Sign-extend） | 000 | 8→XLEN，有號 |
| `lh rd, offset(rs1)` | 半字載入，有號擴展 | 001 | 16→XLEN，有號 |
| `lw rd, offset(rs1)` | 字載入 | 010 | 32 位（RV64 仍 32→64 有號擴展） |
| `lbu rd, offset(rs1)` | 位元組載入，零擴展（Zero-extend） | 100 | 8→XLEN，無號 |
| `lhu rd, offset(rs1)` | 半字載入，零擴展 | 101 | 16→XLEN，無號 |
| `lwu rd, offset(rs1)` | 字載入，零擴展（僅 RV64） | 110 | 32→64，無號 |
| `ld rd, offset(rs1)` | 雙字載入（僅 RV64） | 011 | 64 位 |

### 儲存指令（S-type，opcode 0100011）

| 指令 | 語意 | funct3 | 備註 |
|------|------|--------|------|
| `sb rs2, offset(rs1)` | 存低 8 位 | 000 | 位元組儲存（Store Byte） |
| `sh rs2, offset(rs1)` | 存低 16 位 | 001 | 需 2 位元組對齊 |
| `sw rs2, offset(rs1)` | 存低 32 位 | 010 | 需 4 位元組對齊 |
| `sd rs2, offset(rs1)` | 存 64 位（僅 RV64） | 011 | 需 8 位元組對齊 |

### 對齊與陷阱

| 情況 | 行為 |
|------|------|
| 對齊存取 | 最快，單週期（快取命中時） |
| 未對齊（Misaligned） | 平台相關：有的硬體直接支援（慢），有的觸發例外（Exception）轉軟體模擬 |
| 跨頁未對齊 | 可能觸發缺頁（Page Fault），作業系統處理（見第 13 章） |
| 原子性保證 | 對齊的 `lw/sw` 單次存取具原子性（Atomicity），未對齊則不保證 |
| 效能建議 | 熱迴圈（Hot Loop）一律對齊陣列基址，必要時用 `__attribute__((aligned(4)))` |

## 範例：結構體拷貝與位元組序觀察

```asm
# 例：struct { char c; short h; int w; } 從 a0 拷貝到 a1
# 假設已按 C ABI 對齊：c@0, h@2, w@4（中間 1 位元組填充）
    lbu  t0, 0(a0)        # 無號載入位元組（c 不做符號擴展）
    sb   t0, 0(a1)
    lhu  t1, 2(a0)        # 無號載入半字
    sh   t1, 2(a1)
    lw   t2, 4(a0)        # 字載入
    sw   t2, 4(a1)
    ret
```

```c
#include <stdint.h>
// 有號 vs 無號擴展：同一個 0xFF 位元組，lb 得 -1，lbu 得 255
int8_t  mem8 = (int8_t)0xFF;   // lb  -> 0xFFFFFFFF (-1)
uint8_t umem8 = 0xFF;          // lbu -> 0x000000FF (255)

// memcpy 的字組優化版概念：能用 lw/sw 就不用四次 lb/sb
void copy_word(int *dst, const int *src) {
    *dst = *src;  // 編譯為 lw + sw
}
```

## 本節小結

- Load 是 I-type（`lb/lh/lw/lbu/lhu` + RV64 的 `ld/lwu`），Store 是 S-type（`sb/sh/sw`/`sd`）。
- 有號載入做符號擴展、無號（u 系列）做零擴展——`char` 的正負 bug 八成出在這裡。
- 定址一律 Base+Offset 12 位，大跨度靠 `auipc` 接力。
- 對齊最快，未對齊行為看平台，跨頁未對齊交給作業系統。
- 下一節讓程式會轉彎：分支與跳躍（Control Transfer）。
