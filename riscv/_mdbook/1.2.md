# 1.2 RISC-V 誕生背景與 Berkeley 願景

> 2010 年，Berkeley 的一群師生只想做一個「沒有包袱、免費可用」的研究載體，結果意外改寫了全球晶片史。本節回到 RISC-V 的出生現場。

## 開場動機：一個研究生專案的煩惱

2010 年，加州大學柏克萊分校（UC Berkeley）並行計算實驗室（Parallel Computing Laboratory, Par Lab）遇到一個很實際的困境：

- 做多核心（Many-core）研究需要自己的晶片載體，但 x86 不能用、ARM 太貴。
- 過去 Berkeley 做過 SPARC、MIPS 相關研究，但那些 ISA 都有專利主人，畢業生創業也不能直接帶走。
- 指導教授 David Patterson（RISC 元老、圖靈獎得主）與 Krste Asanović 決定：**乾脆自己設計一個全新的 ISA，而且從第一天就免費開放**。

於是 Andrew Waterman 等博士生動手設計了 RISC-V——名字裡的「V」代表第五代（Fifth Generation），延續 Berkeley 的 RISC-I、RISC-II、SOAR、SPUR 一脈。

## 核心講解：Berkeley 願景的三根支柱

### 支柱一：研究用的乾淨起點（Clean-Slate Design）

RISC-V 設計團隊立下幾條鐵律：

| 設計原則 | 具體做法 | 解決的歷史問題 |
|----------|----------|----------------|
| 凍結基礎、開放延伸 | 基礎整數集（Base Integer ISA）凍結，擴充（Extension）另行加掛 | 避免 ISA 每年大改造成碎片化 |
| 拒絕特殊工作暫存器 | 通用暫存器（GPR）一律 32 個、夠用且對稱 | 告別 x86 暫存器不對稱惡夢 |
| 固定長度優先 | 基本指令一律 32 位元，壓縮（Compressed）才有 16 位元 | 解碼器（Decoder）簡單、面積小 |
| 特權與非特權分離 | 使用者級 ISA（User ISA）與特權級 ISA（Privileged ISA）分開凍結 | 作業系統可以獨立演進 |

### 支柱二：免費且可商用的開放模式

| 項目 | RISC-V 的做法 |
|------|---------------|
| 專利立場 | 創始團隊將基礎 ISA 貢獻出來，任何人實作不需權利金（Royalty-free） |
| 商業友善 | BSD 式開放：學術界與產業界都可閉源販售自研核心 |
| 學研傳承 | 學生的課程作業可以直接變成新創公司的產品（如 SiFive） |

### 支柱三：從教學到產業的飛輪

```mermaid
flowchart LR
    A[Berkeley 課程與研究] --> B[開源核心 Chisel/Rocket]
    B --> C[新創公司 SiFive]
    C --> D[工具鏈與基金會]
    D --> A
```

這個飛輪（Flywheel）轉起來之後：學生學 RISC-V、畢業生用 RISC-V 創業、公司回頭貢獻測試案例與工具，生态自我增強。

## 範例：第一條 RISC-V 程式長什麼樣？

2011 年第一版 RISC-V 手冊就能跑的經典程式：把兩個數相加後存回記憶體。

```asm
# RISC-V 組語（Assembly）：a0-a2 是 ABI 暫存器名，見 2.3 節
    .text
    .globl add_demo
add_demo:
    lw   a1, 0(a0)        # a1 = *p
    lw   a2, 4(a0)        # a2 = *(p+1)
    add  a3, a1, a2       # a3 = a1 + a2
    sw   a3, 8(a0)        # *(p+2) = a3
    ret                   # jalr x0, 0(ra) 的虛擬指令（Pseudo-instruction）
```

```c
// 同一邏輯的 C 語言對照：編譯器（Compiler）會把它降成上面的 lw/add/sw
void add_demo(int *p) {
    p[2] = p[0] + p[1];
}
```

用 `riscv64-unknown-elf-gcc -march=rv64i -mabi=lp64 -S` 編譯上面的 C 檔，就能親眼看到 Berkeley 當年定義的那幾個 opcode 如何被使用。

## 本節小結

- RISC-V 誕生於 2010 年 Berkeley Par Lab，動機是**研究需要免費、無包袱的 ISA**。
- 關鍵人物：David Patterson、Krste Asanović 與 Andrew Waterman 等博士生團隊。
- 「V」是第五代 Berkeley RISC，設計鐵律是**凍結基礎、開放延伸、軟硬協同**。
- 從第一天就設定為 Royalty-free，讓課程作業可以直接變成商業產品。
- 教學 → 開源核心 → 新創 → 工具鏈的飛輪，是 RISC-V 與前輩 ISA 最大的不同。
