# 4.3 F/D 擴充：單/雙精度浮點數與 f 暫存器

> 整數算地址，浮點算世界。本節介紹單精度（Single-precision, F）與雙精度（Double-precision, D）浮點擴充：獨立的 f 暫存器檔、IEEE 754 語意、以及那顆控制捨入的 `fcsr`。

## 開場動機：為什麼浮點要整套暫存器？

浮點值與整數位寬、管線、捨入模式（Rounding Mode）都不同，硬塞進 x 暫存器會讓管線與 ABI 糾纏不清。RISC-V 另開一套 **32 個浮點暫存器（f0–f31）**，整數與浮點之間只用明確的搬運指令溝通，涇渭分明。

## 核心講解：F/D 指令表

### f 暫存器與傳送

| 項目 | F（單精度，32 位） | D（雙精度，64 位） |
|------|-------------------|-------------------|
| 暫存器 | f0–f31（FLEN=32） | f0–f31（FLEN=64，可存單/雙） |
| 載入 | `flw fd, off(rs1)` | `fld fd, off(rs1)` |
| 儲存 | `fsw fs2, off(rs1)` | `fsd fs2, off(rs1)` |
| 整浮互搬 | `fmv.w.x fd, rs1`（整→浮）、`fmv.x.w rd, fs1`（浮→整，按位拷貝） | `fmv.d.x` / `fmv.x.d`（RV64） |

### 運算指令（funct7 區分，預設動態捨入 `dyn`）

| 指令 | 語意 | 備註 |
|------|------|------|
| `fadd.s / fsub.s / fmul.s / fdiv.s` | 單精度加減乘除 | D 版把 `.s` 換 `.d` |
| `fsqrt.s` | 單精度開方 | 迭代或專用電路 |
| `fmin.s / fmax.s` | 取小/大（含 NaN 規則） | 比分支寫法快且無例外 |
| `fcvt.s.d / fcvt.d.s` | 單雙精度互轉 | 精度損失依捨入模式 |
| `fcvt.w.s / fcvt.s.w`（及 `.l/.wu/.lu`） | 浮點↔整數轉換 | 越界/NaN 有定義值，不 trap |
| `feq.s / flt.s / fle.s` | 浮點比較，結果寫整數 rd（0/1） | 無條件碼，結果直接進分支 |
| `fsgnj.s / fsgnjn.s / fsgnjx.s` | 符號注入/取反/互斥或 | `fmv` 與 `fabs/fneg` 的本體（虛擬指令） |

### 控制狀態：fcsr

| 欄位 | 用途 |
|------|------|
| `frm`（捨入模式） | RNE（就近偶數，預設）、RTZ（向零）、RDN/RUP/RMM |
| `fflags`（累積例外旗） | NX（不精確）、UF（下溢）、OF（上溢）、DZ（除零）、NV（非法） |

## 範例：點積與絕對值

```asm
# 單精度點積：a0=x, a1=y, a2=n，fa0 累加（RV32F）
fdot:
    fcvt.s.w fa0, x0      # fa0 = 0.0（整數 0 轉浮點）
fdot_loop:
    beq  a2, zero, fdot_end
    flw  ft0, 0(a0)       # ft0 = x[i]
    flw  ft1, 0(a1)       # ft1 = y[i]
    fmadd.s ft0, ft0, ft1, fa0  # 融合乘加（Fused Multiply-Add，見下）
    fmv.s fa0, ft0        # 或寫成 fa0 = x[i]*y[i] + fa0
    addi a0, a0, 4
    addi a1, a1, 4
    addi a2, a2, -1
    jal  x0, fdot_loop
fdot_end:
    ret                   # 返回值在 fa0（ABI）

# fabs / fneg 本質是 fsgnj 家族
# fabs.s fa0, fa1  = fsgnj.s fa0, fa1, fa1  （取 fa1 符號的正版）
# fneg.s fa0, fa1  = fsgnjn.s fa0, fa1, fa1 （符號取反）
```

```c
// 融合乘加：一次捨入，精度優於分開 mul+add，且更快
float dot_c(const float *x, const float *y, int n) {
    float s = 0;
    for (int i = 0; i < n; i++) s += x[i] * y[i];
    // -march=rv32g 編譯器可生成 fmadd.s
    return s;  // float 返回值在 fa0
}
```

## 本節小結

- F/D 另開 32 個 f 暫存器，整浮互搬只靠 `fmv/fcvt`，管線解耦。
- 運算全家桶：加減乘除、開方、min/max、互轉、比較（結果寫整數暫存器）。
- 比較結果進整數暫存器，直接餵 `bne/beq`——再次體現無旗標哲學。
- `fcsr` 管捨入（frm）與例外旗（fflags），預設 RNE。
- `fmadd.s/d`（融合乘加）是效能關鍵，矩陣/AI 迴圈必備。
