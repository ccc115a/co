# 2.4 記憶體定址與 Endianness

> RISC-V 只有一種記憶體定址模式，加上統一的小端序（Little-endian）。本節把「CPU 如何看到記憶體」一次講清楚。

## 開場問題：定址模式越少越好？

x86 有數十種定址模式，寫起來爽、解碼起來哭。RISC-V 反其道而行：**所有讀寫記憶體的指令，只有「基址暫存器 + 立即偏移」（Base + Offset）一種**。算術一律在暫存器之間做（載入-儲存架構，Load-Store Architecture）。

## 核心講解：定址與位元組序

### 唯一的定址模式

| 項目 | 說明 |
|------|------|
| 語法 | `lw rd, offset(rs1)`，有效位址 = rs1 + sign_extend(offset) |
| 偏移寬度 | 12 位元有號立即數（-2048 ~ +2047） |
| 對齊要求 | `lw` 需 4 位元組對齊，`lh` 需 2 位元組對齊，`lb` 任意；未對齊視平台可 trap 或慢速處理 |
| 超出範圍怎辦 | 用 `auipc` + `jalr`/`lw` 組出 32 位大位址（見範例） |

### 位元組序（Endianness）：只用小端序

| 位元組序 | 定義 | RISC-V 立場 |
|----------|------|-------------|
| 小端序（Little-endian） | 最低有效位元組（LSB）放最低位址 | **標準規定，軟體可假設** |
| 大端序（Big-endian） | 最高有效位元組（MSB）放最低位址 | 不支援（早期草案曾討論，正式版移除） |

記憶體字（Word）`0x12345678` 放在位址 `0x1000`：

| 位址 | 0x1000 | 0x1001 | 0x1002 | 0x1003 |
|------|--------|--------|--------|--------|
| 小端序存放 | 0x78 | 0x56 | 0x34 | 0x12 |

### 記憶體模型速覽

| 主題 | RISC-V 做法 |
|------|-------------|
| 位址空間 | 平坦（Flat）、位元組定址（Byte-addressable），RV32 為 4GB |
| 對齊 vs 未對齊 | 建議對齊；未對齊存取由硬體或 trap 轉軟體模擬（平台相關） |
| 記憶體一致性 | RVWMO 弱記憶體模型（Weak Memory Model），多核同步靠 A 擴充 + FENCE（見 3.5、4.2） |
| MMIO | 外設即記憶體（Memory-Mapped I/O），`lw/sw` 直接操作 UART 等暫存器 |

## 範例：從小偏移到大位址

```asm
# 例 1：結構體欄位存取（小偏移，一條指令搞定）
# struct P { int x; int y; int z; }; a0 = &p
    lw   t0, 0(a0)        # t0 = p.x
    lw   t1, 4(a0)        # t1 = p.y
    lw   t2, 8(a0)        # t2 = p.z

# 例 2：大位址（超過 12-bit）：auipc + lw 組合
# 取全域變數 g（位址由連結器決定）
    auipc t0, %hi(g)      # t0 = PC + high20(g)，取高 20 位
    lw    t1, %lo(g)(t0)  # t1 = *(t0 + low12)，組出完整 32 位位址
```

```c
// MMIO 範例：UART 送一個字元（假設 UART_TX 位址已知，volatile 不可優化掉）
#define UART_TX ((volatile unsigned char *)0x10000000)
void uart_put(char c) {
    *UART_TX = c;  // 編譯為 sb t0, 0(addr)，位元組儲存（Store Byte）
}

// 小端序驗證：這段在 RISC-V 上印出 0x78
unsigned m = 0x12345678;
unsigned char b = *(unsigned char *)&m;  // b == 0x78（小端序）
```

## 本節小結

- RISC-V 是 Load-Store 架構：只有 `lw/sw` 等能碰記憶體，定址一律 Base+Offset。
- 偏移只有 12 位有號數，大位址靠 `auipc` 接力。
- 統一小端序，軟體不必像 ARM 那樣處理雙端序（Bi-endian）切換。
- 對齊存取最快；未對齊是否 trap 看平台，不要依賴它。
- MMIO 讓驅動就是指標操作，為第 15 章 Bare-Metal 埋下伏筆。
