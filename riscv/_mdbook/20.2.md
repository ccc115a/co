# 20.2 開源 EDA 與 OpenPDK

## 動機：ISA 開源了，晶片為什麼還這麼貴？

RISC-V 把指令集的授權費降到零，但做一顆晶片真正的成本在後面：商用 EDA（Electronic Design Automation，電子設計自動化）工具授權一年數十萬美元，晶圓廠 PDK（Process Design Kit，製程設計套件）簽了 NDA 才能看。結果是「前端開源、後端封閉」——學生在 FPGA 上跑得歡，要 tape-out（投片）卻卡在最後一哩。

本節核心觀念：**開源 EDA + OpenPDK 正在把最後一哩鋪平**，從 RTL 到 GDSII（版圖交付格式）的全流程，第一次可以在筆電上免費重現。

## 核心講解

### 1. 開源 RTL-to-GDSII 全流程（OpenROAD 棧）

| 階段 | 開源工具 | 商用對應 | 輸入 → 輸出 |
|------|----------|----------|-------------|
| 合成（Synthesis） | Yosys | Design Compiler | `.v` → 網表（Netlist） |
| 佈局繞線（P&R） | OpenROAD | Innovus/ICC2 | 網表 → GDSII |
| 靜態時序（STA） | OpenSTA | PrimeTime | 時序報告（WNS/TNS） |
| 物理驗證 | KLayout + Magic | Calibre | DRC/LVS 報告 |
| 模擬 | Verilator / Icarus | VCS/Xcelium | 波形與覆蓋率 |
| PDK | SkyWater 130nm / IHP 130nm | 台積電/三星 NDA PDK | 標準單元庫 + 設計規則 |

Google + SkyWater 的 `sky130` 是里程碑：130nm 製程的完整 PDK 以 Apache 2.0 開源，搭配 Efabless 平台，學生專案可免費投片（MPW，多專案晶圓）。

### 2. 一顆 RISC-V 從程式碼到晶片要過幾關？

| 關卡 | 檢查項 | 常見死因 |
|------|--------|----------|
| RTL 凍結 | Verilator 迴歸全過、覆蓋率達標 | 自訂指令語義與 Spike 不一致 |
| 合成 | 時脈達標、面積合理 | 組合邏輯鏈過長（WNS 為負） |
| 佈局 | 擁塞（Congestion）< 閾值 | SRAM 巨集擺放不當 |
| 時序收斂 | SS/TT/FF 三 corner 全過 | 只看 TT，投片後 SS 掛掉 |
| DRC/LVS | 零違規 | 手刻版圖碰最小間距規則 |

記住一句話：**在 FPGA 跑得動，離投片還有十萬八千里**——FPGA 幫你藏起了時序、功耗、面積的真相。

### 3. 成本現實：免費到哪裡為止？

| 節點 | 開源 PDK 狀態 | MPW 成本量級 | 適合對象 |
|------|---------------|--------------|----------|
| 130nm（sky130） | 完全開源 | 免費（補助 shuttle）~ 數千美元 | 教學、MCU、自訂指令驗證 |
| 90nm 以下 | 多為 NDA | 數萬 ~ 數十萬美元 | 新創、量產 MCU |
| 7nm 以下 | 全 NDA + 需授權標準單元 | 百萬美元起 | 大廠、HPC/手機 SoC |

務實路線：用 sky130 證明你的自訂指令與加速器「可投片」，再拿這顆晶片的量測數據去談先進製程與創投。

## 範例：Yosys + OpenROAD 跑通 PicoRV32

```bash
# 步驟 1：合成（Yosys）：Verilog -> 網表
yosys -p "read_verilog picorv32.v; \
  hierarchy -top picorv32; proc; opt; \
  synth -top picorv32; \
  write_verilog picorv32_synth.v"

# 步驟 2：OpenROAD 佈局繞線（以 sky130 為例）
export PDK_ROOT=~/pdks sky130
openroad -no_splash -exit openroad.tcl
# openroad.tcl 內含：floorplan -> place -> cts -> route -> gds

# 步驟 3：檢查時序與面積
opensta post_route.sta.tcl | tee sta.rpt
grep -E 'WNS|TNS|Area' sta.rpt

# 步驟 4：DRC/LVS（KLayout）
klayout -b -r drc_sky130.lydrc -rd input=final.gds -rd report=drc.txt
```

> 實驗分級 ★★：用 Yosys 合成你在第五章寫的單週期 CPU，記錄單元數（cells）與關鍵路徑；把時脈設為 50MHz/100MHz 各跑一次 OpenSTA，觀察 WNS 如何變號。

## 本節小結

- 投片成本 = EDA 授權 + PDK 門檻，開源棧（Yosys + OpenROAD + sky130）把教學級投片降到零元。
- RTL-to-GDSII 五關：合成 → 佈局繞線 → 時序收斂 → DRC/LVS，FPGA 驗證只是起點。
- 130nm 開源 PDK 適合驗證自訂指令與加速器，先進製程仍需商用流程，兩者是接力不是對立。
- 每次改 RTL 都重跑 Verilator 迴歸 + OpenSTA，不要把 bug 留到 GDSII。
