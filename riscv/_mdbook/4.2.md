# 4.2 A 擴充：原子指令與多核心同步（Atomic & LR/SC）

> 兩個核心同時 `counter++`，結果可能只加了 1 次。本節的原子操作（Atomic Operation）就是多核心的紅綠燈：讀-改-寫（Read-Modify-Write）必須一氣呵成。

## 開場動機：丟失的加一

`counter++` 在組語是三步：`lw → addi → sw`。若 Core0 與 Core1 交錯執行，兩次 `lw` 讀到同一個舊值，一次加法就被覆蓋丟失。解法是讓硬體保證「這三步不被插隊」——RISC-V 給了兩套工具：保留載入/條件儲存（Load-Reserved/Store-Conditional, LR/SC）與原子記憶體操作（Atomic Memory Operation, AMO）。

## 核心講解：A 指令表

### LR/SC：樂觀鎖（Optimistic）

| 指令 | 語意 | 備註 |
|------|------|------|
| `lr.w rd, (rs1)` | 保留載入字，設 reservation | R-type 變體，aq/rl 位控制順序 |
| `sc.w rd, rs2, (rs1)` | 若 reservation 仍有效則存入，rd=0 成功，否則 rd≠0 失敗 | 失敗要重試（retry loop） |

約束：LR/SC 之間只能放少量 ALU 指令，不能放 Load/Store、分支跳轉（否則 reservation 可能被清除）。

### AMO：單條原子讀改寫（opcode 0101111）

| 指令 | 語意（atomically: t = *p; *p = t op rs2; rd = t） |
|------|--------------------------------------------------|
| `amoadd.w rd, rs2, (rs1)` | 原子加，取回舊值 |
| `amoswap.w` | 原子交換（隱含 fence，適合建鎖） |
| `amoand.w / amoor.w / amoxor.w` | 原子與/或/互斥或 |
| `amomin.w / amomax.w` | 有號原子取小/大 |
| `amominu.w / amomaxu.w` | 無號原子取小/大 |

後綴 `.aq`（Acquire，獲取語意）/`.rl`（Release，釋放語意）控制記憶體順序；RV64 另有 `.d`（雙字）版本。

| 順序位 | 語意 | 典型用法 |
|--------|------|----------|
| `.aq` | 獲取：後續讀寫不能提前到原子操作之前 | 取鎖（acquire） |
| `.rl` | 釋放：之前讀寫必須先完成 | 放鎖（release） |
| `.aqrl` | 兩者兼具（sequentially consistent） | 全序要求最高時 |
| 無後綴 | 寬鬆（Relaxed），只保證原子性 | 純計數器累加 |

## 範例：自旋鎖（Spinlock）兩種寫法

```asm
# 寫法一：AMO 交換建鎖（a0 = &lock，0=開鎖，1=上鎖）
acquire:
    li   t0, 1
    amoswap.w t1, t0, (a0)  # 原子：舊值->t1，*lock=1
    bnez t1, acquire        # 舊值非 0 表示有人鎖著，重試
    ret
release:
    amoswap.w x0, x0, (a0) # 存 0 開鎖（x0 讀丟棄，amoswap 具順序性）
    ret

# 寫法二：LR/SC 原子加一（a0 = &counter）
atomic_inc:
    lr.w t0, (a0)           # 保留載入
    addi t0, t0, 1          # 中間只做 ALU
    sc.w t1, t0, (a0)       # 嘗試存回
    bnez t1, atomic_inc     # 失敗重試
    ret
```

```c
// C11 <stdatomic.h> 對應：編譯器把 atomic_fetch_add 降成 amoadd.w
#include <stdatomic.h>
atomic_int counter = 0;
void inc(void) {
    atomic_fetch_add(&counter, 1);  // -> amoadd.w（帶 aq/rl 依 memory_order）
}
```

## 本節小結

- 非原子 `lw/addi/sw` 在多核下會丟更新，原子指令保證讀-改-寫不可分。
- LR/SC 是樂觀重試：`lr` 設保留、`sc` 成敗回報，失敗迴圈重來。
- AMO 是單條原子操作：`amoadd/amoswap/amoand/amoor/amoxor/amomin/amomax(+u)`。
- `.aq/.rl` 控制獲取/釋放語意，`amoswap` 自帶順序適合建鎖。
