# 2.3 ABI 命名規範與慣例

> 機器只認 x0–x31，人類卻說 a0、sp、ra——中間隔著一層應用二進制介面（Application Binary Interface, ABI）。本節把「暫存器怎麼分工」變成「函式怎麼互相呼叫」。

## 開場動機：沒有 ABI，連結只是空談

指令集（ISA）規定了 `add x10, x11, x12` 合法，但沒規定 x10 該放引數還是區域變數。若兩個編譯器各行其是，A 編的 `.o` 就接不上 B 編的 `.o`。ABI 就是這層**社會契約**：

- 暫存器別名（x10 叫 a0）與分工；
- 函式呼叫慣例（Calling Convention）：引數、返回值、保存責任；
- 堆疊佈局（Stack Layout）與對齊；
- 資料型別寬度（`int` 幾位、`long` 幾位，即 `ilp32/lp64`）。

## 核心講解：呼叫慣例全圖

### 暫存器 ABI 對照表（含保存責任）

| 編號 | ABI 名 | 用途（Purpose） | Caller/Callee-saved |
|------|--------|----------------|---------------------|
| x0 | zero | 恆零（Hardwired Zero） | — |
| x1 | ra | 返回位址（Return Address） | Caller-saved |
| x2 | sp | 堆疊指標（Stack Pointer），16 位元組對齊 | Callee-saved |
| x3 | gp | 全域指標（Global Pointer，±2KB 快速存取） | — |
| x4 | tp | 執行緒指標（Thread Pointer，TLS） | — |
| x5 | t0 | 暫存（Temporary），連結器跳板也用它 | Caller-saved |
| x6–x7 | t1–t2 | 暫存 | Caller-saved |
| x8 | s0/fp | 被保存／框架指標（Frame Pointer） | Callee-saved |
| x9 | s1 | 被保存 | Callee-saved |
| x10–x11 | a0–a1 | 引數 0–1兼返回值 | Caller-saved |
| x12–x17 | a2–a7 | 引數 2–7 | Caller-saved |
| x18–x27 | s2–s11 | 被保存 | Callee-saved |
| x28–x31 | t3–t6 | 暫存 | Caller-saved |
| f0–f7 | ft0–ft7 | 浮點暫存（F/D 擴充） | Caller-saved |
| f8–f9 | fs0–fs1 | 浮點被保存 | Callee-saved |
| f10–f17 | fa0–fa7 | 浮點引數／返回值 | Caller-saved |
| f18–f27 | fs2–fs11 | 浮點被保存 | Callee-saved |
| f28–f31 | ft8–ft11 | 浮點暫存 | Caller-saved |

### 函式呼叫四步

| 步驟 | 動作 | 使用的暫存器 |
|------|------|--------------|
| 1. 傳參 | 前 8 個整數引數放 a0–a7，浮點放 fa0–fa7，超過的壓堆疊（由右往左） | a0–a7、sp |
| 2. 跳轉 | `jal ra, callee`（或 `call` 虛擬指令），返回位址存 ra | ra |
| 3. 取值 | 整數返回值在 a0（64 位以上用 a0+a1），浮點在 fa0 | a0–a1/fa0 |
| 4. 善後 | caller 自保 a/t 群；callee 若用 s 群則進函式先存、出函式恢復 | s0–s11/sp |

### 堆疊慣例

- `sp` 永遠 16 位元組對齊（ABI 硬性規定，中斷也要遵守）。
- 堆疊向低位址成長（Stack Grows Down）。
- 典型框架：`ra → s0–s11 → 區域變數 → 超過 8 個的引數`。

## 範例：C 呼叫的組語真相

```c
// caller.c：三個引數都在暫存器內，无需堆疊傳參
extern int callee(int a, int b, int c);
int caller(void) {
    return callee(1, 2, 3) + 10;
}
```

```asm
# riscv64-unknown-elf-gcc -O2 編譯 caller 的示意結果
caller:
    addi sp, sp, -16      # 開框架，保持 16B 對齊
    sw   ra, 12(sp)       # 保存 ra（caller-saved 自保）
    li   a0, 1            # 第 1 個引數 -> a0
    li   a1, 2            # 第 2 個引數 -> a1
    li   a2, 3            # 第 3 個引數 -> a2
    call callee           # jal ra, callee；返回時 ra 恢復
    addi a0, a0, 10       # 返回值在 a0，直接 +10
    lw   ra, 12(sp)       # 取回 ra
    addi sp, sp, 16
    ret
```

```asm
# 超過 8 個引數時：第 9 個起走堆疊（示意）
# callee9(1,2,3,4,5,6,7,8,9):
    li   a0, 1
    # ... a1-a7 放 2..8 ...
    li   t0, 9
    addi sp, sp, -16
    sw   t0, 0(sp)        # 第 9 個引數壓堆疊
    call callee9
    addi sp, sp, 16
```

## 本節小結

- ABI = 暫存器別名 + 呼叫慣例 + 堆疊對齊 + 型別寬度（`ilp32/lp64/lp64d`）。
- 引數：a0–a7（浮點 fa0–fa7），超量走堆疊；返回值：a0（/fa0）。
- Caller-saved（a/t）呼叫前自保；Callee-saved（s/sp）用了要還；sp 恆 16B 對齊。
- `midlertidig`？不，是 `t` 用完即丟、`s` 借用歸還、`a` 負責傳話——背起這個口訣。
- 下一節進入記憶體：定址模式與位元組序（Endianness）。
