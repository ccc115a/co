# 20.3 結語工程師定位與機會

## 動機：學完整本書，你站在哪裡？

從第 1 章的 ISA 哲學，到第 20 章的投片與生態，你已經走完一條全棧路：寫過 `rv32i` 解碼、搭過五階管線、追過 xv6 trap、調過 `-march/-mabi`、加過自訂指令、想過向量與投片。這時最該問的不是「還缺哪個知識點」，而是「在 RISC-V 的大分工裡，我要卡哪個位置？」

本節為全書收束：把二十章壓成一張能力地圖，對出三條職涯路線，並給出未來三年的行動清單。

## 核心講解

### 1. 全書一張圖：二十章的能力地圖

| 篇章 | 你已會的硬本領 | 對應產業職位 |
|------|---------------|--------------|
| 一、ISA 基礎（1–4 章） | 讀懂手冊、編解碼、選 Base+Ext | 應用工程師（AE）、技術寫作 |
| 二、微結構（5–7 章） | 管線、OoO、開源核心客製 | CPU 設計、驗證工程師 |
| 三、GPU/CUDA（8–10 章） | SIMT、kernel 轉譯、Vortex | GPU/編譯器工程師 |
| 四、特權與系統（11–14 章） | CSR、Trap、頁表、開機 | 韌體/BSP、安全工程師 |
| 五、OS（15–17 章） | Bare-Metal、xv6、Linux 移植 | 嵌入式、OS/驅動工程師 |
| 六、工具鏈（18 章） | 交叉編譯、組語、Linker Script | 工具鏈、效能優化工程師 |
| 七、擴充與未來（19–20 章） | 自訂指令、加速器、投片 | DSA 架構師、創業 |

核心觀念：**T 型人才**——橫向全棧可溝通（能跟上下游吵架），縱向一柱夠深（有一題你比誰都懂）。

### 2. 三條路線：選一條深耕，兩條結盟

| 路線 | 深耕技能 | 第一個作品（Portfolio） | 三年目標 |
|------|----------|------------------------|----------|
| A. 硬體/晶片 | Chisel/Verilog + 驗證 + OpenROAD | 帶自訂指令、可合成的 RV32IMC + 投片報告 | CPU/SoC 設計工程師 |
| B. 系統軟體 | C/組語 + Linux/RTOS + QEMU/Spike | QEMU 上跑的完整 OS 移植 + 驅動 | 韌體/OS/虛擬化工程師 |
| C. 編譯器/DSA | LLVM/GCC + Profiling + 加速器建模 | LLVM 後端支援你的自訂指令 + 加速比數據 | 編譯器/架構師 |

三條路線共享同一底座（本書 1–4、18 章），分岔點在 5–7（硬體）、11–17（系統）、19（編譯器/DSA）。選路線的判準很俗但有效：**哪種除錯讓你忘記時間，就選哪條**——波形、printk、還是 perf report。

### 3. 未來三年：機會在哪裡？

| 趨勢 | 為什麼是機會 | 新手切入點 |
|------|--------------|------------|
| AI 推論下放邊緣 | 每家都要自訂指令，缺懂 ISA 又懂模型的人 | 為 TinyML 模型加 `dotp8` 類指令並量測 |
| 車用/工控自主化 | 長供貨 + 功能安全，RISC-V 原始碼可審計 | 考量鎖步與 ECC 的 MCU 專案 |

| 主權指令集 | 各國押注開放 ISA | 參與 LLVM/QEMU/Spike 上游貢獻 |

## 本節小結（全書收束）

- 本書主線：**簡潔（ISA）→ 速度（微結構）→ 規模（GPU/向量）→ 秩序（特權/OS）→ 槓桿（工具鏈/自訂擴充）**，每一篇都是下一層的槓桿。
- 四句核心理念回顧：簡潔即力量、模組化即自由、開源即生態、系統觀即全棧觀——它們不是口號，是你做取捨的標尺。
- 工程師定位 = 一條深路線 + 全棧溝通力 + 一個可展示的作品；機會屬於「懂硬體的軟體人」與「懂軟體的硬體人」之間的交界。
- 最後一句話：**ISA 是起點，不是終點——去造一顆別人願意用的晶片，或一套別人願意用的工具。**
