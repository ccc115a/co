# 4.1 M 擴充：乘法與除法架構

> RV32I 故意沒有乘除法——不是做不到，而是不想強迫每顆 MCU 都付面積稅。M 擴充（Integer Multiply/Divide）就是這筆「按需付費」的乘除能力。

## 開場問題：沒有 `mul` 的日子怎麼過？

純 RV32I 要算 `a*b`，只能用移位加（Shift-and-Add）軟體迴圈或呼叫 `__mulsi3`，又慢又佔 Flash。M 擴充用 8 條指令終結這個痛點，代價是一個硬體乘法器（Multiplier）——對高效能核九牛一毛，對極小 MCU 則可省略。

## 核心講解：M 指令表（R-type，opcode 0110011，funct7=0000001）

| 指令 | 語意 | funct3 | 備註 |
|------|------|--------|------|
| `mul rd, rs1, rs2` | 低 XLEN 位：rd = (rs1×rs2)[XLEN-1:0] | 000 | 最常用，溢出直接截斷 |
| `mulh rd, rs1, rs2` | 有號×有號，高位（High） | 001 | 寬乘法、定點數（Fixed-point）高位 |
| `mulhsu rd, rs1, rs2` | 有號×無號，高位 | 010 | 混合符號寬乘法 |
| `mulhu rd, rs1, rs2` | 無號×無號，高位 | 011 | 大數函式庫（Bigint）進位鏈 |
| `div rd, rs1, rs2` | 有號除法 | 100 | 除零得 -1，溢出（INT_MIN/-1）得 INT_MIN，不 trap |
| `divu rd, rs1, rs2` | 無號除法 | 101 | 除零得全 1（2^XLEN−1），不 trap |
| `rem rd, rs1, rs2` | 有號取餘 | 110 | 除零時餘數 = 被除數 |
| `remu rd, rs1, rs2` | 無號取餘 | 111 | 同上，無號版 |

### 兩條設計 철학（Philosophy）

| 規則 | 說明 |
|------|------|
| 除零不 trap | div/divu 定義好除零結果，省掉例外路徑，編譯器不必插檢查 |
| 高低位分開 | `mul` 取低位、`mulh*` 取高位，64 位乘法用兩條拼出 128 位結果 |

RV64 另有 W 系列（`mulw/divw/remw`）：先做 32 位運算再符號擴展到 64 位，對應 C 語言 `int` 語意。

| RV64 專用 | 語意 | 對應 C 型別 |
|-----------|------|-------------|
| `mulw rd, rs1, rs2` | 32 位乘法低 32 位再符號擴展 | `int` 相乘 |
| `divw / remw` | 32 位除法/取餘再符號擴展 | `int` 除法 |

## 範例：寬乘法與除零語意

```asm
# 例 1：32x32 -> 64 寬乘法（a0:a1 = a2 * a3，無號）
    mulhu a1, a2, a3      # a1 = 高 32 位
    mul   a0, a2, a3      # a0 = 低 32 位

# 例 2：数组点积（用 mul + add 即可，-march=rv32im）
dot:
    li   t0, 0            # sum = 0
dot_loop:
    beq  a2, zero, dot_end
    lw   t1, 0(a0)
    lw   t2, 0(a1)
    mul  t1, t1, t2       # t1 = x[i]*y[i]
    add  t0, t0, t1
    addi a0, a0, 4
    addi a1, a1, 4
    addi a2, a2, -1
    jal  x0, dot_loop
dot_end:
    mv   a0, t0
    ret
```

```c
// 除零不 trap 的 C 語意驗證（RISC-V div 定義）
// int q = 5 / 0;    // 組語 div 得 -1，不會進 trap
// unsigned u = 5u / 0u; // divu 得 0xFFFFFFFF
int dot_c(const int *x, const int *y, int n) {
    int s = 0;
    for (int i = 0; i < n; i++) s += x[i] * y[i];  // -march=rv32im 生成 mul
    return s;
}
```

## 本節小結

- M = 8 條 R-type（funct7=0000001）：4 乘（mul/mulh/mulhsu/mulhu）+ 4 除餘（div/divu/rem/remu）。
- 除零與溢出都有定義值、絕不 trap，簡化編譯器與管線。
- 寬乘法靠 `mul`（低位）+ `mulh*`（高位）拼接。
- RV64 加 `mulw/divw/remw` 照顧 32 位 `int` 語意。
