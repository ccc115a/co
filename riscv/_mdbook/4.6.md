# 4.6 V 擴充：向量處理器架構與 AI 算力加速

> 一條指令算 1 筆叫純量（Scalar），一條指令算 128 筆叫向量（Vector）。V 擴充把 RISC-V 變成 AI 與 HPC 的算力引擎，而代價只是 32 個向量暫存器（Vector Register）。

## 開場動機：為何 GPU 不夠，還要向量？

GPU（見第 8 章）擅長大吞吐但啟動開銷大、程式設計模型另起爐灶。向量擴充走另一條路：**在 CPU 內做資料並行（Data-Level Parallelism, DLP）**，同一份 C 程式加自動向量化（Auto-vectorization）就能加速，嵌入式 AI 推論、訊號處理、HPC 核心迴圈直接受惠。

## 核心講解：向量架構三要素

### 要素一：向量暫存器群與組態

| 項目 | 說明 |
|------|------|
| 暫存器 | v0–v31，共 32 個，向量長度由硬體 VLEN 決定（如 128/256/512 位） |
| 元素寬度（SEW） | `e8/e16/e32/e64`：每元素 8/16/32/64 位 |
| 分組（LMUL） | `m1/m2/m4/m8`（或 mf2/mf4/mf8）：把多個暫存器併為一組，拉長向量 |
| 向量長度（VL） | 實際處理的元素數，由 `vsetvli` 按剩餘元素動態設定（見範例） |
| 遮罩（Mask） | v0 可作遮罩暫存器（`.m` 後綴），條件執行、稀疏（Sparse）必備 |

### 要素二：代表指令表

| 群組 | 指令 | 語意 |
|------|------|------|
| 組態 | `vsetvli rd, rs1, e32, m8` | 設 SEW/LMUL，rd = 實際 VL（strip-mining 核心） |
| 載入 | `vle32.v vd, (rs1)` | 連續向量載入（Unit-stride Load） |
| 儲存 | `vse32.v vs3, (rs1)` | 連續向量儲存 |
| 跨步/索引 | `vlse32.v / vluxei32.v` | 跨步（Strided）/索引（Indexed/Gather）載入 |
| 算術 | `vadd.vv / vadd.vx / vadd.vi` | 向量+向量 / 向量+純量 / 向量+立即數 |
| 算術 | `vmul.vv / vdiv.vv / vsqrt.v` | 向量乘除開方 |
| 融合 | `vfmacc.vv vd, vs1, vs2` | vd += vs1×vs2（AI 矩陣乘累加核心） |
| 歸約 | `vredsum.vs vd, vs2, vs1` | 向量歸約求和 → 純量 |
| 遮罩 | `vmand.mm / vmseq.vv` | 遮罩邏輯/比較，條件向量化 |

### 要素三：Strip-mining（長條切分）心法

向量長度未知（VLEN 無關程式設計，Vector Length Agnostic）是 V 的招牌：**程式不寫死一次算幾個**，`vsetvli` 每次回報「這次能算幾個」，迴圈切到做完為止。同一 binary 跑在 128 位與 512 位機器都正確，越寬越快。

## 範例：向量加法（strip-mining 模板）

```asm
# vadd: c[i] = a[i] + b[i]，a0=a, a1=b, a2=c, a3=n（元素數，32-bit）
vadd_loop:
    vsetvli t0, a3, e32, m8   # 設 e32/m8，t0 = 本輪實際 VL
    vle32.v v0, (a0)          # v0 = a[0..VL-1]
    vle32.v v8, (a1)          # v8 = b[0..VL-1]（m8 分組注意編號間隔）
    vadd.vv v16, v0, v8       # v16 = v0 + v8
    vse32.v v16, (a2)         # c[0..VL-1] = v16
    slli t1, t0, 2            # 本輪位元組數 = VL*4
    add  a0, a0, t1
    add  a1, a1, t1
    add  a2, a2, t1
    sub  a3, a3, t0           # 剩餘元素 -= VL
    bnez a3, vadd_loop
    ret
```

```c
// C 版：開自動向量化即可生成上面的 vsetvli/vle/vadd/vse
// riscv64-unknown-elf-gcc -march=rv64gcv -O2
void vadd_c(int *c, const int *a, const int *b, int n) {
    for (int i = 0; i < n; i++) c[i] = a[i] + b[i];
}

// AI 核心：int8 矩陣乘累加概念（實際用 vfmacc / vint8 專用指令）
// C[i][j] += A[i][k] * B[k][j]  -> 內層 k 迴圈向量化，一次算 VL 個 k
```

## 本節小結

- V = 32 個向量暫存器 + SEW/LMUL/VL 組態 + 遮罩，VLEN 無關設計讓 binary 跨寬度可攜。
- 核心三招：`vsetvli`（問長度）、`vle/vse`（搬運）、`vadd/vmul/vfmacc/vredsum`（運算歸約）。
- Strip-mining 模板（vsetvli → 運算 → 指標推進 → 扣剩餘）是本節必背骨架。
- 最大贏家：AI 推論（vfmacc）、HPC（歸約/跨步）、訊號處理（定點向量）。
