# 1.4 為什麼選擇 RISC-V（簡潔模組化可擴展）

> 學一種 ISA 值得花一學期嗎？本節用三個關鍵字——簡潔（Simplicity）、模組化（Modularity）、可擴展（Extensibility）——回答「為什麼是 RISC-V」。

## 開場問題：工程師選 ISA 時在選什麼？

選 ISA 不是選「指令多不多」，而是選未來十年的**總持有成本**：

- 學得會嗎？（手冊厚度、例外多少）
- 做得小嗎？（解碼器面積、功耗）
- 長得大嗎？（從 MCU 到超算能否同一套軟體棧）
- 改得了嗎？（能否加自己的加速器而不分叉）

RISC-V 的答案剛好切中這四題。

## 核心講解：三個關鍵字

### 簡潔（Simplicity）：不到 50 條核心指令

| 對比項 | x86 | ARMv8 | RISC-V RV32I |
|--------|-----|-------|--------------|
| 基礎指令數（約略） | 上千（含延伸） | 數百 | **不到 50** |
| 指令長度 | 1–15 位元組可變 | 固定 32 位（另有 T32） | 固定 32 位 + 可選 16 位壓縮 |
| 定址模式 | 豐富但複雜 | 多種 | **只有一種記憶體定址：基址 + 偏移** |
| 條件執行 | EFLAGS 複雜旗標 | 條件碼（NZCV） | **無旗標，分支直接比兩個暫存器** |

簡潔的紅利：解碼器小、驗證容易、編譯器好寫。學生一個學期就能做出 RV32I 單週期（Single-Cycle）CPU。

### 模組化（Modularity）：Base + Extensions

| 縮寫 | 名稱 | 定位 |
|------|------|------|
| I / E | 基礎整數集（Base Integer） | I：32 個暫存器；E：16 個，超小 MCU 用 |
| M | 乘除法（Multiply/Divide） | 需要乘法才加，不用就省面積 |
| A | 原子操作（Atomic） | 多核心同步用 |
| F / D | 單/雙精度浮點（Floating-Point） | 有 FPU 才加 |
| C | 壓縮指令（Compressed） | 16 位指令，省程式碼體積 |
| B / V | 位元操作 / 向量（Bitmanip/Vector） | 按需掛載 |

命名如 `RV32IMAC`、`RV64GC`（G = IMAFD 通用組合）本身就是一份**規格清單**，工具鏈 `-march` 參數直接對應（詳見 2.1 節）。

### 可擴展（Extensibility）：留白的藝術

RISC-V 在編碼空間預留了：

- 4 組自訂操作碼（custom-0 ~ custom-3）給廠商私用；
- 大量保留編碼（Reserved Encoding）給未來標準擴充；
- 向量（V）、矩陣、加密等大延伸都有獨立 opcode 區間。

結果：**加加速器不必分叉 ISA**，編譯器用內建函式（Intrinsic）即可呼叫。

## 範例：簡潔的力量——同一個加法迴圈

```c
// C：陣列求和，任何 ISA 都能編譯
int sum(const int *a, int n) {
    int s = 0;
    for (int i = 0; i < n; i++) s += a[i];
    return s;
}
```

```asm
# RISC-V RV32I 編譯結果示意（-O2，僅核心迴圈）
# a0 = a, a1 = n, 迴圈只用 5 條基礎指令
sum_loop:
    beq  a1, zero, sum_done  # if (n == 0) done
    lw   t0, 0(a0)           # t0 = *a
    add  t1, t1, t0          # s += t0
    addi a0, a0, 4           # a++
    addi a1, a1, -1          # n--
    bne  a1, zero, sum_loop  # loop
sum_done:
    mv   a0, t1              # return s
    ret
```

沒有旗標、沒有複雜定址、每條指令只做一件事——這就是簡潔帶來的**可讀性與可驗證性**。

## 本節小結

- 簡潔：RV32I 不到 50 條指令、無旗標、單一定址模式，解碼與驗證成本最低。
- 模組化：Base + Extensions 按需掛載，從 E（16 暫存器 MCU）到 GC（應用處理器）同一光譜。
- 可擴展：預留 custom opcode，加速器不必分叉 ISA。
- 三者相乘的效果：**學生做得出來、新創買得起、大廠改得動**。
