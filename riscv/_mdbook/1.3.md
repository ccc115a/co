# 1.3 開源硬體模式與 RISC-V 基金會運作

> 開源軟體（Open Source Software）有 GPL、MIT、Apache；開源硬體呢？本節拆解 RISC-V 如何用「開放 ISA + 會員制基金會」走出一條新路。

## 開場問題：硬體開源，到底在開源什麼？

軟體開源通常指原始碼（Source Code）公開。但硬體有三層，每層開放的意義不同：

| 層級 | 內容舉例 | 開放難度 |
|------|----------|----------|
| ISA（指令集架構） | 指令編碼、手冊 | 最容易開放：一份文件即可 |
| RTL（暫存器傳輸級） | Verilog/Chisel 核心原始碼 | 中等：如 Rocket Chip、Ibex |
| PDK（製程設計套件） | 台積電/晶圓廠製程檔 | 最難：涉及商業機密，近年才有 OpenPDK |

RISC-V 的聰明之處在於：**先開放最關鍵又最容易的一層——ISA**，讓所有人站在同一份契約上競爭 RTL 與晶片實作。

## 核心講解：基金會如何運作

### 從 Berkeley 到 RISC-V International

| 年份 | 里程碑 |
|------|--------|
| 2010–2014 | Berkeley 內部研究，釋出手冊與 Rocket Chip |
| 2015 | 成立 RISC-V Foundation（美國），管理 ISA 標準 |
| 2020 | 總部遷至瑞士，改名 RISC-V International，中立化地緣疑慮 |
| 至今 | 會員超過數千家，涵蓋晶片、EDA、車用、HPC 與學界 |

### 治理結構：誰決定指令長什麼樣？

| 組織單位 | 職責 |
|----------|------|
| 技術指導委員會（Technical Steering Committee, TSC） | 審核擴充提案的技術內容 |
| 工作小組（Task Group） | 如 V 擴充組、B 擴充組，撰寫規格草案 |
| 會員大會與董事會（Board of Directors） | 白金/戰略會員出資並投票治理 |
| 合規計畫（Compliance Program） | 以架構測試（Architecture Test, ACT）確保「自稱 RISC-V」真的相容 |

關鍵流程：提案 → 草案（Draft）→ 凍結（Freeze，編碼不再改）→ 批准（Ratification）。**凍結後才能放心做編譯器與晶片**，這是生態穩定的基石。

### 商業模式：免費 ISA 如何養活大家？

| 角色 | 賺錢方式 |
|------|----------|
| IP 供應商（如 SiFive、晶心） | 賣驗證好的核心（Core IP）與客製服務，ISA 本身免費 |
| 工具鏈廠商 | 賣編譯器支援、IDE、除錯器（Debugger） |
| 晶片公司 | 省下授權費，把錢投向差異化（AI 加速器、自訂擴充） |
| 基金會本身 | 收會員費（Membership Fee），不收權利金 |

## 範例：自訂擴充要走什麼流程？

假設你想為自家馬達控制加一條 `motor.step` 指令，實務上有兩條路：

```asm
# 路線 A：用保留的自訂編碼空間（Custom Opcode），不需基金會批准
# custom-0 / custom-1 是官方預留給廠商私用的操作碼（Opcode）
# .insn 是「手寫機器碼」組語，適合實驗階段
.insn r 0x0b, 0, 0, a0, a1, a2   # 假想的自訂指令：a0 = step(a1, a2)

# 路線 B：想變成標準擴充？就要寫 proposal，經過 Task Group 評審
#   類似：add a0, a1, a2   <- 這種通用指令才值得標準化
```

```c
// 配套的編譯器內建函式（Intrinsic）示意：讓 C 程式能呼叫自訂指令
// 正式做法是用 riscv inscriber / LLVM TableGen 描述，此處僅示意概念
int motor_step(int pos, int vel) {
    int ret;
    __asm__ volatile (".insn r 0x0b, 0, 0, %0, %1, %2"
                      : "=r"(ret) : "r"(pos), "r"(vel));
    return ret;
}
```

重點：**私用自訂今天就能做，公用標準化要走基金會流程**，兩者由編碼空間劃界。

## 本節小結

- 開源硬體分三層：ISA、RTL、PDK；RISC-V 先開放 ISA，帶動後兩層逐步開放。
- RISC-V International（瑞士，非營利）靠會員費運作，不收權利金。
- ISA 演進靠 Task Group → Freeze → Ratification 流程，凍結是生態穩定的關鍵。
- 商業模式是「免費 ISA + 付費 IP/服務」，省下的授權費轉為差異化投資。
- 自訂指令有官方預留編碼空間，私用免審批、公用才需標準化。
