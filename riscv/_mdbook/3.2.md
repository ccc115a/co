# 3.2 算術與邏輯指令（ALU operations）

> 算術邏輯單元（Arithmetic Logic Unit, ALU）是 CPU 的雙手。本節掌握 RV32I 的全部運算指令：加減、移位、比較、邏輯，外加一條 `lui` 彩蛋。

## 開場問題：沒有乘法，ALU 還剩什麼？

RV32I 的 ALU 指令刻意不含乘除法（那是 M 擴充的事），只留下**每個週期都該是單週期（Single-cycle）能做完**的操作：加減、移位、大小比較、位元邏輯，外加立即數版本。這種「少即是快」讓單週期 CPU 一天就能寫完。

## 核心講解：ALU 指令全表

### R-type：暫存器–暫存器運算（opcode 0110011）

| 指令 | 語意 | funct7/funct3 | 備註 |
|------|------|---------------|------|
| `add rd, rs1, rs2` | rd = rs1 + rs2 | 0000000/000 | 基本加法 |
| `sub rd, rs1, rs2` | rd = rs1 − rs2 | 0100000/000 | 唯一用 funct7 區分的減法 |
| `sll rd, rs1, rs2` | 邏輯左移（Shift Left Logical） | 0000000/001 | 低位補 0 |
| `slt rd, rs1, rs2` | 有號小於則 1（Set Less Than） | 0000000/010 | 比較器核心，分支靠它概念 |
| `sltu rd, rs1, rs2` | 無號小於則 1 | 0000000/011 | 位址/邊界檢查用 |
| `xor rd, rs1, rs2` | 按位互斥或 | 0000000/100 | 加密、切換旗標 |
| `srl rd, rs1, rs2` | 邏輯右移（高位補 0） | 0000000/101 | 無號除法 2^n |
| `sra rd, rs1, rs2` | 算術右移（高位補符號） | 0100000/101 | 有號除法 2^n |
| `or rd, rs1, rs2` | 按位或 | 0000000/110 | 置位 |
| `and rd, rs1, rs2` | 按位與 | 0000000/111 | 遮罩（Mask） |

### I-type 立即數版本（opcode 0010011）

| 指令 | 語意 | 備註 |
|------|------|------|
| `addi rd, rs1, imm` | rd = rs1 + sign(imm)，12 位 | 常數加減、調 sp 都靠它 |
| `slti/sltiu` | 與立即數有號/無號比較 | 邊界檢查 `n < MAX` |
| `xori/ori/andi` | 與立即數邏輯運算 | `xori a0, a0, -1` = 按位取反（`not` 虛擬指令） |
| `slli/srli/srai` | 移位立即數（shamt 5 位，RV64 為 6 位） | `slli` ×2^n 最快 |
| `lui rd, imm20` | rd = imm20 << 12（U-type） | 組 32 位大常數的上半 |
| `auipc rd, imm20` | rd = PC + (imm20 << 12) | PC 相對定址（見 2.4） |

注意：RISC-V **沒有專用的 `mov/not/nop`**，全是虛擬指令（Pseudo-instruction）：`mv`=add with x0，`not`=xori −1，`nop`=addi x0,x0,0。

### 常見虛擬指令對照

| 虛擬指令 | 本體 | 用途 |
|----------|------|------|
| `nop` | `addi x0, x0, 0` | 空操作，填管線氣泡（Bubble） |
| `mv rd, rs` | `addi rd, rs, 0` | 暫存器搬移 |
| `not rd, rs` | `xori rd, rs, -1` | 按位取反 |
| `neg rd, rs` | `sub rd, x0, rs` | 取負數 |
| `j off` | `jal x0, off` | 無條件短跳 |
| `jr rs` | `jalr x0, 0(rs)` | 間接跳 |

## 範例：組大常數與取絕對值

```asm
# 例 1：把 0x12345678 載入 a0（12-bit 放不下，需 lui + addi）
    lui   a0, 0x12345       # a0 = 0x12345 << 12 = 0x12345000
    addi  a0, a0, 0x678     # a0 = 0x12345678（注意符號擴展陷阱，見下）

# 例 2：絕對值函式 abs(a0) -> a0
abs_val:
    srai  t0, a0, 31        # t0 = 符號遮罩：負數得 -1（全1），正數得 0
    xor   a0, a0, t0        # 負數則按位取反
    sub   a0, a0, t0        # 負數則 +1（補數）；正數不變
    ret
```

```c
// 上面 abs 的 C 原型；編譯器 -O2 會產出幾乎相同的 srai/xor/sub
int abs_val(int x) {
    int m = x >> 31;        // 算術右移，srai
    return (x ^ m) - m;
}

// 符號擴展陷阱：若低 12 位最高位為 1，addi 會被解釋為負數，
// 此時 lui 要預先 +1。連結器 %hi/%lo 會自動處理，手寫組語要注意。
```

## 本節小結

- RV32I ALU = 加減 + 移位 + 比較（slt/sltu）+ 邏輯，無乘除、無旗標。
- `sub`/`sra` 靠 funct7=0100000 與加法/邏輯右移區分，其餘看 funct3。
- 立即數只有 12 位，大常數靠 `lui+addi`，大位址靠 `auipc+lw/jalr`。
- `mv/not/nop` 都是虛擬指令，本質是借用 `add/xori/addi` + x0。
- 下一節讓 ALU 的結果落地：Load/Store 進出記憶體。
