# 3.4 分支與跳躍指令（Control Transfer）

> 沒有 if、for、函式呼叫，程式只是一條直線。本節講 RISC-V 如何轉彎：比較即分支（Compare-and-Branch），跳轉即存檔（Jump-and-Link）。

## 開場問題：沒有旗標怎麼做 `if (a == b)`？

x86/ARM 先 `cmp` 設旗標（Flag）再 `je/b.eq` 跳，兩條指令分工。RISC-V 把兩步併成一條：**直接比較兩個暫存器，相等就跳**。省掉旗標暫存器，也省掉旗標在亂序執行（Out-of-Order）中的依賴麻煩。

## 核心講解：分支與跳躍全表

### B-type 分支（opcode 1100011，範圍 ±4KB）

| 指令 | 語意 | funct3 | 虛擬指令親戚 |
|------|------|--------|--------------|
| `beq rs1, rs2, off` | 相等則跳（Branch if Equal） | 000 | `beqz rs, off` = beq rs, x0 |
| `bne rs1, rs2, off` | 不等則跳 | 001 | `bnez` |
| `blt rs1, rs2, off` | 有號小於則跳 | 100 | `bltz/blez` 系列 |
| `bge rs1, rs2, off` | 有號大等於則跳 | 101 | `bgez/bgtz` 系列 |
| `bltu rs1, rs2, off` | 無號小於則跳 | 110 | 位址/邊界比較 |
| `bgeu rs1, rs2, off` | 無號大等於則跳 | 111 | `bgeu` 常做 null/邊界檢查 |

### J-type/I-type 跳躍（無條件，範圍大）

| 指令 | 格式/範圍 | 語意 |
|------|-----------|------|
| `jal rd, off` | J-type，±1MB | rd = PC+4；PC += off。`jal x0` = 純跳不存檔 |
| `jalr rd, offset(rs1)` | I-type，12 位偏移 + 基址 | rd = PC+4；PC = (rs1+off) & ~1。間接跳、函式返回都用它 |
| `ret` | 虛擬指令 | = `jalr x0, 0(ra)`，函式返回 |
| `call off` / `tail off` | 虛擬指令 | 長跳轉（auipc+jalr 展開），tail 不存 ra 供尾呼叫優化 |

### 跳轉距離對照

| 指令 | 範圍 | 用途 |
|------|------|------|
| B-type | ±4KB（12 位，低位補 0） | if/for 短跳 |
| `jal` | ±1MB（20 位，低位補 0） | 函式內/近距離呼叫 |
| `auipc+jalr` | 全 32 位 | 遠跳轉、動態連結、switch 大表 |

## 範例：if、迴圈、函式呼叫三連發

```asm
# 例 1：if (a0 == a1) a2 = 1 else a2 = 0
    bne  a0, a1, else_br   # 不等則跳 else
    li   a2, 1
    jal  x0, if_done       # 無條件跳（jal x0 即 j）
else_br:
    li   a2, 0
if_done:

# 例 2：for (i=0; i<10; i++) sum += i  (a0 累加和)
    li   a0, 0             # sum = 0
    li   t0, 0             # i = 0
    li   t1, 10
loop:
    bge  t0, t1, loop_end  # i >= 10 跳出
    add  a0, a0, t0        # sum += i
    addi t0, t0, 1         # i++
    jal  x0, loop
loop_end:
    ret

# 例 3：函式呼叫（call 是 auipc+jalr 的展開，ra 存返回位址）
    call my_func           # ra = PC+4; 跳 my_func
```

```c
// 上面迴圈的 C 原型；-O2 會把 bge+jal 優化為 bne 倒轉迴圈（減少一次跳）
int sum10(void) {
    int s = 0;
    for (int i = 0; i < 10; i++) s += i;
    return s;
}
```

## 本節小結

- 分支 = 比較 + 跳二合一：`beq/bne/blt/bge/bltu/bgeu`，短距 ±4KB。
- 跳躍 = `jal`（±1MB，直跳）+ `jalr`（間接跳、返回、遠跳後半段）。
- `ret/call/j/tail/beqz` 全是虛擬指令，降低記憶負擔。
- 無旗標設計讓亂序執行少一個依賴源，是簡潔的長期紅利。
- 下一節處理「跳出程式本身」：環境呼叫與柵欄（ECALL/FENCE）。
