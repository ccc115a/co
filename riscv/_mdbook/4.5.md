# 4.5 B 擴充：位元操作（Bit Manipulation）

> 加密、編解碼、點陣圖字型——大量程式時間花在「摳位元」上。B 擴充（Bit Manipulation）把原本十幾條指令的迴圈變成一條單週期硬體指令。

## 開場動機：數 1 的個數要幾條指令？

`popcount(x)`（數二進制 1 的個數）在純 RV32I 要寫迴圈逐位檢查；有了 B 擴充，一條 `cpop` 搞定。這就是 B 的價值：**把軟體慣用法（Idiom）硬化**，編譯器認得、內建函式（Builtin）直達。

## 核心講解：B 指令代表表（多為 R/I-type，opcode 0110011/0010011）

| 群組 | 指令 | 語意 |
|------|------|------|
| 計數 | `clz rd, rs`（Count Leading Zeros） | 前導 0 個數（正規化浮點、對齊用） |
| 計數 | `ctz rd, rs`（Trailing Zeros） | 尾隨 0 個數（找最低置位） |
| 計數 | `cpop rd, rs`（Population Count） | 1 的個數（漢明重量，Hamming Weight） |
| 旋轉 | `rol/ror/ rori rd, rs1, rs2/imm` | 左右旋轉（Rotate，加密 S 盒常見） |
| 單一位 | `bset/bclr/bext/binv rd, rs1, rs2` | 置位/清零/抽取/翻轉第 rs2 位 |
| 單一位立即數 | `bseti/bclri/bexti/binvi` | 位索引為立即數版 |
| 擴展 | `sext.b/sext.h rd, rs` | 位元組/半字元號擴展（替代多條 slli+srai） |
| 擴展 | `zext.h rd, rs` | 半字零擴展（RV64 另有 `zext.w`） |
| -or-組合 | `orcb rd, rs`（OR-Combine Byte） | 每位元組內或起來找非零位元組（字串處理） |
| 最小/大 | `min/minu/max/maxu` | 整數取小/大（有號/無號），分支預測殺手終結者 |
| 位元組序 | `rev8 rd, rs` | 位元組反轉（大小端互換，網路協定用） |

註：B 擴充由 Zba（位址生成）、Zbb（基本位操）、Zbs（單位操作）等子擴充組成，`-march=rv32ib` 常細寫為 `rv32i_zbb_zbs_...`。

| 子擴充 | 內容 | 代表指令 |
|--------|------|----------|
| Zba | 位址生成（Address Generation） | `sh1add/sh2add/sh3add`（基址 + 移位索引，陣列尋址一條搞定） |
| Zbb | 基本位元操作 | `clz/ctz/cpop/min/max/rev8/sext/zext/rol/ror` |
| Zbs | 單位元操作 | `bset/bclr/bext/binv`（含立即數版） |
| Zbkb | 位元組級加密加速 | `brev8/zip/unzip`（密碼學置換） |
| Zbkx | 交叉加解密輔助 | `xperm` 系列（S 盒查表加速） |

## 範例：popcount 與位抽取

```asm
# 例 1：popcount —— B 擴充一條 vs. 純 I 迴圈十幾條
    cpop a0, a0              # a0 = 1 的個數（一條！）

# 純 RV32I 對照（示意骨架，實際需迴圈）：
# pop_loop: andi t0, a0, 1 / add t1, t1, t0 / srli a0, a0, 1 / bnez ...

# 例 2：抽取第 5 位並清零第 3 位
    bext t0, a0, 5           # t0 = (a0 >> 5) & 1 —— 免移位+遮罩兩條
    bclr a0, a0, 3           # a0[3] = 0 —— 免 lui+and 序列

# 例 3：rev8 大小端互換（網路位元組序轉主機序）
    rev8 a0, a0              # 0x12345678 -> 0x78563412
```

```c
#include <stdint.h>
// 編譯器內建函式直達 B 指令（-march=rv32im_zbb）
int hw_popcount(uint32_t x) {
    return __builtin_popcount(x);   // -> cpop
}
uint32_t swap32(uint32_t x) {
    return __builtin_bswap32(x);    // -> rev8
}
int lo_bit(uint32_t x) {
    return __builtin_ctz(x);        // -> ctz（注意 x=0 時為 UB，硬體回 XLEN）
}
uint32_t rol32(uint32_t x, int n) {
    return (x << n) | (x >> (32 - n));  // -> rol（編譯器認得旋轉慣用法）
}
```

## 本節小結

- B = 把軟體位元慣用法硬化的擴充：計數（clz/ctz/cpop）、旋轉（rol/ror）、單位（bset/bclr/bext/binv）、擴展（sext/zext）、rev8、min/max。
- 由 Zba/Zbb/Zbs 等子擴充組成，`-march` 可細粒度聲明。
- 加密、壓縮、字串、網路位元組序是最大受益者，常有數量級加速。
- `__builtin_popcount/bswap32/ctz` 是 C 直達車，無需手寫組語。
- 最後一節壓軸：向量擴充 V，AI 算力的門票。
